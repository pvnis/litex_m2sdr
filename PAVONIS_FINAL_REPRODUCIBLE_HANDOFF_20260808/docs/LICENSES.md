# Source Licenses

The Git bundles preserve each repository's source and license text:

| Repository | License paths in bundle |
|---|---|
| OCUDU | `LICENSE`; bundled fmt license under `external/fmt/` |
| qcore | `LICENSE` |
| srsRAN_4G | `LICENSE`; bundled fmt license under `lib/include/srsran/srslog/` |

Extract the bundles before redistribution and review the exact license terms.
The Pavonis report and handoff documents describe local experimental work; they
do not replace the upstream licenses.
