# CHECKPOINT 3170 - Conducted MCS-28 sensitivity

## Verdict

Valid measurement; no throughput improvement from raising the configured
downlink UE MCS ceiling from 9 to 28.

## Measurement

Every CP3168 field is preserved except `max_ue_mcs`.

| Direction | MCS-9 baseline | MCS-28 run | Change |
|---|---:|---:|---:|
| Downlink | 3.112217 Mbit/s | 2.901135 Mbit/s | -6.782% |
| Uplink | 0.186631 Mbit/s | 0.200016 Mbit/s | +7.172% |

The MCS-28 receiver records are complete:

- Downlink: `16,318,960 bytes / 45.000213 s`.
- Uplink: `1,125,096 bytes / 45.000223 s`.

The small opposite-direction changes are treated as run-to-run variation. The
available compact artifacts prove the ceiling was configured but do not expose
the selected MCS for every PDSCH. Therefore this checkpoint supports only the
conclusion that increasing the ceiling does not improve sustained throughput;
it does not prove that MCS 28 was scheduled or that high MCS degrades the link.
