# Checkpoint 3176: all-wireless srsUE OTA baseline

## Verdict

PASS. The established srsUE/bladeRF path completed attach and
receiver-authoritative 45-second sustained transfers in both directions over
the new all-wireless antenna geometry.

Sustained throughput was:

- downlink: `2.983260 Mbit/s`
- uplink: `0.167066 Mbit/s`

The unchanged `10 MHz / 52 PRB / 11.52 Msps / single-layer / MCS9 / FDD`
shape selected the cell at `15.043 dB` SNR. PUSCH produced `66/128` CRC-OK
rows with median CRC-OK SINR `14.523035 dB` and median TBS `528 bytes`.
Soapy timeout and downlink-late counts were both zero. All endpoint, duration,
post-run process, and private user-plane port gates passed.

Compared with CP3168's former conducted reference, DL is `4.14%` lower and UL
is `10.48%` lower. The OTA run has approximately `4 dB` higher cell SNR yet
essentially the same throughput class. This reinforces the prior conclusion:
the current ceiling is structural, not an SNR or MCS-ceiling limit.
