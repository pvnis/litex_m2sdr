# Checkpoint 3178: 20 MHz pre-UE TX-health cap

## Verdict

HONEST PARTIAL. The isolated `20 MHz / 23.04 Msps / 106 PRB` gNB starts
with the CP3176 MCS, layer, duplex, attenuation, gain, and timing semantics
preserved, but it does not pass the established pre-UE transmitter-health
gate. The UE is deliberately not started and no throughput value is reported.

The generic execution summary labels the failure as UE acquisition because no
UE log exists. The append-only sequence record is authoritative: the first
failed stage is `gate_pre_ue_tx_summary_health`, followed by `SKIP_UE`.

## Evidence

During the 60-second pre-UE window, the authoritative Soapy stop summary
records:

- `18` timed-write deadline breaks and timeouts;
- `320696` missing stream samples;
- `302300` abandoned timeout-carry samples;
- `18726` returned-sample deficit;
- zero hard write errors;
- zero binary-safe timeout lines and zero downlink-late lines.

The 10 MHz CP3176 reference records zero timeouts, zero deadline breaks, and
zero stream deficit. CP3178 therefore identifies a live transmitter-service
limit associated with the `23.04 Msps` geometry before UE or traffic behavior
can be judged. It does not support a claim that the UE rejected 20 MHz.

## Decision

Do not retry 20 MHz unchanged and do not tune RF power or MCS. Gate the next
standard width, 15 MHz, using the lowest supported sample rate that can carry
79 PRB. If 15 MHz also requires `23.04 Msps`, or if a lower supported rate
cannot pass configuration and timing checks, the proven 10 MHz shape is the
current capability ceiling of this real-time path.
