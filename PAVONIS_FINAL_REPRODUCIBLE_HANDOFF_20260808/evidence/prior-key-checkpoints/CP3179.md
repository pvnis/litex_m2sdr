# Checkpoint 3179: isolated 15 MHz no-RF gate

## Verdict

PASS. An isolated copy of the proven chain now expresses
`15 MHz / 15.36 Msps / 79 PRB / single-layer / MCS9 / FDD`. It does not
modify CP3121, CP3176, or the CP3178 20 MHz evidence.

This is the next standard channel width and uses only `4/3` of the proven
11.52 Msps rate. It therefore tests additional occupied bandwidth without
repeating CP3178's failing 23.04 Msps transmitter-service class.

## Configuration proof

- The srsRAN PHY helper maps 79 PRB (`948` occupied subcarriers) to a
  1024-point symbol. At 15 kHz SCS this is exactly `15.36 Msps`.
- The generated gNB config contains `15 MHz / 15.36 Msps` and passes OCUDU
  `--dryrun`.
- The generated UE config contains `15.36e6 / 79 / 79`.
- Complete generated configs remain private on their owning lab roles and are
  identified only by SHA-256.

## Timing and isolation proof

All active sample-domain constants are scaled from the 10 MHz baseline by
`4/3`. Non-integral results are rounded to the nearest sample; the machine
audit proves each error is at most half a 15.36 Msps sample. The 19 stage-1
integer shifts use the same rule while fractional-sample and CFO axes remain
unchanged.

The 22-edge copied chain reaches the dedicated CP3179 terminal. Twenty-five
shell files pass syntax checks, both Python files compile, controller
validation passes, and the approval-closed controller returns `2` without
creating a result directory. CP3121's immutable manifest verifies.

## Decision

One bounded all-wireless 15 MHz srsUE run is justified with CP3176's MCS,
layers, duplex, RF levels, duration, and traffic instrument unchanged. The
pre-UE authoritative TX-health gate remains decisive: if 15.36 Msps cannot
pass it, do not start the UE and report 10 MHz as the current real-time
capability ceiling.
