# Checkpoint 3181: all-wireless bandwidth-sweep ceiling

## Verdict

HONEST PARTIAL; SWEEP CLOSED. The one permitted unchanged 15 MHz retry
repeats CP3180 exactly: the `15.36 Msps` transmitter path is clean, but srsUE
does not acquire the cell. No throughput result exists at 15 or 20 MHz.

The highest channel width with proven sustained all-wireless data is therefore
the CP3176 `10 MHz / 52 PRB / 11.52 Msps` result:

- DL: `2.983260 Mbit/s`
- UL: `0.167066 Mbit/s`

The contemporaneous phone OTA baseline is CP3175:

- DL: `8.331264 Mbit/s`
- UL: `0.124854 Mbit/s`

## Width-by-width result

| Width | Geometry | Result |
|---|---|---|
| 10 MHz | 11.52 Msps, 52 PRB | Valid 45-second sustained DL/UL |
| 15 MHz | 15.36 Msps, 79 PRB | Two consecutive clean pre-access failures |
| 20 MHz | 23.04 Msps, 106 PRB | Pre-UE timed-TX health failure |

CP3181 again records zero Soapy timeouts, deadline breaks, stream deficit,
hard errors, and downlink-late events. Its UE completes `100` cell-search
trials with `nonempty=0`, no PBCH, SIB1, PRACH, RAR, PUSCH, or RF-error
markers. This makes 15 MHz an access/configuration compatibility limit in the
current OCUDU/srsUE shape, not a transmitter-throughput limit.

CP3178's 20 MHz shape fails before UE start with `18` deadline breaks and a
`320696`-sample stream deficit. This is a separate 23.04 Msps real-time
transmitter-service limit.
