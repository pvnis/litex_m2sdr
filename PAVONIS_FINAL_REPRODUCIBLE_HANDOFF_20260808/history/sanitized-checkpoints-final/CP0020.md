## Interpretation

PASS: OCUDU demodulates and detects the srsRAN-generated CP17-equivalent waveform when using gNB-side `rb_offset=8`.

The neighboring offsets did not detect, which strengthens the CP18 conclusion: `msg1-FrequencyStart=8` on the OCUDU/gNB side and `freq_offset=7` on the srsRAN UE side are a correct coordinate pair for this 52 PRB carrier / 50 PRB UE configuration.

This rules out the static PRACH frequency mapping path as the primary CP17 failure.

## Remaining Stage 6 suspects

- Live RF path between UE TX and gNB RX.
- Live RX window alignment or capture timing.
- Runtime scaling/saturation/noise in the gNB PRACH window before demodulation.
- UE transmit timing relative to the gNB PRACH receive window.
