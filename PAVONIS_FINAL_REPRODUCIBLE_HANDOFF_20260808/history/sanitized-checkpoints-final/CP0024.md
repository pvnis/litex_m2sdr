## Interpretation

CP24 is inconclusive as an RF-path test because the [host-redacted] capture did not overlap the TX2 transmission. It does not show a decisive TX2 win and should not be used to rule in or rule out a bladeRF TX-port mismatch.

The controlled-tone ladder still points toward one of:

- weak/disconnected RF path between [host-redacted] bladeRF and [host-redacted] M2SDR,
- bladeRF CLI TX not actually radiating/feeding the expected signal despite successful configuration,
- bladeRF physical TX-port mismatch that still needs a properly overlapped TX2 comparison,
- need for a stronger local proof of bladeRF TX output before another full Stage 6 attach attempt,
- M2SDR capture dominated by an unrelated spur/noise floor issue at these settings.
