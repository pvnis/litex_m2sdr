## Interpretation

Invalid for the intended RF TX-path question.

The instrumentation was deployed and the RF plugin rebuilt successfully, but this run did not reach Msg1. The failure happened earlier: srsUE failed NR cell selection. Since `rf_blade_send_timed()` was never exercised by a PRACH burst, CP32 cannot answer whether full-scale PRACH is reaching `bladerf_sync_tx()`.

The [host-redacted]/gNB side was clean and active: strict gate passed, both gNB logs had zero Soapy TX timeouts, and the full gNB log emitted SSB and PRACH windows normally. This points to a UE-side downlink acquisition miss for this run rather than a gNB TX-timeout recurrence.

If it fails cell selection again, run a fresh downlink SSB capture/check with the instrumented RF plugin still deployed to determine whether the UE/[host-redacted] downlink path regressed or the failure is transient.
