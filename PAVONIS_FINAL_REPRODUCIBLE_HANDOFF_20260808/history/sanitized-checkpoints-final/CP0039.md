## Interpretation

PASS.

The CP33 live TX dump remains RF-visible and OCUDU-detectable when the controlled plugin harness runs with:

- live CP33 TX gain `60`,
- live-like RX frequency `1842505998`,
- active RX streaming,
- continuous RX sample consumption,
- the same timed sparse PRACH burst pattern used in CP38.

This removes ordinary full-duplex RX load as the explanation for the CP33 live failure. The remaining boundary is now live `srsUE` behavior outside the controlled plugin harness: exact live RF API call ordering, channel selection, stream setup/reset behavior, absolute device timestamp alignment, or emission timing relative to the gNB raw-window capture opportunities.
