## Interpretation

INVALID for the live Msg1 RF-state question.

This is a cleaner invalid run than CP41. The gNB strict gate passed, the UE did not fail immediately at the same cell-selection string, and the bladeRF state-debug instrumentation captured RF setup and TX stream start. However, the UE never produced a PRACH/Msg1 waveform. The only `PAVONIS_RF_BLADE_TX_DBG` lines are zero-amplitude early TX stream writes.

The current blocker is downlink sync/cell timing stability. CP42 already showed low-margin SSB/PCI evidence, and CP43 now shows the UE losing sync and rejecting PBCH MIB SFN progression before random access.
