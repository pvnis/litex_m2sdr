## Change Deployed

- `srsRAN_4G/lib/src/phy/rf/rf_blade_imp.c`
- CP49 source SHA: `9cdb7837ec5fd6298621e2ea86531d722e9fe04a385951ee84685725bcf97989`

Behavior added behind `PAVONIS_RF_BLADE_FORCE_HIGH_PEAK_SOB=1`:

- if `PAVONIS_RF_BLADE_TX_DBG=1`;
- and a non-SOB TX write has `cf32_peak >= PAVONIS_RF_BLADE_TX_DBG_MIN_PEAK`;
- then the bladeRF metadata is forced to a timed `BLADERF_META_FLAG_TX_BURST_START` using the call's `secs/frac_secs`;
- debug and dump metadata now include `force_sob=0/1`.

Default behavior is unchanged unless the new env var is enabled.
