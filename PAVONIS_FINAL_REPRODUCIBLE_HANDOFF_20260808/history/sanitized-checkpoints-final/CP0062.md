## Interpretation

CP62 falsifies the strongest CP57-source hypothesis. CP57 with guard unset can reach PRACH immediately after CP60. Therefore:

1. The CP57/CP58/CP59 no-PRACH runs were not a reproducible CP57-source failure.
2. The guard branch remains untested in a successful Msg1-reaching run because `tx_guard_samples` was unset here and the previous guard=30000 runs did not reach the high-peak path.
3. The stable failure remains Stage 6 Msg1 at the gNB: UE generates PRACH attempts, but the gNB reports empty detections.

## Next Experiment

The next guard test should avoid another large 30000-sample jump. A smaller guard ladder should be tried only after a Msg1-reaching baseline run in the same deployed binary. Suggested next checkpoint:

- CP63: run CP57 source with `PAVONIS_RF_BLADE_TX_DBG_TX_GUARD_SAMPLES=24000` using the CP57 guard launcher.

Rationale: CP56/CP60/CP62 show `-14` while TX-domain deltas are often about 16k-24k samples. A 24000-sample guard is large enough to test the hypothesis without the blunt 30000-sample shift that coincided with CP57/CP58 no-PRACH runs.

The RF target is currently left on CP57 source/plugin with guard behavior available but disabled unless the env is set.
