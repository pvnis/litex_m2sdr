## Interpretation

The RF source hook was deployed and built correctly, and the CP77 runner propagated the new offset env correctly. The live run itself is inconclusive because the UE failed before camping and RA. No PRACH was generated, so the offset code was not exercised and no CP77 TX dumps exist for offline template analysis.

This does not invalidate the CP76 conclusion or the CP77 hook. It only says the first live offset point had a pre-RA cell-selection failure. The next checkpoint should rerun the same `-16000` offset point once to separate a transient cell-selection miss from an offset-related behavior.
