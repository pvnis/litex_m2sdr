## Interpretation

CP84 partially improved the receive noise metric, but it did not restore CP48-style replay quality. The known-good CP45 waveform still only produced `3/7` selected windows above `0.50`, compared with CP48's historical `7/7`.

The failure mode changed slightly:

- CP82 at 10 MHz bandwidth recovered four strong windows and had high all-capture RMS.
- CP84 at 3 MHz bandwidth reduced all-capture RMS but recovered only three strong windows.
- False or interference-dominated selected windows still had substantial RMS/peak but weak correlation.

This argues that the current controlled path is not only affected by wideband/edge noise. The path is now SIR-limited, intermittently obscured, or otherwise unstable even with a narrower RX filter.

The next controlled lever is TX gain. If a CP45 known-good replay at higher bladeRF gain restores `7/7`, the current problem is likely an RF environment/SIR issue. If higher TX gain still does not restore the known-good replay, the controlled path needs a deeper reset or physical/RF inspection before CP79 conclusions can be trusted.
