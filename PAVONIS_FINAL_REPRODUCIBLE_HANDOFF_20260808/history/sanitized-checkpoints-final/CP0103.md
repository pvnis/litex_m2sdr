## Interpretation

CP103 is a clean controlled replay pass with the CP99 live hook set active:

- The CP99 waveform remains strongly observable through the controlled RF path.
- The burst-only SOB/EOB hook, 40,000-sample guard, `-16000` PRACH timestamp
  offset, and after-error guards do not break controlled replay observability.
- CP99 live failure is therefore not explained by CP99 dump content, the current
  physical RF path, or the live bladeRF hook set alone.

Together with CP101, this narrows the failure to the live gNB receive context:
the UE emits valid PRACH-like bursts, and those bursts can traverse RF when
replayed, but the live gNB predemod windows do not contain a strong recognizable
copy of the UE waveform.

## Next Action

Stop varying only UE waveform/replay settings. The next rung should inspect
live gNB PRACH receive timing/windowing:

- identify exactly when the gNB arms/saves predemod windows relative to UE
  PRACH TX timestamps and TTIs;
- add or use existing instrumentation to record gNB-side sample timestamps for
  each saved PRACH window;
- compare those timestamps against the UE RF debug timestamps and the CP103
  controlled replay timing behavior.

The next live attempt should be diagnostic, not another blind parameter sweep.
