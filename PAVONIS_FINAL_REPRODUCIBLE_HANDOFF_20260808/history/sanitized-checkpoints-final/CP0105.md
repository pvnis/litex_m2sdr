# Checkpoint 105: gNB PRACH timing instrumentation build

Date: [date-redacted]

## Scope

CP105 implemented the CP104 recommendation: enrich the gNB PRACH diagnostic artifacts with adjusted baseband sample timing so the next live run can determine whether the UE PRACH burst falls inside, outside, or partly across the gNB PRACH collection window.

This checkpoint is source instrumentation plus local build/test verification. It is not yet the live RF diagnostic run.

## Source Changes

Files changed:

- `ocudu/include/ocudu/phy/lower/processors/uplink/prach/prach_processor_baseband.h`
- `ocudu/lib/phy/lower/processors/uplink/uplink_processor_impl.cpp`
- `ocudu/lib/phy/lower/processors/uplink/prach/prach_processor_worker.h`
- `ocudu/lib/phy/lower/processors/uplink/prach/prach_processor_worker.cpp`
- `ocudu/lib/phy/upper/channel_processors/prach/prach_detector_generic_impl.cpp`
- `ocudu/tests/unittests/phy/lower/processors/uplink/lower_phy_uplink_processor_test.cpp`

Instrumentation details:

1. `prach_processor_baseband::symbol_context` now carries `baseband_gateway_timestamp timestamp`, defined as the first sample timestamp of the current OFDM symbol adjusted to the lower PHY SFN0 reference.

2. `lower_phy_uplink_processor_impl::process_collecting()` now passes `current_symbol_timestamp` into the PRACH baseband context.

3. `prach_processor_worker` records:

   - `window_start_ts`
   - `window_end_ts`
   - `window_length`
   - `collection_start_symbol`
   - `last_symbol`
   - `last_symbol_ts`

   These fields are appended to `/tmp/pavonis_prach_predemod_manifest.tsv` when `PAVONIS_PRACH_PREDEMOD_DUMP` is enabled.

4. `PAVONIS_PRACHDET_TRACE` now includes detector join keys:

   - `sfn`
   - `slot`
   - `format`
   - `root_sequence_index`
   - `zero_correlation_zone`
   - `start_preamble_index`
   - `nof_preamble_indices`
   - `ra_scs`
   - `nof_rx_ports`

5. The lower PHY uplink unit-test comparison helper now checks the PRACH symbol timestamp, so the handoff is verified by test.
