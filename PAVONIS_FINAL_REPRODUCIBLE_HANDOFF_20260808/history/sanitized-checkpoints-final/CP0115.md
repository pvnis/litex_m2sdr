# Checkpoint 115 - bladeRF skip-zero-EOB deploy/build

## Scope

Implement and deploy the CP114 follow-up: prevent zero-sample end-of-burst
requests from being sent to libbladeRF as invalid `bladerf_sync_tx()` calls,
while preserving debug visibility through `SKIPPED_ZERO_EOB`.

## Local patch

Touched source:

- `srsRAN_4G/lib/src/phy/rf/rf_blade_imp.c`

Behavioral change:

- Adds `tx_dbg_skipped_zero_eob`.
- Sets it when `nsamples == 0 && is_end_of_burst`.
- Skips `bladerf_sync_tx()` when this flag is true.
- Forces such events to remain selected for TX debug logging.
- Reports `status_str=SKIPPED_ZERO_EOB` with `status=0`.

Local checks:

- `git -C srsRAN_4G diff --check -- lib/src/phy/rf/rf_blade_imp.c`: passed
- Patched source SHA256:
  `aeed72d55f0fffba2701c9b20506160b620c579256e2747f5c0e9bf31c9c435c`
