## gNB result

The gNB side stayed alive and collected PRACH instrumentation:

- CP105 timing artifacts were present.
- 512 raw PRACH windows plus manifest/trace files were packaged.
- gNB PRACH rows had `detected_preambles=[]`.

Because the UE did not select a serving cell and did not transmit PRACH, the gNB
PRACH result is not evidence for or against the skip-zero-EOB patch.

## Result

CP116 is inconclusive for the EOB hypothesis. It proves the patched plugin was
loadable, but the UE failed cell selection before any TX debug or PRACH writes,
so it did not exercise the changed zero-sample EOB path.
