## Interpretation

CP150 is a strong raw-IQ negative result.

The CP148 live UE produced five high-peak PRACH TX dumps, but none of those waveform templates appears in the 512-window gNB raw corpus at a meaningful correlation level:

- best same-window score: about `0.0480`
- best global sliding score: about `0.0737`
- hits >= `0.10`: `0`
- hits >= `0.25`: `0`
- hits >= `0.50`: `0`

The wall-clock join makes this stronger than CP141: for CP148, the gNB raw corpus includes windows within about `24 ms` of each estimated UE TX wall time, yet the waveform is still absent.

This supports the same split as CP139/CP141, now after CP143 proved controlled replay can be clean and CP146 proved the gNB strict gate can be clean:

- live srsUE/bladeRF reports high-peak timed writes with OK status,
- gNB records no preamble,
- offline raw-IQ search finds no transmitted waveform,
- controlled replay can carry an equivalent live dump through the same RF path.

The current strongest hypothesis is live bladeRF emission/timestamp/SOB/EOB behavior or a live-only SDR state interaction, not waveform invalidity or gNB detector [interface-redacted].
