## Interpretation

CP154 is important because the five-minute idle interval did not restore the controlled RF path. The hit count instead continued down from `5/7` to `3/7` to `2/7`.

That argues against a simple short thermal recovery pattern like CP132's CP99 recovery. It also means the current RF path should not be treated as healthy enough for more live srsUE conclusions until it is characterized or reset.

The antenna-overheating theory remains incomplete:

- CP153 measured bladeRF RFIC at `34.2 C` and M2SDR AD9361 at `34 C`, which is not overheating.
- CP154 still produced two strong controlled hits, so the path is not totally open/dead.
- The degradation is intermittent/window-selective, with some high-energy low-correlation windows, which fits active RF-chain/path state, interference, or capture/timing instability better than a passive antenna simply getting hot.

Current strongest reading:

- CP148 live absence still points at live srsUE/bladeRF timed-emission semantics for the live failure mode.
- CP151-CP154 show the controlled RF path itself is now degraded/unstable and must be stabilized before the ladder can safely return to live Msg1.
