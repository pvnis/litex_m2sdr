## Purpose

Deploy a bounded gNB-side uplink symbol dump on [host-redacted] so the next live run can test whether UE PRACH energy reaches the gNB RF input outside the existing PRACH pre-demod windows.

## Code change

Added temporary Stage 6 debug-only instrumentation in:

- `ocudu/lib/phy/lower/processors/uplink/uplink_processor_impl.cpp`

The new tap is guarded by `PAVONIS_UL_SYMBOL_DUMP`. When armed it writes:

- `/tmp/pavonis_ul_symbol_manifest.tsv`
- bounded `/tmp/pavonis_ul_symbol_*.cf32` raw symbol files

The dump runs after CFO correction and before PRACH/PUxCH processing. It records symbol radio timestamps, SFN/slot/symbol, port, RMS, peak, arm file, and optional raw path.

The gNB start/package helpers were updated to:

- clear old `/tmp/pavonis_ul_symbol_*` files at start,
- arm the symbol tap with the same arm file as PRACH predemod/detector traces,
- package the manifest and raw symbol files.
