# Checkpoint 192 - bladeRF high-peak TX_NOW deploy/build

## Scope

Add and deploy an env-gated bladeRF TX metadata probe for the next Stage 6 live
test. The probe only affects high-peak PRACH buffers when explicitly enabled:

- env gate: `PAVONIS_RF_BLADE_TX_DBG_HIGH_PEAK_TX_NOW=1`
- condition: `PAVONIS_RF_BLADE_TX_DBG=1`, `nsamples > 0`, and `cf32_peak >= PAVONIS_RF_BLADE_TX_DBG_MIN_PEAK`
- action: preserve the existing PRACH buffer and SOB/EOB framing, set
  `BLADERF_META_FLAG_TX_NOW`, and zero `meta.timestamp`
- debug fields added:
  - `high_peak_tx_now`
  - `high_peak_tx_now_applied`
  - `high_peak_tx_now_old_timestamp`

The default behavior is unchanged when the env var is unset.
