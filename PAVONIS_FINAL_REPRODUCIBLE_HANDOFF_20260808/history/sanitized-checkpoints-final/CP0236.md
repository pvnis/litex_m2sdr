## Interpretation

CP236 is the strongest current downlink result in this segment. It shows the
downlink is present and recoverable as expected PCI 1 when:

- gNB uses `TX_BACKOFF=20`
- the independent bladeRF capture uses gain30, avoiding SC16 rail clipping

It is still not a robust pass: the expected/wrong ratio is `1.135`, below the
`1.200` dominance threshold, so the result is low-margin. But it is materially
better than backoff10 and better than backoff20/gain40.

This supports a receive-side overdrive/margin hypothesis for the UE path:
CP225's UE best config uses `rx_gain = 40`, and CP234 showed gain40 clipping in
the independent capture. A future live UE diagnostic should consider lowering
UE RX gain while keeping gNB at backoff20, but only after cleanup.
