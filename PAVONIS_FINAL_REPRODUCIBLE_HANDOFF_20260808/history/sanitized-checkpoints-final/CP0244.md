# Checkpoint 244 - srsUE cell-selection trace deployed and built

## Summary

CP244 deployed a narrow UE-side `sync_sa.cc` instrumentation patch to [host-redacted] and rebuilt the `srsue` target successfully.

The patch is env gated by `PAVONIS_SRSUE_CELL_SELECT_TRACE=1` and emits `PAVONIS_CELL_SELECT_TRACE` rows for:

- cell search start/trials/done
- cell select start/numerology
- SFN sync start/trials/done
- wait-idle and sync-config failures

It also resets `sfn_sync_nof_trials = 0` when a new cell-select run starts, so the trace reports per-attempt SFN sync trials rather than a stale cumulative counter.
