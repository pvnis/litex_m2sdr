## CP259 runner bug fixed

The CP45 replay gate should have stopped the sequence before live. It did not,
because the numeric gate helpers used `awk ... | tee`, and without `pipefail`
the function returned `tee`'s success status.

Fix applied:

```text
set -o pipefail
```

`bash -n cp259_run_rf_path_gate_then_live_after_remote_unblock.sh` passes after
the fix.
