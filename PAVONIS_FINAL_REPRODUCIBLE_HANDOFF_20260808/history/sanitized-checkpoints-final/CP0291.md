## Interpretation

CP291 is a strong raw-IQ negative result for CP289:

- five UE PRACH dumps are high-amplitude templates (`~0.56-0.57` RMS,
  `~0.99-1.01` peak)
- best same-window correlation is only `0.0478`
- best global saved-window correlation is only `0.0743`
- no saved-window hit reaches `0.10`
- nearest gNB windows are within `0.3 ms` of UE TX metadata, but are
  floor-level (`~1.68e-04` RMS, `~2.7e-04` peak)

This differs from CP214: CP289 does not look like a coarse wall-clock schedule
phase error. The gNB saved PRACH windows are aligned closely enough by wall
clock, but they still do not contain the transmitted waveform.

Taken with CP289, the current active split is:

- srsUE/bladeRF reports five valid high-peak PRACH writes with OK metadata
- the controlled replay ladder has previously shown the same class of captured
  waveform can cross the [host-redacted]-to-[host-redacted] RF path
- the live CP289 gNB raw windows, including aligned windows, remain floor-level
  and waveform-negative

The next rung should test whether CP289's exact dump can still traverse the
controlled plugin path immediately in the current RF state. If controlled replay
passes, focus returns to live srsUE/bladeRF stream-state or emission semantics.
If controlled replay now fails, investigate current RF path state before more
live attach attempts.
