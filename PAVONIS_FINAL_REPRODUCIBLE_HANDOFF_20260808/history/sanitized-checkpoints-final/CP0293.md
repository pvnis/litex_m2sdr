# CHECKPOINT 293 - rf_blade post-sync timestamp debug deploy

Date: [date-redacted]

## Purpose

Add non-behavioral UE-side bladeRF TX debug instrumentation so the next live PRACH run can compare the scheduled PRACH timestamp with bladeRF RX/TX device timestamps immediately after each `bladerf_sync_tx()` call.

This checkpoint does not change the live PRACH scheduling knobs. It only adds selected-row timestamp readbacks and logging.

Sampling rule:

- For selected TX debug rows, read `BLADERF_RX` and `BLADERF_TX` timestamps after `bladerf_sync_tx()`.
- Compute deltas against the final metadata timestamp when non-zero.
- Compute elapsed samples against the pre-call RX/TX timestamp when that pre-call timestamp was available.
