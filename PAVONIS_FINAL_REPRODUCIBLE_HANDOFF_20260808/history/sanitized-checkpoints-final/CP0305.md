Check whether the control channel is currently usable before considering a live CP300 watchdog run. This checkpoint used SSH-only commands and did not start gNB, UE, bladeRF, M2SDR, qcore, or any RF transmit/receive path.

## Decision

Do not launch CP300 live RF while `[host-redacted]` TCP/22 is timing out. The watchdog launcher is now locally hardened, but it still needs a reachable [host-redacted] control path to arm the watchdog, start gNB, enforce the strict gate, stop, package, and retrieve evidence.

Next safe action when the network improves:

1. Repeat the no-RF SSH smoke for both hosts.
2. If both pass, run the CP300 watchdog-backed launcher.
3. If retrieval fails after a live run, preserve the remote tar paths from the launcher log for later recovery.
