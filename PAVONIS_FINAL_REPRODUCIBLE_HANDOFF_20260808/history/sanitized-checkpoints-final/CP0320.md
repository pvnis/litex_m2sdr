## Interpretation

CP320 proves [host-redacted]'s RF harness gNB build now contains the CP319 targeted
UL-symbol raw-save instrumentation. It consumed no RF and left a source backup
on [host-redacted] for rollback.

The next live rung can be a CP316-style self-contained RF run with:

- `PAVONIS_RF_BLADE_TX_DBG_PRACH_TIME_OFFSET_SAMPLES=1637172`
- `PAVONIS_UL_SYMBOL_RAW_TARGET_SFN_MOD=16`
- `PAVONIS_UL_SYMBOL_RAW_TARGET_SFN_REM=1`
- `PAVONIS_UL_SYMBOL_RAW_TARGET_SLOT=4`

The point of that run is not another timing offset test. The point is to force
UL-symbol raw files for the expected PRACH slots so the target rows can be
inspected even if receive amplitude stays below the existing broad peak/RMS raw
save trigger.
