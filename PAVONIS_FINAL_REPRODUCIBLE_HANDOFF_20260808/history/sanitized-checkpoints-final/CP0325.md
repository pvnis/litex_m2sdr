## Interpretation

The self-contained gate worked: both NUCs reached `GO`, the TX run completed,
the RX capture completed, artifacts were packaged, and offline analysis ran.

The RX-path quality gate did not pass. CP325 recovered six strong CP45 waveform
windows, but one selected window was near receiver-floor scale. This is a
partial controlled-path result, not a clean current-path validation.

Compared with the earlier CP264 immediate repeat, which was clean at the same
RX gain class, CP325 indicates that the current controlled TX/RX path is
intermittent or margin-sensitive. That does not yet justify returning to live
UE PRACH debugging.

CP325 final process logs also showed transient-looking self-contained wrapper
or gate-server entries. A no-RF post-check is required before another RF run.
