## Interpretation

The self-contained orchestration worked again: both hosts reached `GO`, the
TX helper completed, the RX capture completed, artifacts were packaged, and
offline analysis ran.

The controlled replay path did not recover. CP325 had six strong selected
windows; CP327 had zero strong selected windows and no OCUDU hits in any
selected window. The RX capture still contains energy, but it no longer matches
the CP45 waveform strongly enough to validate the path.

This is a current controlled-path regression. It argues against moving back to
live UE PRACH and points to a lower-level RF/path/frequency/margin check.

CP327 final process logs showed the same transient wrapper/gate-server pattern
seen after CP325, so CP328 performed a no-RF post-check before the next rung.
