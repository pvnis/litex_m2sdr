# Checkpoint 341: CP339 offline targeted UL-symbol waveform analysis

## Purpose

Search CP339's saved gNB receive artifacts for copies of the five UE PRACH TX
debug waveforms. CP339 used [host-redacted] RX gain `50` and forced targeted UL-symbol raw
saves, so CP341 searched both:

- the saved PRACH predemod raw corpus
- reconstructed full-slot files from the targeted UL-symbol raw saves

## Interpretation

CP341 confirms CP339's online result offline. The UE produced five valid
positive-offset PRACH waveforms, the gNB saved the relevant PRACH and targeted
UL-symbol windows, and the expected target slots are present. Neither the PRACH
raw corpus nor the reconstructed target UL-slot corpus contains a convincing
copy of the UE waveform.

Compared with CP323, raising [host-redacted] RX gain to `50` did not expose the live UE
waveform in the gNB receive artifacts. The next useful controlled check is to
replay one or more actual CP339 UE dumps through the controlled replay path at
RX gain `50`. If that replay is visible, the fault remains specific to live UE
runtime scheduling/RF behavior. If that replay is not visible, the CP339
waveform/replay assumptions or current RF path need direct investigation.
