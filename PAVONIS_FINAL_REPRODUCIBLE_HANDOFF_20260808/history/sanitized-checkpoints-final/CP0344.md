## Interpretation

CP344 repeats CP342's partial-controlled-replay result. The CP339 dump waveform
is again visible in the controlled RF path, and this run had `5/7` windows above
score `0.50`, but it still failed the strict sparse gate and did not behave like
the CP333 CP45 replay pass.

The repeat also adds a useful detail: the five high-correlation windows mostly
show rb12 sweep hits rather than nominal rb8 hits. That points away from a dead
RF path and toward CP339-dump waveform/replay behavior, frequency/RB alignment,
or analysis assumptions that differ from the CP45 known-good waveform. It is not
yet strong enough evidence to spend another live UE attempt.

Before more RF, clean the transient CP344 self-contained wrappers. The next
controlled rung should either re-run a known-good CP45 replay baseline to prove
the path is still clean, or replay other CP339 dumps to see whether dump000001 is
special.
