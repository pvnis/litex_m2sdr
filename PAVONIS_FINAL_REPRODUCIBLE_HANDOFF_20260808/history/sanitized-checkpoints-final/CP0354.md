## Interpretation

CP354 is a strict controlled replay pass. It matches CP350's clean behavior and
confirms that later CP339 dumps can replay strongly through the same RF path at
RX gain `50`.

The completed per-dump CP339 replay pattern is:

- dump000001: partial across two runs (`4/7`, then `5/7` strong)
- dump000002: all visible but one-window margin fail (`7/7 >= 0.50`, min
  `0.684`)
- dump000003: strict pass (`7/7 >= 0.50`, min `0.917`)
- dump000004: partial (`6/7 >= 0.50`, one weak/no-hit window at idx `154`)
- dump000005: strict pass (`7/7 >= 0.50`, min `0.913`)

This keeps the working hypothesis away from a dead gross RF path. The next
useful step is a no-RF cleanup checkpoint, then a cross-dump waveform/timing
comparison to identify why some CP339 dumps replay partially while others pass.
