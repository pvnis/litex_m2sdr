# Checkpoint 381: local Soapy RX dump source/build

## Purpose

Implement the CP380 recommendation locally: add a dormant, env-gated raw Soapy
RX buffer tap below the existing UL-symbol and PRACH predemod taps.

This checkpoint is source/build only. It consumes no RF.

## Source change

Changed:

- `/home/[host-redacted]/CLionProjects/ocudu/lib/radio/soapy/radio_soapy_rx_stream.cpp`

New instrumentation:

- `PAVONIS_SOAPY_RX_DUMP`
- `PAVONIS_SOAPY_RX_DUMP_ARM_FILE`
- `PAVONIS_SOAPY_RX_ARM_POLL_PERIOD`
- `PAVONIS_SOAPY_RX_SUMMARY_MAX`
- `PAVONIS_SOAPY_RX_RAW_MAX`
- `PAVONIS_SOAPY_RX_RAW_PERIOD`
- `PAVONIS_SOAPY_RX_RAW_PEAK_MIN`
- `PAVONIS_SOAPY_RX_RAW_RMS_MIN`

When enabled and armed, `radio_soapy_rx_stream::receive()` now writes:

- `/tmp/pavonis_soapy_rx_manifest.tsv`
- bounded `/tmp/pavonis_soapy_rx_*.cf32`

The tap is below lower PHY processing. It records the completed Soapy RX buffer
after `acquireReadBuffer()` data has been copied into the OCUDU baseband buffer,
but before `lower_phy_baseband_processor` calls `uplink_processor.process()`.

Manifest fields:

```text
idx wall_ns ret_ts nsamples loops overflows port raw_rms raw_peak arm_file raw_path
```

Raw files are normalized `cf32` snapshots of the `ci16_t` Soapy RX buffer and
are bounded by `PAVONIS_SOAPY_RX_RAW_MAX`.
