## Interpretation

CP392 proves the full gated replay path can run with the Soapy RX tap enabled:
gNB startup passed, strict gate passed, sens transmitted the replay, and [host-redacted]
packaged the Soapy/PRACH/UL artifacts.

It also narrows the failure: the replay energy visible at the gNB Soapy boundary
is weak, below the Soapy raw snapshot thresholds, and far below PRACH detector
acceptance. This is not an off-window-only result and not a missing Soapy
package result.

Next useful rung: keep the strict GO/CANCEL pattern, lower Soapy raw snapshot
thresholds enough to capture the weak high-percentile samples, and/or run a
controlled receive-sensitivity variant before spending another live UE attempt.
