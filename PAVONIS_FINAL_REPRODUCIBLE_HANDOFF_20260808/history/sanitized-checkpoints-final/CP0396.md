## Interpretation

CP396 is a controlled baseline degradation. The TX runner and capture process
returned cleanly, and four CP45 windows were still strong, so the RF path is not
dead. But the known-good CP45 baseline fell from the CP346 clean `7/7` pass to
`4/7` above `0.50`, with two near-zero selected scores and one weak score.

This supports an active RF/path variability, receiver state, or device/thermal
state branch. Do not spend the next attempt on another active-gNB live/CP361
retry. The next checkpoint should be a no-TX receive-floor/health check or an RF
state reset/cooldown check before more transmit activity.
