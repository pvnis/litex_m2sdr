## Interpretation

CP399 does not support a simple SDR RFIC overheating explanation. It also does
not show stale RF processes, recent USB resets, recent M2SDR kernel faults, or
TX timing slip counters.

The active branch remains RF environment, physical path state, receiver/device
state, or intermittent receive-floor bursts. CP398 is still important here:
with no TX, [host-redacted] measured `RX_RMS_MAX_10MS=1.270744950e-02`, close to CP396's
controlled replay `RX_RMS_MAX_10MS=1.338989846e-02`.

Passive antenna overheating is unlikely from these data. If there is any active
component in the RF path, CP399 does not directly instrument it, so a powered
external element, cable, connector, attenuator, or physical placement issue
remains possible.
