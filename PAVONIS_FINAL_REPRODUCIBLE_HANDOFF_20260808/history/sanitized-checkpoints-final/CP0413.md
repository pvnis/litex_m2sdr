## Interpretation

The Soapy-RX-instrumented gNB startup path is not deterministically sufficient
to trigger the M2SDR TX writeStream-timeout state. CP411 failed with the same
instrumented start helper and `7254` timeouts; CP413 used the instrumented start
helper without sens replay and passed with zero timeouts.

This points to an intermittent or sequence/state-sensitive active-gNB startup
failure, rather than a dead RF path or a simple Soapy tap configuration fault.
