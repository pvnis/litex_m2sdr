## Interpretation

The CP366 [host-redacted] HTTP gate/watchdog path, GO file write, arm file write, and
short post-GO dwell are not deterministically sufficient to trigger the M2SDR
TX writeStream-timeout state. CP411 failed with the full two-NUC active replay
sequence before replay TX, while CP415 used the same [host-redacted]-side CP366 gate path
without sens replay and passed with zero timeouts.

The remaining differentiators are the full two-NUC active replay sequence,
sens-side waiter/replay staging, timing around the gate, or an intermittent
M2SDR/gNB startup state independent of the isolated [host-redacted] path.
