## Interpretation

CP429 proves the useful runtime configuration is RX-only:

- RX bandwidth can be explicitly set to `10 MHz`.
- RX readback confirms `bandwidth_Hz=10000000`.
- TX bandwidth remains at the LiteXM2SDR default readback of `30720000`.
- The strict gate passes with zero Soapy TX timeouts.

This is the right setup for the next active replay attempt. The next sens TX
checkpoint should keep the strict GO/CANCEL gate and pass
`OCUDU_SOAPY_RX_BW_HZ=10000000` into the [host-redacted] gNB start path, while leaving TX
bandwidth unset.
