## Interpretation

CP437 validates the harness improvement from CP435: the active replay package
now contains Soapy RX tap files. It also confirms RX-only BW10 keeps the gNB out
of the M2SDR TX-timeout failure state during active replay.

The replay still did not produce an accepted PRACH. The detector and predemod
levels are stronger than CP431 but still far below a clean controlled CP361
copy.

One important instrumentation detail remains: the Soapy tap was always-on with a
`200000`-row budget, so it exhausted that budget during gNB startup before the
PRACH windows. CP438 therefore treats the Soapy rows as a coverage-gap finding,
not as proof that the replay was absent from Soapy during the actual TX window.
The next active replay should arm the Soapy tap with the same CP366 PRACH arm
file so Soapy rows overlap the replay/PRACH interval.
