# Checkpoint 454 - TX BW10/RX BW10 gNB Strict-Gate Failure

Date: [date-redacted]
Stamp: [date-redacted]

## Purpose

Test a concrete active-runtime variable from the CP445/CP450 gap: active gNB TX
bandwidth. CP440 and CP450 forced RX BW10 but left TX bandwidth at the default
`30720000` readback. CP454 forced both TX and RX Soapy bandwidth to `10000000`
and ran a [host-redacted]-only strict-gate check with no [host-redacted] replay.

This checkpoint did not launch sens TX.

## Interpretation

CP454 did not test active replay or active-RX correlation because the safety
gate correctly blocked any next replay step. It did prove that the code path can
set and read back TX BW10 and RX BW10 simultaneously.

However, this particular TX-BW10 start hit the known M2SDR TX writeStream
timeout failure state. The result does not yet prove that TX BW10 is
intrinsically invalid, because the timeout state has recurred
nondeterministically in earlier checkpoints. The next safe rung is a no-replay
strict-gate recovery/retry for the same TX-BW10 condition after CP455 cleanup.
