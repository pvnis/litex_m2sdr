## Interpretation

CP458 answers the TX-BW10 active-replay question: forcing both TX and RX Soapy
bandwidth to 10 MHz can pass strict startup health and can run a clean [host-redacted]
replay, but it still does not produce a strong active gNB RX copy or any
accepted PRACH.

This weakens TX-bandwidth mismatch as the explanation for the active/passive
visibility gap. The active gNB/M2SDR full-duplex runtime still sees the CP361
waveform much more weakly than the passive controlled BW10 path.

Because timing was not close (`23.8 ms` nearest TX-to-PRACH distance), CP458 is
not a useful PRACH-accept timing attempt. The main result is active Soapy
visibility under RX/TX BW10.
