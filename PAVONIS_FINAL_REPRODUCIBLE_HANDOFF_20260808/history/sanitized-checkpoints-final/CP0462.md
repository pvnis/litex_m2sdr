## Source Findings

The passive controlled capture path uses `test_record.py`, which opens the
LiteXM2SDR RX stream as `SOAPY_SDR_CF32`.

- `litex_m2sdr/litex_m2sdr/software/soapysdr/test_record.py:26`
- `litex_m2sdr/litex_m2sdr/software/soapysdr/test_record.py:63`

OCUDU active gNB opens Soapy streams as `SOAPY_SDR_CS16`.

- `ocudu/lib/radio/soapy/radio_soapy_device.h:147`

The LiteXM2SDR driver converts 12-bit RX samples differently for those formats:

- `CF32`: sign-extend 12-bit samples, then divide by `_samplesScaling`.
- `_samplesScaling` is `[date-redacted].0f` for the 12-bit path.
- `CS16`: sign-extend 12-bit samples and return integer values directly.

Relevant code:

- `litex_m2sdr/litex_m2sdr/software/soapysdr/LiteXM2SDRStreaming.cpp:1561`
- `litex_m2sdr/litex_m2sdr/software/soapysdr/LiteXM2SDRStreaming.cpp:1573`
- `litex_m2sdr/litex_m2sdr/software/soapysdr/LiteXM2SDRStreaming.cpp:1577`
- `litex_m2sdr/litex_m2sdr/software/soapysdr/LiteXM2SDRStreaming.cpp:1635`
- `litex_m2sdr/litex_m2sdr/software/soapysdr/LiteXM2SDRStreaming.cpp:1647`
- `litex_m2sdr/litex_m2sdr/software/soapysdr/LiteXM2SDRDevice.hpp:687`

The OCUDU `PAVONIS_SOAPY_RX_DUMP` instrumentation records active `CS16`
buffers as `CF32` by dividing by `int16_t::max()` rather than by the M2SDR
12-bit full scale.

- `ocudu/lib/radio/soapy/radio_soapy_rx_stream.cpp:306`
- `ocudu/lib/radio/soapy/radio_soapy_rx_stream.cpp:313`
- `ocudu/lib/radio/soapy/radio_soapy_rx_stream.cpp:343`

Therefore active debug amplitudes are expected to be scaled by:

- `[date-redacted] / 32767 = 0.0624713`
- inverse correction: `32767 / [date-redacted] = 16.0073`

## Interpretation

The earlier statement that active Soapy raw amplitudes were about an order of
magnitude below passive controlled amplitudes should be treated as a debug
scaling artifact, not as proof of weak active RF.

The remaining valid CP458 failure signal is the normalized correlation failure:
the active gNB runtime buffers contain RF-scale energy, but not a clean
time/frequency copy of the CP361 replay waveform where expected. That points
away from gross antenna/RX-path collapse and toward active full-duplex runtime
timing, timestamp, buffering, stream status, or gNB receive-window alignment.
