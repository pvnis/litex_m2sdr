# Checkpoint 476 - CP474 TX Backoff Effect Local Audit

Date: [date-redacted] UTC

## Purpose

Verify that CP474 actually reduced the active gNB TX sample amplitude versus the
previous CP472 active run. This is a no-RF, no-SSH local artifact audit.

If `tx_gain_backoff: 40` did not materially lower the M2SDR TX samples compared
with CP472's `tx_gain_backoff: 20`, then CP474 would not be a valid test of the
static downlink-amplitude/self-desense branch.

The first live TX probe lines show the same order-of-magnitude change:

- CP472 early nonzero RMS: about `0.055` to `0.061`
- CP474 early nonzero RMS: about `0.0056` to `0.0060`

## Interpretation

CP474 did apply the intended additional 20 dB downlink backoff. The observed
M2SDR TX input amplitude fell by about `19.9 dB` relative to CP472.

Therefore CP474 is a valid negative test of the static downlink-amplitude branch:
lowering active gNB TX amplitude by about 20 dB did not improve active PRACH
acceptance or direct correlation.

The remaining active/passive gap is more likely tied to runtime active M2SDR
TX/RX state, stream scheduling/alignment, RX handling while the gNB is running,
or another full-duplex interaction that is not solved by a static DL amplitude
reduction.
