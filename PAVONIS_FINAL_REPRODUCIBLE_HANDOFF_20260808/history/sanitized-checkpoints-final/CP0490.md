# Checkpoint 490 - CP366 Lower-PHY TS-Bridge Env Forwarding Patch

Date: [date-redacted] UTC
Dry-run stamp: CP490DRYRUN

## Purpose

Fix the CP487 tooling issue where `PAVONIS_LOWER_PHY_TS_BRIDGE_SUMMARY_MAX`
was exported by the wrapper but did not reach the [host-redacted] start helper. This caused
CP487 to use the default bridge cap `250000` instead of the intended `400000`.

## Change

Patched:

- `cp366_launch_selfcontained_cp361dump000001_replay_into_live_gnb_rxgain50.sh`

Details:

- added default launch variables:
  - `PAVONIS_LOWER_PHY_TS_BRIDGE_ARM_POLL_PERIOD=64`
  - `PAVONIS_LOWER_PHY_TS_BRIDGE_SUMMARY_MAX=250000`
- forwarded both variables through `remote_env_prefix()`
- logged the lower-PHY bridge poll/cap settings in the launch log

The [host-redacted] start helper already honors these variables if they are present, so no
remote start-helper change was needed.
