## Purpose

Deploy and build a default-off Soapy RX dump control that lets a future RF
checkpoint delay raw file saving until a chosen post-arm manifest index.

New environment variable:

- `PAVONIS_SOAPY_RX_RAW_START_IDX`

Default:

- `0`, preserving prior behavior.

When set, raw saving starts only once the armed Soapy dump row index is greater
than or equal to this value. Periodic saving uses
`(idx - raw_start_idx) % raw_period == 0`, so `RAW_PERIOD=1` creates a
contiguous raw dump beginning at the requested index.
