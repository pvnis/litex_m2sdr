## Purpose

Deploy a default-off LiteXM2SDR Soapy knob for the next active-gNB split:

`M2SDR_SOAPY_TX_ZERO_AFTER_ARM=1`

When enabled, the Soapy `writeStream` path keeps the active gNB runtime, stream
activation, write cadence, timestamps, and existing TX probes, but replaces TX
payloads with zeros after the existing TX-probe arm file is observed. This sets
up the next RF checkpoint to distinguish actual gNB TX payload/RF effects from
full active-gNB runtime behavior.
