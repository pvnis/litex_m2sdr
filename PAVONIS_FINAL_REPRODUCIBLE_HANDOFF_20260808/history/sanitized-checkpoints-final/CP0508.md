## Purpose

- keep the CP495 delayed contiguous Soapy RX/raw capture shape

- set `M2SDR_SOAPY_RX_IGNORE_TIMED_ACTIVATION=1`

timed RX activation while standalone full-duplex controls use immediate RX

## Interpretation

CP508 is a valid active-gNB negative. Ignoring the active gNB's timed RX
activation request did not recover CP361 in Soapy RX raw, lower PHY, or the
gNB PRACH detector.

This rules out the timed RX activation/drop/alignment path as the sufficient
cause of the active-gNB disappearance. The remaining branch is deeper
active-gNB RX/runtime behavior: sustained RX stream consumption, scheduling
state, lower-PHY integration, timestamp/runtime coupling, or another active
gNB read-path difference not reproduced by standalone full-duplex Soapy.

One additional observation: ignoring timed activation fragmented the saved raw
capture into 24 contiguous segments, unlike CP495/CP504's single long segment.
That fragmentation is a side effect to keep in mind, but it did not create a
strong hidden CP361 copy in any saved segment.
