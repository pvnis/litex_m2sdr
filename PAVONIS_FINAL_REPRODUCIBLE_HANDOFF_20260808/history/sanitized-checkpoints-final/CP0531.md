## Interpretation

CP531 shows the active raw path is still strong late in the run, so a simple
late-run RF fade or thermal loss is not supported by this run. It did not,
however, capture raw at CP531's actual sub-millisecond PRACH crossing because
the initial phase moved between runs.

The next diagnostic run should not target one fixed raw index. Use sparse
full-run Soapy raw capture (`RAW_PERIOD=16`, start near `0`) so the saved raw
corpus spans the whole 32 s sweep and covers whichever burst becomes the actual
best PRACH crossing in that run.
