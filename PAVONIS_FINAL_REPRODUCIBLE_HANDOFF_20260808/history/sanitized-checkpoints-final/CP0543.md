## Misconfiguration

CP543 is not a valid backoff10 amplitude test. The [host-redacted] start log shows:

- `TX_GAIN_BACKOFF=20`
- `CONF_TX_BACKOFF_LINE=26:    tx_gain_backoff: 20`

Root cause: `cp543_launch_...` exported `TX_GAIN_BACKOFF=10`, but the shared
`cp366_launch_selfcontained_cp361dump000001_replay_into_live_gnb_rxgain50.sh`
remote environment prefix does not forward `TX_GAIN_BACKOFF` to [host-redacted]. The [host-redacted]
start helper therefore used its own default:

- `TX_GAIN_BACKOFF="${TX_GAIN_BACKOFF:-20}"`
