## Interpretation

CP559 confirms the CP557 online result in the saved target UL-symbol artifacts:
the UE produced six full-scale positive-offset PRACH waveforms, but the
reconstructed gNB target UL slots do not contain a convincing copy of those
waveforms.

The PRACH predemod raw instrumentation was capped too early for this run: the
actual UE-timed PRACH manifest rows were `828..833`, while only `0..511` had
raw files. Future live attempts that rely on PRACH predemod raw same-window
analysis should raise `PAVONIS_PRACH_PREDEMOD_RAW_MAX` or arm capture later.

Given the target-slot negative result, the next useful branch is still to
replay one CP557 UE dump through the controlled path at RX gain `50`. If that
controlled replay is visible, the fault remains live `srsue` runtime RF
behavior/timing. If not, inspect the CP557 waveform/replay assumptions or the
current RF path.
