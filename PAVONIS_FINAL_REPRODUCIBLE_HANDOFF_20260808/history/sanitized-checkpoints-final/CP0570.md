## Interpretation

CP570 is a valid live UE PRACH no-detect result and a useful control. The
original CP557-style raw512 capture path still reaches UE SFN sync and Msg1,
while the raw1600 CP564/CP566 attempts and the CP568 delayed-arm45 attempt all
failed before Msg1.

This points away from a general antenna/RF-path outage and toward an interaction
between the raised raw capture configuration/timing and UE DL/SFN stability, or
a narrower timing/load race around the raw1600 runs. gNB still does not detect
the five healthy UE-side PRACH transmissions at threshold `0.24`.

The next non-RF step should analyze whether CP570's earlier five PRACH attempts
landed inside the saved raw512 PRACH windows. If raw512 captured the exact
windows in CP570, use this run for offline correlation before spending another
live attempt.
