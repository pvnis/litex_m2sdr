## Interpretation

CP573 is a clean controlled replay pass for the CP570 dump. A CP570 UE PRACH
waveform that was not visible in CP570's exact live gNB PRACH windows becomes
strongly visible when replayed through the controlled path at the same [host-redacted] RX
gain `50`.

Together with CP572, this sharply narrows the failure boundary. The issue is
not a malformed CP570 UE dump, not a gross failed antenna/RF path at the current
time, and not merely a raw512 capture miss. The remaining gap is live UE runtime
PRACH emission/timestamp alignment into the active gNB PRACH receive window, or
an active-gNB/runtime reference mismatch that the controlled replay path does
not exercise.
