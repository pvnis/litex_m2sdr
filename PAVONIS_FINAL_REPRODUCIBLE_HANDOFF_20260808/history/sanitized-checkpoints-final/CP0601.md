## Interpretation

CP601 confirms CP599's repeatability result. The CP597 recipe is valid and can
accept, but it is not deterministic at the current active-gNB runtime alignment:

- CP597: valid active accept, `2` accepted rows
- CP599: valid repeat, `0` accepted rows
- CP601: valid repeat, `0` accepted rows

The common negative-run shape is clean control flow, strict gate pass, expected
TX burst count, and strong lower-RX CP570-shaped energy, but weak saved PRACH
same-window correlation and sub-threshold gNB detector peaks. The strongest
focused lower-RX copies for CP599 and CP601 were roughly `0.74 ms` late
relative to the detector-max PRACH windows.

The next ladder step should stop treating offset `1773655` as a deterministic
acceptance recipe. It remains the only proven active accept point, but further
work should either package the result as stochastic or investigate why the
active-gNB PRACH windows sometimes land about `8.5k` samples away from the
strong lower-RX copy.
