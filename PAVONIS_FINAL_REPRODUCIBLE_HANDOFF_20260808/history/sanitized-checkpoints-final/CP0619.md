## Source timing audit

Active replay timing path:

- file: `cp47_srsran_blade_plugin_paced_sparse_timed_tx.c`
- when timed start is enabled, it calls `srsran_rf_get_time()`,
- then applies `add_seconds(&start_secs, &start_frac, cfg.timed_lead_ms / 1000.0)`,
- each chunk timestamp is `start + chunk_index * chunk_sec`,
- `TIMED_LEAD_MS=-0.67` therefore shifts the entire paced replay sequence about
  `0.67 ms` earlier relative to the device time sampled at replay start.

Live UE timing path:

- file: `/home/[host-redacted]/CLionProjects/srsRAN_4G/lib/src/phy/rf/rf_blade_imp.c`
- for high-peak PRACH chunks, the live path rebuilds `meta.timestamp` from the
  UE-provided `secs/frac` timestamp and forces SOB/EOB when requested,
- it then applies
  `PAVONIS_RF_BLADE_TX_DBG_PRACH_TIME_OFFSET_SAMPLES` directly to
  `meta.timestamp`,
- there is no live equivalent of active replay `TIMED_LEAD_MS`.
