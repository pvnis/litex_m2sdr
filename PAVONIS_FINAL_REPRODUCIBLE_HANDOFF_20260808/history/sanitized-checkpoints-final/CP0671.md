## Interpretation

CP671 is a regression relative to CP667. CP667 accepted the same +500 Hz CP663
template with the same offset/gain family; CP671 did not. This changes the
current working state:

- The latest live failures, CP668 and CP670, cannot be attributed only to a
  live UE waveform problem.
- As of CP671, the controlled replay path itself is no longer accepting under
  the last known-good recipe.
- The first failed ladder stage remains Stage 6. Do not move to Stage 7.

The next debugging branch should re-establish the controlled replay baseline
before drawing further conclusions about live UE Msg1. A practical next step is
to repeat the CP661/CP667 accepted replay recipe once more, then compare RF
receiver-side power/Soapy/predemod metrics against CP667 and CP671 to decide
whether this is path drift, timing drift, gain/path attenuation, or detector
repeatability.
