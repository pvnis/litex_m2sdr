## Interpretation

CP710 passes as no-RF prep.

The next rung should be a gNB-only strict gate at `GNB_RX_GAIN=55`, not a live
UE run. The gate must prove:

- gNB starts;
- strict gate returns `PASS`;
- total Soapy TX timeouts remain `0`;
- RX/TX bandwidth readbacks are still `10 MHz`;
- RX readback reports the requested gain or a clearly understood device-limited
  value.

Only if that strict gate passes should the next live-UE launcher preserve the
CP705 live recipe and change only gNB RX gain from `50` to `55`.
