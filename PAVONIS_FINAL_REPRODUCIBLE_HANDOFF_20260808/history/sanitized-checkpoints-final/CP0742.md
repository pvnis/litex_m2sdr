waveform alignment, but the actual live RA receiver windows stayed weak and
unaccepted:

| Metric | CP740/CP741 value |
| --- | ---: |

| expected rows max P0 peak | `0.08308784664` |

| CP733 controlled best raw RMS | `0.0007071315099` |
| live expected RSSI family | about `-74 dB` |
| CP733 controlled RSSI | `-52.89 dB` |

CP741 therefore moved the leading theory away from "TX waveform shape only" and
toward:

```text
live receiver-path strength/visibility or active RF/stream state
```

CP742 prepares the next low-risk rung:

```text
Verify whether the CP733-style controlled path is strong immediately before
and after a live attempt, while the live attempt itself still uses the current
best TX-aligned live settings.
```

## Prepared sequence

The CP742 real-mode sequence is:

| Phase | Purpose | Gate port | Settings |
| --- | --- | ---: | --- |
| `pre` controlled replay | Verify CP733-style controlled strength before live | `18742` | RX gain `50`, demod offset `562`, threshold `0.24`, PRACH offset `1773617`, TX gain `59.0` |
| `live` UE attempt | Try current best live TX-aligned candidate | `18743` | RX gain `50`, demod offset `562`, threshold `0.24`, PRACH offset `1773617`, freqrot `725`, UE TX gain `59`, preamble max `20`, 10 MHz RX/TX |
| `post` controlled replay | Check whether the controlled path changed after live | `18744` | same as `pre` controlled |

The wrapper intentionally supports cleanup only before and after the full
paired sequence, not between phases by default. That keeps the probe focused on
whether receiver/RF state around the live attempt is different, while still
allowing explicit cleanup at the outer boundaries.

## Interpretation

CP742 does not move the RF ladder by itself. It prepares the next rung and
validates that the local orchestration resolves the intended phase tags,
settings, gate ports, remote artifact names, and dry-run safety behavior.

The prepared experiment directly tests the current leading theory:

```text
Is the receiver path strong for CP733-style controlled replay immediately
around a live UE attempt, or is the whole RF/receiver state weak when live
also fails?
```

Useful outcomes from the real run would be:

| Outcome | Interpretation |
| --- | --- |
| controlled pre strong, live weak, controlled post strong | live UE path/coupling remains weaker than controlled replay; receiver state is not globally dead |
| controlled pre strong, live weak, controlled post weak | live attempt or intervening RF state may degrade the controlled path |
| controlled pre weak | do not trust another live attempt; lower controlled rung regressed again |
| live accepts | move up to RAR/Msg3 evidence, not registration yet until Stage 7 is verified |
