## Analyzer failure

The live analyzer failed here:

```text
FileNotFoundError: /pavonis_rf_blade_tx_dbg_000001.meta.txt
```

This is not tarball corruption. The tarball passed gzip validation, but the UE
never produced PRACH TX debug dumps because SFN sync failed before Random
Access. The analyzer assumes at least one PRACH TX debug metadata file exists.

Because `cp742_run_paired_visibility_probe_sequence.sh` was running with
`set -e`, this analyzer error aborted the sequence before the post-controlled
phase.

## Interpretation

CP743 is a useful failed checkpoint, but not a complete paired visibility
probe:

- controlled-pre showed strong raw controlled replay visibility but no detector
  accept at threshold `0.24`;
- live did not test Msg1 because the UE failed SFN sync and never transmitted
  PRACH;
- post-controlled did not run because the live analyzer hard-failed on missing
  PRACH TX debug metadata;
- cleanup after the failure completed successfully.

This narrows the immediate operational issue:

```text
The paired probe wrapper must tolerate a live no-PRACH analyzer failure and
continue to the post-controlled phase, otherwise it cannot answer the bracketing
question under exactly the condition we now observed.
```
