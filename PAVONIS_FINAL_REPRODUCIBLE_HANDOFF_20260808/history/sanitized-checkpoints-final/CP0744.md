```text

```

Behavior change:

- `ALLOW_LIVE_ANALYZE_FAIL` defaults to `1`.
- After live collection, the sequence now runs a tolerant partial live summary
  before the strict live analyzer.
- The strict live analyzer still runs, but its nonzero return code is logged as
  a soft failure when `ALLOW_LIVE_ANALYZE_FAIL=1`.
- A soft live analyzer failure no longer prevents the post-controlled phase.
- Setting `ALLOW_LIVE_ANALYZE_FAIL=0` restores hard-fail behavior.
