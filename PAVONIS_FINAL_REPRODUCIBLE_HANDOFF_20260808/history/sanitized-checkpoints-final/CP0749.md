## Corrected interpretation

This changes the evidence chain:

- CP733 did not prove a current controlled accept at true demod offset `562`.
- CP745 controlled pre/post did not bracket the live UE at the same demod
  offset. They bracketed live `562` with controlled `847`.
- CP748 did not test the CP745 live dump at true demod offset `562`.
- CP748 still provides useful evidence: the CP745 live dump can create a strong
  preamble-0 controlled replay row at offset `847`, but it lands just below
  threshold (`0.2319558114 < 0.24`) and is not accepted.

This does not invalidate the live UE failure. CP745 live still used offset
`562`, transmitted 18 PRACH attempts, and CP746 still showed the exact live
windows had weak P0. It does invalidate the claim that the nearby controlled
baseline was using the same demod input offset as live.
