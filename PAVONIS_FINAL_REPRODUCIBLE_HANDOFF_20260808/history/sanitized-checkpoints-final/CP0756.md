## Interpretation

The CP745 saved live dump was already post-rotation with live
`PRACH_FREQ_ROT_HZ=725`. CP754 then accepted after applying an additional
`-375 Hz` correction to that saved dump.

Because the live path and replay correction path both use:

```text
samples * exp(+j*2*pi*freq_hz*n/fs)
```

the equivalent live setting is:

```text
725 + (-375) = 350 Hz
```

This proves the sign/value mapping for the next candidate. It does not prove
that a live RF run at `350 Hz` will accept, because live RF arrival timing,
coupling, and stream state remain unproven.
