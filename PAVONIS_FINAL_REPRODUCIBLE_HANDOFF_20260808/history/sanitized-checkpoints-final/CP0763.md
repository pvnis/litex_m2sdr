## Tolerant analysis behavior

The original CP739 analyzer is strict and expects TX debug dumps. That is not
appropriate for this baseline because a cell-search/cell-select failure is the
main outcome being tested.

The CP763 analyzer wrapper:

1. Runs the strict CP739 live analyzer first.
2. Records `MODE=strict` if TX dumps exist and strict analysis succeeds.
3. Falls back to `cp744_summarize_live_visibility_probe_noextract.py` if strict
   analysis fails.
4. Records `MODE=tolerant` if the no-PRACH tolerant summary succeeds.

This mirrors the CP759 fix that made CP758/CP760 no-PRACH runs checkpoint-grade
instead of local analyzer failures.
