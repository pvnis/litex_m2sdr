## Scope

CP765 is a local, no-RF audit of UE-side `srsue.stdout.log` and `result.env`
from the latest live runs. It compares runs that reached PRACH against runs
that failed earlier at SFN sync or cell search.

The question was:

```text
Did the visible UE bladeRF RX setup change between the PRACH-reaching runs and
the recent pre-PRACH failures?
```

The answer from the logs is no. The logged UE bladeRF open, gain, sample-rate,
RX stream, and RX frequency setup are identical across the compared good and
bad runs through the point where cell search starts.

## Interpretation

CP765 rules out a visible UE setup regression in the logged digital/control
path:

```text
The same UE bladeRF device opens successfully, uses the same sample rates,
starts the RX stream successfully, applies the same RX/TX gains, and [interface-redacted] to
the same RX frequency in both PRACH-reaching and cell-search-failing runs.
```

The regression is therefore not explained by the UE log-visible open/gain/rate
/frequency setup.

This does not rule out an actual RF condition problem. CP765 does not measure
temperature, analog front-end health, cable/antenna state, external interference,
or over-the-air SSB power at the UE input. It only says that the software-visible
UE RX path setup stayed the same.

The current best-supported ladder state remains:

```text
First failed stage: UE downlink cell search, before SFN sync, cell select, PRACH,
Msg1, RA response, NAS, PDU, or IP.
```

## Relation to overheating theory

The antenna-overheating theory remains possible only as a broad physical/RF
condition hypothesis, not as something proven by the logs. The evidence so far:

| Evidence | Effect on theory |
| --- | --- |
| CP740/CP745 reached PRACH with the same logged UE setup | shows the path worked earlier |
| CP758 regressed to SFN/cell-select failure | shows degradation before PRACH |
| CP760/CP764 regressed further to cell-search failure | shows current failure below PRACH |
| CP762 found no visible wrapper/config drift | points away from config drift |
| CP765 found no visible UE RX setup drift | points away from UE software setup drift |
| No temperature telemetry exists in these reports | overheating is not proven or falsified |

The stronger statement is:

```text
Some DL visibility/RF condition changed, but the current artifacts do not show
whether that is antenna heat, bladeRF analog state, cabling/attenuation, gNB TX
state, UE RX sensitivity, interference, or another physical/runtime issue.
```
