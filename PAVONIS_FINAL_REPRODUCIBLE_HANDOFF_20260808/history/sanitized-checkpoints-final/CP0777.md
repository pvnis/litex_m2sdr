# Checkpoint 777 - CP199 versus current raw quality comparison without TX

## Scope

Compare the old CP199 passing raw capture against current failing captures
without transmitting again. This checks whether a gross receiver pathology is
visible in the raw IQ before spending more RF.

Inputs:

- CP199 passing raw: old `0.50 s EXPECTED_CELL_PROVEN` detector proof
- CP772 failing raw: generic RX path at `TX_BACKOFF=10`
- CP776 failing raw: explicit RX1 at `TX_BACKOFF=10`

This checkpoint uses no RF:

- no gNB TX
- no UE PRACH TX
- local analysis only after pulling already-existing raw files

## Interpretation

`CP777_CURRENT_RX1_IS_LOWER_AND_FLATTER_NO_GROSS_IQ_FAILURE`

CP777 finds two important differences:

- the current RX1/generic captures are about 6 dB lower than CP199
- the current spectrum is less center-weighted and looks flatter across the
  capture bandwidth

But the detector degradation is larger than the 6 dB level drop alone:

- CP199: 0.50 s best PSS `0.7673`, expected PCI rank `1`, `PCI1_DOMINATES=1`
- CP772: 0.50 s best PSS `0.1827`, expected PCI rank `242`, `PCI1_DOMINATES=0`
- CP776 RX1: 0.50 s best PSS `0.1821`, expected PCI rank `86`,
  `PCI1_DOMINATES=0`

So the current blocker is not just "a little weak." The receiver sees RF energy,
but the signal quality/correlation content at RX1 is not like the old passing
capture. This is consistent with an installed RF path quality problem, a
transmit waveform quality problem at the receiver, or another non-port RF-chain
effect. It is not explained by DC offset, I/Q imbalance, gross time instability,
or wrong bladeRF RX channel.

The first failed rung remains below PRACH: independent DL SSB/PBCH visibility.
