# Checkpoint 779 - Local low-pass detector sweep without TX

## Scope

Run an offline low-pass sweep over the first 0.50 s of the old detector-proven
capture and two current failing captures. The goal is to test whether the
current flatter/wider spectrum from CP777 is enough to explain the failed PCI1
detector result, and whether suppressing outer-band energy can recover the
expected cell.

This checkpoint uses no RF:

- no gNB TX
- no UE PRACH TX
- local analysis only on already-pulled raw files

There is also no known-good installed physical RF path control. The user has
confirmed with a spectrum analyzer that LiteX SDR TX can emit a signal, but not
that the complete installed path is decodable at the RX side. Therefore this
checkpoint only tests an offline signal-processing hypothesis.

## Interpretation

`CP779_LOWPASS_DOES_NOT_RECOVER_CURRENT_PCI1`

Low-pass filtering did not restore PCI1 dominance on either current failing
capture:

- CP772 stayed `TX_SEEN_BUT_PCI_NOT_PROVEN` for all variants.
- CP776 RX1 stayed `TX_SEEN_BUT_PCI_NOT_PROVEN` for all variants.
- The best PSS score improved under narrower filters, but the expected PCI rank
  remained wrong and PCI1 never dominated.

The same filtering also damaged the old CP199 passing capture:

- raw CP199 remained the reference pass: PCI1 rank `1`,
  `PCI1_DOMINATES=1`, `EXPECTED_CELL_PROVEN`
- `1800 kHz` low-pass dropped CP199 to PCI1 rank `81`
- `1200 kHz` low-pass kept PCI1 at rank `1`, but only low margin
- `600 kHz` low-pass dropped CP199 to PCI1 rank `10`

This means the CP777 flatter-spectrum observation is still real, but it is not
explained by a simple removable outer-band-noise component. A naive offline
low-pass is not a recovery path and is not a good ladder step.

The current failed rung remains independent DL SSB/cell visibility below PRACH:
current RX1 captures show energy from the bounded gNB window but do not produce
a stable expected PCI1 result. Since there is no known-good installed physical
path to compare against, the next useful checkpoints should continue to avoid
unbounded UE TX and focus on bounded capture controls, TX/RX timing, gain state,
clock/[interface-redacted] assumptions, and detector-independent raw comparisons.
