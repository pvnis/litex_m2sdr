## Interpretation

CP785 establishes a repeatable LiteX-originated RF baseline through the installed path. The AD9361 BIST tone was strong, stable, and absent in the no-TX captures. This means the independent bladeRF RX path, the installed RF path at least for a CW tone, and the LiteX/AD9361 RF output path can work repeatably.

This changes the current fault isolation:

- CP784 native host-DMA tone: not visible above no-TX captures.
- CP785 AD9361 BIST TX tone: clearly visible and repeatable.

Therefore the current failure is no longer best explained by "the installed RF path is generally dead" or "the bladeRF capture setup cannot see LiteX output." The next suspect layer is between host-generated samples and the AD9361 RF output: DMA TX routing, crossbar/mux selection, channel layout, stream activation, sample formatting, TX gating, or Soapy/gNB-specific TX path behavior.

This checkpoint does not prove the NR SSB/gNB waveform is correct. It proves only that a low-level AD9361 internal CW tone can traverse the RF path repeatably.
