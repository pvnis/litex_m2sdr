offline mix, low-pass, and decimate transform. CP810 attempted to replay that

Manual sanity checks after the scripted run showed:

- The upstream default `nr_cell_search_test` simulation still passes.
- The same harness does not validate the Band 3 / 15 kHz SSB simulation used by Pavonis.
- `nr_sa_cell_search_test` with the Band 3 settings starts the actual SA cell-search path but does not complete when the cell is not acquired; it repeatedly rejects zero-SNR candidates and must be bounded externally.

## Interpretation

CP810 is a harness limitation checkpoint, not a radio failure checkpoint.

`nr_cell_search_test` file mode was not suitable as the decisive Pavonis replay
harness because its own Band 3 / 15 kHz simulation did not detect PCI 1. The
result does not override CP809. It only says that this particular higher-level
measurement test is not a clean replay vehicle for the current Band 3 case.

The next checkpoint therefore used the lower-level `ssb_file_test`, which
directly exercises `srsran_ssb_csi_search` and `srsran_ssb_search` on CF32
files.
