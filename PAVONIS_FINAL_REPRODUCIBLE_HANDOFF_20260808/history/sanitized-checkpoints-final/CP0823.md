## Interpretation

CP823 is the cleanest boundary test so far:

```text
Same-window zero-copy TX ring PBCH/MIB: PASS
Same-window bladeRF RF PSS/SSS/PCI: present at 0.25 s
Same-window bladeRF RF PBCH/SFN: KO in one-second score and 847 aligned windows
```

This moves the active failure boundary downstream of the normal zero-copy TX
ring. The remaining suspects are now the TX consumption/RF egress path, the
physical RF path, bladeRF receive behavior, and/or receive-side PBCH tolerance.
It is no longer plausible that the current gNB waveform, Soapy pre-DMA samples,
or zero-copy ring payload simply lack PBCH.

The CP823 RF level is slightly hotter than CP813 (`-15.83 dBFS`, max estimate
`[date-redacted]`, small clip estimate), so the next RF-side rung should reduce only the
bladeRF receive gain or bandwidth while preserving the paired TX dump. A good
single-variable follow-up is the same paired run at bladeRF gain `43` or `42`,
then rerun the same RF PBCH/window scoring.
