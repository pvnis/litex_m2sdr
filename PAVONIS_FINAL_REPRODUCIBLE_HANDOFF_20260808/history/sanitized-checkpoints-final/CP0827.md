## Interpretation

Copy-mode PBCH is still OK while recent zero-copy post-DMA PBCH is KO. This
rules out a broad current gNB waveform or analyzer failure and points at one of:

```text
zero-copy ring contents,
the zero-copy diagnostic dump point,
zero-copy state after prior RF/TX runs,
or a zero-copy-specific interaction with the current LitePCIe reader/ring logic.
```

The immediate next check is a zero-copy repeat after this copy-mode run. If it
stays KO, the anomaly is path-specific and currently reproducible.
