still saw RF PBCH KO. CP830 lowers only bladeRF receive gain to `42` while
keeping the same paired TX/RF geometry, to test whether reducing receive level

## Interpretation

Gain `42` improves the RF synchronization side relative to the gain `43`
repeat:

```text
Remote detector PCI1 rank: 1 at 0.10 s, 0.25 s, and 0.50 s
Aligned-window CSI PCI1 windows: 81
Clipping: 0
PBCH CRC OK windows: 0
```

The same-window zero-copy TX ring remains valid, so the RF PBCH KO is still
downstream of the normal LiteX DMA ring. Lower receive gain helps PSS/SSS/PCI
classification but does not by itself recover PBCH/MIB. The next receive-gain
rung should test `41` with the same paired control before changing bandwidth.
