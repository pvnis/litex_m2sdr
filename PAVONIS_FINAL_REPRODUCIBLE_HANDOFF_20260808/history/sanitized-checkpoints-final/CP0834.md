same waveform passes in copy-mode. CP834 immediately repeats zero-copy after
the copy-mode pass to test whether the zero-copy state recovers again, as it

## Interpretation

The zero-copy anomaly is state-dependent:

```text
CP832 zero-copy TX-only: post-DMA PBCH KO
CP833 copy-mode TX-only: post-DMA PBCH OK
CP834 zero-copy TX-only: post-DMA PBCH OK
```

This repeats the earlier CP827/CP828 behavior. The immediate RF ladder can
resume, but only paired runs with same-window post-DMA PBCH OK should be used
as clean RF datapoints. The next clean RF step is to repeat gain `41` now that
zero-copy has recovered, or move to bandwidth testing at the known-clean gain
`42`.
