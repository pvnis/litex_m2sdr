# Checkpoint 838 - Offline CFO correction sweep: no PBCH recovery

## Purpose

CP837 varied only the SSB frequency metadata and did not recover PBCH. CP838
tests the stronger frequency hypothesis by actually rotating the captured IQ
samples over a range of CFO corrections before running `ssb_file_test`.

## Method

Added helper:

```text
cp838_cfo_correction_sweep.py
```

The helper:

- Reads a saved `SC16` RF capture.
- Applies complex sample rotations from `-30000` to `+30000` Hz.
- Runs `ssb_file_test` on each corrected one-second vector.
- Keeps `center=1839650000` and `SSB=1839650000`.

## Interpretation

Applying explicit IQ frequency corrections does not recover PBCH:

```text
CP835 CFO sweep: 0/21 PBCH CRC OK
CP830 CFO sweep: 0/21 PBCH CRC OK
```

This rules out the simple residual-CFO explanation for the observed RF PBCH KO.
The RF captures still contain enough structure for expected PCI to appear under
many corrections, but PBCH remains PCI `0` / CRC `KO`.
