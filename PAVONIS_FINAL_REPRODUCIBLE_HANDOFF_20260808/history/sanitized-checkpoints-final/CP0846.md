## Interpretation

The CP830 gain42 raw remains PBCH-undecodable under a broad local scan of
frequency shifts and both pattern A/C. The decoder does repeatedly find
expected PCI 1 under some shifts, so the issue is not simply "no expected cell
structure present." The active failure remains that PBCH payload decoding
cannot survive the RF path even when same-window TX memory contains a valid
PBCH waveform.
