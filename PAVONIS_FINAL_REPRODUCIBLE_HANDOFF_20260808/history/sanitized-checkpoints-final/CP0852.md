## Interpretation

The wideband SSB-offset probe is captured at a healthy level with no clipping, but it does not correlate cleanly with the transmitted reference. The long-template scores remain near random-search levels, even with a `+/-100 kHz` CFO search. A short `4096`-sample template finds only weak local correlation (`0.094`), far below the `~1.0` positive controls.

Together with CP849, the current split is:

- narrowband CF32 tone via `test_play.py`: PASS
- SSB-width offset OFDM-like probe via `test_play.py`: weak/no clean correlation
- known-good PBCH vector via `test_play.py`: no PBCH decode and no clean reference correlation

This points at a wideband/offset waveform impairment in the RF path or TX/RX analog filtering/clocking assumptions, not a simple dead transmitter, dead bladeRF receiver, or CF32 file replay format failure.
