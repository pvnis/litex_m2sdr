## Interpretation

The LiteX Soapy file replay path can carry the SSB-offset wideband waveform, and LiteX RX can recover it with strong reference correlation. This rules out basic CF32 file replay, LiteX Soapy TX, and the generated wideband probe as the cause of CP852's bladeRF weak-correlation result.

The current failure boundary is now outside the LiteX internal RX/TX path. The likely area is the physical RF path into bladeRF, bladeRF receive configuration/calibration, antenna/cabling/coupling geometry, or a bladeRF-specific wideband capture impairment. This also makes the earlier PBCH RF failures more likely to be bladeRF/physical-path receive failures than live-gNB or LiteX waveform-generation failures.
