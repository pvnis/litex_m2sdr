## Interpretation

Gain mode is not the missing fix.

The manual-gain branch does take effect after the bladeRF RX channel is enabled, and AGC/no-gain produce much higher capture levels without improving correlation. The bladeRF receive path remains weak even when:

- LiteX TX/RX file replay is proven good in CP861
- bladeRF bandwidth is narrowed in CP862
- RF level is increased in CP863
- the one-subcarrier probe is moved away from DC in CP864
- manual gain, no explicit gain, and AGC are all tried in CP866

The remaining fault boundary is still bladeRF/physical receive behavior, but no longer simple RX gain mode. Next useful probes are bladeRF correction/calibration state inspection, IQ orientation/correction checks, and a simpler non-OFDM phase-continuity waveform to see whether the bladeRF path is distorting symbol-to-symbol phase rather than only reducing SNR.
