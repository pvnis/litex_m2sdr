## CLI Findings

The `calibrate` help exposes:

- `calibrate dc <rx|tx> [<I> <Q>]`
- `calibrate dc <rxtx>`
- `calibrate iq <rx|tx> <gain|phase> <value>`
- `calibrate table dc <rx|tx> ...`
- `calibrate table agc <rx|tx> ...`
- LMS internal DC operations

The `print` help does not expose a `correction` parameter on this CLI build.

Both attempted correction readbacks failed:

```text
print: Invalid parameter (correction)
Error: Invalid parameter provided
```

## Interpretation

CP867 confirms that this bladeRF CLI can run DC/IQ calibration operations, but it does not provide a simple `print correction` readback command. Calibration should not be run blindly because the CLI help includes operations that can set correction parameters or write calibration tables.

The next safe step is to inspect bladeRF2 state and active RX routing without mutating calibration.
