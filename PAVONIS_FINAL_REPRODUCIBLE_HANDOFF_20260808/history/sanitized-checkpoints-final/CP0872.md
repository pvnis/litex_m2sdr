## Interpretation

CP872 rules out `test_play.py` as the primary explanation.

The custom Soapy streamer wrote every intended sample with no timeouts or errors, yet the bladeRF capture still contains a strong target-bin component that does not carry the transmitted symbol sequence.

The full-waveform score improved from CP871 `0.2686` to CP872 `0.3739`, but the direct symbol checks remain decisive:

- target-bin energy is strong
- phase sequence is not the transmitted QPSK sequence
- circular symbol search does not find a hidden symbol/reference offset

The next rung should reduce the modulation bandwidth dramatically: transmit a slow phase-coded tone at the same offset. If slow phase changes pass, the path is acting like a very narrow/memory-heavy channel. If slow phase changes also fail, the bladeRF is probably seeing a coherent leakage/spur component rather than the intended modulated RF output.
