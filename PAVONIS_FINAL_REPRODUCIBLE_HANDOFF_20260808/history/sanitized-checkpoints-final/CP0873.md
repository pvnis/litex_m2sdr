# Checkpoint 873 - Circular Symbol Sequence Search

## Purpose

Validate the CP870 symbol-projection conclusion by searching over:

- all `384` possible sample-boundary offsets
- circular reference-symbol offsets
- a CFO grid
- normal and conjugate capture transforms

This avoids assuming that CP851's best whole-waveform start aligns with reference symbol `0`.

## Analyzer

- Script: `cp873_symbol_sequence_search.py`
- Search method:
  - project the target subcarrier per symbol
  - accumulate capture symbols modulo the reference period
  - use circular correlation to find the best reference-symbol offset
  - scan sample-boundary offset and CFO

## Interpretation

CP873 validates the local analysis method:

- The LiteX-only control scores `0.969`.
- The bladeRF `test_play.py` capture scores only `0.048`.
- The bladeRF custom-streamer capture scores only `0.043`.

Therefore the missing sequence is not a trivial start-symbol, sample-boundary, CFO, or conjugation issue.

Combined with CP872's clean TX counters, the current evidence says:

```text
LiteX host stream writes all intended modulated samples.
bladeRF captures a strong component at the intended subcarrier.
That component does not contain the transmitted phase-symbol sequence.
```

The next probe should test phase-change bandwidth directly with a much slower phase-coded tone.
