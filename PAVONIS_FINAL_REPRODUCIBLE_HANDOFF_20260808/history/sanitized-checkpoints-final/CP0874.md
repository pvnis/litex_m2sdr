# Checkpoint 874 - Slow Phase-Coded Tone

## Purpose

Test whether the LiteX-to-bladeRF path can carry much slower phase modulation.

CP871/CP872 showed that a one-subcarrier QPSK sequence changing every `384` samples (`66.7 us`) is not recovered, even though the target bin is energetic. CP874 slows the phase changes to one QPSK phase every `10 ms`.

## Interpretation

CP874 is a partial positive and a sequence-level negative:

- A short segment of the slow phase-coded tone correlates strongly (`0.8595`), unlike the fast `66.7 us` phase-symbol probes.
- The full slow QPSK phase sequence is still not recovered cleanly. The best high-projection sequence score is only about `0.266`.

This suggests the path can carry a coherent tone and possibly short locally constant phase segments, but it is still not preserving the intended phase transitions reliably.

The next clean discriminator is a simpler phase-transition probe, such as a single BPSK phase flip halfway through the file. That avoids random QPSK sequence ambiguity and directly tests whether bladeRF sees a commanded `180 deg` phase transition.
