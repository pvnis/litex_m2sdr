## Interpretation

CP875 is the first clean phase-transition pass:

- custom LiteX streamer wrote all samples cleanly
- bladeRF captured a level-valid signal
- a deterministic, very slow `180 deg` phase flip is visible as about `164 deg`

Combined with CP871-CP874:

- pure tones pass
- a single slow phase flip passes
- short locally constant tone segments pass
- random QPSK phase changes every `66.7 us` do not pass
- random QPSK phase changes every `10 ms` are still weak as a sequence

The failure now looks like phase-transition bandwidth/coherence in the current physical/bladeRF receive path, not a dead TX, not dead RX, not `test_play.py`, and not simple gain/BW/clipping.

Next useful rung: sweep deterministic phase-flip period downward, for example `20 ms`, `10 ms`, `5 ms`, `2 ms`, `1 ms`, to estimate the phase-transition bandwidth of the installed path.
