# Checkpoint 876 - Phase Flip Period Sweep

## Purpose

Estimate the current RF path's ability to preserve deterministic phase transitions by sending one composite LiteX TX probe and receiving it with bladeRF:

```text
+495 kHz tone, BPSK phase alternation
segments: 20 ms, 10 ms, 5 ms, 2 ms, 1 ms dwell
```

This is the direct follow-up to CP875, where a single very slow `180 deg` phase flip was visible. CP876 asks where the path stops preserving repeated phase flips.

## Caveat

The first broad CFO pass over this composite probe was misleading: the dense fast sections can bias the best global fit. The final result above uses the stable fine pass around `2911 Hz`, where the per-segment behavior is coherent and matches the expected ladder: slow dwells pass and fast dwells fail. Treat the threshold as a current-path estimate, not an intrinsic hardware specification.

## Interpretation

CP876 establishes a deterministic phase-transition threshold for the current LiteX TX to bladeRF RX path:

- `20 ms` dwell: pass
- `10 ms` dwell: pass
- `5 ms` dwell: pass, with more phase spread
- `2 ms` dwell: fail
- `1 ms` dwell: fail

The transition is therefore between `5 ms` and `2 ms` under the current path and settings. This is consistent with CP875 proving a very slow single flip is visible, while CP871-CP874 showed that fast modulated phase sequences are not recovered even when tone energy is strong.

Next useful rung: run a LiteX-only RX/TX baseline with this same phase-flip style probe to isolate bladeRF from the result, then refine the threshold between `5 ms` and `2 ms`.
