## Interpretation

CP879 proves bladeRF can recover this compact deterministic BPSK phase ladder down to `1 ms` in the current session when the analysis is anchored by a full-period reference. This contradicts any simple "bladeRF cannot receive 1 ms phase flips" conclusion.

The important nuance is sequence/run dependence:

- CP877 proves the LiteX-only path is clean down to `1 ms`.
- CP878 shows a broader `3-2 ms` bladeRF ladder is recoverable but `2 ms` can degrade depending on anchor.
- CP879 shows a compact full-period ladder is strongly recoverable through `1 ms`.

So the current problem is not a fixed physical bandwidth limit at `2 ms`. The failure mode looks more like intermittent or sequence-dependent full-waveform coherence loss in the bladeRF/physical receive path, plus analysis sensitivity when using composite probes without a full-period anchor.
