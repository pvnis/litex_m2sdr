- But CP876 still represents poor full-sequence bladeRF recovery: full-period reference correlation is only `0.405`.
- CP879, by contrast, has full-period correlation `0.897` and clean `1 ms` dwell recovery.

The updated conclusion is:

- LiteX-only RX/TX is known-good for the phase-flip probe family from CP877.
- bladeRF can recover compact deterministic phase-flip ladders down to `1 ms` in CP879.
- bladeRF did not recover the broader CP876 full sequence coherently.

So the remaining unexplained behavior is sequence/run-dependent bladeRF/physical-path coherence, not a fixed inability to receive sub-2 ms phase flips.
