## Interpretation

CP881 is the cleanest evidence so far that the bladeRF path problem is tied to coherent recovery over a longer template duration, not simply to fast phase transitions.

The same dwell ladder that passed in CP879 degrades when the period is doubled from `0.15 s` to `0.3 s`. The capture level is healthy, there is no clipping, and the custom LiteX TX wrote every sample cleanly. This points toward time-varying phase/CFO/coherence behavior in the bladeRF/physical receive path.

Next useful rung: repeat the CP879 short-period probe once to confirm that `0.15 s` remains repeatably clean after CP881, then test an intermediate duration if we need a finer boundary.
