## Interpretation

CP883 confirms CP881 is not a simple "this waveform is not recoverable" failure.

The same CP881 bladeRF capture has recoverable `0.15 s` local windows:

- first half: strong local match, `0.891`
- second half: decent local match, `0.771`

But the complete `0.3 s` period only scores `0.452`. That means the bladeRF/physical path preserves local chunks better than one coherent alignment across the full `0.3 s` duration.

This reinforces the current model:

- fast phase transitions down to `1 ms` can pass
- local `0.15 s` coherence can pass
- coherence over `0.3 s` can degrade badly

The next useful rung is to test explicit phase/CFO drift compensation or shorter analysis windows on the original broader CP876/CP881 captures before spending more RF time.
