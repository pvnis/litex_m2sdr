- gross timing/sample slip across the period, or

This is local analysis only. No RF transmission was run.

## Interpretation

CP884 rules out gross timing slip as the main reason CP881's full `0.3 s` template fails. All four quarter windows independently imply almost the same full-period start, within `8` samples.

But each quarter only becomes a strong match with its own local CFO choice:

- q0: `3480 Hz`
- q1: `3430 Hz`
- q2: `3470 Hz`
- q3: `3480 Hz`

That is consistent with phase/CFO curvature over the full period. Local `0.075 s` and `0.15 s` windows are recoverable, but one static CFO over `0.3 s` is not sufficient.

Updated model:

- CP879/CP882 show `0.15 s` full-period recovery is repeatable.
- CP881 shows `0.3 s` full-period recovery can fail.
- CP883/CP884 show CP881 contains strong local windows with consistent timing.
- The remaining issue is therefore not missing signal, clipping, bad TX, or sample slipping; it is likely time-varying phase/frequency behavior in the bladeRF/physical receive path.

Next useful rung: implement a piecewise-CFO or phase-detrended full-period analysis on CP881. If piecewise correction recovers the full `0.3 s` period, the diagnosis becomes much more concrete.
