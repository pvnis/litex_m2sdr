## Interpretation

CP886 turns the CP881 coherence failure into a concrete pattern:

- the capture contains excellent local quarter-window matches
- those excellent quarters are distributed across different transmitted repetitions
- no single captured `0.3 s` repetition has all quarters coherent

This supports a bursty/local coherence model rather than a simple CFO value problem:

- static full-period correction fails
- per-quarter CFO at one fixed start fails
- quarter-local search succeeds, but selects different repetitions

The next useful rung is to determine whether the bursty coherence is periodic in capture time or related to absolute capture position/RF level. That can be done locally by expanding the heatmap to shorter windows or by one more repeated capture of the same CP881 waveform if RF time is acceptable.
