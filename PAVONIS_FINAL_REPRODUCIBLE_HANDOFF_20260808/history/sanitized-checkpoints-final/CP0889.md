## Interpretation

This strongly supports the CP887 theory: the CP881 bladeRF capture is not simply missing the signal, and the problem is not the CP881 waveform or LiteX TX path. A time-varying phase/frequency correction recovers one full physical period that a single-CFO analysis could not.

The limitation is also important: the same global linear model does not recover the second full period (`2630850`) beyond `0.303`. That means a single capture-wide linear CFO model is still incomplete. The next useful rung is a per-period or piecewise phase model using CP887's window phases and CFOs, rather than only a global linear CFO slope.
