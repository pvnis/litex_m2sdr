# Checkpoint 890 - CP881 Piecewise Window Phase Recovers Both Full Periods

## Purpose

Follow CP889 by testing whether the remaining CP881 full-period failure is caused by unmodeled phase jumps between windows. CP889 showed that a global linear CFO correction can recover one full physical period, but not the next one. CP890 uses the CP887 per-window CFO and dot-phase estimates directly as a diagnostic equalizer.

This is not a proposed live receiver yet. It is a localization test: if per-window CFO plus phase alignment recovers the fixed periods, then the signal is present and the remaining failure is phase/coherence modeling rather than missing RF energy.

## Interpretation

This is the clearest result in the current branch:

- CP888 proved the same CP881 waveform and LiteX RX/TX path are healthy.
- CP887 proved every fixed `37.5 ms` CP881 bladeRF window is locally recoverable.
- CP889 proved a time-varying CFO model can recover one complete period.
- CP890 proves both full physical periods are recoverable when each window gets its own CFO and phase alignment.

The important negative result is that per-window CFO alone does not recover the periods. The missing piece is not just smooth frequency drift; there are window-to-window phase offsets or phase discontinuities that a single CFO or single linear CFO model cannot absorb.

The current failure boundary is therefore narrowed to bladeRF-side or physical-path phase coherence over tens to hundreds of milliseconds. The next useful step is to characterize those phase jumps directly, then test whether they are stable across a fresh bladeRF capture or vary run-to-run.
