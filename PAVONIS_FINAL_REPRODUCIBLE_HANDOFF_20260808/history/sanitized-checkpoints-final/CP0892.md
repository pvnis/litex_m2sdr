## Interpretation

The current LiteX-to-bladeRF path still carries a strong narrowband tone: high SNR, exact expected byte count, no clipping, and stable window FFT peak tracking. This rules out a completely dead RF path at the time of CP892.

However, the tone is not well described as one continuous coherent sinusoid over `10 ms` windows. The FFT peak stays in a narrow `504.3..504.5 kHz` range, but fixed-frequency coherent means and autocorrelation are poor. This is consistent with a path that has enough energy for spectral detection but has phase/coherence impairments that can break longer coherent waveform analyses.

This does not by itself prove the antenna or bladeRF is overheating, but it supports the broader post-CP891 theory: the bladeRF/physical path is not giving us a stable coherent baseband reference, even when a simple tone is visibly present.

The next useful rung is to compare this CP892 phase-stability analyzer against the older CP847 tone capture. If the old tone capture has the same poor continuous-phase behavior, then this has been a standing limitation of the tone harness/path. If the old capture is cleaner, then CP892 captured a new degradation.
