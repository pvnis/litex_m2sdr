## Interpretation

CP908 proves RFIC BIST loopback can return a strong, unclipped 100 kHz tone.
That is an important result: the RFIC-adjacent internal path is not dead.

However, this first RFIC BIST run is not a clean stability verdict because the
stimulus had two avoidable artifacts:

1. RX was started before TX, producing a bad startup window (`window 0`).
2. The repeated tone file length was `262144` samples. At `100 kHz` and
   `5.76 Msps`, that is not an integer number of tone cycles, so every file
   repeat can introduce a deterministic phase discontinuity.

Those artifacts are enough to explain the CP892 `WARN` without concluding that
RFIC BIST has the same random-looking coherence failure as the external RF
capture path.

The next checkpoint should rerun RFIC BIST with:

- an integer-cycle tone file length, for example `258048` samples
  (`258048 / 288 = 896`, and `288` samples contain exactly five 100 kHz cycles
  at 5.76 Msps),
- TX started before RX to avoid capturing startup silence,
- the same CP892/CP904 analysis.
