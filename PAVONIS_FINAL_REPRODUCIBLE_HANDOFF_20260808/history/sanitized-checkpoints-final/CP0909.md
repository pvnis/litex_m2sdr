## Interpretation

CP909 passes cleanly and resolves CP908's `WARN` as a stimulus/setup artifact.

With a continuous integer-cycle stimulus and TX-before-RX sequencing, RFIC BIST
loopback is perfectly coherent by the current CP892/CP904 metrics. This means
the large phase discontinuities seen on the external LiteX-TX to bladeRF-RX
captures are not caused by:

- local analysis,
- raw-file handling,
- bladeRF RX USB streaming,
- bladeRF host TX streaming,
- firmware sample loopback,
- RFIC BIST loopback.

The remaining fault boundary is now narrower: the bladeRF normal external RX
path below RFIC BIST, the RF switch/front-end path into RX1/RF3(B), correction
state that only affects normal RF receive, or the physical path from LiteX TX to
bladeRF RX.
