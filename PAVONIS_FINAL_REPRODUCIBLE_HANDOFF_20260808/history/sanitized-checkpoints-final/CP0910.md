and RFIC BIST loopback changed the normal external path. It uses the known CP894

## Interpretation

CP910 confirms the normal external path is still degraded after the clean
firmware-loopback and RFIC-BIST-loopback tests.

The result is internally consistent with CP902, CP903, CP904, and CP905:

- strong RF energy at the expected tone offset,
- no clipping,
- stable FFT-bin peak,
- poor coherent phase behavior,
- many window-to-window phase jumps after removing a global phase slope.

The important contrast is now:

| Path | Result |
| --- | --- |
| CP907 firmware sample loopback | coherent, `PASS` |
| CP909 RFIC BIST loopback | coherent, `PASS` |
| CP910 external LiteX TX to bladeRF RX1/RF3(B) | strong tone but incoherent phase behavior |

That pushes the likely fault boundary out of bladeRF host streaming and internal
loopback paths, and back onto the normal external RX chain: RF switch/front-end,
normal RF receive correction state, or the physical path from LiteX TX to
bladeRF RX1/RF3(B).
