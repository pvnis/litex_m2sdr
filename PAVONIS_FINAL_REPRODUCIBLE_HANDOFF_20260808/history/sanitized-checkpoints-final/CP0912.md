`500 kHz` tone offset used by CP894/CP910/CP911.

captures bladeRF RX1/RF3(B) with the same normal settings as CP910:

- bladeRF loopback `none`

- RX bandwidth `2 MHz`
- manual RX gain `42`

The new CF32 file is exactly one second long and contains exactly `100000`
cycles, so replay looping should not introduce phase discontinuities.

## Interpretation

The external-path coherence failure is not specific to the `500 kHz` tone
offset.

The `100 kHz` external tone looks materially the same as the `500 kHz` external
tone:

- strong FFT tone,
- no clipping,
- similar RMS level,
- similar poor FFT-peak coherence,
- similar poor autocorrelation coherence,
- many phase jumps after removing a global phase slope.

This closes the tone-offset branch for the current deterministic setup. The
normal external RX path remains the only branch showing the failure; firmware
loopback and RFIC BIST loopback remain clean.
