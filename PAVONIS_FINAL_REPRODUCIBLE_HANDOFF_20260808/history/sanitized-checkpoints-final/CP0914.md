# Checkpoint 914 - Tone Image Structure Local Analysis

## Purpose

Analyze whether the external LiteX-to-bladeRF coherence failure is primarily an
image/mirror-tone problem.

This checkpoint is local-only. It performs no SSH, no RF operation, no bladeRF
state change, and no calibration/correction write.

The analyzer compares:

- the CP894 generated source CF32 tone,
- CP896 LiteX-only CF32 captures,
- CP909 clean bladeRF RFIC BIST capture,
- CP910 external LiteX-to-bladeRF `500 kHz` capture,
- CP912 external LiteX-to-bladeRF `100 kHz` capture.

## Method

For each capture, CP914:

1. Finds the measured FFT peak near the expected tone and uses that as `f_fit`.
2. Measures the mirror/image peak near `-f_fit`.
3. Fits a least-squares model:

   ```text
   x = a*exp(+j*2*pi*f_fit*t) + b*exp(-j*2*pi*f_fit*t) + c
   ```

4. Repeats the fit in `10 ms` windows and measures fitted-tone phase residuals
   after removing a global linear phase slope.
5. Lists the strongest non-nearby spectral peaks.

The first exploratory CP914 run used nominal frequency for the least-squares
fit. That was intentionally superseded because the external captures include
CFO. The authoritative output is the v3 run below, which fits at measured
`f_fit`.

## Sideband Observations

The generated source file is clean; its non-main peaks are below about
`-164 dBc`.

The LiteX-only captures have deterministic sidebands around the main tone. The
strongest are near:

- `500 kHz + 5636 Hz`, about `-12 dBc`,
- `500 kHz - 5636 Hz`, about `-12 dBc`.

Despite those sidebands, the LiteX-only fitted-tone phase remains coherent:

- phase RMS `0.462-1.740 deg`,
- no `>60 deg` phase steps.

The external bladeRF captures also show sidebands/spurs, but their fitted-tone
phase is unstable:

- phase RMS about `101-105 deg`,
- `41-47` steps above `60 deg`.

## Interpretation

The external failure is not primarily explained by a dominant mirror/image tone.

There is a measurable external-path image around `-37 dBc`, which is worse than
the LiteX-only `-51` to `-55 dBc` spectral image floor. That could still be
consistent with normal-RF receive I/Q correction imperfections. However, the
image is far below the main tone and does not explain the main discriminator:
large fitted-tone phase instability appears only on the external bladeRF receive
captures.

The deterministic sideband comb is also not sufficient to explain the failure,
because the LiteX-only captures contain strong sidebands near `+/-5636 Hz` from
the tone and remain phase coherent.

CP914 therefore sharpens CP913:

- source CF32 tone: clean,
- LiteX-only path: sidebanded but coherent,
- bladeRF RFIC BIST: clean and coherent,
- external LiteX-to-bladeRF normal RX: sidebanded and phase-unstable.

The likely boundary remains the normal external bladeRF RX chain or the
installed physical path into RX1/RF3(B), not a pure image-tone artifact.
