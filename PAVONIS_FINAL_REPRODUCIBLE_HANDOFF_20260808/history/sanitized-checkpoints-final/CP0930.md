# Checkpoint 930 - Long external tone shows sustained phase-jump bursts

## Purpose

CP927 showed the current external LiteX/M2SDR TX to bladeRF RX tone path still
has large phase jumps in a two-second capture. CP928 then showed the bladeRF
RFIC BIST internal path remains coherent.

CP930 repeats the external tone path as a four-second capture:

```text
LiteX/M2SDR TX deterministic 500 kHz tone -> installed RF path -> bladeRF RX1/RF3(B)
```

The goal is to check whether the phase instability is sparse/recoverable or
whether it can enter a longer sustained failure mode without changing any
bladeRF calibration or correction state.

## Interpretation

CP930 strengthens the CP927/CP929 result:

```text
LiteX-only RX/TX: PASS
bladeRF RFIC BIST internal path: PASS
LiteX TX -> bladeRF normal external RX: FAIL, strong unclipped tone but
                                      sustained late phase-jump bursts
```

The four-second capture shows the external bladeRF receive path can enter a
much more severe sustained mode than the two-second capture: the late section
has adjacent 10 ms windows repeatedly stepping by about 170 to 180 deg after a
single global phase slope is removed.

This is not explained by missing RF energy, clipping, or the LiteX source path.
No calibration or correction mutation was performed. The first failed ladder
rung remains Stage 5 RF receive coherence/PBCH at the bladeRF/external path.
Do not move to PRACH/Stage 6.
