## Purpose

After CP931 reconfirmed the LiteX-only PBCH/vector baseline, repeat the CP930
four-second external tone capture without changing settings:

```text
LiteX/M2SDR TX deterministic 500 kHz tone -> installed RF path -> bladeRF RX1/RF3(B)
```

This checks whether CP930's late sustained phase-burst state is repeatable in
the current hardware/software state.

## Interpretation

CP933 reproduces the CP930 failure class after the CP931 LiteX-only baseline:

```text
Strong unclipped tone: yes
Normal bladeRF external RX route: yes
LiteX-only source/RX baseline: PASS in CP931
External LiteX TX -> bladeRF RX phase coherence: FAIL again
```

The repeat is not numerically identical to CP930, but it has the same structure:

- early burst in the first `0.5 s`;
- quiet middle around `1.0-2.0 s`;
- transition after `2.0 s`;
- near-continuous large phase steps by `2.5-3.0 s`;
- sustained `100%` `>=60 deg` event fraction after `3.0 s`.

This makes the "we did not change anything and now we cannot receive anything"
concern less ambiguous: the LiteX side is currently good, while the external
bladeRF receive path repeatedly enters a time-dependent phase-burst failure
mode under the same deterministic tone test.

The first failed ladder rung remains Stage 5 RF receive coherence/PBCH at the
bladeRF/external path. Do not move to PRACH/Stage 6.
