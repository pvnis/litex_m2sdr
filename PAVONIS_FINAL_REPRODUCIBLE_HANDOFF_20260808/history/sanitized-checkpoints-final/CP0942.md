# Checkpoint 942 - Centered SSB dec2 external PBCH still fails

## Purpose

CP940 and CP941 showed that the original CP823 PBCH replay still fails through
bladeRF even with `dec2`, and that the failure is not explained by the default
correlation scan window or CFO range. CP942 removes another variable: the
11.52 Msps source with the SSB off-center in the TX passband.

This checkpoint replays the already SSB-centered 5.76 Msps reference directly at
the bladeRF capture center:

```text
CP918 SSB-centered 5.76 Msps PBCH-positive reference
  -> LiteX TX at 1839.65 MHz
  -> external RF path
  -> bladeRF RX at 1839.65 MHz, 5.76 Msps, 5.6 MHz BW, dec2
```

No bladeRF calibration or correction state was changed.

## Interpretation

CP942 removes the original off-center transmit arrangement as the primary
explanation. The local centered source is PBCH-positive, but after external RF
capture through bladeRF `dec2`, the expected waveform is still not coherently
present.

Current boundary:

```text
Centered 5.76 Msps PBCH source: local decode PASS
Centered LiteX TX -> bladeRF dec2 RX: capture execution PASS, PBCH FAIL
Reference correlation after RF: noise-floor score around 0.025
```

The next remaining comparison is to run the same centered 5.76 Msps replay with
bladeRF RX FIR `normal`. If `normal` also fails, the failure is independent of
the tested PBCH waveform centering and FIR choice; if `normal` improves, then
`dec2` is only tone-helpful and not PBCH-helpful.
