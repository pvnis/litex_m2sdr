external bladeRF path with the normal RX FIR at the usual `TX_ATT_DB=20`. CP944
changes only the LiteX TX attenuation from `20 dB` to `15 dB`, a modest +5 dB
source-side level increase intended to test whether the centered PBCH failure is
simply a level/SNR problem.

## Interpretation

CP944 keeps the first failed rung at Stage 5 external bladeRF reception. The
centered PBCH failure is now isolated away from a modest TX level change as
well as the earlier FIR and frequency-centering variables.

Important gap found while preparing the next step: CP938 baselined the original
11.52 Msps PBCH vector through LiteX-only RX/TX, but CP942-CP944 used the
centered 5.76 Msps CP918 reference. The next checkpoint should baseline this
centered 5.76 Msps reference through LiteX-only RX/TX before spending more
external RF time.
