# Checkpoint 946 - No-TX bladeRF centered normal matches PBCH failure floor

## Purpose

CP943 and CP944 transmitted the centered 5.76 Msps PBCH-positive source through
LiteX and captured with bladeRF RX FIR `normal`. Both failed PBCH and had
capture levels around `-19.9 dBFS`. CP946 runs the same bladeRF RX settings with
the LiteX transmitter explicitly cleaned up and no replay started.

This tests whether the CP943/CP944 captures are distinguishable from bladeRF's
receive noise floor.

```text
No LiteX TX
  -> bladeRF RX at 1839.65 MHz, 5.76 Msps, 5.6 MHz BW, normal FIR, gain 42
  -> same PBCH/window/correlation analyzers
```

No bladeRF calibration or correction state was changed.

## Interpretation

CP946 is a strong boundary checkpoint:

```text
Centered source local decode: PASS
Centered source LiteX-only TX/RX: PASS
Centered source LiteX TX -> bladeRF RX: indistinguishable from no-TX floor
```

This means the current centered PBCH failure is not explained by the source
file, the LiteX-only replay path, PBCH centering, bladeRF FIR `normal` versus
`dec2`, or modest TX attenuation. At the tested settings, the bladeRF external
PBCH captures do not show a measurable received version of the LiteX source.

The first failed ladder rung remains Stage 5 external bladeRF reception. The
next useful step should compare a simultaneous or near-adjacent simple-tone
capture and centered-PBCH capture under the same RF route and power assumptions,
because CP937 showed a tone can be seen while CP946 shows centered PBCH looks
like no-TX noise.
