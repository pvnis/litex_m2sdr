## Interpretation

CP948 removes the current LiteX source and LiteX RX/TX state as plausible
explanations for the external PBCH failures. The same centered source still
correlates strongly and decodes PBCH through LiteX-only paths after the bladeRF
tests.

The current first failed ladder rung remains Stage 5 external bladeRF reception:

```text
Centered source local decode: PASS
Centered source LiteX-only RX/TX, CP945 and CP948: PASS
Simple tone through external bladeRF route, CP947: PASS
Centered source through external bladeRF route, CP942-CP944: FAIL
No-TX external bladeRF floor, CP946: matches PBCH failures
```

The remaining failure is therefore not "LiteX stopped transmitting" or "the
source file is bad." It is specifically that the external bladeRF path does not
recover the structured centered PBCH waveform even though it can receive a
simple tone at the same RF center.
