# Checkpoint 951 - x2 centered PBCH external bladeRF capture still floor

## Purpose

CP947 proved that the same centered external bladeRF route can receive a strong
500 kHz tone. CP950 produced an x2 centered PBCH source that is locally valid,
strongly correlated through LiteX-only loopbacks, and PBCH-decodable through the
`phy` and `ad9361` loopbacks.

CP951 tests a narrower link-margin question:

```text
Does a +6 dB centered PBCH source rise above the external bladeRF no-TX floor?
```

This is not treated as a pure PBCH pass/fail gate because CP950 had one
LiteX-only full-capture PBCH caveat in the `none` loopback. The primary CP951
metric is external x2-reference correlation versus the prior external floor.

No bladeRF calibration or correction state was changed.

## Interpretation

CP951 does not support "the PBCH source was simply too weak by about 6 dB."
The x2 source is visible and decodable in the LiteX-only `ad9361` loopback, but
through the external bladeRF path it still behaves like receive floor:

```text
x2 source local decode: PASS
x2 LiteX-only ad9361 decode: PASS
x2 external bladeRF PBCH: FAIL
x2 external bladeRF correlation: still floor-like
```

The small correlation increase from about `0.02` to `0.034` is not enough to
change the ladder boundary. The first failed stage remains external bladeRF
reception of structured PBCH/SSB. The successful CP947 tone result still says
the route is not fully dead, but CP951 says a modest broadband PBCH power boost
does not make that waveform recover coherently.
