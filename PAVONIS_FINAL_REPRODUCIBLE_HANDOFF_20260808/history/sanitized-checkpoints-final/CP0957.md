## Interpretation

CP957 passes the LiteX-only x4 gate. The 60-subcarrier centered OFDM probe is valid and recoverable internally at the same safe x4 amplitude used for CP956.

This clears the external bladeRF test for the narrower waveform. If the 60SC x4 external path correlates while the 240SC x4 path does not, the failure boundary is likely occupied bandwidth/coherence related. If it also fails despite visible energy, the next rung should narrow further toward one-subcarrier/tone-like probes.
