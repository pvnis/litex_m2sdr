## Interpretation

Narrowing to 12 subcarriers improves external visibility again:

- CP960 has a strong spectral peak at `31728.5 Hz` with `18.82 dB` peak SNR.
- CP958 60SC had `12.31 dB` peak SNR.
- CP956 240SC had `8.99 dB` peak SNR.
- CP947 tone still remains much stronger at `39.87 dB`.

The CP959 reference correlation also rises above no-TX (`0.0786` vs `0.0197`), so the external capture contains some signal-related structure. But it is still not a valid waveform recovery because the clean internal signature would be a large normal-transform score at 0 Hz. CP960 instead selects an unrelated conjugate/CFO candidate with a low absolute score.

Current conclusion: the external path improves progressively as occupied bandwidth narrows from 240SC to 60SC to 12SC, but still does not preserve enough multi-subcarrier OFDM sequence coherence for CP851 recovery. The remaining boundary is now between 12SC OFDM-like signals and the known narrow tone pass.

## Next rung

- If 1SC sequence does not correlate but CP947 tone remains strong, the issue is not only bandwidth; it is likely tied to sequence/modulation preservation versus a continuous narrow tone.
