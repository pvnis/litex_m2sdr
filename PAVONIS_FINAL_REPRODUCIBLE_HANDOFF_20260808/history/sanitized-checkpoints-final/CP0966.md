## Interpretation

The CP964 external result is repeatable:

- CP966 returns the same best transform (`normal`) and same refined CFO (`[date-redacted] Hz`).
- Correlation is slightly higher but still in the same partial-recovery range (`0.2838` vs `0.2806`).
- Capture RMS is essentially identical after SC16 scaling (`0.37856` vs `0.37850`).
- There is still no digital clipping estimate despite strong received energy.

The lower-gain CP965 run did not improve the result, so the current evidence does not support simple bladeRF digital clipping or high-gain compression as the dominant failure mode.

Current boundary: the external path is stable and visibly strong for centered 1SC x16, but CP851 recovery remains roughly `36%` of the LiteX-only score (`0.284 / 0.784`). The failure is now a stable external coherence/phase/noise issue rather than a silent TX/RX-path issue.

## Next step

Use CP966/CP964 as the stable external baseline and refine analysis rather than adding RF power:

- Run a local CP851 variant focused around the repeatable `0..5000 Hz` CFO area and inspect whether start/CFO ambiguity is limiting the score.
- Then, if needed, test a slightly more structured 1SC reference or a short known phase sequence to separate frequency-offset drift from waveform distortion.

Do not increase amplitude above x16 until the CFO/start ambiguity has been characterized; the current capture is already strong and repeatable.
