## Interpretation

CP969 does not overturn the CP960 external failure. Short templates help, but not enough:

- CP960 external rises from the old long-window `~0.078` range to `0.317` at `[date-redacted]`.
- The same 12SC reference against no-TX reaches only `0.0776` at `[date-redacted]`, so CP960 is signal-related.
- But the LiteX-only 12SC internal control reaches `0.908` at `16384`, and remains around `0.704` at `32768..65536`.

This differs sharply from the 1SC x16 external result:

- CP967 1SC x16/gain42 short-template score: `0.950..0.951`
- CP969 12SC x4/gain42 short-template score: `0.317`
- CP969 no-TX short-template floor: `0.0776`

The 12SC external capture contains signal-related structure, but it is still far from clean local recovery. Therefore CP960 was not merely a long-template detector-window issue; the external path is materially less coherent for 12 occupied subcarriers than for 1 occupied subcarrier.

## Current boundary

The refined boundary is now:

- 1SC x16 external: clean short-window recovery, poor long-window coherence.
- 12SC x4 external: weak even with short templates, though above no-TX.
- 12SC LiteX-only internal: clean at moderate/long template lengths.

So the unresolved external boundary lies between `1SC` and `12SC`, with both occupied bandwidth and multi-subcarrier coherence still plausible factors.

## Next step

Run an intermediate-subcarrier rung, starting with a centered `4SC` waveform:

3. If it passes internally, run external bladeRF capture.
4. Analyze with both long CP851 and the short-template sweep.

This directly brackets whether the break happens near `2..4SC` or closer to `12SC`.
