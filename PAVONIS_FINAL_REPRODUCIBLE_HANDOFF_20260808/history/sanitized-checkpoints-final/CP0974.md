## Interpretation

CP974 passes execution and signal-presence checks:

- LiteX TX replay started, completed, and archived.
- bladeRF RX captured the expected number of samples.
- There was no clipping.
- bladeRF temperature stayed normal for this hardware path (`33.3 C` to `34.2 C`).
- Focused correlation is far above the noTX floor.

CP974 fails clean external recovery:

- Long-template score is only `0.158`.
- Best long-template transform is `conjugate_capture`, not consistently normal.
- Best short-template result is only `0.521`, below the 1SC x4 score and far below the LiteX-only control.
- Best CFO and transform vary with template length.

The current evidence supports a multi-subcarrier external coherence problem rather than a missing LiteX TX signal or a same-session LiteX RX/TX regression.

## Next Step

The first clean-to-weak transition is now narrowed to `1SC -> 2SC`. The next useful rung is a controlled 2SC power/amplitude repeat, not a wider waveform:

1. Generate or reuse the CP973 2SC waveform.
2. Run a safe higher-amplitude 2SC LiteX-only baseline, keeping pre-RF peak below the already tested safe 1SC x16 range.
3. If the LiteX-only path passes, run the corresponding external bladeRF capture.

This separates an SNR/level limitation from the observed multi-subcarrier coherence limitation.
