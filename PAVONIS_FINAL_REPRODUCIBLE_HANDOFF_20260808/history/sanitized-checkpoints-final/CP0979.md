# Checkpoint 979 - Piecewise CFO/Phase Does Not Recover 2SC x8 External Long Coherence

Date: [date-redacted]

## Purpose

CP979 continues from CP977 and CP978.

CP977 showed that the CP976 centered 2SC x8 external bladeRF capture has stable
short-window recovery, but weak long-window coherence. CP978 then reran the
same CP973 2SC x8 waveform through the bladeRF-independent LiteX-only RX/TX
path and passed cleanly.

CP979 tests whether the CP976 long-window weakness is recoverable by a simple
piecewise CFO/phase model. It also runs the same diagnostic on the fresh CP978
LiteX `phy` control to make sure the diagnostic can still see long coherence
when the path is healthy.

## Method

For each case, CP979:

1. Estimates the best local [date-redacted]-sample short-template match per chunk over a
   dense low-CFO grid.
2. Builds three piecewise-corrected capture variants:
   - `cfo_only`
   - `phase_only`
   - `cfo_phase`
3. Re-runs global 32768/65536 energy-template correlation on raw and corrected
   captures.
4. Tests whether each strong [date-redacted] hit extends to 32768/65536 at the same local
   start using a fixed-start CFO sweep.

The same-start extension medians are treated carefully: short-template hits can
land on locally good but long-incompatible positions even in the healthy LiteX
control. The more decisive comparison is therefore global long-template recovery
and whether any high same-start long windows exist.

## Interpretation

CP979 rules out a simple correction model as the main CP976 blocker:

- Stable [date-redacted]-window recovery is real, matching CP977.
- A piecewise CFO-only correction barely improves CP976 `32768` correlation and
  does not improve `65536`.
- Adding piecewise phase does not recover the long templates.
- The fresh CP978 LiteX-only control has strong raw long-window coherence with
  the same reference and scanner.
- The external CP976 capture does not contain any high same-start 32768/65536
  extension windows under the tested fixed-start CFO model.

The boundary therefore remains external-path-specific, but it is now narrower:
the failure is not explained by absence of signal, not explained by a broken
LiteX-only RX/TX path, and not recovered by simple per-segment CFO/phase
stitching.

## Verdict

CP976 external short-window signal: PRESENT.

CP978 LiteX-only x8 baseline: PASS.

CP976 piecewise CFO/phase long-coherence recovery: FAIL.

Current likely class: external receive-path distortion, timing/fractional-delay
variation, I/Q/path asymmetry, or a more complex time-varying impairment than a
single local CFO/phase per chunk.

## Next Step

Move from scalar CFO/phase correction to structure-specific analysis. The next
checkpoint should compare CP976 external versus CP978 LiteX control in the
frequency-domain/two-subcarrier structure, looking for differential phase,
amplitude imbalance, timing drift, or frequency-selective distortion that would
preserve short local correlation while destroying longer 2SC coherence.
