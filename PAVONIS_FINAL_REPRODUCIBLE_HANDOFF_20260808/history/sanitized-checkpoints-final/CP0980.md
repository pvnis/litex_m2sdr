# Checkpoint 980 - Two-Subcarrier Structure Shows External Common and Differential Phase Instability

Date: [date-redacted]

## Purpose

CP980 follows CP979. CP979 showed that simple piecewise CFO/phase correction
does not recover CP976 long-window coherence. CP980 therefore inspects the
actual CP973 waveform structure: a no-CP OFDM probe with `nfft=384`, `15 kHz`
subcarrier spacing, and only occupied bins `-1` and `0`.

The goal is to compare CP976 external bladeRF RX against the fresh CP978
LiteX-only `phy` control at the occupied-bin level, not just with scalar
time-domain correlation.

## Interpretation

CP980 confirms the CP976 external path is not simply shifted by one scalar CFO
or phase:

- The CP976 long window has direct occupied-bin coherence `0.200672`, matching
  the weak time-domain long-correlation picture.
- Removing one common complex channel per OFDM symbol only raises CP976 to
  about `0.280567`. If the failure were just fast common phase rotation, this
  score should have risen much closer to the LiteX control.
- The per-symbol pair median remains moderately high (`0.749668`), so both
  occupied subcarriers are often locally visible.
- The common phase residual is very large through CP976 external
  (`3.523489 rad`) versus CP978 LiteX (`0.124888 rad`).
- The differential phase is far less stable through CP976 external:
  `42.220909 rad` span and `6.837489 rad` residual std versus `1.672933 rad`
  span and `0.244120 rad` residual std for CP978 LiteX.
- The relative amplitude of bins `0` and `-1` is much less stable externally:
  `7.752 dB` std versus `1.246 dB` in the LiteX long control.
- The occupied-to-guard margin is also lower externally, but still positive
  (`13.059 dB`), so this is not no-signal.

The best CP976 short hit shows the same pattern. It has locally visible
two-bin symbols, but over a 65536-sample window direct coherence collapses and
symbol-common equalization still only reaches about `0.280`.

## Verdict

CP980 narrows the external failure mode:

- Signal presence: PASS.
- LiteX-only 2SC structure: PASS.
- External 2SC common phase stability: FAIL.
- External 2SC differential phase/amplitude stability: FAIL.
- Simple common-symbol equalization as an explanation: FAIL.

The bladeRF/external path is preserving enough local occupied-bin energy for
short correlation, but it is not preserving a stable two-subcarrier channel over
long windows.

## Next Step

The next useful rung is to determine whether this instability is introduced by
bladeRF RX itself or by the installed RF path before bladeRF. A good next
checkpoint is a bladeRF-side receive-chain isolation test that does not require
changing persistent calibration: either a repeat external 2SC capture with the
same CP978-before/after LiteX guard, or a read-only/temporary bladeRF internal
loopback/path test if the current bladeRF command surface allows restoring the
state cleanly.
