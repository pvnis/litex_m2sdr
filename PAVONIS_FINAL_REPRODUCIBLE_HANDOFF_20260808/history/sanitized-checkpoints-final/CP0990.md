## Interpretation

CP990 weakens a simple high-TX-level explanation:

- The external run completed cleanly and cleanup succeeded.
- Lowering TX scale by `6 dB` reduced the bladeRF receive level by roughly the
  expected amount.
- Digital clipping remained absent.
- PBCH remained KO across all windows.
- Focused long-window scores did not improve.
- The two-subcarrier instability persisted.

This does not rule out every amplitude-dependent effect, but it makes a simple
`TX scale 8 is too hot` theory unlikely. The first-failed boundary remains the
installed external LiteX TX -> bladeRF RX path as observed by bladeRF RX, not
the generated CP973 waveform or the LiteX-only RX/TX path.

## Next Step

The next single-variable rung should test the hardware attenuation path rather
than the digital replay scale:

- return `AMPL=8`
- keep `CAP_BW_HZ=200000`
- keep `CAP_FILTER=bypass`
- keep `CAP_GAIN_DB=42`
- increase TX attenuation from `20 dB` to `26 dB`

If hardware attenuation behaves like CP990, level alone is unlikely. If it
differs materially from CP990, the attenuator/DAC/RF-output ordering becomes a
useful clue.
