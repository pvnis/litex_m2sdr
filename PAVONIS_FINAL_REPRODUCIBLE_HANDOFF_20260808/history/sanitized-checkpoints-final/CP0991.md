## Interpretation

CP991 has two useful outcomes:

- The external path still fails long-window coherence and PBCH.
- The `TX_ATT_DB` label is unreliable for this replay path because the value is
  passed to Soapy `setGain`, and requesting `26` did not reduce received level.

This means CP990 remains the clean level-reduction evidence. CP991 should not
be used as evidence that hardware attenuation failed to help; it is evidence
that the current `TX_ATT_DB` control needs readback/semantics validation before
using it as a ladder variable.
