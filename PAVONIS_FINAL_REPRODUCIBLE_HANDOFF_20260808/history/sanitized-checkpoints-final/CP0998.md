# Checkpoint 998 - Post-Setup/Activate ATT40 Persists and RF Level Drops

Date: [date-redacted]

## Purpose

CP997 showed that the current CP920/CP848 streaming order loses the requested
LiteX TX attenuation: `setGain(..., 40)` is visible before `setupStream`, but
`setupStream` resets readback to `20`, and active writes run at `ATT=20`.

CP998 retests the same external path while applying `setGain(..., 40)` again
after `setupStream` and after `activateStream`. The goal is to prove whether TX
attenuation can be made effective during active streaming and whether the bladeRF
capture level follows.

## Interpretation

CP998 resolves the transmit attenuation control path:

1. `setupStream` resets the LiteX Soapy TX `ATT` value to `20`.
2. Reapplying `setGain(..., 40)` after `setupStream` restores the requested
   attenuation.
3. `activateStream` preserves the post-setup `ATT=40` setting.
4. Active writes read back `ATT=40`.
5. bladeRF sees a large RF-level drop, so the post-setup attenuation is real,
   not just a Soapy readback artifact.

The active-ATT40 RF level is probably too low for the current external
correlation ladder. The more useful next step is not more ATT40; it is an active
post-setup attenuation sweep at intermediate values, because previous CP991 and
CP994 did not actually test those values during active streaming.

## Verdict

CP998 post-setup/post-activate TX attenuation control: PASS.

Active `ATT=40` persists through streaming and produces a real bladeRF-level
drop. It does not recover decoding or long-window coherence at this low level.

The external long-coherence first-failed boundary remains, but the transmit
level knob is now trustworthy if and only if attenuation is applied after
`setupStream`.

## Next Step

Patch or wrap future CP920/CP848-style replays so TX attenuation is applied after
stream setup. Then sweep active attenuation values, starting with a moderate
value such as active `ATT=26` or `ATT=30`, to see whether the external
short/long split improves at a lower but not severely underdriven RF level.
