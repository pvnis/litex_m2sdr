## Verdict

CP1001 active `ATT22` repeat: level repeatability PASS, decode/coherence
recovery FAIL.

The same active attenuation, replay script, waveform, bladeRF RX settings, and
post-setup gain ordering reproduce the external-path failure mode. This reduces
the likelihood that CP1000 was a one-off bad capture or that the remaining issue
is simple TX power.

## Next Step

Before more bladeRF-path experiments, take a fresh LiteX-only RX/TX baseline
using the same centered two-subcarrier probe. That isolates whether the LiteX SDR
can still receive its own transmitted waveform cleanly today. If the LiteX-only
baseline still gives high long-window correlation near the CP996 result, the
first failed boundary remains the external LiteX TX -> bladeRF RX path. If it
regresses, the next branch is LiteX TX/RX software or hardware state rather than
bladeRF.
