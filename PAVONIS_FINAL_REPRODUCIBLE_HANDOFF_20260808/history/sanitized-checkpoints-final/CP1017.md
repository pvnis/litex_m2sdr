## Interpretation

CP1017 confirms CP1016 is not a new failure mode. It repeats the same local
analysis class as CP1010:

- short templates recover strongly
- 32768 and 65536 templates remain weak
- selected CFO/transform is not stable across template length
- occupied bins are visible above guards
- normal occupied coherence is poor compared with LiteX-only `phy`
- phase residuals stay high in external bladeRF observation windows

This reinforces the boundary from CP1016: the system can carry a deterministic
tone and the LiteX-only path carries the same centered 2SC reference cleanly,
but the external bladeRF observation of the centered 2SC waveform loses the
coherent structure needed for PBCH/long-template recovery.

## Verdict

CP1016 local focused sweep and image/mirror analysis: PASS as a diagnostic.

Failure-class repeatability: confirmed.

The unresolved issue is not a transient post-reboot state, not a bladeRF route
selection problem, and not pure receive-floor noise. The next rung should alter
waveform structure or observation timing.
