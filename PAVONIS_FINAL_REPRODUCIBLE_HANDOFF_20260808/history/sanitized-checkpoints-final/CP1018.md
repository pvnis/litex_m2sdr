## Purpose

CP1018 introduces a stationary two-tone waveform that sits between the CP1015
single deterministic tone and the CP1016 modulated centered two-subcarrier
OFDM-like probe.

The new vector keeps CP973's key geometry:

- sample rate: `5760000`
- subcarrier spacing: `15000 Hz`
- occupied bins: `-1,0`
- tones: `-15000 Hz, 0 Hz`
- duration: `0.25 s`
- samples: `1440000`
- target RMS: `0.05`
- peak: `0.070710681`

Unlike CP973, it does not randomize QPSK per OFDM symbol. It is a
loop-continuous stationary two-tone. This isolates "two close-in carriers" from
"symbol-to-symbol modulation/phase changes."

This checkpoint only runs the LiteX-only RX/TX baseline. It does not use the
bladeRF external receiver.
