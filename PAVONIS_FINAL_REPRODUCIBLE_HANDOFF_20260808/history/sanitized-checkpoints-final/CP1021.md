## Interpretation

CP1021 rules against a simple "DC carrier is missing" theory:

- RX1 sees the DC/baseband-carrier test at the same level class as CP1015 and
  CP1020.
- RX2 remains much weaker, confirming RX1 is still the installed receive path.
- The apparent DC tone is offset to about `+2 kHz`, which matches the offset
  family seen in CP1019.

Combined with CP1019 and CP1020, the remaining issue looks like interaction
between components and/or the external path's close-in phase behavior, not a
complete failure to pass either component alone.

## Verdict

Single DC deterministic carrier through explicit bladeRF RX1/RX2: PASS for
RX1, expected weak/WARN on RX2.

DC component alone: PASS.

## Next Step

The next high-value rung is a two-tone test without a DC component, e.g.
stationary bins `-1,+1` (`-15 kHz` and `+15 kHz`). If that is clean, the DC
interaction is implicated. If it is still only partially coherent, close-in
two-tone interaction is implicated even without DC.
