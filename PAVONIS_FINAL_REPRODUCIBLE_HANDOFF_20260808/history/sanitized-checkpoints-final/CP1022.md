# Checkpoint 1022 - No-DC Stationary 2-Tone LiteX-Only Baseline Pass

Date: [date-redacted]

## Purpose

CP1022 introduces the next waveform-structure isolation rung after CP1019,
CP1020, and CP1021.

CP1019 showed that a stationary `-15 kHz + DC` two-tone partially recovers
long coherence externally, but still stays below the LiteX-only baseline.
CP1020 proved the `-15 kHz` component alone passes on RX1. CP1021 proved the
DC component alone passes on RX1.

CP1022 removes DC while keeping two close-in stationary tones:

- tones: `-15000 Hz`, `+15000 Hz`
- bins: `-1,+1`
- no DC component

This checkpoint only runs the LiteX-only RX/TX baseline. It brackets the new
vector before any external bladeRF capture.
