## Verdict

FAIL, repeatable.

CP1024 confirms CP1023 was not a one-off missing receive event. The LiteX-only source-path baseline remains good, while the external bladeRF capture path repeatedly fails to preserve long-window coherence for the same no-DC stationary two-tone.

## Next rung

Proceed to isolate bladeRF/external receive variables. Recommended next step is a receiver-side parameter split with the same no-DC two-tone:

1. Run a narrower bladeRF RX bandwidth while keeping center/gain/filter/vector fixed.
2. If that improves coherence, focus on bladeRF RX bandwidth/filter/decimation behavior.
3. If it does not, run gain split and then RX channel/path split before returning to more protocol-like waveforms.
