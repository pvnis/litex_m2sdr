## Verdict

RX path split completed.

- RX1: strong received power but the same poor long-window coherence as the generic CP1023/CP1024 path. This is the actual external-path failure branch.
- RX2: very weak path with an early DC/startup transient. The higher correlation is a false-good single-component match, not successful reception of the intended no-DC two-tone.

CP1027 therefore does not find a clean physical receive path. It does localize the generic failing path to RX1-like behavior and shows RX2 is not a viable alternate good path in this setup.

## Next rung

Use a non-symmetric no-DC two-tone vector, for example bins `-1,+2`, to break the symmetry that makes image/mirror and single-component false matches ambiguous. Run it first through the LiteX-only baseline, then through the external RX1/generic path. This should separate true two-component preservation from DC/startup or one-tone impostors.
