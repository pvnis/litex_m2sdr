## Interpretation

The external PBCH path does not recover after the LiteX-only PBCH baseline. The source-side PBCH path is demonstrably healthy at ATT22, the replay writer completes the intended sample count, and the bladeRF capture is present and unclipped, but the external capture does not contain a usable SSB/PBCH structure.

This isolates the current failure to the external bladeRF/RF/cabled/capture geometry or an interaction only visible in that geometry. CP1044 also suggests that the weak CP1042 SSB-reference island was not stable or repeatable.

One caveat remains: CP1043 validated the LiteX-only PBCH path at the full `1842500000 Hz` / `11.52 Msps` PBCH center, while CP1042/CP1044 use the external `1839650000 Hz` / `5.76 Msps` SSB-centered capture geometry. That geometry difference should be isolated next if tooling allows it.

## Verdict

External PBCH repeat after LiteX baseline: FAIL. The bladeRF/RF path remains the active failure domain, and the CP1042 weak PBCH structure did not repeat. Continue by isolating the SSB-centered capture geometry, then return to external RF only after a source-side geometry-matched baseline is available.
