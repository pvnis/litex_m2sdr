## Interpretation

CP1045 narrows the failure:

- The centered source is valid offline.
- The centered source survives LiteX-only RX/TX with strong correlation and PBCH CRC OK.
- The same centered source through the external bladeRF/RF path is present only weakly: some CSI PCI 1 detections and a `0.0914` reference-correlation island, but no PBCH PCI 1 and no CRC OK.

That means the external path is not purely missing the waveform, but it is degrading it severely. The likely next branch is not PBCH waveform generation; it is external receive coherence/SNR/linearity/calibration. Since CP1045 still sits around `-19 dBFS` with no clipping and ATT changes did not move level in CP944, the next useful tests should focus on bladeRF receive state and physical path coupling rather than further source-side PBCH edits.

## Verdict

Centered external PBCH current-state control: FAIL with stronger weak structure. Use CP1045 as the current best external PBCH structure checkpoint: centering improves CSI/correlation, but the bladeRF/RF path still cannot preserve the PBCH waveform well enough for decode.
