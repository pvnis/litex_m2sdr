## Conclusion

CP1045 did not contain a later missed PBCH-good window near the strongest reference-correlation island. The centered external RF path still has measurable weak waveform structure, but the structure is far below the LiteX-only centered baseline from CP945 and is not decodable even when directly cutting around the best late alignment estimate.

This keeps the current boundary unchanged:

- LiteX-only centered source path is healthy: CP945 decoded PBCH CRC OK on none/phy/ad9361 loopbacks.
- LiteX-only PBCH source path is healthy: CP1043 decoded PBCH CRC OK on none/phy/ad9361 loopbacks.
- External LiteX-to-bladeRF path remains the failing boundary for PBCH decode.
