Date: [date-redacted]

## Purpose

CP1045 used the centered CP918 SSB/PBCH source over the external LiteX-to-bladeRF path at bladeRF RX gain `42 dB`. It produced weak structure but no PBCH decode. CP1047 showed that the external capture has high raw power but poor long-window coherence.

CP1048 changes one reversible receive-side variable:

```text
CP1045 geometry and source
same CP1034 partial-write-fixed LiteX replay helper
same TX ATT22
same 1536-sample requested chunks
same bladeRF bypass filter
bladeRF RX gain: 42 dB -> 36 dB
```

The goal is to test whether the CP1045 coherence failure is caused or improved by bladeRF receive gain/front-end compression.

## Verdict

CP1048 FAILS as a recovery attempt. Lowering bladeRF RX gain from `42 dB` to `36 dB` reduces raw capture level and keeps the capture unclipped, but it does not improve PBCH decode or reference coherence.

This weakens the "simple RX overgain/compression" theory for PBCH. The external path still shows only short weak fragments of CSI-like structure and poor long-window coherence, while the same centered source remains known-good through LiteX-only CP945 and CP1043/CP945 baselines.
