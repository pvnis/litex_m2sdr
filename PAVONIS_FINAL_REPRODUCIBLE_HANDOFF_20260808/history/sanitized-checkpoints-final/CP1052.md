## Interim Verdict

CP1052 is not a PBCH recovery, but it is a useful positive control within the external failing path:

- Stronger TX at G30 increases expected-PCI CSI detections from `9` to `125`.
- First-6M reference correlation improves from `0.099973988` to `0.113996242`.
- No PBCH PCI1 or CRC OK appears.

This points away from a pure "not enough signal reaches bladeRF" explanation. The external path can produce recognizable short CSI-like structure when driven harder, but it still does not preserve the PBCH waveform coherently enough to decode. A targeted decode around the first6M CP1052 island should be run next before closing this stronger-TX branch.
