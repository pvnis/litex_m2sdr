## Interim Verdict

CP1054 improves external-path visibility but still does not recover PBCH:

- RX gain `36 dB` raises capture level by about `6 dB` with no clipping.
- One-second decode now sees expected CSI PCI `1`, but PBCH remains PCI `0` / CRC `KO`.
- First-6M reference correlation rises to `0.155114791`, the best in this centered external branch.
- No aligned sweep window has PBCH PCI `1` or CRC OK.

This weakens the "not enough signal" theory further. The external path is carrying stronger, TX-related, expected-PCI structure, but PBCH coherence is still broken. The late first-6M island at capture start `2057968` should be directly decoded next before closing the `TX_ATT15/G36` branch.
