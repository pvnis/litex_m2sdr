# Checkpoint 1061 - ATT10/G42 Invalid Comparison: Default CP848 Replay

Date: [date-redacted]

## Purpose

CP1061 attempted to raise LiteX TX power from `TX_ATT15` to `TX_ATT10` while
holding the CP1057 external path settings fixed:

- CP918 centered SSB/PBCH source
- `5760000/5600000` sample rate and bandwidth
- TX/RX center `1839650000 Hz`
- bladeRF RX gain `42 dB`
- bladeRF RX filter `bypass`
- `CHUNK_LEN_SAMPLES=1536`

The intended comparison target was CP1057/CP1058, which used the CP1034
partial-write-fixed/gaintrace replay helper.

## Critical Confound

`REPLAY_SCRIPT_LOCAL` was not set in this run. The CP920 harness therefore used
its default replay wrapper:

```text
REPLAY_SCRIPT_LOCAL="${REPLAY_SCRIPT_LOCAL:-$ART/cp848_remote_nuc4_start_cf32_replay_tx.sh}"
```

The CP1061 remote replay log confirms the fallback:

```text
===== cp848 LiteX CF32 replay TX start =====
PLAY=/home/[host-redacted]/CLionProjects/m2sdr/litex_m2sdr/software/soapysdr/test_play.py
TX_ATT_DB=10
```

This makes CP1061 invalid as a one-variable ATT15 -> ATT10 comparison against
CP1057. The corrected comparison is CP1062.

## Verdict

CP1061 is an invalid comparison because it changed the replay helper as well as
the TX attenuation. Do not use it to conclude that `TX_ATT10` is worse. Use
CP1062 as the corrected ATT10/G42 checkpoint.
