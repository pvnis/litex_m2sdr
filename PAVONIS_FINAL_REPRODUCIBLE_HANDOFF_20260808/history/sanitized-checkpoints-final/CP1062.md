## Interpretation

CP1062 is the first recent external LiteX-to-bladeRF centered SSB/PBCH run in
this branch to recover PBCH CRC OK windows. It does not yet provide robust
full-buffer acquisition: the one-second decoder still locks onto a wrong CSI
candidate and PBCH CRC KO. However, the aligned-window sweep proves the external
path can again carry PBCH-decodable fragments with the CP918 source.

The correction from CP1061 matters: using the CP1034 helper restored the intended
partial-write-fixed replay behavior and gain trace. With that helper, `TX_ATT10`
is a real improvement over `TX_ATT15/G42`.

## Verdict

Corrected ATT10/G42 external run: windowed PBCH recovery. The next step should
be a repeat at the same CP1062 settings to test repeatability, then [interface-redacted] toward
full-buffer acquisition from the recovered window clusters if it repeats.
