## Purpose

fails from sample zero at `1000 ms`. CP1067 maps that behavior more precisely by
holding the start at sample zero and varying only buffer length.

## Interpretation

CP1067 identifies two decoder transition boundaries for the CP1063 sample-zero
prefix:

- Below `225 ms`, the buffer is too short or the decoder reports an early bad
  PBCH candidate.
- From `225 ms` through `600 ms`, the same sample-zero capture decodes PBCH CRC
  OK.
- At `625 ms` and above, adding later samples flips the reported PBCH result
  back to PCI 0 CRC KO, matching the original CP1063 full one-second failure.

This is strong evidence that CP1063's one-second failure is not an RF absence or
bladeRF no-RX condition. The PBCH-positive content is already present in the
first `225-600 ms`; the analyzer's candidate selection changes when later
samples are included.

## Verdict

CP1067: PASS for finding a deterministic sample-zero full-buffer decode band on
CP1063. A practical next local check is to run the same sample-zero
prefix-length sweep on CP1062; if it also has a valid shorter prefix band, the
next RF test can reduce capture/decode length before changing RF settings.
