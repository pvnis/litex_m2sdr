## Interpretation

CP1076 confirms the current working baseline:

- LiteX TX replay is healthy and stable with ATT `10 dB`.
- bladeRF RX state and temperatures are normal.
- Raw capture level is stable and unclipped.
- Full-buffer `ssb_file_test` remains unreliable, as expected.
- The external LiteX-to-bladeRF path repeatedly contains PBCH-decodable PCI 1
  windows under the CP1075 gate.

This is not a no-RX/no-TX condition and not consistent with an overheating
antenna/bladeRF symptom in this run. The remaining ladder should treat
short-window PBCH recovery as the RF baseline and move upward into integration
only after this gate passes.

## Verdict

CP1076: PASS for the fresh external RF path under the CP1075 sliding-window
smoke gate; FAIL only for the known-fragile full one-second decoder path.
