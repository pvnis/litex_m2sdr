## Changes

- `sync_raster_t` now initializes `N_first` and `M_idx_first` from `gscn_first`.
- `reset()` now restores the first `M` index.
- `get_gscn()` avoids unsigned underflow for row-1 `M=1` by doing the row-1 arithmetic with signed intermediate values.
- Added a band 3 test that validates:
  - first GSCN: 4517
  - first frequency: 1807250000.0 Hz
  - target GSCN: 4598
  - target frequency: 1839650000.0 Hz
  - reset returns to GSCN 4517
