## Conclusion

CP1089 shows CP1088 was not a persistent loss of the target RX/TX path. PBCH/MIB
acquisition recovered on the next run with the same source replay, RF frequency,
gain, and binary.

The current regression is one rung higher: SFN synchronization is not reliably
reached within 100 trials even when PBCH/MIB is decoded. CP1086 reached SFN sync
with the same nominal target path, so this is repeatability/timing sensitivity in
the live replay-to-UE cell-select stage, not a total RF-path outage.

Next action: run a target-only profile with a larger max-trial budget and bounded
post-select loop. This tests whether the SFN miss is mostly a window-length issue
without returning to the long post-camping soak.
