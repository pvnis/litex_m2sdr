# Checkpoint 1093 - UE-Like Target Search With LiteX TX ATT 5 dB

Date: [date-redacted]  
Status: PASS FOR PBCH/MIB, SFN SYNC, AND BOUNDED CAMPING

## Purpose

Apply the CP1092 lower-level RF finding to the UE-like
`nr_sa_cell_search_test` path. CP1092 showed that reducing LiteX TX attenuation
from 10 dB to 5 dB improved the best lower-level PCI 1 SNR from about `-24 dB`
to `-0.7 dB`. CP1093 tests whether that added RF margin stabilizes target-only
UE cell search and cell selection.

## Conclusion

CP1093 is the current best UE-like target baseline:

- LiteX TX at `TX_ATT_DB=5`
- bladeRF RX gain `42`
- target-only SSB frequency `1839650000`
- 100-trial budget
- bounded post-select run of 200 TTIs
- no post-stop soak

This setting reached PBCH/MIB, SFN sync, and camping with much less noise than
the earlier default-soak runs. It also explains the recent instability: the
previous `TX_ATT_DB=10` setting left too little margin for reliable UE
cell-selection behavior, even though lower-level SSB detection could still see
the signal.

Next experiments can be grouped unless a failure occurs. If the bladeRF/LiteX
interaction becomes ambiguous again, the next isolation fallback is a LiteX-only
OTA TX/RX baseline. The Android phone connected to `[host-redacted]` is reserved for later
end-to-end validation once the RF/UE ladder is stable enough to make that useful.
