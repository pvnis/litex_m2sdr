# Checkpoints 1099-1101: Live gNB plus `nr_sa_cell_search_test` no-cell series

Date: [date-redacted]

## Purpose

After CP1096 proved the live SSB-centered downlink with the raw detector, and
CP1097/CP1098 showed carrier-centered/off-center ambiguity, these checkpoints
tested the srsUE NR-SA cell-search path directly against the live LiteX gNB.

The point was to separate:

- carrier-centered/off-center SSB geometry failure
- srsUE live acquisition failure even when SSB-centered
- RF margin/power sensitivity

## Interpretation

CP1099 reproduces the full srsUE-path failure in carrier-centered/off-center
geometry, matching the suspicion raised by CP1097/CP1098.

CP1100 is more important: even with SSB-centered [interface-redacted] and a raw detector
baseline that had just passed in CP1096, `nr_sa_cell_search_test` did not find
the cell. That means the current failure is not only PRACH or attach, and not
only carrier-centered channelization. The srsUE acquisition path is failing
before cell selection in this live setup.

CP1101 did not recover by increasing gNB power to `tx_gain_backoff: 10`. Later
CP1102 showed that this backoff-10 condition is not a clean raw RF improvement,
so CP1101 should not be interpreted as a simple "more power still failed" test.

## Current conclusion

The direct NR-SA path sees no cell in all tested live geometries. The next
useful tests should align the NR-SA receive gain with the raw detector baseline
and, if still blind, add lower-level instrumentation in the srsUE cell-search
receive path.
