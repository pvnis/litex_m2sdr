# Checkpoint 1106: Live gNB lower-level `nr_cell_search_rf` sees weak ambiguous PCI 1

Date: [date-redacted]

## Purpose

CP1104 and CP1105 showed that `nr_sa_cell_search_test` does not find a cell in
the live SSB-centered setup, even though CP1103 proved the custom raw detector
can prove PCI 1 at the same gNB backoff. CP1106 ran srsRAN's lower-level
`nr_cell_search_rf` against the same live gNB to determine whether the srsRAN RF
scanner can see the downlink at all.

## Setup

- Harness: `cp1106_run_live_gnb_nr_cell_search_rf.sh`
- Stamp: `[date-redacted]TCP1106LIVE_NRCELLSEARCHRF_SSBCENTER`
- gNB backoff: `20`
- gNB config line: `tx_gain_backoff: 20`
- Scanner: `nr_cell_search_rf`
- Scanner target SSB: `1839650000 Hz`
- Scanner sample rate: `5760000 sps`
- Scanner RX gain: `42`
- Threshold: `-30 dB`
- Measurement length/period: `20 ms / 20 ms`

## Result

Diagnostic partial pass. `nr_cell_search_rf` did see expected PCI 1, but the
result was weak and mixed with wrong-PCIs.

Observed cells:

- PCI 1: `rsrp=-33.4 dBfs`, `snr=-25.0 dB`, `cfo_hz=-4743.3`
- PCI 487: `rsrp=-30.5 dBfs`, `snr=-21.2 dB`
- PCI 304: `rsrp=-30.7 dBfs`, `snr=-19.6 dB`
- PCI 382: `rsrp=-34.1 dBfs`, `snr=-26.1 dB`

Summary table included:

- `pci=001; arfcn=1839650; count=1`
- `pci=304; arfcn=1839650; count=1`
- `pci=382; arfcn=1839650; count=1`
- `pci=487; arfcn=1839650; count=1`

gNB health:

- `SOAPY_TX_TIMEOUT_COUNT=0`
- gNB cell line: `Cell pci=1, bw=10 MHz, 1T1R, dl_arfcn=368500 (n3), dl_freq=1842.5 MHz, dl_ssb_arfcn=367930, ul_freq=1747.5 MHz`

## Interpretation

This is the missing bridge between CP1103 and the NR-SA no-cell runs:

- The custom raw detector can prove PCI 1 at `tx_gain_backoff: 20`.
- srsRAN lower-level RF search can see PCI 1, but only weakly and with
  competing wrong-PCIs.
- `nr_sa_cell_search_test` needs stronger, cleaner acquisition to decode
  PBCH/MIB and select the cell, so it returns no cell.

Compared with replay CP1093, which reached PBCH/MIB and camping with TX
attenuation 5 dB, the live gNB backoff-20 path is currently too marginal for
the UE-like acquisition path.

## Next step

Before rerunning NR-SA, sweep the lower-level scanner RX gain upward at the same
live gNB backoff. Start with RX gain 50, because historical full-live harnesses
used RX-gain-50 variants.
