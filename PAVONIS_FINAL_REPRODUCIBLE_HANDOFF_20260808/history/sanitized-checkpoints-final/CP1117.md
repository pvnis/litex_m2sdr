# Checkpoint 1117 - Live NRSA at +3000 Hz: no cell after lower-level PCI-only pass

## Purpose

CP1116 showed the best lower-level live `nr_cell_search_rf` result so far:
with live gNB TX backoff 20, bladeRF RX gain 50, SSB-centered [interface-redacted], and
`rf.freq_offset=+3000`, every reported neighbour-cell hit was the expected
PCI 1. CP1117 moved that same RF operating point up to
`nr_sa_cell_search_test` to test whether the full NR SA cell-search path could
decode a cell.

## Command geometry

- Wrapper: `cp1099_run_live_gnb_nr_sa_cell_search.sh`
- Stamp: `[date-redacted]TCP1117LIVE_NRSA_SSBCENTER_RXG50_FOFFP3000`
- gNB TX backoff: `20`
- NRSA RF center: `1839650000 Hz`
- Target SSB center: `1839650000 Hz`
- Sample rate: `5760000`
- bladeRF RX gain: `50 dB`
- `rf.freq_offset`: `+3000 Hz`
- Max cell-search trials: `100`
- Post-select TTIs: `1000`
- Post-stop TTIs: `0`

## Result

The harness and gNB side were clean, but NRSA did not detect a cell.

```text
Cell search finished without detecting any cell
PAVONIS_CELL_SELECT_TRACE line=30 event=cell_search_done result=0 trials=100 pci=0
NR_SA_CELL_SEARCH_TEST_RC=0
```

The `rc=0` is only the test program's process result. It is not a radio pass:
there was no PBCH/MIB decode, no SFN sync, and no camping event.

## gNB health

- `TX_READY.env` was present.
- gNB advertised PCI 1, band 3, `dl_arfcn=368500`, `dl_ssb_arfcn=367930`.
- AMF connection completed.
- `SOAPY_TX_TIMEOUT_COUNT=0`.
- Cleanup after the run completed.

## bladeRF health

The bladeRF hardware status was readable before and after the run.

- Start temperature: `34.2 C`
- End temperature: `38.6 C`
- Power monitor: about `4.92 V`, `0.55-0.56 A`, `2.72 W`
- Loopback mode: `none`
- RX mux: `BASEBAND`
- RX filter: `normal`

This does not point at bladeRF overheating during this run.

## Interpretation

CP1117 separates two levels:

- Lower-level `nr_cell_search_rf` at the same RF point can repeatedly identify
  expected PCI 1 (CP1116).
- Full `nr_sa_cell_search_test` at that RF point cannot acquire a cell at all.

That makes the current boundary more specific: the live path is not dead, and
PSS/SSS-grade structure is present, but the full NR SA acquisition path still
does not see a PBCH/MIB-grade cell.

The next useful check is a fresh live gNB to bladeRF raw capture at the same
stable TX point, followed by local PBCH window decoding on that raw capture.
That tests whether the captured live waveform actually contains decodable PBCH,
instead of only repeating cell-search retries.
