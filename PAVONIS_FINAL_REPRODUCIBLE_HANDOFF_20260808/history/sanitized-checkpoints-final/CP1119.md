# Checkpoints 1119-1121 - Gain 40 +3000 Hz: lower-level pass, NRSA still no cell

## Purpose

CP1118 showed that bladeRF RX gain 50 clips the live SSB-centered capture and
does not cleanly prove PCI 1. CP1119 moved the best offset found at gain 50
(`rf.freq_offset=+3000`) back to RX gain 40, where previous raw captures were
not clipped. CP1120 and CP1121 then moved that same clean RF point back up to
`nr_sa_cell_search_test`.

## Shared RF geometry

- gNB TX backoff: `20`
- gNB PCI: `1`
- SSB center: `1839650000 Hz`
- srsRAN RF center argument: `1839650000 Hz`
- srsRAN sample rate: `5760000`
- bladeRF RX gain: `40 dB`
- `rf.freq_offset`: `+3000 Hz`

## CP1119 - `nr_cell_search_rf`

CP1119 was a lower-level scanner pass.

There were no wrong PCI hits in this run. The gNB summary showed
`SOAPY_TX_TIMEOUT_COUNT=0`.

## CP1120 - NRSA, 100 trials

CP1120 used the same gain 40 / `+3000 Hz` RF point in
`nr_sa_cell_search_test` with `PAVONIS_SRSUE_CELL_SEARCH_MAX_TRIALS=100`.

Result: no cell.

```text
Cell search finished without detecting any cell
PAVONIS_CELL_SELECT_TRACE line=30 event=cell_search_done result=0 trials=100 pci=0
NR_SA_CELL_SEARCH_TEST_RC=0
```

The gNB summary again showed `SOAPY_TX_TIMEOUT_COUNT=0`.

## CP1121 - NRSA, 1000 trials

CP1121 tested whether CP1120 was simply too short. The trial budget was raised
to `1000`.

Result: no cell.

```text
PAVONIS_CELL_SEARCH_MAX_TRIALS value=1000
PAVONIS_CELL_SELECT_TRACE line=120 event=cell_search_done result=0 trials=1000 pci=0
Cell search finished without detecting any cell
NR_SA_CELL_SEARCH_TEST_RC=0
```

RF overflows started around trial 270 in the long NRSA run, but NRSA had
already missed the early interval where the lower-level scanner can detect PCI
1. The overflow issue is still useful information: long NRSA search loops are
not clean indefinitely on this bladeRF path, so further NRSA retries should be
short and hypothesis-driven.

## Interpretation

The clean-gain result removes the gain-50 clipping concern from the main
question:

- Live gNB to bladeRF is not dead.
- At RX gain 40 and `+3000 Hz`, the lower-level srsRAN scanner sees only the
  expected PCI 1, with one relatively strong hit (`snr=-4.7 dB`).
- The full NRSA cell-search path still never reports a cell, even with 1000
  trials.

The current boundary is therefore PBCH/MIB-grade acquisition, not PSS/SSS-grade
visibility. The next useful checkpoint is a fresh live gNB to bladeRF raw
capture at RX gain 40, followed by local PBCH window decoding on the same raw
file. That will tell us whether the live capture contains any decodable PBCH at
all, independent of the `nr_sa_cell_search_test` state machine.
