## Interpretation

CP1149 removes the simple bladeRF clipping explanation for the live PBCH failure:

```text
Live gain42 full geometry: light ceiling hits, PBCH KO (CP1144/CP1145)
Live gain36 full geometry: no clipping, lower level, PBCH still KO (CP1149)
Same-vector file replay gain42: no clipping, weak PBCH PASS (CP1147)
LiteX-only current vector: strong PBCH PASS (CP1148)
```

The live failure persists when the bladeRF capture level is clean. That does not
prove gain is irrelevant at every setting, but it makes "gain42 clipping caused
the live PBCH KO" unlikely. The remaining boundary stays around live gNB
streaming/cadence/RF egress/external receive interaction, rather than corrupt
vector content or simple receive saturation.

The next control should replay the same CP1145 pre-DMA vector at bladeRF gain
`36 dB`. If file replay still produces PBCH OK at gain36, CP1149 becomes a
strong live-vs-file replay split at the same external RX gain. If file replay
also fails at gain36, then CP1149 is still useful for ruling out clipping but not
for proving the lower-gain receiver setting is independently PBCH-capable.
