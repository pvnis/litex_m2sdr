## Interpretation

Timed nonzero-island replay does not reproduce the live PBCH failure:

```text
Live gNB gain36 full geometry:              0 / 170 PBCH OK (CP1149)
Continuous file replay gain36 full geometry: 10 / 167 PBCH OK (CP1150)
Timed nonzero replay gain36 full geometry:  34 / 167 PBCH OK (CP1152)
```

This rules out an overly broad "LiteX timed TX API is broken" explanation. The
remaining difference is narrower: live gNB runtime behavior or the exact live
Soapy write pattern/state, not simply timed writes, nonzero sparse islands, RX
gain, vector content, or LiteX-only baseband health.

The next useful split is to compare the exact live gNB write/DMA pattern against
the CP1152 timed replay pattern in more detail, or to run a live gNB variant that
changes the TX stream behavior while preserving the same cell configuration.
