## Conclusion

These checkpoints reinforce the boundary:

- Live gNB RF is present and clean-level.
- The bladeRF RX path is not saturated.
- The live path repeatedly fails PBCH at gain36 with no TX timeouts.
- Frequency correction over a broad range does not recover PBCH.
- Reference correlation overlaps with passing replay controls, so the live
  failure is not explained by total absence of the known waveform.
- Soapy probe logging was not obtained via gNB logs even with Soapy INFO enabled.

The most useful next rung is an exact live TX-dump write-pattern replay: use the
CP1145 `pre_dma_tx.cs16` plus `pre_dma_tx.cs16.meta.jsonl` write sizes, split
boundaries, duplicate timestamps, and HAS_TIME flags rather than the simplified
CP1152 nonzero-island replay. If exact write-pattern replay fails, the live
Soapy write pattern is implicated. If it passes, the remaining difference is
inside the live gNB process/runtime state rather than the observed write
metadata alone.
