## Interpretation

The full-buffer one-shot is misleading here, but the aligned 50 ms sweep passes PBCH in `11/167` windows. This is a valid pass because CP1150, CP1152, and CP1161 also require aligned window evaluation to expose the decodable SSB/PBCH islands.

CP1162 closes the pacing branch tested here:

- Stored metadata pattern passes with CF32 pre-queueing: CP1161.
- Stored metadata pattern also passes with live-like wall pacing and 50 ms lookahead: CP1162.
- The CS16 direct replay branch fails, but CF32 replay of the same sample content passes.

The remaining live failure is now outside the stored vector, stored metadata, and simple standalone pacing model. The suspect narrows to live gNB/runtime state around the Soapy stream, for example interaction with the live gNB process, thread scheduling, queue depth under real runtime conditions, or a live-only driver state not reproduced by standalone replay.

## Next step
