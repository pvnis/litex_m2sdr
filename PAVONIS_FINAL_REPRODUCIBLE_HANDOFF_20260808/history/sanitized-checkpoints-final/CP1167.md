## Interpretation

CP1167 proves the live gNB process can be launched with the same patched module
load environment that recovered CP1166 raw CS16 replay. It did not recover live
RF PBCH.

This narrows the branch:

- Installed-module CS16 scaling was a real replay issue and CP1166 fixed it.
- The same patched module path is not sufficient for live gNB RF recovery.
- Live RF level is clean and not clipped, roughly `-24.14 dBFS`, max `499`.
- The capture overlaps live TX, but the expected PCI and PBCH are not decoded.

The live blocker therefore remains in live runtime presentation/cadence/egress
or another live-only RF interaction, not in the static vector content and not
solely in the installed-module CS16 scaling mismatch.

Next useful work should compare CP1167 live raw against known-pass replay raws
from CP1166/CP1150/CP1152 using the same off-center geometry and reference
correlation. Another blind live retry with only the patched module env would be
a repeat.
