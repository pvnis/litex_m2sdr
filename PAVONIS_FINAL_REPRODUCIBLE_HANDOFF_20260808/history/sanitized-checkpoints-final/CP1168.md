# Checkpoint 1168 - CP1167 live raw versus known-pass replay correlation

## Purpose

Compare the CP1167 live patched-module full-geometry raw capture against the
known-pass current-vector RF replays from CP1150, CP1152, and CP1166.

This is an offline checkpoint. It spends no RF time. It uses saved bladeRF raw
captures, the CP1145 pre-DMA reference vector, correct off-center SSB geometry,
and the existing CP851 reference-correlation scanner.

## Interpretation

CP1168 makes the CP1167 failure sharper:

- CP1167 is not simply low amplitude. Its capture RMS is close to CP1150 and
  CP1166, and it is cleanly unclipped.
- CP1167 is not just a wrong centered-SSB analysis artifact. The correct
  off-center one-shot and off-center 20 ms sweep both fail.
- CP1167 does not correlate with the CP1145 pre-DMA reference like the
  known-pass replays do. Its best reference-correlation score is far lower and
  only marginally better than the conjugate transform.
- CP1166 proves the patched-module CS16-to-SC12 replay path can carry the same
  current vector class to a decodable bladeRF RF capture, so CP1167's live
  failure is not explained by static vector content or by the installed-module
  CS16 scaling mismatch alone.

The next branch should focus on live-only runtime presentation after the vector
leaves the static replay path: live gNB egress cadence, burst/timestamp
semantics, buffer segmentation, or another live-only AD9361/LiteX interaction.
Another patched-module live retry without changing the live presentation would
repeat CP1167.
