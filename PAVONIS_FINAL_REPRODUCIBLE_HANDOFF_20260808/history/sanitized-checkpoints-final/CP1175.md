## Source Change

Files changed:

```text
ocudu/lib/radio/soapy/radio_soapy_tx_stream.cpp
ocudu/lib/radio/soapy/radio_soapy_tx_stream.h
```

The patch keeps the CP1170 empty-discontinuous-EOB behavior and adds the CP1174
segmentation/cadence fix:

- Adds `OCUDU_SOAPY_TX_TRACE_WRITES` for per-`writeStream` logging.
- Adds `OCUDU_SOAPY_TX_FORCE_CHUNK_SAMPLES` as an optional chunk-size limiter.
- Caps normal write requests to the device MTU by default.
- Preserves `SOAPY_SDR_HAS_TIME` on only the first logical write, as before.
- Applies `SOAPY_SDR_END_BURST` only when the current requested chunk is the
  final logical chunk.
- Logs per-write request/return/offset/flags/final/time when trace-writes is
  enabled.

This targets the CP1174 finding that live OCUDU could repeat EOB metadata on
every LiteX short write of an end-marked logical buffer.
