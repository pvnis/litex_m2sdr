## Next Step

The last-EOB/chunk patch improved correlation but did not recover PBCH. The
next useful branch is a targeted baseline before another blind live retry:

1. Run a LiteX-only TX/RX full-geometry baseline with the current source/module
   state to confirm the non-bladeRF path still decodes after CP1176.
2. If LiteX-only still passes, either run a short trace/counter capture to
   verify actual live OCUDU write segmentation without excessive log volume, or
   compare against a forced known-pass chunk size if the LiteX MTU differs from
   replay-helper cadence.
3. Do not move to Android/PRACH until independent downlink PBCH/NRSA is stable.
