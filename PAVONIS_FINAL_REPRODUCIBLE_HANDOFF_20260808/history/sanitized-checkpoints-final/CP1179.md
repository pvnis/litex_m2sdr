## Patch

New env controls:

```text
OCUDU_SOAPY_TX_SUMMARY
OCUDU_SOAPY_TX_SUMMARY_PERIOD
```

The summary is disabled by default. When enabled, it logs one configuration
line, bounded periodic summaries, and a final stop-time summary. The default
period is `10000` logical transmit calls; setting
`OCUDU_SOAPY_TX_SUMMARY_PERIOD=0` disables periodic summaries and keeps only
the stop summary.

Counters include:

```text
logical transmit calls
data and empty logical transmit calls
logical HAS_TIME and END_BURST counts
total data samples
total writeStream calls
data, power-ramp, empty-EOB, and stop-flush writes
requested and returned samples
min/max requested and returned write sizes
zero-request and zero-return writes
HAS_TIME, END_BURST, both-flag, and zero-flag writes
final and non-final data chunks
partial returns, over-returns, timeouts, and errors
MTU, forced chunk size, write timeout, and discontinuous mode
```

The existing unbounded per-write trace remains behind
`OCUDU_SOAPY_TX_TRACE_WRITES`; CP1179 adds a safer aggregate alternative for
live debugging.
