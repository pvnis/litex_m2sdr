# Checkpoint 1185 - Live gNB Env Probe Script Bug

Date: [date-redacted] Europe/Zurich

Scope: [host-redacted]-only live gNB process environment probe. No bladeRF capture, no UE,
no Android, no PBCH/NRSA analysis.

## Result

INVALID as an environment proof, but useful as a script bug isolation.

The wrapper started a live gNB TX window and reached TX-ready, but the env
probe command had a quoting bug:

```text
bash: line 1: $1: unbound variable
GNB_PID=
/proc//environ: No such file or directory
```

The remote `pids.txt` did contain the gNB PID:

```text
qcore 589030
gnb 589091
```

The failed `awk "$1==\"gnb\" ..."` expression expanded `$1` in the shell under
`set -u`. CP1185 therefore did not prove whether the summary env reached the
gNB process.
