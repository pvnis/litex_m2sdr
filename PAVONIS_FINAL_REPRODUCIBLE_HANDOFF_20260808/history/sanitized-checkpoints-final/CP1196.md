live full-geometry downlink.

## Verdict And Next Step

CP1196 proves the suppress-empty-EOB live RF path is operational but not
sufficient. Do not repeat this exact full-geometry RF proof unless a new
variable changes the live egress path.

The next useful branch should move below the already-tested caller-side Soapy
return semantics. Good candidates are:

1. LiteX-only TX/RX OTA or cabled baseline with the current live stack state if
   we need to isolate bladeRF from LiteX again.
2. Instrumenting or comparing the LiteX Soapy driver / FPGA timed-TX arbiter /
   AD9361 presentation below OCUDU's `writeStream` calls.
3. A minimal live-like replay harness that reproduces OCUDU's logical cadence
   but lets us control whether the failure appears before the full gNB stack.

Do not move to Android/PRACH until independent live downlink PBCH/NRSA is
stable.
