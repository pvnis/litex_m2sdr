# Checkpoint 1203 - LiteX TX Time Offset No-RF Late-Header Control

Date: [date-redacted] Europe/Zurich

## Goal

CP1202 proved that an actual post-dedup late timed DMA header can occur during
ordinary full-MTU live TX. CP1203 tests a conservative no-RF mitigation before
spending another RF proof: apply a positive `M2SDR_SOAPY_TX_TIME_OFFSET_NS`
larger than the observed late slip and check whether late headers disappear
without caller-side Soapy errors.

## Conclusion

With `M2SDR_SOAPY_TX_TIME_OFFSET_NS=1000000`, the live gNB no-RF run had:

- `post_late_count=0`
- zero `LiteX TX release late:` lines
- worker `late_count=0`
- no underflows or acquire errors
- OCUDU `samples_req=samples_ret`
- OCUDU `partial_ret=over_ret=timeouts=errors=0`

This proves the post-dedup late-header condition found by CP1202 is removable
with a +1 ms timed-TX offset in the no-RF live gNB path. The next useful
checkpoint is a full-geometry RF proof with the same +1 ms offset and the
existing CP1202 late-trace/release-summary instrumentation enabled.
