## Purpose

Try the missing standalone combination:

- CP1145 `pre_dma_tx.cs16` plus `pre_dma_tx.cs16.meta.jsonl`,

## Interpretation

CP1206 mainly proves the harness/env mistake: setting `SOAPY_SDR_ROOT`,
`SOAPY_SDR_PLUGIN_PATH`, and `M2SDR_SOAPY_TX_CS16_TO_SC12` around the local
CP920 invocation is not enough. The remote helper must set and log the patched
module environment itself.

The clipping matches the old unpatched/raw-CS16 failure class, so do not use
CP1206 as evidence against patched-module CS16 exact metadata replay.
