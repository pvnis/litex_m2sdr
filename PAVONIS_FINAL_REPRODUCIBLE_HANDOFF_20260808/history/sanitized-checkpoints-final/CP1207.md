## Interpretation

CP1207 closes the raw CS16 exact-metadata standalone replay branch when the
patched module is actually loaded. The exact CP1145 CS16 samples plus captured
metadata can produce clean bladeRF RF and PBCH CRC OK through LiteX Soapy.

Compared with the live failure:

- CP1204 live gNB with +1 ms offset: post-dedup late headers zero, PBCH KO,
  20 ms sweep `0/65`, reference score `0.0623252750`.
- CP1207 standalone exact metadata CS16 patched replay: PBCH OK, 20 ms sweep
  `11/65`, 50 ms sweep `33/167`, reference score `0.1219685951`.

So the current live blocker is not the CS16 sample vector, not the exact
captured metadata pattern, not patched CS16-to-SC12 conversion, and not simple
post-dedup timed-header lateness. The remaining standalone isolation is the
wall-clock paced CS16 metadata replay with the same patched module environment.
