## Interpretation

CP1210 is an intermediate/marginal rung, not a clean CP1208-style fail and not
a clean CP1209-style recovery.

Comparison:

- CP1208, 50 ms lookahead: one-shot PBCH KO, 50 ms sweep `0/167`, reference
  score `0.0819968589`.
- CP1210, 150 ms lookahead: one-shot PBCH KO, 50 ms sweep `6/167`, reference
  score `0.0927197786`.
- CP1209, 250 ms lookahead: one-shot PBCH OK, 50 ms sweep `4/167`, reference
  score `0.2486964235`.

The first useful PBCH windows appear by 150 ms lookahead, but the capture is
still not robust enough for the one-shot detector or strong reference
correlation. This suggests two thresholds:

- an aligned-window PBCH threshold somewhere between 50 ms and 150 ms;
- a stronger one-shot/coherence threshold somewhere above 150 ms and at or
  below 250 ms.

## Next Step

Run one lower bracket such as `PACE_AHEAD_S=0.10` to locate the aligned-window
PBCH onset. If 100 ms fails, the onset is between 100 and 150 ms. If 100 ms
passes, test below it. Separately, use `0.20` if the next question is the
stronger one-shot/coherence threshold between 150 and 250 ms.
