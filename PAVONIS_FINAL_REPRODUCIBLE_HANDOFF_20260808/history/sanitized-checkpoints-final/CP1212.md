## Purpose

threshold.

CP1211 passed strongly at 100 ms, while CP1210 was marginal at 150 ms and
CP1209 passed at 250 ms. A repeat control is therefore more informative than
immediately testing another threshold value: it separates a stable setting from
timing phase or run-to-run coherence sensitivity.

## Interpretation

CP1212 is a marginal repeat of the CP1211 100 ms pass.

The TX side is clean and the reference correlation is still high, but PBCH
stability is not reproduced:

- CP1211 at 100 ms: one-shot PBCH OK, 20 ms sweep `9/65`, 50 ms sweep
  `13/167`, reference `0.3144885418`.
- CP1212 at 100 ms repeat: one-shot PBCH KO, 20 ms sweep `0/65`, 50 ms sweep
  `3/167`, reference `0.2963808035`.

This means 100 ms lookahead is not a stable all-by-itself threshold. It is
better than CP1208's 50 ms failure class and it can produce strong correlation,
but PBCH decode depends on timing phase, capture placement, or another
run-to-run coherence variable not captured by the simple lookahead scalar.

## Next Step

Do not jump to live gNB yet. The next useful rung is a reproducibility-oriented
control:

- run another 100 ms repeat only if quantifying variability is the priority, or
- run `PACE_AHEAD_S=0.075` to test whether the 50-to-100 ms lower edge is
  meaningful, while interpreting a single pass/fail cautiously.

Because CP1212 stayed high-correlation but PBCH-marginal, also consider adding
a capture-placement or reference-start diagnostic to distinguish "good RF but
PBCH not in the analysis window" from true PBCH damage.
