## Interpretation

CP1212 was not a true "no PBCH" repeat. The first 20 ms had zero PBCH OK
windows and the first 50 ms had only 3 PBCH OK windows, so the earlier
classification as marginal was correct for the short inspection window. The
250 ms sweep shows that the same capture contains many later decodable PBCH
windows, including strong windows around 83 ms and windows aligned with the
reference-correlation best start around 167 ms.

This changes the branch interpretation:

- The 100 ms paced-CS16 patched-module path is reproducibly decodable in both
  CP1211 and CP1212 when the analysis searches enough of the capture.
- The visible PBCH windows move substantially between runs. CP1211 has early
  strong windows near 10 ms and 40 ms, while CP1212's strongest window is near
  83 ms.
- Short 20-50 ms sweeps are not a sufficient classifier for paced metadata
  captures unless the capture placement is already known.
- The remaining issue is capture/window placement and run-to-run phase/coherence
  variability, not absence of a decodable 100 ms paced-CS16 RF signal.
