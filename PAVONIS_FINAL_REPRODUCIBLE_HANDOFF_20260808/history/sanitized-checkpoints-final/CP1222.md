# CHECKPOINT 1222: Live timestamped full-geometry +1 ms RF proof

Date: [date-redacted] Europe/Zurich

## Goal

Run the live OCUDU gNB full-geometry downlink with the current patched LiteX
Soapy module, suppress-empty-EOB path, and `+1 ms` TX timestamp offset, while
capturing one second on the bladeRF with CP1219 metadata timestamping.

The specific question was whether the CP1220 timestamped bladeRF harness would
show hidden later PBCH windows in a live gNB RF capture, analogous to the
paced-CS16 replay cases, or whether live full-geometry still fails across a
250 ms off-center sweep despite continuous capture and clean TX counters.

No UE, PRACH, NRSA, or Android operation was included.

## Interpretation

CP1222 passes as a harness and observability checkpoint:

- live gNB start, capture, analysis, log collection, and cleanup all completed
  under one script
- the one-second bladeRF metadata capture was complete and timestamp-continuous
- no bladeRF overrun/underrun or timestamp gap was observed
- live caller-side Soapy counters and LiteX worker summaries were clean through
  the last observed periodic summaries
- `+1 ms` TX offset kept observed live worker lateness at zero in the captured
  window
- empty-gap EOB suppression was active

CP1222 fails as an RF/PBCH checkpoint:

- one-shot PBCH was CRC KO
- the full 250 ms off-center sweep found `0/847` PBCH CRC OK windows
- the sweep found `0/847` PBCH PCI1 windows
- only `4/847` CSI windows reported expected PCI1, all at poor SNR
- reference correlation was only `0.0275720579`, matching failed-live behavior
  rather than known-pass replay behavior

This closes the immediate "maybe live PBCH is present later in the capture,
as with paced-CS16 replay" theory for this live full-geometry +1 ms run. A
250 ms phase-aware style analysis still finds no live PBCH windows.

## Current Frontier Update

Do not repeat live full-geometry +1 ms timestamped bladeRF capture without
changing a meaningful variable. CP1222 already combines:

- live gNB full geometry
- patched build-module Soapy environment
- forced CS16-to-SC12 conversion
- suppress-empty-EOB
- `+1 ms` TX timestamp offset
- continuous one-second bladeRF metadata capture
- 250 ms off-center PBCH sweep
- first-2M reference correlation

The next useful branch should compare live capture placement/content against
same-window digital TX dump material, add tighter live schedule/capture
placement instrumentation, or build a minimal live-cadence replay that
preserves OCUDU-like timing, chunking, format, and discontinuity behavior while
remaining analyzable over 250 ms.

If that branch stalls, use the LiteX-only TX/RX OTA baseline to isolate
bladeRF/LiteX interaction before another full live RF proof.
