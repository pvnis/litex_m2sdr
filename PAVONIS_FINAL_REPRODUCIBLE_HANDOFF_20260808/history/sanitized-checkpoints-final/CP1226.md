## Method

The generator parsed CP1223 `tx_dma_buffers.bin.meta.jsonl`, extracted the
channel 0 and channel 1 payloads from each DMA frame, rebuilt the start sample
for every row from `timestamp_samples`, and wrote two classes of vectors:

- concatenated CF32 vectors, where each DMA row is stored back-to-back and the
  metadata carries the gaps
- gap-expanded CF32 vectors, where the observed timestamp gaps are zero-filled
  locally for analysis/reference correlation

It then generated `actual_dma_ch0_concat_replay_meta.jsonl` with:

- one row per actual DMA row
- `numElems=1022` for every row
- monotonic generated `timeNs` for pacing every row
- `SOAPY_SDR_HAS_TIME` preserved only on the original 35 timed DMA rows
- `inputOffsetElems` pointing into the concatenated ch0 CF32 vector

## Interpretation

CP1226 proves the CP1223 actual-DMA dump can be represented as a replay-ready
partial 512-row CF32 metadata payload that preserves the observed 35 timed DMA
headers and positive gap pattern without overlaps.

The important caveat is that CP1223's actual-DMA dump is partial. It captures
only the first `512` DMA rows, covering `0.172443576 s` of reconstructed
actual-DMA time. The CP1223 pre-DMA metadata span is `0.672611110 s`, so the
dump does not contain about `0.500167535 s` of the full metadata span. The next
RF replay must not silently loop the 512-row dump at the short `0.172443576 s`
duration and pretend it is the full live period.

## Status

CP1226 is a local preparation pass. It creates a reusable payload for the next
RF rung but also tightens the requirement for that rung:

- use a CF32 metadata player
- pace by generated monotonic row `timeNs`
- set `SOAPY_SDR_HAS_TIME` only on the 35 original timed rows
- if repeating the partial DMA window, pad or override the loop period to the
  `0.672611110 s` CP1223 pre-DMA metadata span

This is the next useful step after CP1225 because it preserves actual-DMA gaps
more tightly than the pre-DMA paced replay, while acknowledging that the CP1223
DMA dump is only a partial live window.
