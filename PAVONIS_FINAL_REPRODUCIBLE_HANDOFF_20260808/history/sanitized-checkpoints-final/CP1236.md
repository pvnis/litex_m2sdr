## Interpretation

Status: RF pass / diagnostic pass.

CP1236 applies the CP1235 attenuation bracket to the live gNB path and recovers
decodable RF PBCH without weakening the digital guardrails. The same-window
pre-DMA, post-DMA ch0, and reconstructed timed-DMA ch0 material still decode
PBCH, the [date-redacted]-row actual-DMA reconstruction remains full-span with no
overlaps, the timestamped bladeRF capture is continuous, and the RF classifier
now finds `27/847` PBCH OK windows.

This is the first live full-geometry timestamped RF proof in this branch that
moves the paired live RF capture out of the CP1228/CP1234 failed-live class.
It strongly supports the CP1233-CP1235 conclusion that live TX
attenuation/backoff was the leading blocker for independent downlink PBCH.

The one-shot PBCH test remains KO, so future RF checks should keep using the
250 ms or phase-aware classifier. Do not repeat the live `TX_BACKOFF=20` proof
or the helper `5/10/15/20 dB` attenuation points without a new variable.

Next useful rung: establish whether this recovered live downlink is stable
enough for NRSA/cell-search style validation at the `10 dB` backoff class,
using the same cleanup discipline and avoiding Android/PRACH until independent
downlink PBCH/NRSA is stable.
