## Interpretation

CP1239 is a clean live NRSA no-cell result, not a transport or cleanup failure.
The recovered live downlink now has:

- PBCH windows over timestamped bladeRF RF capture: pass at CP1236.
- Lower-level `nr_cell_search_rf` expected PCI only: pass at CP1238.
- Full `nr_sa_cell_search_test`: no cell at CP1239 with 100 trials.

This means the live downlink has enough signal for the lower-level scanner and
offline PBCH-window classifier, but the full NRSA state machine still does not
cross its cell-search/acquisition gate. Do not repeat this exact
`TX_BACKOFF=10`, RX gain 40, `+3000 Hz`, SSB-centered 100-trial NRSA run
without adding a new diagnostic variable.

The next useful branch should isolate why `nr_sa_cell_search_test` misses when
`nr_cell_search_rf` and offline PBCH evidence pass. Good candidates are a
short NRSA diagnostic build/log that exposes per-trial PSS/SSS/PBCH outcomes,
or a paired CP1239-style raw capture with the same NRSA window to compare the
state machine's live input against the existing CP1236 PBCH-pass classifier.
