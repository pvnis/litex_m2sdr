# CHECKPOINT 1242: NRSA Trace on Known-Pass CP1129 Replay

Date: [date-redacted]

## Goal

Establish a traced NRSA SNR baseline on a known-pass LiteX-to-bladeRF replay.
CP1241 showed the live gNB NRSA path sees expected PCI1 candidates but rejects
them at the state-machine gate because SNR is about `-20 dB`, below the
`-10 dB` threshold despite PBCH CRC true. CP1242 reruns the CP1129 known-pass
replay through the same CP1240/CP1241 trace wrapper to measure what NRSA SNR
looks like when acquisition and camping succeed.

## Comparison To CP1241

CP1241 live gNB trace:

```text
trial 31: pci=1 snr=-21.570 pbch_crc=1 result=0
trial 54: pci=1 snr=-20.409 pbch_crc=1 result=0
```

CP1242 known-pass replay trace:

```text
trial 4: pci=1 snr=+4.748 pbch_crc=1 result=1
```

The same CP1240-instrumented NRSA state machine therefore accepts when SNR is
well above the `-10 dB` gate and rejects the CP1241 live candidates because
their NRSA SNR metric is roughly `25 dB` lower. This makes the next frontier
signal quality/level/normalization at the NRSA input or live RF delivery, not a
broken CP1240 trace, not a generic NRSA camping failure, and not an all-empty
state-machine handoff.
