## Interpretation

CP1255 removes the main CP1254 confounder. With clean gNB counters, the same
software behavior and the same high-level RF result repeat:

- initial cell search succeeds on expected PCI1;
- SFN sync sees multiple PBCH-CRC-true hits;
- every decoded hit has absolute delay far above `2.4 us`;
- CP1253 rejects each hit before feedback mutation;
- no TRACK transition, no CAMPING, and SFN sync reaches max trials.

The current strict absolute-delay threshold is too narrow for this live SFN
path, but simply allowing all large delays is known-bad from CP1250 because it
enters TRACK with large negative offsets and then loses PBCH. The next useful
rung is to widen the absolute-delay gate in a bounded way, starting around
`10 us`, because CP1254 contained one rejected PBCH hit at `+8.076634 us`.
