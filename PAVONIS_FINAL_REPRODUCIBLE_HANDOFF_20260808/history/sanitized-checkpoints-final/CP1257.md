## Interpretation

CP1257 proves `30 us` is wide enough to recover SFN sync and CAMPING at the
current RF point. It also proves that the old CP1250 large-negative-delay
explanation is not sufficient for the post-camping failure: the first
post-camping TRACK period entered with a small, plausible delay of
`-1.817929 us`, yet all 20 TRACK opportunities had PBCH CRC false and the
state dropped back to FIND.

The active failure is now narrower:

- initial cell search can pass;
- SFN sync can pass with bounded absolute-delay gating;
- bad-delay feedback rejection works;
- gNB TX counters remain clean;
- post-camping TRACK still fails by repeated PBCH misses.

The next useful rung should focus on the TRACK path itself, not only the
FIND-to-TRACK delay threshold. Candidate next steps are to instrument or alter
TRACK SSB search assumptions: selected subframe/slot, half-frame, SSB index,
search window placement, and CFO/delay feedback applied during TRACK. A blind
wider gate is lower value now, because `30 us` already restores CAMPING and
the first failure occurs after a small `-1.8 us` TRACK entry.

## Checkpoint Status

Result: **CAMPING PASS, THEN POST-CAMPING TRACK PBCH-MISS FAIL**.

Reusable conclusion: `30 us` is sufficient to recover SFN/CAMPING, but not
post-camping stability. Large negative FIND-to-TRACK delay is no longer
necessary for the TRACK PBCH-miss failure.
