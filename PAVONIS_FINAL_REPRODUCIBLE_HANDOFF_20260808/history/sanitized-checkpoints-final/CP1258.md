Date: [date-redacted] Europe/Zurich

## Goal

CP1257 restored SFN sync and CAMPING with a `30 us` absolute delay gate plus
bad-delay feedback rejection, but post-camping TRACK still failed with 40/40
TRACK PBCH CRC misses across two 20-miss cycles. This checkpoint adds bounded
TRACK-path diagnostics to distinguish two cases in the next live RF rung:

- TRACK is looking in the wrong place or with the wrong context while the same
  1 ms buffer still contains decodable PBCH.
- The TRACK opportunity buffer itself no longer contains a decodable SSB/PBCH.

paired TRACK decode result. Default behavior remains unchanged unless the new
env is enabled.

## Interpretation

CP1258 is a build/deploy checkpoint, not an RF result. It prepares the next
live RF rung by adding a direct discriminator for the CP1257 post-camping TRACK
misses:

- If `track_pbch_crc=0` but `search_crc=1` on the same opportunity buffer,
  focus on TRACK placement/context: `ssb_idx`, half-frame, candidate offset,
  periodicity/SFN, or TRACK-specific PBCH decode assumptions.
- If both `track_pbch_crc=0` and `search_crc=0`, the buffer presented at the
  TRACK opportunity is itself not blindly decodable and the next rung should
  look at timing drift, CFO feedback, sample-offset application, or live RF
  continuity into TRACK.
