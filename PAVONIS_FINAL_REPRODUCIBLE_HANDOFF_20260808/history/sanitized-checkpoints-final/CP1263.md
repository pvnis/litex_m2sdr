# Checkpoint 1263: opt-in TRACK blind fallback build/deploy and first live attempt

Date: [date-redacted] Europe/Zurich

## Goal

Test the CP1262 finding that blind same-buffer SSB search can occasionally
decode PBCH while scheduled TRACK decode fails at the same opportunity.

CP1263 added an opt-in behavior:

```text
PAVONIS_SRSUE_UE_SYNC_NR_TRACK_BLIND_FALLBACK=1
PAVONIS_SRSUE_UE_SYNC_NR_TRACK_BLIND_FALLBACK_LIMIT=20
```

When scheduled TRACK PBCH fails, the code can use a same-current-1ms blind
sidecheck hit only if it has PBCH CRC true and matching PCI. It then resets
the TRACK miss streak and feeds the blind result through the existing
`ue_sync_nr_update_ssb()` path. Default behavior is unchanged unless the env
knob is enabled.

## Conclusion

CP1263 passed the software/deploy rung: the opt-in blind fallback builds
locally, deploys to `[host-redacted]`, rebuilds remotely, and is active in the wrapper.

The first live attempt did not test the fallback behavior because the UE
SFN-failed before CAMPING/TRACK. A same-point rerun is justified before
changing code again, because CP1262 reached TRACK at the same 60 us gate and
CP1263 needs a TRACK window to exercise the new behavior.
