## Conclusion

CP1268 is a clean same-point rerun but still does not exercise feedback-only
fallback. The run found expected PCI1 with healthy initial SNR, then SFN failed
before TRACK with zero `update_ssb`, zero TRACK opportunities, and zero
fallback events.

After CP1267 and CP1268, the feedback-only fallback code is built, deployed,
active in the wrapper, and still untested live. This is not evidence that
feedback-only fallback fails; it is evidence that the current live point can
still SFN-fail before reaching the post-camping TRACK branch. A further
same-point rerun remains defensible because CP1266 reached TRACK at this point,
but if the no-TRACK/SFN-fail pattern persists, the next branch should isolate
SFN acquisition variability before drawing conclusions about feedback-only
fallback behavior.
