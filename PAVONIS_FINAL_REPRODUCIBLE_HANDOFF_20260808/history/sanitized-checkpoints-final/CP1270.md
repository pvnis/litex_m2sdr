# Checkpoint 1270: TRACK fallback offset correction build/deploy and first live attempt

Date: [date-redacted] Europe/Zurich

## Goal

Test the next opt-in rung after CP1269. CP1269 proved feedback-only fallback
works mechanically, but the single valid rolling blind hit was far from the
scheduled TRACK offset:

```text
selected_sf_offset=825
search_current_offset=-1359
search_minus_selected_offset=-2184
feedback-only next_rf_offset_after=7
```

CP1270 adds a default-off offset correction path so feedback-only fallback can
optionally set `next_rf_sample_offset` from the blind hit offset delta plus the
normal residual feedback offset.

## Code Change

Edited:

```text
srsRAN_4G/lib/src/phy/ue/ue_sync_nr.c
```

New default-off controls:

```text
PAVONIS_SRSUE_UE_SYNC_NR_TRACK_FALLBACK_OFFSET_CORRECT=1
PAVONIS_SRSUE_UE_SYNC_NR_TRACK_FALLBACK_OFFSET_CORRECT_MAX_SAMPLES=6000
```

When feedback-only fallback is active and offset correction is enabled, the
code computes:

```text
raw_corrected_offset = fallback_result->offset_delta + feedback_next_offset
```

It applies the correction only if the value is inside the configured absolute
sample limit and inside the subframe size. The trace now logs
`track_fallback_offset_correction`, whether it was applied, the selected and
blind offsets, `feedback_next_rf_offset`, and the corrected offset.

## Conclusion

CP1270 validates the software/build/deploy rung for offset-corrected
feedback-only fallback. The new source built locally and remotely, the remote
binary contains the new env knobs and trace strings, the live wrapper enabled
the offset correction controls, and the gNB/harness side stayed clean.

The live RF attempt did not test the new behavior. It SFN-failed before
CAMPING/TRACK, so there were zero TRACK opportunities, zero fallback events,
and zero `track_fallback_offset_correction` events. This should not be counted
as evidence that offset correction is ineffective.

The next justified step is a same-point rerun with the CP1270 binary and
wrapper. CP1263/CP1265/CP1267 all had first attempts that SFN-failed before
TRACK, and CP1269 already proved this RF point can reach TRACK and exercise a
rolling feedback-only fallback.
