## Conclusion

CP1271 is a clean same-point rerun of the CP1270 offset-corrected fallback
configuration, but it still does not test offset correction. The run found
expected PCI1, then SFN-failed before CAMPING/TRACK with zero `update_ssb`,
zero TRACK opportunities, zero fallback events, and clean gNB counters.

This is now two consecutive CP1270-binary live attempts that SFN-failed before
TRACK, but CP1269 showed the same RF point can reach TRACK and exercise a
rolling feedback-only fallback. One more same-point rerun is justified before
changing code or delay gates. If the next rerun also SFN-fails before TRACK,
the active branch should pivot from offset-correction behavior to SFN
acquisition variability under the 60 us feedback-reject gate.
