## Conclusion

CP1303 is a negative raw downlink budget probe. Matching CP1298's independent
capture bandwidth in the srsUE bladeRF path did not raise the scheduled
TRACK-opportunity gate:

```text
CP1302: 11.52 Msps / 9.216 MHz BW / RXG32 -> mean -21.986 dB, 0/73 >= -10 dB
CP1303: 11.52 Msps / 10.000 MHz BW / RXG32 -> mean -22.382 dB, 0/79 >= -10 dB
```

Do not resume `ue_sync_nr.c` sync/anchor scheduler work from this result. The
current frontier remains raw live downlink/link budget. The next raw-only probe
should change a different RF/link-budget variable, not timing-anchor logic.
