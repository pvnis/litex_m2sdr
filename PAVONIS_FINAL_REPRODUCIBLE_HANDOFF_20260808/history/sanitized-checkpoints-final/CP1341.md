# Checkpoint CP1341 - CP1332 Direct Track-at-Offset Probe

Date: [date-redacted] Europe/Zurich

## Purpose

Remove CP1340's main ambiguity by calling the same SSB primitive used by the
live scheduled TRACK path: `srsran_ssb_track_at_offset()`. This is an offline
local analysis of the CP1332 dump. It performs no RF run and no `ue_sync_nr.c`
source edit.

The live raw scheduled TRACK gate remains active and failed until a live run
raises mean `event=track_opportunity meas_snr` and the fraction of
opportunities `>= -10 dB`.

## Method

The runner tests CP1332 opportunities `48..72`.

For every opportunity, it extracts the live-equivalent 1 ms RF-call crop and
runs:

```text
srsran_ssb_track_at_offset(..., t_offset=825)
```

For the six opportunities where CP1340 found a PBCH-OK crop, it also runs
`srsran_ssb_track_at_offset()` at the CP1340-derived absolute PBCH offset
inside a 5 ms crop starting at the same RF-call boundary.


## Interpretation

CP1341 proves the CP1332 dump contains PBCH-decodable samples that the same
SSB tracking primitive can decode, but not at the live static offset. The
live-equivalent static offset remains sub-threshold and CRC-false in offline
replay, matching the live trace. The successful alternate offsets are not a
ladder unlock because they are not the scheduled live TRACK metric.

This weakens antenna-overheat or broad RF-power-loss theories for these
CP1332 samples: the RF samples are present and decodable in the dump. The
remaining frontier is receive-buffer/slot-phase/timing alignment at the live
static TRACK opportunity, or a true RF-path change that raises the live static
metric without editing `ue_sync_nr.c` sync/anchor logic.

## Verdict

CP1341 is not a live gate pass. It is a reusable offline diagnostic baseline:
static `track_at_offset(825)` fails `0/25`, while alternate offsets decode
`6/6` on the same CP1332 samples. Do not move to PRACH/Android/NAS and do not
resume `ue_sync_nr.c` scheduler edits until a live run raises the scheduled
TRACK mean SNR and `>= -10 dB` fraction.
