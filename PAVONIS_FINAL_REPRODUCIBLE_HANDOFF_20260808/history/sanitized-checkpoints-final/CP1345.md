# Checkpoint 1345 - SSB-Centered TX_BACKOFF4 Raw Scheduled TRACK Probe

Date: [date-redacted] Europe/Zurich

## Goal

CP1334 and CP1342 showed the best local SSB-centered live scheduled TRACK
point at `TX_BACKOFF=3`, RX gain `32`, `5.76 Msps`, `rf.freq_offset=+3500 Hz`,
but it remained below the raw downlink gate. CP1344 closed the helper-gain
class / RX gain `60` theory at that same point. CP1345 tests one remaining
small RF-budget hypothesis: whether backing off gNB TX drive from `3` to `4`
avoids analog overdrive and raises the scheduled TRACK metric.

This is a raw-gate checkpoint only. It does not edit `ue_sync_nr.c`
sync/anchor logic and does not move to PRACH, Android, or NAS.

## Verdict

CP1345 does not raise the raw scheduled downlink gate. Backing off the gNB
from `TX_BACKOFF=3` to `TX_BACKOFF=4` at the SSB-centered RX gain `32`,
`+3500 Hz` point still produces a sub-threshold scheduled TRACK metric:
mean `-21.903 dB`, `0/72 >= -10 dB`, and zero TRACK PBCH hits.

This closes SSB-centered `TX_BACKOFF=4` as an analog-overdrive relief fix. The
active ladder gate remains unchanged: no more `ue_sync_nr.c` sync/anchor edits
and no PRACH/Android/NAS work until a live scheduled TRACK run raises mean
TRACK SNR and the `>= -10 dB` opportunity fraction.
