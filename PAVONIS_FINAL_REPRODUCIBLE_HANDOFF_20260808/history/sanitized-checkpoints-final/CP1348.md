# Checkpoint 1348 - SSB-Centered +4000 Hz Frequency-Offset Probe

Date: [date-redacted] Europe/Zurich

## Goal

CP1334 made `rf.freq_offset=+3500 Hz` the best local SSB-centered frequency
offset so far, but the scheduled TRACK metric remained below gate. CP1345
through CP1347 closed lower gNB TX drive as a fix. CP1348 extends the
SSB-centered frequency-offset bracket upward to `+4000 Hz` at the same
baseline: `TX_BACKOFF=3`, RX gain `32`, `5.76 Msps`, and default RX bandwidth.

This is a raw-gate checkpoint only. It does not edit `ue_sync_nr.c`
sync/anchor logic and does not move to PRACH, Android, or NAS.

## Verdict

CP1348 does not raise the raw scheduled downlink gate. Raising the
SSB-centered [interface-redacted] offset from `+3500 Hz` to `+4000 Hz` worsens the scheduled
metric to mean `-22.958 dB`, with `0/86 >= -10 dB`, `1/86 >= -15 dB`, and
zero TRACK PBCH hits.

This closes `+4000 Hz` as an upward frequency-offset fix at the current
SSB-centered `TX_BACKOFF=3`, RX gain `32`, default-bandwidth point. The active
ladder gate remains unchanged: no more `ue_sync_nr.c` sync/anchor edits and no
PRACH/Android/NAS work until a live scheduled TRACK run raises mean TRACK SNR
and the `>= -10 dB` opportunity fraction.
