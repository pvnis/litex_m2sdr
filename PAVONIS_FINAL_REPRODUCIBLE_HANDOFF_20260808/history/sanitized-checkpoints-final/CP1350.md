# Checkpoint 1350 - SSB-Centered 420 us gNB TX Time-Offset Probe

Date: [date-redacted] Europe/Zurich

## Goal

CP1340/CP1341 showed that the CP1332 TRACK-era samples are PBCH-decodable
away from the live static `selected_sf_offset=825`, with the nearest
successful offline direct-track offset about `+580 us` from static. CP1350
tests whether moving the gNB timed TX release earlier by that amount raises
the live scheduled TRACK metric, without editing `ue_sync_nr.c`.

The RF point returns to the best local SSB-centered baseline:
`TX_BACKOFF=3`, RX gain `32`, `5.76 Msps`, default RX bandwidth, and
`rf.freq_offset=+3500 Hz`. The changed variable is only
`M2SDR_SOAPY_TX_TIME_OFFSET_NS`, reduced from the usual `1000000 ns` to
`420000 ns`.

This is a raw-gate checkpoint only. It does not edit `ue_sync_nr.c`
sync/anchor logic and does not move to PRACH, Android, or NAS.

## Verdict

CP1350 does not raise the raw scheduled downlink gate. Reducing
`M2SDR_SOAPY_TX_TIME_OFFSET_NS` from `1000000 ns` to `420000 ns` at the
best local SSB-centered RF point gives mean `-22.063 dB`, with
`0/76 >= -10 dB`, `0/76 >= -15 dB`, and zero TRACK PBCH hits.

The timing knob was applied and the gNB remained clean, so this closes the
nearest `+580 us` CP1340/CP1341 offline-offset sign as a raw-gate fix. The
active ladder gate remains unchanged: no more `ue_sync_nr.c` sync/anchor edits
and no PRACH/Android/NAS work until a live scheduled TRACK run raises mean
TRACK SNR and the `>= -10 dB` opportunity fraction.
