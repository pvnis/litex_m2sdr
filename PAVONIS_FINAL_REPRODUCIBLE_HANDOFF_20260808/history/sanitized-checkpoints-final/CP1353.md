# Checkpoint 1353 - SSB-Centered 2360 us gNB TX Time-Offset Probe Blocked Before RF

Date: [date-redacted] Europe/Zurich

## Goal

CP1353 was intended to test another CP1341 alternate timing hypothesis without
editing source code. CP1341 found an alternate direct TRACK decode at
opportunity 70 with delta `+1360.4 us` from the live static window and direct
TRACK SNR `-13.4 dB`. The planned live gNB timed-TX offset was:

```text
default M2SDR_SOAPY_TX_TIME_OFFSET_NS=1000000
plus CP1341 alternate delta=1360400
planned M2SDR_SOAPY_TX_TIME_OFFSET_NS=2360400
```

The intended RF point matched CP1350-CP1352: `TX_BACKOFF=3`, RX gain `32`,
SSB-centered `freq_dl=target_ssb=1839650000`, `5.76 Msps`, default
`4.608 MHz` RX bandwidth, and `rf.freq_offset=+3500 Hz`.

This checkpoint did not reach RF. It does not provide a scheduled TRACK metric
and is not a raw-gate pass or failure.

## Method

No source files were changed. A thin runner was added:

```text
cp1353_run_live_nrsa_rawtrack_ssbcenter_txbackoff3_rxg32_srate5760k_foffp3500_timeoffset2360us.sh
```

The runner was started with SSH/SCP escalation because the same helper pattern
is blocked by the local sandbox. The run failed during the first three
[host-redacted] helper steps and skipped the CP1239 RF harness:


No gNB TX window was started for CP1353.

## Verdict

CP1353 is a pre-RF infrastructure block, not a radio result. The planned
`M2SDR_SOAPY_TX_TIME_OFFSET_NS=2360400` raw-gate test remains unrun and should
be retried only after [host-redacted] is visible on Tailscale or another known-good
route to the bladeRF host exists.

The active ladder gate remains unchanged: no more `ue_sync_nr.c` sync/anchor
edits and no PRACH/Android/NAS work until a live scheduled TRACK run raises
mean TRACK SNR and the `>= -10 dB` opportunity fraction.
