# Checkpoint CP1366 - CP1364 Alternate-Offset Phase/SFN Audit

Date: [date-redacted] Europe/Zurich

## Purpose

Audit the CP1365 alternate-offset decodes before spending another live RF run
on a timing knob. CP1365 proved the CP1364 `RX_NOW` dump decodes at alternate
offsets, but that alone does not prove those alternates are the scheduled
same-frame TRACK opportunity.

This is a no-RF checkpoint: no gNB/UE run, no PRACH, no Android/NAS, and no
`ue_sync_nr.c` sync/anchor logic edit.

The active ladder gate remains the live scheduled TRACK metric: mean
`event=track_opportunity meas_snr` and the fraction of opportunities
`>= -10 dB`.

## Method

For each of the 19 CP1365 alternate-offset direct decodes, the audit compares
the decoded PBCH `track_sfn_lsb` from `srsran_ssb_track_at_offset()` with the
live trace's scheduled `sfn % 16` for that `event=track_opportunity`.

This is a phase sanity check, not a new decoder. The comparison asks whether a
CP1365 alternate decode is plausibly the same scheduled TRACK frame, or a
neighboring/wrong-phase SSB decode found inside the larger offline crop.

## Interpretation

CP1366 explains why using the CP1365 alternate offsets directly as new gNB
TX-time-offset RF probes is risky:

- Most alternate decodes (`13/19`) do not match the live scheduled
  `sfn % 16`.
- The useful-looking high-SNR alternate (`opportunity=33`, `-4.3 dB`) is
  wrong-phase (`lsb_delta_mod16=7`).
- Same-phase alternates exist, but they are still weak: `0/6 >= -15 dB` and
  best same-phase SNR is only `-17.7 dB`.
- The same-phase timing deltas cluster near static (`-99..+553 us`), which
  overlaps the already-tested CP1350/CP1351 `+/-580 us` timing branch and does
  not give a strong new constant-offset candidate.

So CP1365 does not justify spending RF on another large CP1341-style timing
offset such as `+1.44 ms`, `+1.85 ms`, or `+4.48 ms`: those decodes mostly
belong to different `sfn_lsb` phase buckets.

## Verdict

CP1366 is not a ladder unlock and does not raise the live scheduled TRACK
metric. It is a reusable no-RF filter for the CP1365 result: alternate offsets
prove the dump contains decodable PBCH, but they do not provide a clean
same-phase timing knob for the live scheduled static TRACK path.

The next useful work should avoid another broad gNB time-offset sweep derived
from all CP1365 alternates. It should instead target the receive-buffer/slot
phase question directly, or test a true RF/link-budget/transport change that
is judged by the live scheduled TRACK gate.
