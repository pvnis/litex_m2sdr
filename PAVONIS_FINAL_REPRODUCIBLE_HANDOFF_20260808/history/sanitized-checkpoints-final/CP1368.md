## Goal

Test whether the user's "live gNB native CF32" suspicion is feasible as a
controlled source-level A/B. CP1363 already showed there is no YAML/config-only
CF32 switch in OCUDU. CP1368 therefore adds an env-gated TX-only Soapy format
patch and builds it on the actual live [host-redacted] Soapy/M2SDR gNB tree before any RF
time is spent.

This checkpoint does not run RF and does not unlock the ladder. It only proves
that a live RF checkpoint can now select CF32 TX transport with an environment
variable.

## Patch

Files patched locally and deployed to [host-redacted]:

- `/home/[host-redacted]/CLionProjects/ocudu/lib/radio/soapy/radio_soapy_device.h`
- `/home/[host-redacted]/CLionProjects/ocudu/lib/radio/soapy/radio_soapy_tx_stream.h`
- `/home/[host-redacted]/CLionProjects/ocudu/lib/radio/soapy/radio_soapy_tx_stream.cpp`

Behavior:

- Default path remains `SOAPY_SDR_CS16`.
- TX stream only can be switched to `SOAPY_SDR_CF32` with
  `OCUDU_SOAPY_TX_FORMAT=cf32` or `OCUDU_SOAPY_TX_CF32=1`.
- RX remains unchanged.
- OCUDU's existing `ci16_t` TX chunks are converted to `cf_t` scratch buffers
  with `ocuduvec::convert(..., scale=32767)`.
- Chunking, timestamps, EOB handling, forced chunking, and existing TX summary
  counters are preserved.
