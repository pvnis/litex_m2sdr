## Conclusion

Live gNB TX CF32 at the current CP1373 least-bad geometry does not raise the
raw downlink budget. It should be treated as closed as a raw-gate fix unless
the implementation changes materially.

The result also further weakens the broad theory that the scheduled-TRACK SNR
collapse is caused simply by live gNB Soapy API format conversion/downsample.
It does not prove the M2SDR hardware path is float-native end to end; the known
local implementation still converts OCUDU `ci16_t` chunks to CF32 scratch
buffers before the Soapy call, and the lower device path remains integer/DMA
backed. But at the live-gNB API boundary, CF32 does not improve the raw gate.

Continue to gate all ladder movement on raw scheduled TRACK improvement. Do
not resume `ue_sync_nr.c` scheduler/sync/anchor edits, and do not move to
PRACH/Android/NAS from this result.
