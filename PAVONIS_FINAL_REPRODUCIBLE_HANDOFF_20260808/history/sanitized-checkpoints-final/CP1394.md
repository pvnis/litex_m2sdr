## Native CF32 Note

This checkpoint intentionally did not retest live TX CF32. CP1369 and CP1388
already tested live gNB TX CF32 at the Soapy API boundary at the older
`5.76 Msps` and current CP1373 `7.68 Msps` geometry classes. Both failed the
raw scheduled-TRACK gate, with clean TX health. The LiteX/AD9361 path is also
not float-native end to end; CF32 at the Soapy API boundary still eventually
feeds integer hardware lanes. The current evidence points away from blind TX
CF32 retests and toward RX/link-budget/receive-path isolation.

## Verdict

CP1394 proves the live gNB-owned M2SDR RX append path is reading channel 0 at
the intended SSB-centered geometry: `1839650000 Hz`, `11.52 Msps`,
`7.68 MHz` bandwidth, and gain `66 dB`. Same-run digital TX remains
PBCH-decodable and TX counters remain clean.

Despite that, the 250 ms gNB-owned RX append stream still decodes no PBCH and
no CSI PCI1. CP1394 does not raise the raw scheduled-TRACK gate and does not
unlock the ladder. It rules out a simple "wrong gNB-owned RX [interface-redacted]/rate/BW" bug
for this append diagnostic. Next work should either isolate LiteX RX with a
known TX/RX OTA baseline using the gNB-owned or helper path, or change the
actual link budget/RX path before revisiting scheduler/offset logic.
