# CP1395 LiteX Split-Frequency Full-Geometry RX-Centered Baseline

Date: [date-redacted]

## Purpose

CP1394 proved that the live gNB-owned M2SDR RX append stream was actually
configured at the intended SSB-centered receive point, but that append still
decoded no PBCH. CP1395 isolates the remaining simple LiteX-only question:
can the M2SDR receive the same class of CP1394 full-geometry waveform when TX
is carrier-centered at `1842500000 Hz` and RX is independently SSB-centered at
`1839650000 Hz`?

This checkpoint does not use the bladeRF/srsUE path and does not unlock the
raw scheduled-TRACK gate by itself.

The AD9361 loopback also passed:

- CSI PCI1: `294/340`

The PHY loopback did not model this split-frequency RF condition usefully:

- Capture sha256:
  `bda8b724a434a71cafd75b70701028370934323df88fbe329f39bef865b43f34`
- Reference correlation was weak: best score `0.0355095768`
- Targeted PBCH decode: `0/340` PBCH CRC OK
- CSI PCI1 rows were low-value/non-decodable (`28/340`, best listed SNR

The PHY result is recorded as a loopback-mode caveat, not as the checkpoint
verdict, because the external RF `none` path and AD9361 loopback both passed
the intended split-frequency RX-centered test.

## Conclusion

CP1395 rules out the simple theory that LiteX cannot receive this
full-geometry waveform when TX is carrier-centered and RX is SSB-centered. The
standalone LiteX external RF path decodes strongly at exactly that split
frequency condition.

This also narrows the CP1394 failure: CP1394's live gNB-owned RX append was
correctly [interface-redacted] but had RMS about `0.000205`, while CP1395's external RF
`none` capture under the split-frequency baseline has RMS about `0.003775`.
That is roughly a `25 dB` receive-level difference before considering decoder
details. The next useful work should therefore focus on the live gNB runtime
TX/RX level/path or on a true live link-budget change, not on more
`ue_sync_nr.c` scheduler/anchor edits and not on a generic split-frequency
LiteX RX impossibility.

The raw live scheduled-TRACK gate remains locked: no srsUE scheduled TRACK
metric was produced in this LiteX-only checkpoint, and no ladder movement is
justified until the live raw mean TRACK SNR and `% >= -10 dB` improve.
