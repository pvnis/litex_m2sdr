## Interpretation

CP1456 does not reveal a hidden stronger bladeRF receive channel. RX2 is
software-selectable and sees a weak coupled copy of the tone, but it is about
`22.3 dB` below RX1 at the current BW2.0/bypass/gain48 live-geometry point.
Both channels still show the same broad instability class (`CP892 WARN`,
about `11 kHz` 10 ms max window steps).

Together with CP903, this closes explicit RX2 as a remote-only escape hatch for
the current branch. The active external path remains RX1/RF3(B), and the next
meaningful progress still requires either a physical/independent receive-path
change, a spectrum-analyzer/independent receiver observation at the bladeRF
input point, or a truly different bladeRF front-end state that first proves a
real TX-on/TX-off delta.

CP1456 is not a raw scheduled TRACK metric datapoint and does not unlock the
ladder.

## Do Not Repeat

Do not rerun explicit RX2 current live-geometry tone capture unchanged. RX2 is
weaker than RX1 and not a hidden good receive path in this setup.
