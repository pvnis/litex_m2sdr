# Checkpoint 1462: bladeRF Flash Calibration Backup

## Purpose

CP1461 confirmed that a future bladeRF calibration/correction branch remains an
explicit-approval branch because current runtime correction values are not
readable through this CLI. CP1462 performs the safe preparatory step from the
CP922 safety plan: back up the bladeRF flash calibration region before any
possible later approved calibration/correction experiment.

This checkpoint does not calibrate, restore flash, transmit, receive, retune,
stream, change loopback, change `rx_mux`, change filters, or toggle bias tees.
It reads the bladeRF flash calibration region and writes a backup file.

## Interpretation

CP1462 creates a useful flash-calibration safety artifact for any later
approved bladeRF calibration/correction experiment. It does not make the
calibration/correction branch fully reversible, because CP1461/CP922 still show
that current runtime DC/IQ correction values are not readable through this CLI.

This checkpoint does not raise the raw scheduled TRACK gate and does not change
the frontier conclusion. The next meaningful ladder step still needs one of:

- a physical/independent receive-path change;
- explicit approval for a bounded calibration/correction experiment using this
  backup plus before/after RF logs;
- explicit approval for a bias-tee or other hardware-affecting branch.

Do not rerun CP1425-CP1462 unchanged.
