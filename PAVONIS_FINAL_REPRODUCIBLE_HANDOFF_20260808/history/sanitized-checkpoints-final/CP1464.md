# CP1464 - bladeRF AD9361 Read-Only Peek Plan, No RF

Date: [date-redacted] Europe/Zurich

## Goal

Make concrete progress after CP1463 without changing hardware state. CP1463
showed that the installed bladeRF CLI has no safe high-level read-only
correction-state view, but it does provide `peek rfic` for bladeRF2 AD9361
register reads. CP1464 turns that into a reviewed, bounded register-read plan
rather than an exploratory low-level command.

This checkpoint did not run SSH, transmit, receive samples, retune, set
bladeRF state, calibrate, toggle bias tees, peek/poke registers, or edit
source code. It is a local evidence and planning checkpoint.

## Register Families Selected

The selected families are read-only candidates for the leading external
bladeRF receive-path/front-end theory. They are intentionally biased toward
state, lock, gain, overload, RSSI, and correction readback. They exclude any
`set`, `calibrate`, `poke`, `flash_restore`, or bias-tee operation.

| Range | Local symbolic names / meaning | Why it is in scope |
| --- | --- | --- |
| `0x013-0x017` | `REG_ENSM_MODE`, `REG_ENSM_CONFIG_1`, `REG_ENSM_CONFIG_2`, `REG_CALIBRATION_CTRL`, `REG_STATE` | Confirms AD9361 ENSM and calibration state; register map marks `0x017` as state/read-only. |
| `0x035-0x036` | `REG_CTRL_OUTPUT_POINTER`, `REG_CTRL_OUTPUT_ENABLE` | Matches CP1461/CP1463 `CTRL_OUT` evidence and can confirm no odd control-output routing state. |
| `0x03f-0x04e` | BBPLL control words | Checks BBPLL control/lock-adjacent state without touching clock configuration. |
| `0x050-0x055` | RX synth/analog/ADC power-down override registers | Can catch a stuck RX synth, analog, or ADC power-down override. |
| `0x0fa-0x10e` | AGC config, overload thresholds, manual RX1/RX2 LMT/LPF/digital gain | Confirms manual/AGC configuration and programmed RX gain split beneath the high-level gain API. |
| `0x120-0x12a` | overload/gain-step/counter-related slow-attack registers | Captures overload-counter configuration relevant to high no-TX floor and possible overrange behavior. |
| `0x150-0x15d` | RSSI measurement configuration | Pairs with high-level RSSI and raw RMS observations; not a substitute for RF decode. |
| `0x160-0x163` | channel ADC and RX-filter power readbacks | Register map describes these as power readbacks near ADC/RFIR/HB1 output. |
| `0x168-0x181` | RX quadrature gain/phase/offset correction registers | Read-only capture of RX IQ correction state without running `calibrate iq`. |
| `0x185-0x194` | RX DC offset control/tracking registers | Captures DC offset tracking configuration without running `calibrate dc`. |
| `0x19a-0x1a5` | RX1/RX2 BB DC words and tracking correction words | Captures current BB DC correction readback/state. |
| `0x1a7-0x1ae` | RX1/RX2 RSSI symbol/preamble and RX path gain | Direct receive-path readback family. |
| `0x1b0-0x1fc` | RX LNA, mixer, TIA, BBF, [interface-redacted], and bandwidth-related analog path registers | Broad but still bounded receive-front-end state block. |
| `0x230-0x251` | RX synthesizer, VCO calibration/status, lock, correction words | Direct RX LO/VCO lock and synthesizer state family. |
| `0x2b0-0x2b9` | RX gain readback and overrange signal registers | Register map and local names identify RX1/RX2 gain/LPF/digital gain, loop states, and overrange signals. |
| `0x3f4-0x3f6` | BIST/observe/data-port test registers | CP1411/CP1461 mention these as BIST-related; confirms no test mode is latched. |

## Interpretation Rules

This plan can only produce state evidence. It cannot raise the raw TRACK gate
by itself.

Useful outcomes would be:

- RX power-down override or ADC override unexpectedly active.
- RX synthesizer/VCO lock/status inconsistent with the [interface-redacted] receive state.
- RX gain readback or overrange status contradicting the high-level gain and
  raw RMS observations.
- RX IQ/DC correction words obviously stuck, saturated, or divergent across
  RX1/RX2 in a way that matches the no-TX-like floor/spur evidence.
- BIST/test registers nonzero when the high-level state says normal operation.

Non-useful outcomes:

- Normal-looking register state with the raw link still at `-20` to `-22 dB`.
- Differences in opaque calibration words without a before/after or known-good
  comparison.
- Any result that tempts a write-path change without a bounded rollback plan.
