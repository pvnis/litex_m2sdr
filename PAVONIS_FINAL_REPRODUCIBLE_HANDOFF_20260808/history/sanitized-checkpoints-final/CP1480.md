## Interpretation

CP1480 refines CP1479 rather than reversing it. The CP1166 helper does produce
a real, weak SSB/PBCH signal at the true SSB offset, but the received signal is
still far below the former pass-class baseline. It is only about `0.4 dB` over
the immediate no-TX broadband floor, and the first 250 ms contains CSI but no
PBCH CRC. The full 1 s one-shot can find PBCH OK, so this is a marginal,
intermittent, low-coherence received helper baseline, not a restored Stage 5
baseline.

This means the current boundary is not "no signal exists at all" and not
"live gNB cadence alone". It is still below ladder movement: current external
bladeRF reception of even the known helper is too marginal compared with the
CP1166 pass class. The live gNB path remains below this helper control.
