# Checkpoint 1483 - CP1481 pre-DMA timed metadata helper replays

Date: [date-redacted] Europe/Zurich

## Goal

After CP1482 proved CP1481's live pre-DMA payload decodes when presented by the
continuous CP1166 helper, CP1483 tested whether live-style timed/gapped CS16
metadata presentation itself reproduces the live gNB RF failure. No hardware
branch, calibration, bias-tee, retune-reset, or scheduler/sync-anchor edit was
run.

## Verdict

CP1483 passes. The CP1481 payload decodes not only under continuous helper
presentation (CP1482), but also under exact/prequeued timed CS16 metadata and
under a live-like paced 75 ms metadata helper. Therefore the CP1481 live gNB
failure is not explained by payload content, the current RF path/power,
bladeRF capture mechanics, the CS16-to-SC12 patched helper conversion, the
timed/gapped metadata format, or simple 75 ms paced metadata submission.

The remaining boundary is a live-only gNB runtime or lower-device behavior
below the host-visible dump and below what the standalone helpers reproduce.
The next comparison should keep the same hardware and directly contrast the
continuous helper against live gNB again in an immediate back-to-back run, then
inspect whichever live-only runtime/cadence variable differs.
