# Checkpoint 1495: srsUE PBCH DMRS Threshold Plumbing and Build Smoke

Date: [date-redacted]

## Goal

Address the CP1494 software gate without changing `ue_sync_nr.c` sync/anchor
logic or touching hardware: expose a default-off runtime PBCH DMRS threshold
override so the live blind PBCH search can be rerun at `0.25`.

## Changes

Patched `srsRAN_4G`:

- `srsue/hdr/phy/nr/cell_search.h`
  - Adds `cell_search::args_t::pbch_dmrs_thr`, default `0.0f`.
- `srsue/hdr/phy/nr/sync_sa.h`
  - Forwards `ssb_min_scs` and `pbch_dmrs_thr` into cell search args.
  - Forwards `disable_cfo`, `pbch_dmrs_thr`, `cfo_alpha`, and
    `thread_priority` into slot sync args.
- `srsue/src/phy/nr/cell_search.cc`
  - Passes `args.pbch_dmrs_thr` into `srsran_ssb_init()`.
  - Logs when the cell-search threshold override is active.
- `srsue/src/phy/phy_nr_sa.cc`
  - Parses `PAVONIS_SRSUE_PBCH_DMRS_THR`.
  - Accepts only finite `0 < value <= 1`.
  - Leaves default behavior unchanged when the env var is absent or invalid.

No `srsRAN_4G/lib/src/phy/ue/ue_sync_nr.c` sync/anchor logic was edited in this
checkpoint.

## Interpretation

CP1495 removes the first actionable CP1494 software plumbing gap. Both SA cell
search and slot sync can now receive a non-default PBCH DMRS threshold from
`PAVONIS_SRSUE_PBCH_DMRS_THR`, while default operation remains unchanged.

This does not prove the live RF ladder rung yet. It only proves the code path
needed for the next live test is compiled locally and on `[host-redacted]`.
