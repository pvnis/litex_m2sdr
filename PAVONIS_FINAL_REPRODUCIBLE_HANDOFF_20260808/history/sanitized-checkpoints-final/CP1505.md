## Method

CP1505 uses the existing artifact-local forced-track grid binary and applies
one common fallback window to all four cases:

```text
timing: public_t-72 .. public_t+96, step 1 sample
CFOs: -5000,-3750,-2500,-1250,-625,-312,0,80,312,625,853,1250,2500,3750,5000 Hz
```

Total grid points: `10140` (`2535` per case). A candidate is considered
recovered only by PBCH CRC OK.

## Interpretation

CP1505 proves the fallback concept is feasible on saved vectors: a bounded
post-public-search timing/CFO fan-out can recover both forced-only positive
classes without producing a false positive on the known live negative. This
supports the CP1504 conclusion that the current blocker is a public-search
handoff/candidate-selection issue rather than absent RF content.

This is not yet a runtime-ready patch. The fan-out used here is deliberately
broad (`2535` forced-track attempts per case). Before any runtime change, the
candidate set needs to be compressed to a small deterministic list and
re-tested against the same positive/negative guard cases.
