## Findings

The public blind path is split across `ssb.c`:

- `ssb_search_at()` starts at `ssb.c:1277`.
- It performs PSS search and returns `N_id_2`, `t_offset`, and
  `coarse_cfo_hz` at `ssb.c:1282-1289`.
- It subtracts CP at `ssb.c:1291-1296`.
- It demodulates using `ssb_demodulate(q, in, t_offset, coarse_cfo_hz, ...)`
  at `ssb.c:1303-1308`.
- It selects the PBCH DMRS candidate at `ssb.c:1321-1328`.
- It skips PBCH decode if `pbch_meas.corr < q->args.pbch_dmrs_thr` at
  `ssb.c:1330-1333`.
- It returns a found cell only after PBCH CRC OK at `ssb.c:1335-1361`.

Top-level `srsran_ssb_search()` starts at `ssb.c:1364` and runs an outer CFO
grid:

- `0 Hz` first, using the original raw input buffer.
- then `+/-` quarter-subcarrier-spacing steps to `+/-1.5*SCS`, using a
  pre-compensated temporary buffer (`ssb.c:1391-1401`).
- it calls `ssb_search_at(q, ptr, ...)` for each hypothesis and returns on the
  first PBCH CRC OK (`ssb.c:1402-1414`).

CP1506's candidate policy was validated on saved raw vectors:

```text
relative timing = public_t - 17 samples
CFO = +1250 Hz
n_hf = 0 preferred by all forced OK cases
```

That policy was measured relative to the public timing found on the raw
outer-CFO-zero candidate. If applied naively inside `ssb_search_at()` for every
outer CFO hypothesis, `+1250 Hz` would be applied to already pre-compensated
buffers for nonzero outer-CFO rows. That changes the meaning of the fallback
CFO and risks an unbounded or false-positive runtime behavior.

## Conclusion

The safest default-off prototype surface is not a broad fallback inside every
`ssb_search_at()` call. It should be scoped either:

1. in `srsran_ssb_search()` around the first outer-CFO-zero raw-buffer attempt,
   so `public_t - 17` and `+1250 Hz` keep the CP1506 semantics, or
2. through a small helper that exposes the failed public candidate `(N_id,
   public_t, coarse_cfo/pbch_meas)` to the top level, then runs a raw-buffer
   fallback decode with explicit absolute/residual CFO semantics.

Do not implement it in `ue_sync_nr.c` sync/anchor logic. Keep the CP1506 saved
guard set in the test path: recover `live_159`, `helper_190`, and `helper_056`
while keeping `live_069` negative.
