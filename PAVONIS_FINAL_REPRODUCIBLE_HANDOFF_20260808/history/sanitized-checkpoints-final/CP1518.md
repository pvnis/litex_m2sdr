# Checkpoint 1518 - LiteX TX DMA Dump Window Build

Date: [date-redacted] Europe/Zurich

## Goal

Prepare the next lower-boundary live diagnostic without transmitting RF:
capture a post-DMA payload/header window near the bladeRF capture interval
instead of only dumping the first DMA buffers after TX starts.

CP1517 showed the residual CP1516 good/bad RF windows do not separate by
host-side HAS_TIME/source-gap timing. CP1516's existing `tx_dma_buffers.bin`
cannot answer the lower-device question because it is an initial-window dump:
it ends at dump seq `[date-redacted]`, handle `7050`, source time
`[subscriber-redacted] ns`, while the CP1516 bladeRF capture overlap in the worker
trace spans handles `56760..67955` and source time
`[subscriber-redacted]..[subscriber-redacted] ns`.

## Change

`LiteXM2SDRStreaming.cpp` now supports default-off post-DMA dump window filters:

- `M2SDR_SOAPY_TX_DMA_DUMP_START_HANDLE`
- `M2SDR_SOAPY_TX_DMA_DUMP_START_TIME_NS`

The existing `M2SDR_SOAPY_TX_DMA_DUMP_BUFFERS` cap was raised from `4096` to
`65536` so a future run can capture roughly one second of live TX DMA buffers
when explicitly requested. Normal behavior is unchanged unless the existing
DMA dump is enabled and one of the new start filters is set.

The metadata rows also record `dump_start_handle` and `dump_start_timeNs`, and
the module log line now prints `start_handle` and `start_time_ns`.

## Verdict

CP1518 is a no-RF build/setup pass. It does not raise the downlink gate by
itself. It enables the next live diagnostic: run guarded live gNB with worker
trace plus OCUDU write metadata still active, but set a post-DMA dump start
near the CP1516 capture-overlap handle range and dump enough buffers to cover
the bladeRF capture window. Then compare capture-window post-DMA headers,
payload continuity, decode, and same-window RF correlation.

Recommended first CP1519 parameters, based on CP1516 timing:

- `M2SDR_SOAPY_TX_DMA_DUMP_START_HANDLE=54000`
- `M2SDR_SOAPY_TX_DMA_DUMP_BUFFERS=16000`
- Keep `M2SDR_SOAPY_TX_ALIGN_HAS_TIME_REMAINDER=1`
- Keep worker trace and OCUDU write metadata enabled

Do not rerun CP1518 unchanged.
