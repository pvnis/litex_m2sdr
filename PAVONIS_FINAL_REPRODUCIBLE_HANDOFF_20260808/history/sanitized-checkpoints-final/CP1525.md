# Checkpoint 1525 - [host-redacted]-only M2SDR self-RX helper/live A/B while [host-redacted] is down

Date: [date-redacted]

## Goal

Run the user's receiver-bypass discriminator while `[host-redacted]` is unavailable:
compare a continuous helper replay against live gNB TX using only [host-redacted] and the
M2SDR's own RX path, with no bladeRF and no [host-redacted] dependency. If live is
sparse even on M2SDR self-RX, the failure is visible before the external
receiver path.

## Method

I added CP1525-only wrappers which generate no-`[host-redacted]` variants of the
existing CP1400/CP1395 harnesses. They preserve the prior RF mechanics and
remove only the final receiver-host post-check.

Primary sequence:

1. Run live gNB first through the CP1424-style immediate/no-arm
   `OCUDU_SOAPY_RX_USE_READSTREAM=1` M2SDR self-RX append path.
2. Use that same live run's freshly generated
   `pre_dma_full_scale32768.cf32` as the input to the CP1395 split-frequency
   continuous helper.
3. Decode both captures at RX/SSB center `1839650000 Hz`, Fs `11.52 Msps`.

No bladeRF capture, srsUE, Android, PRACH, hardware branch, or
`ue_sync_nr.c` sync/anchor edit was used.

## Interpretation

CP1525 does not show a dead live M2SDR self-RX path. Live gNB self-RX is
PBCH-positive on both targeted and aligned analyses.

It does show a material live-vs-helper density gap with payload held constant:
the continuous helper replays the live pre-DMA vector and gets `208/332`
targeted PBCH and `207/847` aligned PBCH on M2SDR `none` self-RX, while the
live gNB gets `98/332` on the same targeted grid and `78/847` on the same
aligned grid. The helper also has much stronger same-payload correlation
(`0.719`) and about `14.5 dB` higher CF32 RMS than the live append.

So the current read is:

- The external bladeRF/[host-redacted] receiver is not required to see a live-vs-helper
  quality gap.
- The live path is not absent on M2SDR self-RX; it is weaker/sparser than the
  continuous helper.
- This supports a live TX presentation/cadence/coherence issue below the
  host-visible pre/post-DMA bytes, while preserving the earlier evidence that
  the external bladeRF path has its own receive/coupling problems.
