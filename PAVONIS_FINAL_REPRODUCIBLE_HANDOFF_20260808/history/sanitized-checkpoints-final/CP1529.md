## Interpretation

CP1529 confirms the live/helper difference is visible with no external
bladeRF/[host-redacted] receiver in the experiment: the helper has much higher
amplitude, strong same-vector refcorr, and a denser aligned sweep
(`239/847` versus live `153/847`).

It does not support a simple "live is always dead/sparse on self-RX" claim.
This live run is healthier than CP1525 (`153/847` aligned PBCH versus
`78/847`) and close to CP1528 (`168/847`). On the wider helper-grid targeted
decode, live even exceeds helper `none` (`192/332` versus `178/332`), likely
because the longer windows catch live's good islands. The primary discriminator
therefore remains temporal density/coherence, not absolute decodability.

The branch reading is: external receiver involvement is not required to see
the quality gap, so a receiver-only explanation is insufficient; however the
fault is intermittent/condition-sensitive effective live TX egress/cadence, not
a fixed live waveform absence. The live worker trace has no late rows, no
dedup, and no sequence gaps, so unchanged host-visible write/worker repeats are
not the next useful step.
