## Goal

Add and build-smoke a default-off OCUDU RX append/sample-start metadata sidecar
for the [host-redacted]-only self-RX branch. This is software-only: no RF run, no gNB
runtime window, no bladeRF/srsUE/[host-redacted] receive, no Android, and no
`ue_sync_nr.c` sync/anchor edits.

## Change

Patched:

- `/home/[host-redacted]/CLionProjects/ocudu/lib/radio/soapy/radio_soapy_rx_stream.cpp`

New opt-in env:

- `PAVONIS_SOAPY_RX_APPEND_META_PATH`

When set together with the existing RX append path, the sidecar writes rows
that bind each appended CF32 span to:

- RX receive sequence and manifest index
- `ret_ts` and estimated hardware-time ns
- append file offset and append count in samples
- estimated append start/end time
- read-loop chunk count and overflow count
- first/last `readStream()` or `acquireReadBuffer()` return samples, flags,
  time ns, copied samples, and wall-clock call bounds
- HAS_TIME/no-time chunk counts and time-regression count

With the env unset, this is inert.
