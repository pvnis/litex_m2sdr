## Interpretation

The user-requested discriminator passes and gives a clear A/B split without
the external receiver in the loop. The live gNB is not dead on M2SDR self-RX,
but it is still sparser than the continuous helper on the same [host-redacted]/M2SDR
path and same payload: live `164/847` aligned PBCH versus helper `291/847`,
and live helper-grid `154/332` targeted PBCH versus helper `none` `228/332`.

Because the helper is dense on the same receiver path while live stays
relatively sparse with clean host-visible TX, clean worker/write counters, and
clean RX append metadata, this strengthens the TX-side effective
egress/cadence/coherence branch. It is not explained by bladeRF, srsUE,
[host-redacted], RX append gaps, RX chunk timing regressions, no-time chunks, RX
overflows, OCUDU write return errors, worker late rows, dedup rows, or worker
sequence gaps.

The conclusion is not "live always fails on self-RX"; CP1528-CP1533 show live
is condition-sensitive and can produce healthy islands. The unresolved fault is
the density/continuity gap between live runtime egress and continuous helper
presentation.
