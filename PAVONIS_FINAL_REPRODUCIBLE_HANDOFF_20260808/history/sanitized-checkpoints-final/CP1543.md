## Interpretation

CP1543 moves the branch from "we need external IQ evidence" to "the saved
external IQ contains decodable PBCH, but not at the live static TRACK window."

That reproduces the CP1365/CP1384-style split at the current CP1540 geometry:
offline or alternate-offset windows can decode, while the live scheduled
`selected_sf_offset=1650` window remains KO. The failure is therefore not
"external IQ is absent" and not "M2SDR self-RX dropout"; it is still a
decoder-facing timing/window/candidate-state problem or a raw metric gate
problem inside the scheduled TRACK path.

Because this run did not catch a `>= -10 dB` row, it does not directly explain
CP1540 opportunity `67`. Another unchanged raw repeat is low value. The next
software-only diagnostic should be bounded and targeted: capture decoder
candidate state or a small IQ/candidate bundle around a high-SNR CRC-KO TRACK
opportunity, while keeping the raw TRACK gate as the metric and leaving
`ue_sync_nr.c` sync/anchor behavior unchanged.
