## Interpretation

The requested discriminator did not trigger. Live gNB is PBCH-positive on the
M2SDR's own RX in this current run, with clean RX metadata and healthy
host-visible TX. CP1556 therefore does not support "live is sparse even in
self-loopback" as the current explanation.

The helper remains higher-level and denser on the same payload, so the live
runtime/cadence/egress branch is still relevant. But this run matches the
CP1533/CP1537/CP1544/CP1547 lineage: current [host-redacted]-only self-RX evidence points
away from a simple dead live TX path and remains compatible with the
CP1540/CP1541 split where M2SDR self-RX sees decodable live TX while the
external scheduled-TRACK/raw gate remains below threshold.

No raw scheduled TRACK metric was run in CP1556, so the ladder gate is
unchanged. Do not rerun this A/B unchanged. The next changed work should return
to the active CP1555 frontier: separate no-candidate acquisition instability
from the skip-EOB/no-candidate hypothesis, or otherwise target the remaining
raw scheduled-TRACK sub-threshold/overflow problem without `ue_sync_nr.c`
sync-anchor edits.
