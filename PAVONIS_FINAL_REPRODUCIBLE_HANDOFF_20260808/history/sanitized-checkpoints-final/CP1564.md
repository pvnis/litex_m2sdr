# Checkpoint 1564 - force live gNB TX into helper-like continuous writes

Date: [date-redacted]

## Goal

Test the user hypothesis that the live deficit is coherence/EVM from segmented
timed-TX/DMA burst boundaries, not raw power, RX bandwidth, RF-gap EOB, or
candidate-probe load. CP1564 keeps the CP1540/CP1557/CP1563 raw scheduled-TRACK
geometry and verified `ATT=5 dB`, but forces the live OCUDU Soapy TX stream to
emit as continuous untimed chunks like the helper.

## Code and run shape

Default-off OCUDU diagnostic added:

- `PAVONIS_SOAPY_TX_FORCE_CONTINUOUS_STREAM=1`
- configured `tx_mode` remains discontinuous, but effective Soapy TX stream
  mode is forced continuous.
- logical scheduler flags are still counted, while actual `writeStream()`
  `HAS_TIME`/`END_BURST` flags are stripped to zero.
- stop-time zero-length EOB is also suppressed in this diagnostic mode.

## Comparison

CP1563B directly proved `ATT=5 dB` with the normal segmented timed live TX path
and still failed: `68` opportunities, mean SNR `-22.0339 dB`,
`0/68 >= -10 dB`, zero scheduled PBCH hits.

CP1564 changes the live TX presentation to helper-like continuous writes and
immediately becomes scheduled-PBCH-positive: `31/70` scheduled PBCH hits and
`21/70 >= -10 dB`.

This is the first current raw scheduled-TRACK result that materially raises the
gate. It supports the theory that the live failure is dominated by the timed
TX/DMA burst-boundary presentation, not by power, RX bandwidth, RF-gap EOB, or
passive candidate load.

## Caveats and next step

This is a diagnostic bypass, not a final gNB TX fix. The median TRACK SNR is
still low (`-20.721 dB`) and `49/70` opportunities remain below `-10 dB`. The
continuous override may also concatenate scheduler chunks in a helper-like way
rather than preserving every live wall-clock gap exactly.

Next work should keep the amplitude/RX/EOB branches closed and focus on turning
this positive discriminator into a proper live-TX solution: either preserve
continuous no-time streaming while maintaining correct gNB sample cadence, or
isolate and remove the phase/timing discontinuity introduced at segmented
timed-TX/DMA burst boundaries. Higher-ladder work should use this continuous
TX mode as the current positive raw-DL baseline until an equivalent production
TX cadence is implemented.
