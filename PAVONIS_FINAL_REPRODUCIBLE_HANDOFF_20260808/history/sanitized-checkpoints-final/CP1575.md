## Goal

Test the user-selected coherence/EVM theory directly: keep the CP1540/CP1563
raw scheduled-TRACK downlink geometry, but make live gNB TX use a native
continuous stream path instead of segmented timed bursts. This run also checks
the CP1562 RSRP question before moving on.

## Interpretation

CP1575 is a strong positive baseline. It reproduces and slightly improves the
CP1564 raw scheduled-TRACK class without using
`PAVONIS_SOAPY_TX_FORCE_CONTINUOUS_STREAM=1`.

This strengthens the timed-TX/DMA burst-boundary phase/timing discontinuity
theory. It also closes simple amplitude/RX/EOB explanations for the downlink
gate: verified ATT=5 alone did not raise scheduled RSRP or SNR, while changing
TX cadence/presentation did.

CP1575 does not solve the uplink branch. CP1569/CP1570 still show that, even on
the continuous downlink baseline, bladeRF PRACH/tone energy is not visibly
reaching the live gNB predemod/RX append path under real TX-active conditions.
