# Checkpoint 1582 - OCUDU TX Skip Stream-IO Build Smoke

Date: [date-redacted]

## Goal

Add a default-off software discriminator for the next uplink-visibility rung:
keep the live gNB/RX append/control path intact, but allow a run to bypass the
M2SDR TX stream activation/write/deactivation path entirely. This is intended
to separate "live TX stream/control state breaks RX" from "live TX payload
content breaks RX" after CP1580/CP1581 proved TX payload zeroing alone does not
restore the uplink tone.

## Change

Added `PAVONIS_SOAPY_TX_SKIP_STREAM_IO=1` to OCUDU Soapy TX:

- `radio_soapy_tx_stream` now records `tx_skip_stream_io`.
- TX readback sidecar includes `tx_skip_stream_io` and
  `env_PAVONIS_SOAPY_TX_SKIP_STREAM_IO`.
- Startup log emits
  `PAVONIS_SOAPY_TX_SKIP_STREAM_IO enabled: ... TX activate/write/deactivate calls will be skipped`.
- `start()` skips `activateStream()` and the TX async status task when enabled.
- `transmit()` still follows the logical TX decision/accounting path, then
  returns before any `writeStream()`.
- `stop()` skips stop-time EOB flush and `deactivateStream()` when enabled.

Default behavior is unchanged when the env var is unset or `0`.

## Conclusion

CP1582 is a no-RF implementation/build checkpoint. It makes the next RF rung
interpretable: run the native-continuous gNB RX append + bladeRF uplink tone
check with `PAVONIS_SOAPY_TX_SKIP_STREAM_IO=1`. That run must prove via the TX
readback/log markers that TX stream activation and write/deactivate calls were
skipped before interpreting the tone result.

Do not treat CP1582 as RF evidence. Do not rerun CP1582 unchanged unless the
OCUDU source changes or the [host-redacted] binary is rebuilt away from hash
`5fa1f00b549e5749dd0ec83af5cafa718b7a0e200d753876a28f2031bf3d4e52`.
