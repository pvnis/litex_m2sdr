# Checkpoint 1584 - OCUDU TX Skip Stream-Setup Build Smoke

Date: [date-redacted]

## Goal

Add and build-smoke a default-off discriminator for the next uplink-visibility
run: keep the live gNB/RX append path, but skip TX channel configuration and
TX `setupStream()` entirely. CP1583 already skipped TX activation, writes,
stop-time EOB flush, and deactivation; CP1584 prepares the next test for
whether TX setup/configuration itself perturbs live gNB RX visibility.

No RF was run in this checkpoint.

## Change

Added `PAVONIS_SOAPY_TX_SKIP_STREAM_SETUP=1` to OCUDU Soapy.

When enabled, it:

- Requires `PAVONIS_SOAPY_TX_SKIP_STREAM_IO=1`; otherwise session creation
  fails before RF.
- Skips TX channel sample-rate, frequency, gain, and bandwidth configuration.
- Skips TX `setupStream()`.
- Keeps the RX channel configuration and RX `setupStream()` path intact.
- Preserves TX port mapping but makes later TX gain/frequency management calls
  logged no-ops.
- Allows `radio_soapy_tx_stream` to hold a null TX stream only when both setup
  bypass and stream-I/O bypass are active.
- Uses a logical TX MTU of `1022` by default when no Soapy TX stream exists,
  overrideable with `PAVONIS_SOAPY_TX_SKIP_STREAM_SETUP_MTU`.
- Adds `tx_skip_stream_setup` and
  `env_PAVONIS_SOAPY_TX_SKIP_STREAM_SETUP` to the TX readback sidecar.
- Adds `skip_stream_setup` to Soapy TX start/periodic/stop summaries.

Default behavior is unchanged when the env var is unset or `0`.

## Conclusion

CP1584 is a no-RF implementation/build checkpoint. It makes the next RF rung
interpretable: run the CP1583 native-continuous gNB RX append + bladeRF uplink
tone check with both:

- `PAVONIS_SOAPY_TX_SKIP_STREAM_IO=1`
- `PAVONIS_SOAPY_TX_SKIP_STREAM_SETUP=1`

That RF run must invalidate itself unless the TX sidecar and `gnb.log` prove
`tx_skip_stream_setup=1`, `tx_skip_stream_io=1`, skipped TX channel
configuration, skipped TX `setupStream()`, and zero actual TX write/flush
counters. If the uplink tone recovers, TX setup/control state is implicated.
If it still fails, the leading suspect moves deeper into live gNB RX/control or
gNB RX/predemod path behavior rather than TX stream setup/write activity.

Do not treat CP1584 as RF evidence. Do not rerun CP1584 unchanged unless the
OCUDU source changes or the [host-redacted] `gnb` binary is rebuilt away from hash
