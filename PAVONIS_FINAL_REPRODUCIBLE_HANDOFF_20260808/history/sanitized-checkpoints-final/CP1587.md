# Checkpoint 1587 - OCUDU RX-CF32 Build Smoke

Date: [date-redacted]

## Goal

Add and build-smoke a default-off OCUDU Soapy RX diagnostic for the CP1586
sample-format hypothesis: open live gNB RX as `SOAPY_SDR_CF32`, read samples
through `readStream()`, convert them back to `ci16_t` for the existing lower
PHY interface, and expose sidecar/log proof that the mode is active.

No RF was run in this checkpoint.

## Change

Added RX-side CF32 controls to OCUDU Soapy:

- `OCUDU_SOAPY_RX_FORMAT=cf32` or `OCUDU_SOAPY_RX_CF32=1` makes
  `radio_soapy_device::setup_stream()` open RX as `SOAPY_SDR_CF32`.
- Default RX behavior remains `SOAPY_SDR_CS16`.
- RX-CF32 mode forces the existing `readStream()` fallback.
- `radio_soapy_rx_stream` reads into per-channel CF32 scratch buffers, clamps
  and converts CF32 back to `ci16_t` with scale `32767`, then lets the existing
  lower-PHY and append code consume the normal `ci16_t` buffers.
- `PAVONIS_SOAPY_RX_READBACK_PATH` now records `rx_use_read_stream`,
  `rx_cf32_stream`, `rx_format`, `cf32_to_ci16_scale`,
  `env_OCUDU_SOAPY_RX_FORMAT`, `env_OCUDU_SOAPY_RX_CF32`, and
  `env_OCUDU_SOAPY_RX_USE_READSTREAM`.
- `PAVONIS_SOAPY_RX_DUMP active` logs now include `rx_use_read_stream` and
  `rx_cf32_stream`.

interpretable: rerun the CP1585 native-continuous live gNB RX-append uplink

sample-format/scaling path is implicated. If it still fails, the blocker moves
deeper than TX setup/I/O and RX sample format, into live gNB RX/control or
predemod behavior.
