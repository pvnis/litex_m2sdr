## Conclusion

CP1595 is an invalid/diagnostic checkpoint, not the requested
standalone-pass/live-fail comparison. It usefully proved the CP1233-style
snapshot machinery can run in both phases and that the gross key state did not
differ in this attempted A/B, but the standalone half did not pass and the live
tone phase was missing.

The [host-redacted] helper was fixed after this run. Do not use CP1595 as RF evidence
that live and standalone RX states are equivalent. The next attempt must use a
known-positive standalone receiver path, not this custom full-duplex recorder
as the pass side.
