## Conclusion

CP1596 is a valid diagnostic run but not the requested pass/fail A/B. It fixes
the CP1595 helper bug and proves the CP1233-style key register/mux/crossbar
state can match between this standalone session and the live gNB session.
However, the standalone half did not see the tone, so the comparison cannot
explain the known CP1571/CP1574 standalone-positive versus live-gNB-negative
split.

Do not rerun CP1595/CP1596 unchanged and do not use this custom full-duplex
simple-tone recorder as the pass-side proof. The next checkpoint must pair the
same CP1233-style readback with a known-positive standalone receiver harness:
either the CP1571/CP329 raw LiteX RX tone path or a CP1574-exact zero-TX
full-duplex replay/tone path.
