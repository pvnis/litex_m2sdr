# CHECKPOINT 1600: Near-Tone/Masking Gate For Live RX Append Analyzer

Date: [date-redacted] Europe/Zurich

## Goal

Turn the CP1599 finding into a reusable analyzer/gate fix. CP1599 showed that
the CP1598 live1 capture was misclassified by the exact-bin/best-window gate:
the bladeRF tone was present near `98 kHz`, but an earlier exact-bin window was
masked by a stronger off-target spur. CP1600 updates the live raw/post analyzer
so future checkpoints explicitly report near-tone peak frequency, off-target
masking, and both legacy-exact and near-tone pass/fail states.

No RF was transmitted and no hardware state was changed in this checkpoint.

## Conclusion

CP1600 closes the CP1599 analyzer/gate follow-up. The live raw/post analyzer
now reports and gates on near-tone visibility while preserving the old
exact-bin result for diagnostics. Replaying it on CP1598 correctly classifies
both live phases as tone-visible and exposes why live1 was previously
misclassified: one masked exact-bin window plus later near-tone-dominant
windows.

Do not rerun CP1598/CP1599/CP1600 unchanged. The next changed work can use
this corrected analyzer in one materially changed live uplink diagnostic, or
move to the next ladder rung only if the corrected tone visibility gate is used
to avoid false live-RX negatives.
