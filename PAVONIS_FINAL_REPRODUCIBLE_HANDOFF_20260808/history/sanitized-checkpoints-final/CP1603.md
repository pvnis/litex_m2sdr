# Checkpoint 1603 - TX setupStream-only skip discriminator build

Date: [date-redacted] Europe/Zurich

## Goal

Build the CP1602-requested discriminator: keep normal TX channel
configuration/readback, but skip only TX `setupStream()` and skip all TX
stream I/O. This is meant to isolate the CP1583-vs-CP1585 split before the
next RF run.

## Scope

- No RF run.
- No gNB runtime launch.
- No hardware-affecting bladeRF, LiteX, calibration, bias, or physical-path
  change.
- Target-source deploy and build on [host-redacted] only, with remote source backup.

## Code Change

Added default-off `PAVONIS_SOAPY_TX_SKIP_SETUPSTREAM_ONLY=1`.

Behavior:

- It is mutually exclusive with `PAVONIS_SOAPY_TX_SKIP_STREAM_SETUP=1`.
- It requires `PAVONIS_SOAPY_TX_SKIP_STREAM_IO=1`.
- It keeps TX sample-rate/frequency/gain/BW configuration active.
- It skips only TX `setupStream()`.
- It permits a null TX stream only when paired with stream-I/O skip.
- It adds TX readback and summary proof fields:
  `tx_skip_setupstream_only`,
  `env_PAVONIS_SOAPY_TX_SKIP_SETUPSTREAM_ONLY`, and
  `skip_setupstream_only`.
