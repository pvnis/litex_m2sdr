## Code Change

Added `PAVONIS_PRACH_COLLECTION_DELAY_SAMPLES`, active only for the current
format-zero, start-symbol-zero, single-TD, single-FD PRACH case.

When unset, the PRACH worker follows the existing collection behavior.

When set:

- the delay target is anchored on the normal requested PRACH slot start;
- if the normal slot has already been missed before the target is anchored,
  the existing late-request behavior is preserved;
- after anchoring, the worker waits across later symbols/slots until the
  requested delayed timestamp falls inside an incoming symbol buffer;
- collection starts at that delayed timestamp, using a
  `baseband_gateway_buffer_reader_view`;
- predemod dumping now records proof fields:
  `collection_delay_samples`, `collection_delay_target_ts`,
  `collection_delay_start_context_sfn`,
  `collection_delay_start_context_slot`,
  `collection_delay_start_context_symbol`, and
  `collection_delay_start_offset_samples`.

The existing `PAVONIS_PRACH_DEMOD_INPUT_OFFSET_SAMPLES` crop remains separate
and still applies after the predemod dump.
