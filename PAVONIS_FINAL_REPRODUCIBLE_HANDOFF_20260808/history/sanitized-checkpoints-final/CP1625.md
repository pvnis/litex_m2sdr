## Important Caveat

Do not use CP1625's raw append scores as event-window evidence. CP1626 audits
the saved CP1625 metadata and proves the `24 s` raw append ended about
`78.299..79.259 s` before the seven real UE PRACH windows. The CP1625 raw
append is therefore useful only as an instrumentation-health file, not as a
same-window raw-vs-predemod comparison for the real UE events.

## Conclusion

CP1625 proves the CP1624 delayed-collection diagnostic is active in the live
real-UE path and can collect across later slots. With `141666` collection delay
plus `847` demod crop, the real UE still produces weak detector p0 rows and
zero accepts. It does not prove the raw append missed or contained those same
events, because the append window did not cover the late Msg1 time.

Next changed RF rung should either extend or re-arm the raw append so it covers
the real UE Msg1 time, then repeat the same delayed-collection run, or build a
lower-volume same-window capture keyed off the actual PRACH time.
