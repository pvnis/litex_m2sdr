## Verdict

`TAIL_GUARD_REMOVES_STRONG_DELAYED_MARKER2_COPY`

Extending the waveform tail removes the broad-search failure without changing
the near-scheduled marker latency. CP1645 is now the cleanest [host-redacted]-only
live-rate timed-marker harness baseline:

- live-rate C++ RX metadata is gap-free;
- all TX worker rows are timed and non-late;
- the broad analyzer passes without needing a bounded override;
- the previous marker2 delayed-copy artifact is absent.

The measured helper timed-TX self-RX latency remains tens of microseconds
(`-14..-33 us`), not milliseconds. This does not by itself explain the
`11..20 ms` PRACH raw-hit spread from CP1618/CP1621; the next ladder rung
should connect this clean helper marker result to the live gNB lower-PHY
timestamp source used for PRACH collection, or proceed with the widened PRACH
collection/search patch if the timestamp sources are already proven aligned.

Do not use the old CP1642/CP1643 `+22.631945 ms` broad marker hit as a delay.
