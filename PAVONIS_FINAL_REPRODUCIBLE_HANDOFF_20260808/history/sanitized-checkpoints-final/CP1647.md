# Checkpoint 1647 - Live TX Marker Build Smoke

Date: [date-redacted] Europe/Zurich

## Goal

Implement the CP1646 next rung as default-off instrumentation: an RF-visible
marker inserted inside the actual OCUDU live lower-PHY/Soapy TX path, keyed by
a live `baseband_gateway_timestamp`, so a later [host-redacted]-only self-RX run can
measure live continuous-frame timing instead of standalone helper timing.

This checkpoint is no-RF. It builds and deploys the instrumentation on [host-redacted]
but does not run the marker over the air/self-RX yet.

## Implementation

Patched:

```text
ocudu/lib/radio/soapy/radio_soapy_tx_stream.cpp
ocudu/lib/radio/soapy/radio_soapy_tx_stream.h
```

New default-off environment surface:

```text
PAVONIS_SOAPY_TX_MARKER_ENABLE=1
PAVONIS_SOAPY_TX_MARKER_START_TS=<baseband_gateway_timestamp>
PAVONIS_SOAPY_TX_MARKER_LEN=<samples, default 4096>
PAVONIS_SOAPY_TX_MARKER_AMP=<CI16 amplitude, default 1024>
PAVONIS_SOAPY_TX_MARKER_PORT=<channel, default 0>
PAVONIS_SOAPY_TX_MARKER_SEED=<seed, default 1647>
PAVONIS_SOAPY_TX_MARKER_META_PATH=<tsv path>
```

The marker overlay runs inside `radio_soapy_tx_stream::transmit()` after the
live chunk timestamp is known:

```text
chunk_start_ts = tx_md.ts + data_start + sent_total
```

It copies only the overlapping channel chunk, adds a deterministic QPSK-like
CI16 marker with saturation, then passes that modified chunk to the existing
CS16 or CF32 TX path. When active, it writes a TSV row for each overlapping
chunk:

```text
row channel chunk_start_ts chunk_time_ns logical_offset overlay_start_ts overlay_end_ts marker_offset samples
```

The TX readback sidecar now also records marker enable/start/len/amp/port/seed
and marker env values.

## Verdict

`LIVE_TX_MARKER_BUILD_SMOKE_PASS`

The live-path marker instrumentation is compiled into the Soapy-enabled [host-redacted]
`gnb` binary and is default-off unless `PAVONIS_SOAPY_TX_MARKER_ENABLE=1` and
a nonzero `PAVONIS_SOAPY_TX_MARKER_START_TS` are supplied.

This does not yet measure live RF timing. The next checkpoint should run a
[host-redacted]-only live gNB/self-RX marker measurement under the CP1575 native-
continuous baseline, choose a marker start timestamp inside the live TX window,
capture same-run M2SDR RX metadata, and analyze marker RX time against the
marker meta TSV.
