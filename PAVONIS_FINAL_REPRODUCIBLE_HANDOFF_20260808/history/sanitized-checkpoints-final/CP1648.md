# Checkpoint 1648 - Live TX Marker Dynamic-Start Build Smoke

Date: [date-redacted] Europe/Zurich

## Goal

Remove CP1647's practical blocker for the live gNB/self-RX marker measurement.
CP1647 required a nonzero absolute `PAVONIS_SOAPY_TX_MARKER_START_TS` before
the gNB process started, but the live lower-PHY timestamp is not reliably known
before process start. This checkpoint adds a default-off dynamic start mode
that selects the marker timestamp from the first non-empty live TX chunk.

This checkpoint is no-RF.

## Implementation

Patched:

```text
ocudu/lib/radio/soapy/radio_soapy_tx_stream.cpp
ocudu/lib/radio/soapy/radio_soapy_tx_stream.h
```

New environment surface:

```text
PAVONIS_SOAPY_TX_MARKER_DELAY_SAMPLES=<samples after first live TX chunk>
```

Behavior:

```text
if PAVONIS_SOAPY_TX_MARKER_START_TS is nonzero:
  use the CP1647 absolute timestamp mode
else if PAVONIS_SOAPY_TX_MARKER_DELAY_SAMPLES is set:
  select marker_start_ts = first_non_empty_live_chunk_start_ts + delay_samples
```

The marker remains default-off and still requires:

```text
PAVONIS_SOAPY_TX_MARKER_ENABLE=1
```

The TX readback sidecar now records dynamic-mode proof fields:

```text
tx_marker_configured_start_ts
tx_marker_delay_samples
tx_marker_dynamic_start
tx_marker_start_selected
env_PAVONIS_SOAPY_TX_MARKER_DELAY_SAMPLES
```

The marker TSV records the selected live timestamp when dynamic arming occurs:

```text
selected_start_ts
selected_first_chunk_start_ts
selected_first_chunk_time_ns
selected_first_chunk_logical_offset
```
