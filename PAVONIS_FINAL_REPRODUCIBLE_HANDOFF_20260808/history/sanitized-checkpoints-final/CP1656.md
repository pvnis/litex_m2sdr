# CHECKPOINT 1656 - TX All-Timed Live-Chunk Build

Date: [date-redacted]

## Goal

Implement and build-smoke a stronger software variant after CP1655:
make the native-continuous live gNB path optionally send every non-empty TX
data chunk with `SOAPY_SDR_HAS_TIME` and the chunk's own timestamp. This tests
the hypothesis that CP1652/CP1654 drift comes from leaving continuation chunks
untimed after the initial anchor.

## Change

Added default-off OCUDU Soapy TX env:

```text
PAVONIS_SOAPY_TX_ALL_TIMED_CHUNKS=1
```

When enabled:

- every non-empty live TX data chunk ORs `SOAPY_SDR_HAS_TIME` into the
  chunk flags;
- the existing per-chunk `chunk_time_ns` is passed unchanged to
  `write_stream()`;
- TX readback records `tx_all_timed_chunks` and
  `env_PAVONIS_SOAPY_TX_ALL_TIMED_CHUNKS`;
- `Soapy TX summary` records `all_timed_chunks` and `all_timed_writes`;
- default behavior is unchanged when the env is unset or `0`.
