# Checkpoint 1658: Native Continuous All-Timed Live gNB TX Raw-TRACK Gate

Date: [date-redacted] Europe/Zurich

## Goal

Carry the CP1657 timing fix into the actual downlink gate before spending any
UE/PRACH RF. CP1657 proved that `PAVONIS_SOAPY_TX_ALL_TIMED_CHUNKS=1`
stabilizes live native-continuous TX latency at two separated markers; CP1658
tests whether that mode preserves or improves the CP1575 raw scheduled-TRACK
baseline.

## Interpretation

CP1658 is a decisive raw-DL unlock. It validates CP1657's all-timed-chunk fix
on the actual scheduled-TRACK gate and makes CP1658 the new downlink baseline
for ladder movement.

This also changes the conclusion from CP1564/CP1575. Untimed continuous TX was
good enough to partially raise the raw gate, but all-timed native-continuous TX
is the first current live path to make every scheduled TRACK opportunity usable
and PBCH-positive in this geometry. The leading model remains TX cadence/timing
presentation, not simple power, RX bandwidth, EOB handling, or UE sync/anchor
scheduler logic.

Next work may move above the raw downlink gate using this TX mode. Keep the
void-retry rule: any UE/PRACH RF run where the UE emits no Msg1 is not a
datapoint. Do not fall back to CP1564/CP1575 unchanged unless CP1658
reproducibility itself is being audited.
