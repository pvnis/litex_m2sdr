# CP1668 srsUE SIB1/RACH trace instrumentation build

Date: [date-redacted]

## Question

CP1660/CP1665 acquire DL/SFN under all-timed TX but never reach usable RACH
config or Msg1, while CP1666 native-continuous reaches real RACH config and
emits seven Msg1 attempts. Existing CP1660/CP1665/CP1666 logs cannot tell
whether all-timed loses SI/SIB1 decode before RRC, decodes SIB1 but fails to
apply RACH config, or reaches the PHY handoff and fails later.

## Method

No RF was run in this checkpoint.

Added default-off `PAVONIS_SRSUE_SIB1_TRACE` instrumentation to:

- `srsRAN_4G/srsue/src/stack/rrc_nr/rrc_nr.cc`
- `srsRAN_4G/srsue/src/phy/nr/worker_pool.cc`
- `srsRAN_4G/srsue/src/phy/nr/cc_worker.cc`

The trace is written to stderr so it is visible even with the existing UE
`all_level=error` logging. It covers SI-RNTI PDCCH/PDSCH grant visibility,
BCCH-DLSCH/SIB1 decode, RACH ASN.1 fields, MAC/PHY RACH config conversion,
`phy->set_config()`, and the worker-pool PRACH offset handoff.

Patched the current real-UE runners so the next RF run enables the trace and
summarizes it:

- `cp193_sens_start_stage6_high_peak_tx_now_ue_remote.sh`
- `cp1660_run_stage6_txatt5_nativecontinuous_alltimed_lead30ms_guard0_sequence.sh`
- `cp1617_run_stage6_txatt5_nativecontinuous_delayedarm_predemod_guard_sequence.sh`

## Result

CP1668 is a no-RF observability checkpoint. It does not change the CP1658
raw-downlink baseline and does not prove any new RF behavior. It does give the
next RF run enough visibility to classify the all-timed no-RACH-config failure:

- No `si_pdcch`/`si_pdsch_grant`/`bcch_dlsch_decoded`: SI/SIB1 decode path is
  failing before RRC.
- `bcch_dlsch_decoded`/`processing_sib1` present but no `phy_set_config_ok`:
  RRC/RACH-config apply path is failing.
- `phy_set_config_ok` and `worker_pool_prach_after_offset` present but no
  nonzero PRACH `set_cell`: PHY worker/PRACH-buffer handoff is failing.
- Nonzero PRACH config and Msg1 rows return: the all-timed no-Msg1 failure is
  not reproduced under this instrumented binary and the detector branch can
  resume.
