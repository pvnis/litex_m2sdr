## Verdict

The user-requested two-point marker gate passes: the all-timed `30 ms` path has
no millisecond-scale offset growth or jump between `+5 s` and `+90 s` in this
same-device self-RX measurement. The measured differential spread is only
`0.002865 ms`.

This checkpoint does not validate the CP1675 split as an SIB1 fix, because the
new timed-discontinuous split log did not fire. It is also not a perfectly clean
delayed-real-UE precondition because it produced `12` release-late rows.

Do not use CP1676 as proof that the CP1675 patch fixes CP1673's SI/SIB failure.
It does close the early-only-marker concern for this patched all-timed marker
run. The next SIB1/real-UE rung should require its own TX-late gate and should
record whether the CP1675 split path fires during the real-UE run.
