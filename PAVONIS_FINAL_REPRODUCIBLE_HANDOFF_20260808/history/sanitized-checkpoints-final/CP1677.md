## Verdict

CP1677 is a clean real-UE SIB1 validation run for the patched module, and it
fails in the same all-timed layer as CP1673.

Useful conclusions:

- The CP1675 timed-remainder split does not fire in this real-UE run.
- The delayed all-timed TX path is clean on late counters and release-late logs.
- The UE acquires PBCH/SFN and keeps the first 160 camping TTIs aligned.
- SI-RNTI PDCCH still never produces a grant: `800/800` summaries have
  `n_dl_max=0`, with best `max_corr=0.337581`.
- No real RACH config or Msg1 is produced, so this is void for PRACH detector
  timing and p0/window conclusions.

Do not rerun CP1677 unchanged. The timed-remainder split hypothesis is not
supported as the active cause of the CP1673 SI/SIB failure, because the split
path count stays zero. The next changed work should pivot away from the
CP1675 split unless a new run can force it active, and should instead compare
the all-timed TX presentation against the CP1672 native-continuous positive
path at the SI scheduling/search level, or test a different TX-presentation
variant that preserves CP1658 raw PBCH/TRACK while recovering CP1672-class
SIB1/RACH config.
