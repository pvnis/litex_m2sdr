# CP1679 - Native-Continuous 30 ms SIB1 Discriminator

Date: [date-redacted] Europe/Zurich

## Goal

Run the CP1672 native-continuous positive-control path with the same
`M2SDR_SOAPY_TX_TIME_OFFSET_NS=30000000` headroom used by the all-timed
CP1673/CP1677 failures.

This isolates the remaining CP1678 confound:

- If native-continuous `30 ms` recovers SIB1/RACH config, all-timed presentation
  is the likely blocker.
- If native-continuous `30 ms` also loses SIB1, the `30 ms` headroom itself is
  implicated.

## Verdict

CP1679 fails the intended discriminator: native-continuous with `30 ms` headroom
also loses SI-RNTI PDCCH visibility. This means CP1673/CP1677's failure is not
caused only by all-timed chunk presentation or the CP1675 timed-remainder split
gap.

The `30 ms` TX headroom is now directly implicated in the post-SFN SIB1/RACH
config failure. CP1672's native-continuous `1 ms` path remains the positive
real-UE SI/SIB1/RACH-config control, while CP1679 native-continuous `30 ms`
matches the no-SIB class: PBCH/SFN and camping alignment pass, but `800/800`
SI summaries have `n_dl_max=0`.

Do not rerun CP1679 unchanged. The next changed RF rung should bracket native-
continuous TX headroom downward, starting at `10 ms`, using the same low-impact
SIB1 trace. If native `10 ms` succeeds, the SIB1 break point lies between
`10 ms` and `30 ms`; if native `10 ms` fails, bracket between CP1672's `1 ms`
positive point and `10 ms`.
