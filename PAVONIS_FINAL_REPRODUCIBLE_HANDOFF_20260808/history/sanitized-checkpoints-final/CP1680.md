## Goal

`M2SDR_SOAPY_TX_TIME_OFFSET_NS=10000000`, using the same low-impact SIB1 trace.

This brackets the CP1679 result:

- CP1672 native-continuous `1 ms` reaches SI grant, SIB1, real RACH config, and
  seven Msg1 attempts.

  visibility.

## Verdict

CP1680 is a valid negative SIB1 bracket point. Native-continuous `10 ms` still
preserves PBCH/SFN and first-160 camping alignment, but it loses SI-RNTI grant
visibility in the same no-SIB class as CP1679: `800/800` SI summaries have
`n_dl_max=0`, there are zero SI grants, zero SI PDSCH grants, zero BCCH/SIB1
decodes, zero `phy_set_config_ok` events, and zero real RACH config or Msg1.

The breakpoint is now below `10 ms`: CP1672 native-continuous `1 ms` is the
positive SI/SIB1/RACH-config control, while CP1680 native-continuous `10 ms` is
already negative. Do not interpret CP1680's PRACH detector artifacts as timing
evidence, because the UE emitted no Msg1.

Next changed RF should bracket native-continuous TX headroom between `1 ms` and
`10 ms` with the same low-impact SIB1 trace. A `5 ms` midpoint is the next
useful rung unless a marker-specific latency measurement is being run instead;
any live latency-marker variant must keep two same-stream markers, one shortly
after stream start and another around `60-120 s`.
