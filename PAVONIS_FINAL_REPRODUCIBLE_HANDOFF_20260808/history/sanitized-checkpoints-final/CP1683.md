## Goal

`M2SDR_SOAPY_TX_TIME_OFFSET_NS=5000000`, using the same low-impact SIB1 trace.

This brackets the current native-continuous headroom boundary:

- CP1672 native-continuous `1 ms` reaches SI grant, SIB1, real RACH config, and
  seven Msg1 attempts.

  visibility.
- CP1680 native-continuous `10 ms` is also no-SIB.
- CP1683 tests the midpoint `5 ms`.

## Verdict

CP1683 is a valid negative SIB1 bracket point. Native-continuous `5 ms`
preserves PBCH/SFN and first-160 camping alignment, but it still loses
SI-RNTI grant visibility: `800/800` SI summaries have `n_dl_max=0`, and there
are zero SI grants, zero SI PDSCH grants, zero BCCH/SIB1 decodes, zero
`phy_set_config_ok` events, zero real RACH config, and zero Msg1.

The native-continuous SIB1 breakpoint is now below `5 ms`: CP1672 `1 ms`
passes, while CP1683 `5 ms`, CP1680 `10 ms`, and CP1679 `30 ms` all fail in
the same no-SIB class. Do not interpret CP1683's PRACH detector artifacts as
timing evidence, because the UE emitted no Msg1.

Next changed SIB1 RF should bracket between `1 ms` and `5 ms`, for example
`2 ms` or `3 ms`, unless the next branch changes TX presentation instead of
offset.
