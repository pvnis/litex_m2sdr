## Verdict

CP1684 is a valid partial SIB1 recovery point, not a ladder pass. Native
single-anchor TX at `2 ms` recovers one SI-RNTI PDCCH and one SI PDSCH grant,
but does not decode BCCH/SIB1, does not apply real RACH config, and emits no
Msg1. Therefore:

- CP1672 `1 ms` remains the only current native-continuous full
  SIB1/RACH-config/Msg1 positive control.
- CP1684 `2 ms` is intermediate: SI grant visible, SIB1 decode absent.
- CP1683 `5 ms`, CP1680 `10 ms`, and CP1679 `30 ms` remain no-SI-grant
  failures.

The native-continuous SIB1 breakpoint is now narrowed to `1 ms < breakpoint <=
2 ms` for full SIB1/RACH-config recovery, with a separate intermediate
SI-grant-only class at `2 ms`. Any future marker experiment for this live path
must keep the CP1682 lesson: measure at two well-separated points in the same
stream, one shortly after stream start and one around the `60-120 s` real-Msg1
epoch, because an early-only marker can falsely clear native single-anchor
timing.
