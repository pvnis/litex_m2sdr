## Verdict

CP1688 validates the user's two-point concern at the exact CP1687 `1.5 ms`
native-continuous setting. The early marker at `+5 s` measures about
`+1.019 ms`, while the late marker at `+60 s` measures about `+9.732 ms`, a
same-stream spread of `8.713 ms`.

The run is mechanically clean and the overflow rows are away from both marker
windows, so the result should be treated as another valid native single-anchor
epoch-dependence datapoint. A single early marker at this setting would have
falsely suggested the live path was near the requested `1.5 ms` offset, while
the late real-UE epoch is nearly `+10 ms`.

This does not invalidate CP1687's SIB1/RACH recovery: CP1686 already showed
the known-good `1 ms` path also drifts. The combined result is that native
single-anchor timing drift is real at `1 ms`, `1.5 ms`, `2 ms`, and `10 ms`,
but drift magnitude alone does not separate SIB pass from SIB partial/fail.
