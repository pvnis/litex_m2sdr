## Verdict

CP1689 is mechanically valid but void for PRACH detector/window conclusions.
The UE did not emit Msg1, so the saved append/predemod/trace data cannot answer
whether CP1687's real bursts miss the detector window or arrive weak.

The useful finding is diagnostic: a CP1618-style heavy append/predemod rerun at
the same `1.5 ms` native-continuous offset did not reproduce CP1687's SIB1/RACH
config and seven Msg1 attempts. Treat this as evidence that the heavy
RXBW30720 append/predemod path is not equivalent to the low-impact CP1687
real-UE baseline.

Next changed work should either rerun a CP1687-style no-append/low-impact SIB1
trace control to confirm the real-Msg1 baseline still reproduces, or build a
lighter targeted raw-capture diagnostic that preserves the CP1687 SIB/RACH
path. If another raw append attempt is made, enable low-impact SIB1 trace and
gate runs with no UE Msg1 as void retries, not detector datapoints.
