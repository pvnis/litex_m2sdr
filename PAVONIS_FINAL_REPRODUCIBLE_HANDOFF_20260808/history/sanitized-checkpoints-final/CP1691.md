## Source fix

Patched:

```text
litex_m2sdr/litex_m2sdr/software/soapysdr/LiteXM2SDRStreaming.cpp
```

Two changes were made:

1. The timed-remainder discontinuity check now compares sample indices, not a
   `+/-1 ns` rounded time delta:

```text
remainder_start_sample = ns_to_samples(rate, remainder_timeNs)
expected_sample = remainder_start_sample + remainderOffset
incoming_sample = ns_to_samples(rate, incoming timeNs)
timed_discontinuity = incoming_sample != expected_sample
```

2. The missing partial-buffer carry path is fixed. If an incoming timed
   `writeStream()` first completes an existing partial TX buffer and then
   continues into a fresh buffer, the fresh buffer now gets the timestamp of
   its first payload sample:

```text
buffer_start_sample = ns_to_samples(rate, incoming timeNs) + consumed_samples
buffer_timeNs = samples_to_ns(rate, buffer_start_sample)
```

Before CP1691, that fresh tail buffer inherited the original incoming
`timeNs`, even though its payload started `samp_avail` samples later. That is
the lower LiteX partial-buffer path CP1675 did not complete.

New binary/log string:

```text
M2SDR TX HAS_TIME partial carry: advancing fresh buffer timestamp ...
```
