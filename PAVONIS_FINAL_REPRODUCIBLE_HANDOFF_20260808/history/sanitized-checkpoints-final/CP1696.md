## Goal

Validate the CP1695 OCUDU TX timeout-retry fix on the same all-timed `30 ms`
real-UE SIB1 gate shape as CP1694, keeping the `1 ms` first-attempt write
timeout that restored acquisition in CP1694.

Success criterion:

- zero abandoned/returned TX sample deficit under the retry path
- normal PBCH/SFN acquisition

Only a run satisfying both would be a valid SIB1/PRACH ladder datapoint.

## Verdict

CP1696 is not a valid SIB1/PRACH ladder datapoint.

It fails both required gates:

- TX gate failed: nonzero returned-sample deficit and
  `timeout_retry_abandoned_samples=1112`.
- Acquisition gate failed: UE failed cell select/SFN, with only one very weak
  PBCH-positive trial.

Do not rerun CP1696 unchanged. The result suggests the synchronous retry loop
is the wrong shape for this real-time path: it recovers samples but blocks the
caller heavily enough to degrade acquisition, while still not guaranteeing zero
abandonment. The next work should stay no-RF and revise the retry strategy so
unwritten samples are preserved without long head-of-line blocking in
`transmit()`.
