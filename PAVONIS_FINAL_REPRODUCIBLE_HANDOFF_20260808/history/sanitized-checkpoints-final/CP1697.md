# CHECKPOINT 1697 - OCUDU TX timeout carry build

Date: [date-redacted] Europe/Zurich

## Goal

Stop [interface-redacted] the write-timeout constant after CP1696 and change OCUDU's Soapy TX path so a timed write timeout preserves the unwritten stream samples without a long synchronous retry train inside `transmit()`.

This is a no-RF build checkpoint. It is not a SIB1, PRACH, or Msg1 datapoint.

## Source change

Touched files:

- `/home/[host-redacted]/CLionProjects/ocudu/lib/radio/soapy/radio_soapy_tx_stream.cpp`
- `/home/[host-redacted]/CLionProjects/ocudu/lib/radio/soapy/radio_soapy_tx_stream.h`

Implemented default-on timeout carry support:

- `OCUDU_SOAPY_TX_TIMEOUT_CARRY`
- `OCUDU_SOAPY_TX_TIMEOUT_CARRY_MAX_SAMPLES`
- `OCUDU_SOAPY_TX_TIMEOUT_CARRY_DRAIN_WRITES`
- `OCUDU_SOAPY_TX_TIMEOUT_CARRY_WRITE_TIMEOUT_US`

Behavioral change:

- When carry is enabled, a `SOAPY_SDR_TIMEOUT` from a data write queues the timed chunk and the rest of that logical buffer instead of retrying repeatedly inside the same `transmit()` call.
- Later `transmit()` calls first try to drain queued chunks with a bounded number of short-poll writes.
- If queued data remains, current chunks are queued too so the stream is not written out of order.
- `stop()` performs a bounded final drain and reports any remaining pending chunks/samples.
- The older CP1695 synchronous retry path remains available only when carry is disabled.

Accounting change:

- Added `stream_samples`, which counts the intended continuous stream samples, including continuous-mode empty/zero-fill buffers.
- Added `stream_deficit = stream_samples - samples_ret` to the Soapy TX summary.
- Kept `data_samples` as non-empty payload accounting.
- Added carry counters for queued/drained/pending/overflow/abandoned samples.

## Verdict

Next RF gate should use the CP1694-class all-timed `30 ms`, `1 ms` write-timeout real-UE path with carry enabled and synchronous retry disabled or ignored. A valid SIB1 datapoint must satisfy both:

- TX gate: `stream_deficit=0`, `timeout_carry_abandoned_samples=0`, `timeout_carry_pending_samples=0`, no carry overflows/errors, and normal LiteX late/underflow/acquire health.
- UE gate: normal PBCH/SFN acquisition plus SIB1/RACH config; no-Msg1 runs remain void for PRACH detector/window conclusions.
