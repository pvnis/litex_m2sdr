# CHECKPOINT 1709 - No-RF prepared CP1706 deadline-write pre-UE runner

## Goal

Move the active CP1706 deadline-write branch forward without using the
currently untrusted physical RF path. CP1708 made the safety gates explicit;
CP1709 prepares the actual [host-redacted]-only no-UE pre-UE TX gate runner so the next RF
checkpoint can be run directly once the lab wiring is cleared.

No RF, TX, OTA, UE start, SSH, cleanup, or remote command was run by CP1709's

The runner is intentionally guarded. It hard-aborts before the read-only
hardware preflight, cleanup, SSH, helper deployment, or gNB start unless both
of these are set:

```text
PAVONIS_PHYSICAL_PATH_CLEARED=1
PAVONIS_ALLOW_RF_TX=1
```

This prevents accidental RF emission while the cable path is unknown.

## Prepared RF shape

When explicitly enabled later, the runner will:

1. Run `cp1708_readonly_hardware_preflight.sh`.
2. Clean stale Stage 6 processes with the existing CP98 cleanup helper.
3. Start [host-redacted] gNB only, with no UE/[host-redacted] start.
4. Use the CP1658/CP1698 all-timed/native-continuous baseline:

```text
PAVONIS_SOAPY_ALLOW_M2SDR_CONTINUOUS_TX_MODE=1
PAVONIS_SOAPY_TX_ALL_TIMED_CHUNKS=1
PAVONIS_SOAPY_TX_REANCHOR_INTERVAL_SAMPLES=0
M2SDR_SOAPY_TX_ALIGN_HAS_TIME_REMAINDER=1
M2SDR_SOAPY_TX_TIME_OFFSET_NS=30000000
TX_ATT=5
TX_BACKOFF=10
```

5. Enable the CP1706 deadline-aware direct-write mode:

```text
OCUDU_SOAPY_TX_DEADLINE_WRITE_TIMEOUT=1
OCUDU_SOAPY_TX_DEADLINE_WRITE_GUARD_US=[date-redacted]
OCUDU_SOAPY_TX_DEADLINE_WRITE_MAX_TIMEOUT_US=50000
```

6. Keep carry/deadline accounting explicit:

```text
OCUDU_SOAPY_TX_TIMEOUT_RETRY=0
OCUDU_SOAPY_TX_TIMEOUT_CARRY=1
OCUDU_SOAPY_TX_TIMEOUT_CARRY_DEADLINE=1
OCUDU_SOAPY_TX_TIMEOUT_CARRY_DEADLINE_DROP=0
OCUDU_SOAPY_TX_TIMEOUT_CARRY_MAX_LAG_SAMPLES=11520
OCUDU_SOAPY_TX_TIMEOUT_CARRY_MAX_SAMPLES=1152000
```

7. After the pre-UE wait, run the installed [host-redacted] CP1708 gate:

```text
cp1708_strict_tx_deadline_gate.py \
  --require-carry-fields \
  --require-deadline-write-fields \
  --require-latest-pending-zero \
  --max-any-pending-samples 0
```

8. Stop/package/fetch [host-redacted] artifacts and write a compact JSON summary.

The runner never starts UE; it is only the pre-UE TX-health gate.
