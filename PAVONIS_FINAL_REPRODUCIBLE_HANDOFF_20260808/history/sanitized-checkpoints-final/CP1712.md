# CP1712 no-RF CP1709 prep-failure guards

Date: [date-redacted] Europe/Zurich

## Purpose

The lab wiring/cabled path is currently untrusted, so this checkpoint stays
strictly no-RF. CP1709 already hard-aborted unless
`PAVONIS_PHYSICAL_PATH_CLEARED=1` and `PAVONIS_ALLOW_RF_TX=1` were both set,
but its cleanup/helper-deploy/chmod preparation stages used `run_or_note`.
Those failures would set `OVERALL_RC=1` while allowing the script to continue
toward `start_gnb_deadline_write_preue`.

CP1712 hardens that path: any failed cleanup, helper deployment, or chmod
preparation stage now writes the manifest and exits before the start command.
