# CP1714 RF hardware-path tone differential pass

Date: [date-redacted] Europe/Zurich

## Purpose

After the user cleared the physical-path uncertainty, CP1714 tests the RF path
before moving back up the ladder. The test uses a TX-off/TX-on differential so
that a bladeRF floor/spur near the expected tone cannot be mistaken for a real
received signal.

This is not a raw scheduled-TRACK, SIB1, PRACH, or UE datapoint. It is a
hardware-path smoke test.

## Commands

No-TX baseline:

```text
STAMP=[date-redacted]CP1714A_NOTX_HWPATH_BW3840_NORMAL_GAIN32 \
CAP_BW_HZ=3840000 CAP_FILTER=normal CAP_GAIN_DB=32 \
bash cp1452_run_bladerf_notx_livegeom_tone_geometry_baseline.sh
```

TX-on same-window M2SDR self-RX plus bladeRF capture:

```text
STAMP=[date-redacted]CP1714B_TXON_HWPATH_BW3840_NORMAL_GAIN32_TXATT5 \
CAP_BW_HZ=3840000 CAP_FILTER=normal CAP_GAIN_DB=32 TX_ATT_DB=5 \
bash cp1451_run_litex_tone_selfrx_and_bladerf_samewindow.sh
```

Geometry:

- M2SDR TX RF: `1842500000 Hz`
- M2SDR TX tone: `-2350000 Hz` baseband
- Expected bladeRF capture tone: `+500000 Hz`
- bladeRF RX center: `1839650000 Hz`
- bladeRF RX sample rate / bandwidth / gain / filter:
  `7.68 Msps / 3.84 MHz / 32 dB / normal`
- TX-on leg attenuation: `5 dB`

## Mechanics

CP1714A no-TX completed with `overall_rc=0`.

CP1714B TX-on completed with `overall_rc=0`:

```text
marker_rc=0
capture_rc=0
self_phase_rc=0
bladerf_tone_rc=0
bladerf_phase_rc=0
cleanup_after rc=0
```

The bladeRF active capture route used RX1 through `RF3(B)`, RX mux `BASEBAND`,
normal filter, requested bandwidth `3840000`, and requested gain `32`.

## Conclusion

CP1714 passes the hardware-path smoke. Unlike CP1452-CP1460's old no-TX-like
external-tone branch, the current TX-on leg produces a real bladeRF receive
delta (`+5.93 dB`) and a CP847 tone PASS while the same-window M2SDR self-RX
also passes. The bladeRF CP892 result is still `WARN` because its 10 ms window
frequency estimates are broad, but the tone is now clearly present above the
no-TX floor.

The next rung can proceed to the CP1712-hardened CP1709 no-UE pre-UE
deadline-write TX gate.
