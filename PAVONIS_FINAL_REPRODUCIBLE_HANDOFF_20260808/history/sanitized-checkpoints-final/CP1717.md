# CP1717 - RF Attenuator Explicit RX1/RX2 No-TX Baseline, TX-On Deferred

Date: [date-redacted] Europe/Zurich

## Purpose

The lab path had just been restored with an attenuator, and the requested next
hardware check was to test both bladeRF receive paths because one path should
be cabled and one should be antenna. CP1717 captured a no-TX explicit RX1/RX2
baseline before the user pivoted to the periodic re-anchor / backpressure
checkpoint. It is therefore a partial hardware-path checkpoint, not a complete
pair classification.

mutation. It verified [host-redacted] and [host-redacted] reachability, bladeRF visibility, and
idle bladeRF state. Then [host-redacted] captured one second of no-TX samples from
explicit bladeRF `channel=1` and `channel=2` at the same receive geometry:

## Conclusion

CP1717 is only a noise-floor baseline. It does not identify which physical
pair is cabled versus antenna because no same-geometry TX-on differential was
run before the user changed priority. A complete pair check still requires a
TX-on/TX-off differential for both explicit RX paths, preferably using the same
geometry as this baseline and preserving the no-TX values above for comparison.
