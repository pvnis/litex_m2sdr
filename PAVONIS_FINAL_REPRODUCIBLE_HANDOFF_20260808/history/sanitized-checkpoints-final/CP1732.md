## Interpretation

CP1732 restores the raw scheduled-TRACK gate on the current binary using the
CP1658 cadence: the mean TRACK SNR is well above the `-10 dB` gate and every
TRACK opportunity decodes PBCH.

This closes the immediate post-CP1729 question: the current CP1726-instrumented
binary plus CP1658 cadence is still a valid raw-downlink baseline. The next
ladder step may move above raw TRACK into a real-UE SIB1/RACH-config check,
but only with the CP1732/CP1658 cadence and the same readback gate. CP1732 is
not a Msg1/PRACH detector datapoint because no real UE PRACH attempt was run.
