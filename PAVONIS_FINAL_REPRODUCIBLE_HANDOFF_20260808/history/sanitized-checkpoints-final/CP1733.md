# CHECKPOINT 1733 - Current-Binary CP1658-Cadence Real-UE SIB1/RACH Config

Date: [date-redacted]

## Goal

Move one rung above CP1732's restored raw scheduled-TRACK gate by running a
real-UE SIB1/RACH-config smoke on the current CP1726-instrumented gNB binary,
while keeping the CP1658/CP1732 native-continuous all-timed cadence and the
same readback gate.

This checkpoint is a SIB1/RACH-config and Msg1-emission gate. It is a PRACH
detector datapoint only if the UE emits real Msg1 bursts.

## Interpretation

CP1733 is the first current-binary CP1658-cadence rung after CP1732 to recover
real SIB1/RACH config and real UE Msg1 emission. It moves the active frontier
above raw downlink and SIB1 back to the Stage 6 PRACH Msg1 detector failure:
the UE emits seven Msg1 bursts, but the gNB detector sees zero nonempty and
zero accepted PRACH rows.

This does not prove the TX sample-return deficit is harmless in general; the
stop counters are still large. But for this run it did not prevent PBCH/SFN,
SIB1, RACH config, or UE Msg1 emission. Future PRACH work can use the saved
CP1733 predemod/raw artifacts for offline detector/window analysis, because
this is no longer a void no-Msg1 datapoint.
