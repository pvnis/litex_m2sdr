# CHECKPOINT 1745 - No-delay real-UE SIB1 gate with TX write timeout 1000 us

Date: [date-redacted]

## Purpose

Run the CP1744-recommended single RF discriminator: exact CP1733/no-delay
real-UE shape, but with `OCUDU_SOAPY_TX_WRITE_TIMEOUT_US=1000` instead of the
`200 us` value used by CP1733/CP1738/CP1740/CP1742.

This was intended to test whether the intermittent SIB1 failure is marginally
coupled to the short write timeout before moving to configuration-level
de-marginalization.

## Command shape

The RF run used:

- `PRACH_COLLECTION_DELAY_SAMPLES=0`
- `TX_TIME_OFFSET_NS=30000000`
- `TX_WRITE_TIMEOUT_US=1000`
- `PRACH_PREDEMOD_SUMMARY_MAX=1700`
- `PRACH_PREDEMOD_RAW_MAX=1700`

RF was explicitly enabled with `PAVONIS_PHYSICAL_PATH_CLEARED=1` and
`PAVONIS_ALLOW_RF_TX=1`.

The gNB saw no real Msg1/RAR path:

- `soapy_tx_summary_lines=3080`

The accepted PRACH row is not a real-UE datapoint because the UE emitted no

Final TX stop summary:

- `write_timeout_us=1000`
- `write_deficit=130523240`
- `data_write_deficit=130523240`
- `stream_deficit=1390932064`
- `partial_ret=7694`

- carry/deadline backlog/drop counters all zero

Compared with the `200 us` no-SIB baselines, the timeout count dropped modestly
but did not restore SIB1. The SI correlation improved enough to produce one
row above `0.5`, but still no SI grant.

## Interpretation

`OCUDU_SOAPY_TX_WRITE_TIMEOUT_US=1000` took effect and is not sufficient to
make the CP1733/no-delay all-timed `30 ms` real-UE path reliably decode SIB1.
This closes the single-change timeout-marginality test as a failed SIB1 gate.

The `321600` sample PRACH-window hypothesis remains parked: CP1745 emitted no
real Msg1, so it provides no PRACH detector/window evidence.

Next work should de-marginalize SI acquisition at the gNB configuration level
before spending another PRACH-window RF run. The specific branch is to inspect
supported YAML keys and raise SI/PDCCH robustness or downlink power in a
controlled way, then rerun a SIB1/Msg1 gate. Only a run with real UE Msg1
emission is valid for resuming the parked PRACH collection-delay test.
