# CHECKPOINT 1747 - gNB demarg PDCCH common block invalid for 10 MHz cell

Date: [date-redacted]

## Purpose

Run the CP1746 YAML-demarginalized CP1733/no-delay real-UE gate and first test
whether the gNB accepts the generated config.

Intended RF shape:

- `PRACH_COLLECTION_DELAY_SAMPLES=0`
- `TX_TIME_OFFSET_NS=30000000`
- `TX_WRITE_TIMEOUT_US=1000`
- `GNB_SRSUE_PDCCH_COMPAT=1`
- `GNB_CORESET0_INDEX=12`
- `GNB_SS0_INDEX=0`
- `GNB_FIXED_SIB1_MCS=0`
- `GNB_SSB_BLOCK_POWER_DBM=-4`

## Result

The checkpoint failed before TX readback and before UE start:

- `start_gnb_nativecontinuous_stage6 rc=124`
- `overall_rc=1`
- `gate_rc=1`
- `late_gate_rc=1`
- `ue_started=0`
- no TX readback sidecar
- no PRACH predemod/detector artifacts
- no UE artifacts
- post-run `[host-redacted]` ping and helper SSH passed

This is not a SIB1, Msg1, or PRACH datapoint.

## Failure cause

The generated YAML did contain the requested CP1746 demarg block:

```yaml
pdcch:
  dedicated:
    ss2_type: common
    dci_format_0_1_and_1_1: false
  common:
    ss0_index: 0
    coreset0_index: 12
pdsch:
  fixed_sib1_mcs: 0
ssb:
  ssb_block_power_dbm: -4
```

OCUDU rejected that config immediately:

```text
Unable to derive a valid SSB pointA and k_SSB for CORESET#0 index=12,
SearchSpace#0 index=0 and cell bandwidth=10Mhz
OCUDU ERROR: Invalid configuration detected.
```

Therefore the srsUE example `coreset0_index=12` is not valid for the current
Band 3 `10 MHz` M2SDR cell. Do not rerun CP1747 unchanged.

## Interpretation

CP1747 closes the first config-demarg attempt as an invalid gNB-start shape,
not an RF or UE failure.

The next config-level RF rung should leave the 10 MHz cell's derived
CORESET0/SearchSpace0 untouched and test only the YAML levers that remain valid
for this bandwidth:

- `pdsch.fixed_sib1_mcs: 0`
- `ssb.ssb_block_power_dbm: -4`

The parked `321600` PRACH-window test remains parked until a run again supplies
real SIB1/RACH/Msg1.
