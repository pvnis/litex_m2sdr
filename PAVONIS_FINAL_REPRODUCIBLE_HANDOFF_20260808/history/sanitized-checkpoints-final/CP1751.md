## Purpose

before SFN sync. This keeps the CP1745/CP1733 no-delay real-UE shape with
`TX_WRITE_TIMEOUT_US=1000` and changes only:

## Interpretation

CP1751 proves the CP1749 `n8` override is active in a run that reaches
PBCH/SFN/SI search, but `n8` does not restore SIB1. It produces high SI
correlation summaries without any decoded SI-PDCCH/PDSCH grant. Therefore this
branch should not move to the `321600` PRACH delay test yet.

The immediate next RF discriminator should be a patched-binary default-`n4`
CP1745-style control with the same no-delay, `TX_WRITE_TIMEOUT_US=1000` shape
and no SIB1 aggregation env. If default `n4` recovers SIB1/Msg1, then `n8`
hurts the UE's SI search/candidate geometry despite the higher correlation
metric. If default `n4` also fails, the post-CP1749 binary/current hardware is
still in the random SIB1/no-grant regime and the next de-margining should avoid
blindly increasing aggregation further.
