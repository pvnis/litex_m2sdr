## Conclusion

CP1754 proves `GNB_POWER_CONTROL_OFFSET_SS_DB=6` restores the current
all-timed `30 ms` real-UE SIB1/RACH/Msg1 supply on the default-`n4`,
`write_timeout_us=1000` shape. This closes CP1751/CP1752's no-SIB blocker as a
common-channel power-margin issue, at least for this run.

It does not solve Stage 6 by itself because this run deliberately kept
`PRACH_COLLECTION_DELAY_SAMPLES=0`; with no delay, real UE Msg1 still misses
the gNB detector/predemod windows. The parked CP1737 `~321600` sample
collection-delay hypothesis is now unparked: the next RF rung should repeat
this exact CP1754 shape with `PRACH_COLLECTION_DELAY_SAMPLES=321600`, still
keeping `GNB_POWER_CONTROL_OFFSET_SS_DB=6`, and judge the PRACH detector only
if the UE again emits real Msg1.
