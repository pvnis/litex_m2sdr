# Checkpoint 1762 - No-RF RX Append SI Perturbation Compare

Date: [date-redacted]

## Goal

Before treating SIB1 supply as an independent blocker, compare saved no-append
and append-enabled runs to test whether the same-device RX append itself
perturbs SI acquisition. The requested comparison was CP1754/CP1755
no-append pass runs against CP1758/CP1760 append void runs; CP1761 was included
as an additional append-enabled replicate because it had just completed with
the same failure shape.

## Method

No RF commands were run. I added and ran:

```text
cp1762_no_rf_rxappend_si_perturbation_compare.py
```

The script reuses CP1744's SI-to-PRACH-manifest time-base join helpers, then
reports SI correlation/outcome plus SI-era TX period deltas for `timeouts`,
`partial_ret`, `write_deficit`, and `stream_deficit`.

## Conclusion

The visible splitter is append activity during SI acquisition, not a worse
SI-era TX timeout/partial-return burst. Keep
`GNB_POWER_CONTROL_OFFSET_SS_DB=6`, stop pre-UE append arming for the sample-
domain PRACH measurement, and retry with RX append armed only after SIB1/RACH
evidence appears. No-Msg1 runs remain void.
