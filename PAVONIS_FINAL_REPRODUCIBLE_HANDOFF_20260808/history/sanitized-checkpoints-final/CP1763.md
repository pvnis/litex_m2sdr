# Checkpoint 1763 - Late RX Append Arm Harness

Date: [date-redacted]

## Goal

Implement the CP1762 conclusion without another RF run: keep normal PRACH
trace/predemod/UL-symbol instrumentation armed before UE start, but stop
arming the same-device Soapy RX append during SI acquisition. The append should
use a separate arm file and be touched only after the UE proves SIB1/RACH
progress.

## Changes

Updated harness scripts only:

- `cp1660_run_gnb_b3_txatt5_nativecontinuous_alltimed_lead30ms_stage6_prachtrace_detached.sh`
  - adds `RX_APPEND_ARM=${PAVONIS_SOAPY_RX_APPEND_ARM_FILE:-$ARM}`
  - removes that file at startup when separate from `ARM`
  - uses `RX_APPEND_ARM` for `PAVONIS_SOAPY_RX_DUMP_ARM_FILE`
  - logs `RX_APPEND_ARM`
- `cp1733_run_stage6_currentbinary_cp1658cadence_realue_sib1_rachconfig.sh`
  - adds `RX_APPEND_ARM=/tmp/pavonis_soapy_rx_append_stage6_cp1733_currentbinary_cp1658cadence_${STAMP}_arm`
  - adds `PAVONIS_SOAPY_RX_APPEND_ARM_MODE`, default `pre_ue`
  - adds late-arm knobs `PAVONIS_SOAPY_RX_LATE_ARM_TIMEOUT_SEC` and
    `PAVONIS_SOAPY_RX_LATE_ARM_POLL_SEC`
  - exports `PAVONIS_SOAPY_RX_APPEND_ARM_FILE` into the [host-redacted] start command
  - always prearms the main `ARM` for PRACH trace/predemod/UL-symbol dumps
  - only prearms `RX_APPEND_ARM` when append mode is `pre_ue`
  - when append mode is `after_sib1`, watches the [host-redacted] UE stdout for
    `phy_set_config_ok`, `PAVONIS_SRSUE_PRACH_CFG transmitted`, or `PRACH-TX`;
    if seen, it touches `RX_APPEND_ARM` on [host-redacted], then waits for UE completion

This mode may miss the first Msg1 because SIB1-to-PRACH can be only a few
milliseconds, but later attempts are spaced by about `160 ms`. The measurement
criterion is capturing one or more real Msg1 attempts in the same M2SDR
sample/hardware-time domain, not necessarily attempt zero.
