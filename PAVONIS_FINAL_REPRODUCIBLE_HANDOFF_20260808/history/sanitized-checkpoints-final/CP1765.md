## Interpretation

CP1765 does not test the CP1764 sample-domain offset. It is a no-SIB/no-Msg1
void and produced no late append because the late-arm trigger never fired.

The CP1764 conclusion remains the active timing evidence: same-device PRACH
bursts were present at about `+349k..+352k` template-start samples after the
nominal predemod window, but only two append-overlapped attempts were captured
and the spread was too large to set a final static delay.

Next work should not draw timing conclusions from CP1765. Either run another
late-append measurement only if SIB1/Msg1 supply is restored, or improve the
late-arm/measurement design so it captures more post-SIB1 attempts without
arming during SI acquisition.
