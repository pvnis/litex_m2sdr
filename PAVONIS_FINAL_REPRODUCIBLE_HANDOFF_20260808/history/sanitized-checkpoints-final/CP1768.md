# CHECKPOINT 1768 - srsUE PRACH Defer Helper Propagation Fix

Date: [date-redacted]

## Goal

Fix the no-RF plumbing bug exposed by CP1767: `UE_PRACH_DEFER_MS` reached the
CP1733 wrapper and `stage6_cp1660_ue.sh`, but the final generated
`run_srsue_bounded.sh` did not pass `PAVONIS_SRSUE_PRACH_DEFER_MS` into the
sudo-launched `srsue` process.

## Changes

- Updated `cp193_sens_start_stage6_high_peak_tx_now_ue_remote.sh`.
- Added `PAVONIS_SRSUE_PRACH_DEFER_MS="${PAVONIS_SRSUE_PRACH_DEFER_MS:-0}"` to:
  - the generated `sudo -n env` block that launches `srsue`
  - the `nohup env` block that launches the runner
- Added `PAVONIS_SRSUE_PRACH_DEFER_MS=...` to both generated env audit files.
- Parameterized `cp1764_analyze_late_rxappend_sample_domain.py` so CP1767 and
  later late-append runs can reuse the exact same sample-domain analyzer by
  passing `PAVONIS_ANALYZE_*` paths. CP1764 defaults remain unchanged.
