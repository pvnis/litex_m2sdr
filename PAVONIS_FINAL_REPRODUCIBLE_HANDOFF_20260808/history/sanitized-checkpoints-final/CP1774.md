# CHECKPOINT 1774 - No-RF Widened Predemod Raw-Dump Audit

Date: [date-redacted]

## Goal

After CP1772 and CP1773 both failed below SIB1 with the combined
`delay=352536` / `extra=12000` shape, check whether the widened predemod raw
dump volume is a plausible measurement-side perturbation and identify the
knob for the next RF attempt.

## Findings

The CP1733 real-UE wrapper already exposes the needed controls:

```text
PRACH_PREDEMOD_SUMMARY_MAX="${PRACH_PREDEMOD_SUMMARY_MAX:-1700}"
PRACH_PREDEMOD_RAW_MAX="${PRACH_PREDEMOD_RAW_MAX:-1700}"
```

It forwards them to [host-redacted] as:

```text
PAVONIS_PRACH_PREDEMOD_SUMMARY_MAX
PAVONIS_PRACH_PREDEMOD_RAW_MAX
```

The [host-redacted] CP1660 runner then uses:

```text
export PAVONIS_PRACH_PREDEMOD_DUMP=1
export PAVONIS_PRACH_DUMP_ARM_FILE="$ARM"
export PAVONIS_PRACH_PREDEMOD_SUMMARY_MAX="${PAVONIS_PRACH_PREDEMOD_SUMMARY_MAX:-1200}"
export PAVONIS_PRACH_PREDEMOD_RAW_MAX="${PAVONIS_PRACH_PREDEMOD_RAW_MAX:-512}"
```

Therefore setting local `PRACH_PREDEMOD_RAW_MAX=0` should preserve the PRACH
detector trace and predemod manifest summaries while disabling raw
`pavonis_prach_predemod_*.cf32` file writes.

The CP1773 widened-window run wrote:

- `1530` `pavonis_prach_predemod_*.cf32` files.
- `275M` of predemod raw CF32 files.
- `343M` total under the packaged `tmp/` directory.
- `0` `pavonis_ul_symbol_*.cf32` files, so the new bulk is the widened PRACH
  predemod raw dump, not UL-symbol raw capture.

This is a plausible perturbation candidate for the repeated no-SIB behavior:
with `PRACH_COLLECTION_EXTRA_SAMPLES=12000`, each raw predemod file grows from
the nominal `11520` samples to `23520` samples, while the wrapper still writes
up to `1700` raw windows during the UE run.

## Next RF Shape

Retry the combined detector test with the same RF and detector knobs, but add:

```text
PRACH_PREDEMOD_RAW_MAX=0
```

Keep:

```text
PRACH_PREDEMOD_SUMMARY_MAX=1700
PRACH_COLLECTION_DELAY_SAMPLES=352536
PRACH_COLLECTION_EXTRA_SAMPLES=12000
GNB_POWER_CONTROL_OFFSET_SS_DB=6
UE_PRACH_DEFER_MS=1000
TX_WRITE_TIMEOUT_US=1000
PAVONIS_SOAPY_RX_APPEND_ENABLE=0
```

## Conclusion

CP1774 identifies a concrete low-risk measurement-side change for the next RF
attempt: disable widened predemod raw CF32 writes while keeping summaries and
the detector trace. This is not a detector or SIB1 datapoint by itself.
