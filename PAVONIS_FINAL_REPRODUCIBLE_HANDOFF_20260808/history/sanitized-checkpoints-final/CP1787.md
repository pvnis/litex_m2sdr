# Checkpoint 1787: Zero global UL offset control still void before SIB1

Date: [date-redacted] Europe/Zurich.

## Goal

Run the CP1786-recommended RF control: keep the CP1784 wrapper/source
environment and all PRACH-specific compensation disabled, but set
`PAVONIS_LOWER_PHY_UL_RX_TIMESTAMP_OFFSET_SAMPLES=0`. This isolates whether
the negative global lower-PHY UL timestamp offset value itself caused the
repeated CP1784/CP1785 SIB1-supply voids.

## Interpretation

CP1787 refutes the narrow theory that the active negative global UL offset
value alone caused the CP1784/CP1785 SIB1-supply failures. With the offset set
to zero, the same wrapper/source environment still fails before SIB1/RACH/Msg1.

Do not draw RAR/Msg3 conclusions from CP1787, and do not [interface-redacted] PRACH delay,
PRACH extra width, or RAR offset from this void. The next useful RF control is
to rerun the closest current positive-control shape, CP1781
(`PAVONIS_PRACH_TIMING_COMPENSATION_SAMPLES=352536`,
`PRACH_COLLECTION_EXTRA_SAMPLES=12000`, defer on, raw predemod off, PCOSS
`+6`, global lower-PHY offset unset/zero). If CP1781 still passes, the SIB1
blocker is specific to the CP1784/CP1787 no-comp/no-extra run shape or wrapper
environment. If CP1781 now also voids, the current SIB1 supply has regressed
outside the global-offset hypothesis.
