# Checkpoint 1829: RAR PDU Dump And Late-Armed UE RAR Trace Build

Date: [date-redacted] Europe/Zurich

## Goal

Implement the requested CP1827 branch-1 discriminator before more RF:

- gNB side: dump the transmitted RAR MAC PDU content, including RAPID and UL
  grant fields, without perturbing the UE.
- UE side: make the RAR trace silent until after `phy_set_config_ok`, buffer it
  in memory, and flush it at exit.
- Runner side: pass the new trace env vars through the existing Pavonis helper
  path and summarize the new event counts.

## Source Changes

- `ocudu/lib/mac/mac_dl/rar_pdu_assembler.cpp`

Interpretation gate: a single no-SIB1 run is scatter; require two consecutive
no-SIB1 runs under this final trace architecture before blaming the
instrumentation. A valid run should join:

- gNB transmitted RAPID/UL grant from `PAVONIS_GNB_RAR_PDU_TRACE`
- UE sent preamble from `PRACH-TX`/RA timing
- UE RA-PDSCH/TB/`ra_response_*` state from the late-armed buffered trace
