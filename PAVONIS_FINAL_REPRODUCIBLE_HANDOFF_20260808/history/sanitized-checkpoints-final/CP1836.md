## Result

CP1836 is a mechanically clean RF run but void for the ladder criterion. It
does not answer whether the CP1835 non-PRACH shift fixes real Msg3 CRC,
because the UE never decoded SIB1/RACH config, never sent Msg1, and never
decoded/accepted a RAR.

Do not [interface-redacted] PRACH, RAR, or non-PRACH shift from this datapoint. The correct
next action is to keep the CP1836 shape unchanged and retry once for a valid
SIB1/Msg1/RAR/Msg3 supply. If a second consecutive run voids at the same
SI-control stage, then treat the current all-timed downlink health
(`~125k` TX timeouts plus `~3.4k` downlink-late warnings) as the leading
blocker before drawing conclusions about UL offset semantics.
