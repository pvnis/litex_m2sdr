# CHECKPOINT 1852 - No-RF UL-symbol manifest buffered flush-at-exit patch

Date: [date-redacted]

## Purpose

After CP1851 restored SIB1/Msg1 supply but repeated CP1840's true
PRACH-detection void, stop same-shape RF retries and remove the main IO delta
from the trace-enabled shape: the 260k-row UL-symbol manifest stream that was
opening, appending, and closing `/tmp/pavonis_ul_symbol_manifest.tsv` for every
symbol.

## Source Change

Updated:

```text
ocudu/lib/phy/lower/processors/uplink/uplink_processor_impl.cpp
```

The `PAVONIS_UL_SYMBOL_DUMP` raw CF32 dump behavior is unchanged. Only the TSV
manifest writer moved off the hot path:

- format each manifest row in memory
- buffer rows in a process-local vector protected by a mutex
- register one `std::atexit()` flush
- sort rows by manifest index before writing
- write `/tmp/pavonis_ul_symbol_manifest.tsv` once with the same header and row
  format
- log a single `PAVONIS_UL_SYMBOL_DUMP buffered manifest flushed ... rows=N`
  line at flush

This preserves the existing artifact shape while avoiding per-symbol file IO.
