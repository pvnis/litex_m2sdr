# CHECKPOINT 1856 - No-RF typed-row UL-symbol manifest buffer

Date: [date-redacted]

## Purpose

After CP1854 and CP1855 both proved the CP1852 buffered manifest flush works
but repeatedly voided before SIB1/Msg1, audit the remaining instrumentation
overhead. The CP1852 implementation removed per-symbol file IO but still
allocated one `std::string` per manifest row on the lower-PHY hot path. CP1856
removes that heap-allocation path.

## Source Change

Updated:

```text
ocudu/lib/phy/lower/processors/uplink/uplink_processor_impl.cpp
```

The manifest buffer now stores typed fixed-size rows:

- no per-row `std::string`
- no per-row formatting on the hot path
- one pre-reserved `std::vector<pavonis_ul_symbol_manifest_row>`
- one process-level `arm_file` copy
- bounded `raw_path` storage in the row
- format TSV lines only during the `std::atexit()` flush

The artifact format remains unchanged: same path, header, columns, and bounded
row count. Raw CF32 symbol dumps remain unchanged.
