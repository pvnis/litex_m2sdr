aggregate late counts are not the discriminator.

## Conclusion

CP1863 rules out these causes for the CP1860 versus CP1861/CP1862 split:

```text
different PRACH detector config
different UE PRACH root/preamble/frequency offset
missing PRACH collection window
weak raw predemod amplitude
different PRACH collection delay/extra/compensation geometry
aggregate downlink-late count
```

The remaining failure is correlation/coherence on energized windows. Because
`PRACH_PREDEMOD_RAW_MAX=0` for these runs, the saved artifacts do not include
raw per-window CF32 needed to replay the exact strong windows offline through
phase/CFO/frequency-bin experiments.

Next work should either stay source-level and inspect the PRACH sample
preparation/correlation path for nondeterministic phase/frequency/coherence
inputs, or run a tightly bounded event-triggered raw-window capture that saves
only the strong PRACH windows needed for offline replay. Do not reintroduce
lower-PHY per-sample hot-path instrumentation, and do not run another unchanged
metadata-only RF retry.
