# CHECKPOINT 1867 - No-RF PRACH segment trace runner plumbing

Date: [date-redacted]

## Purpose

Before spending an RF run on the CP1866-ready PRACH collection segment trace,
verify and fix the wrapper path so the new trace is actually enabled, logged,
packaged, fetched, and summarized.

This checkpoint is no-RF and does not touch the NUC binaries.

## Finding

The CP1807 top-level wrapper and [host-redacted] detached gNB starter already propagated
`PAVONIS_UL_SYMBOL_METADATA_ONLY`, PRACH predemod dumps, and the PRACH arm file,
but they did not yet propagate:

```text
PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE
PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_ARM_FILE
PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_MAX
```

The [host-redacted] package helper also did not include:

```text
/tmp/pavonis_prach_collection_segments.tsv
```

Without this checkpoint, the next RF run could have generated no segment trace
or left the TSV behind on [host-redacted].

## Changes

Updated top-level wrapper:

```text
cp1807_run_stage6_raresp40_realue_rar_msg3.sh
```

It now:

- defines default trace settings: trace off, arm file defaults to the PRACH arm
  file, max rows default to `4096`
- includes those settings in `remote_env_prefix()`
- logs them in the sequence log and final manifest
- exports them in the [host-redacted] start command
- includes the new binary marker in the [host-redacted] preflight string check
- includes `PAVONIS_PRACH_COLLECTION_SEGMENT` in the remote env echo grep
- records `prach_collection_segments` and `prach_collection_segment_rows` in the
  summary JSON

Updated [host-redacted] detached starter:

```text
cp1807_run_gnb_b3_txatt5_nativecontinuous_alltimed_lead30ms_raresp40_stage6_prachtrace_detached.sh
```

It now:

- removes stale `/tmp/pavonis_prach_collection_segments.tsv` before each run
- exports the three segment-trace envs into the actual gNB process environment
- echoes the active settings in the detached harness log

Updated [host-redacted] package helper:

```text
cp30_nuc4_package_stage6_ueprachtxdbg_remote.sh
```

It now packages `/tmp/pavonis_prach_collection_segments.tsv` when present.

## Decision

The next checkpoint can spend one bounded RF run. Use the CP1860-shape settings
with:

```text
PAVONIS_UL_SYMBOL_METADATA_ONLY=1
PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE=1
PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_MAX=4096
```

Keep `PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_ARM_FILE` at its default so it
shares the proven PRACH arm file. Judge accepted/rejected strong bursts first
on segment count, `timestamp_delta`, symbol/slot crossing, and append
continuity. If the TSV is absent despite Msg1 supply, treat that as wrapper or
arm-file plumbing failure, not an RF datapoint.
