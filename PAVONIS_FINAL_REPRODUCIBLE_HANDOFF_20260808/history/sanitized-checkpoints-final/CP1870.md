# CHECKPOINT 1870 - No-RF PRACH Segment Trace Late-Arm Plumbing

Date: [date-redacted]

## Purpose

CP1868 proved that `PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE` and the artifact
fetch path work, but the default pre-UE arm consumed the `4096` row cap on idle
PRACH windows before any real Msg1 supply. CP1869 then rejected a simple
same-day shared coherence decay as the explanation. CP1870 keeps RF off and
changes the runner shape so the next discriminator can arm the segment trace
only after the UE reaches `PAVONIS_SRSUE_SIB1_TRACE event=phy_set_config_ok`.

## Conclusion

CP1870 is a no-RF plumbing checkpoint. The next RF discriminator should use:

- `PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE=1`
- `PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_ARM_MODE=after_sib1`
- `PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_MAX=4096`
- `PAVONIS_UL_SYMBOL_METADATA_ONLY=1`
- `PAVONIS_PUXCH_ORDER_TRACE=1`
- `PAVONIS_NON_PRACH_UL_RX_TIMESTAMP_OFFSET_SAMPLES=-352536`
- `PRACH_PREDEMOD_RAW_MAX=0`

If SIB1/`phy_set_config_ok` does not happen, the segment trace should remain
pending and the RF run is void for PRACH continuity. If Msg1/RAR/Msg3 supply
returns, the restored non-PRACH UL shift makes Msg3 judgement meaningful.
