## Invalidating Bug

`prearm_nuc4` returned `rc=2`. The small prearm log shows why:

```text
ls: cannot access '/tmp/pavonis_prach_stage6_cp1733_currentbinary_cp1658cadence_[date-redacted]CP1873_METADATAONLY_SUPPLY_CONTROL_RF_arm': No such file or directory
```

CP1870 introduced a segment-trace arm file variable. When segment trace is
disabled, the default `PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_ARM_FILE` aliases
the main `$ARM`. The top-level prearm command touched `$ARM`, then removed
`$PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_ARM_FILE` in the disabled-trace branch,
which deleted the main PRACH arm before the final `ls -l "$ARM"`.

Therefore CP1873 is not a valid clean supply control for CP1872. The no-SIB1
result is real, but the intended prearm state was not preserved.
