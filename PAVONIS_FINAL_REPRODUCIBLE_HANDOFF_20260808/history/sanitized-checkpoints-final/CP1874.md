# CHECKPOINT 1874 - No-RF Prearm Arm-Alias Fix

Date: [date-redacted]

## Purpose

Fix the CP1873 wrapper bug before rerunning the segment-trace-disabled supply
control. CP1873 showed that when segment trace was disabled,
`PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_ARM_FILE` defaulted to the main PRACH
`$ARM`, and the top-level prearm command removed it.

## Change

Updated `cp1807_run_stage6_raresp40_realue_rar_msg3.sh` prearm logic.

Before:

- Always touched `$ARM`.
- If segment tracing was not enabled in `pre_ue` mode, removed
  `$PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_ARM_FILE`.
- When that file equaled `$ARM`, the main PRACH arm was deleted.

After:

- Still touches `$ARM`.
- Still touches the segment arm for enabled `pre_ue` segment tracing.
- In the disabled or late-arm branch, removes the segment arm only when
  `PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE_ARM_FILE != ARM`.
- This matches the detached [host-redacted] starter's existing stale-arm cleanup guard.
