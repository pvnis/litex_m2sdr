## Interpretation

`PAVONIS_GNB_POWER_CONTROL_OFFSET_SS_DB` maps to the FAPI
`power_control_offset_ss` enum. That enum only supports `-3`, `0`, `3`, and
`6` dB. The intended effective +8 dB supply control cannot be represented by
that SS enum directly.

The existing PDSCH power path sums two fields:

- `power_control_offset_ss`: enum, allowed `-3/0/3/6`
- `power_control_offset_profile_nr`: signed dB offset, documented range
  `{-8,...,15}`

Therefore the least invasive no-RF solution is not to invent enum value `8`.
Instead, keep `PAVONIS_GNB_POWER_CONTROL_OFFSET_SS_DB=6` and add a default-off
Pavonis override for the separate CSI/PDSCH profile offset, then run the RF
control as effective `+8 dB = +6 dB SS + +2 dB profile offset`.
