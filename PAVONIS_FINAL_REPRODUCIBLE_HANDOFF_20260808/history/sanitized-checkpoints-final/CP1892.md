## Boot-persistent unit

Installed and enabled on both hosts:

```text
/usr/local/sbin/pavonis-realtime-[interface-redacted]
/etc/systemd/system/pavonis-realtime-[interface-redacted]
```

The unit is oneshot, enabled for `multi-user.target`, and runs:

```text
/usr/local/sbin/pavonis-realtime-[interface-redacted] apply
```

The script applies and verifies CPU governor/EPP performance state, sets
`powerprofilesctl performance` when available, sets Intel pstate performance
knobs when present, and keeps the M2SDR PCI function power-control state `on`
when the Xilinx `10ee:7021` device exists.
