## Interpretation

CP1893 does not answer the Msg3/PUSCH ordering or sample-domain stability
question. It is a supply void below SIB1/Msg1, despite clean host-state gates
and PBCH success. Since the late-armed append/segment traces never armed, this
run is not evidence that the measurement path perturbs Msg3 or PRACH.

Next action: one unchanged retry of the CP1893 shape. If a second consecutive
run again dies below SIB1/Msg1, pause RF and compare CP1891 versus CP1893/1894
on SFN/SIB1-era downlink health and the late-arm instrumentation pre-SIB1
control path before changing uplink timing.
