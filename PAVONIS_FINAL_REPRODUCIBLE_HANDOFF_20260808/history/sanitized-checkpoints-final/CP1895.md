# CP1895 No-RF Observer Rule, USB Power Gate, and Rule-Compliant Capture Plumbing

Date: [date-redacted]

## Purpose

Codify the CP1894 lesson before any more RF: full-rate M2SDR RX append is an
observer-effect diagnostic and makes PRACH/RAR/Msg3 detector conclusions void.
Replace the CP1893/CP1894 full append measurement path with bounded,
late-armed UL-symbol capture for Msg3/PUSCH sample-domain work; keep segment
trace capability-gated; and extend host-state readback with [host-redacted] bladeRF
USB power-management state.

## Changes

- `AGENTS.md` now states that `PAVONIS_SOAPY_RX_APPEND_ENABLE=1` makes a run
  detection-void unless the checkpoint explicitly tests instrumentation
  overhead.
- The CP1807-family RF runner now aborts before RF if full append is enabled
  without `PAVONIS_ALLOW_DETECTION_VOID=1`.
- The runner now rejects non-metadata UL-symbol sample scans unless they are
  late-armed after RAR/Msg3, or explicitly marked detection-void.
- The detached gNB launcher now defaults UL-symbol instrumentation to
  metadata-only with raw capture disabled. Bounded raw capture requires
  explicit `PAVONIS_UL_SYMBOL_RAW_MAX` plus a late arm file.
- Added a late RAR/Msg3 arm path for bounded UL-symbol capture.
- Added pre-RF binary capability gates for UL-symbol dump and PRACH segment
  trace so CP1894's "env exported but binary cannot consume it" failure cannot
  silently recur.
- Extended the realtime [interface-redacted] script with bladeRF USB power-management
  readback and apply support for `2cf0:5250` devices.

- gNB hash:
  `06b7f243c8a94244caa886ebaa39b4e7532af8bd2dc480b679bbb125ff946c99`

- `pavonis_ul_symbol_manifest.tsv`: present
- `PAVONIS_PUXCH_ORDER_TRACE`: present
- `PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE`: absent
- `pavonis_prach_collection_segments.tsv`: absent

Therefore the segment-trace arm-to-TSV path is fixed at the harness level by
preflight capability gating, but it must remain disabled on this binary. Do not
enable `PAVONIS_PRACH_COLLECTION_SEGMENT_TRACE=1` until a segment-trace-capable
gNB binary is deliberately deployed and gated.
