# CP1897 No-RF gNB-Side Late UL Raw Arm Patch

Date: [date-redacted]

## Purpose

Fix the CP1896 bounded raw-capture arm failure without RF. CP1896 proved the
UE-side RAR/Msg3 trigger is not live-visible because the UE RAR trace is
memory-buffered and flushed at exit. The arm trigger must therefore come from a
[host-redacted]-local live gNB marker.

## Change

The CP1807-family RF runner now supports three additional UL-symbol dump arm
modes:

- `after_gnb_prach`
- `after_gnb_rar`
- `after_gnb_pusch`

When one of these modes is active, the runner starts a [host-redacted]-local wait process
after UE start. That process watches `/tmp/gnb_m2sdr_band3_ota.log` with
binary-safe `grep -a`, then touches `PAVONIS_UL_SYMBOL_DUMP_ARM_FILE` on [host-redacted]
as soon as the selected gNB marker appears.

For the next run, use `after_gnb_prach`: the trigger is `prach(ra-rnti=...)`,
which occurs after accepted PRACH and before the first Msg3 PUSCH decode, so it
does not perturb Msg1 detection and should arm early enough for the first Msg3
symbol windows.
