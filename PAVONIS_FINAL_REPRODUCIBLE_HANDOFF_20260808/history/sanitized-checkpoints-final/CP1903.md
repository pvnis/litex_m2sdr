# CP1903 No-RF In-Process UL-Symbol Arm Build

Date: [date-redacted]

## Purpose

Replace gNB-side log polling entirely with an in-process arm. The gNB now
touches `PAVONIS_UL_SYMBOL_DUMP_ARM_FILE` itself on a once-per-run event,
without a separate process scanning `/tmp/gnb_m2sdr_band3_ota.log`.

## Source Change

Added default-off in-process arm support:

- `PAVONIS_GNB_INPROCESS_UL_SYMBOL_ARM=1` enables the feature.
- `PAVONIS_GNB_INPROCESS_UL_SYMBOL_ARM_EVENT` selects `accepted_prach`,
  `rar_pdu`, or `both`.
- `prach_detector_generic_impl.cpp` touches the arm file once on first accepted
  PRACH when the selected event allows `accepted_prach`.
- `rar_pdu_assembler.cpp` touches the arm file once on first RAR PDU encode
  when the selected event allows `rar_pdu`.
- The CP1807 runner exports/logs/manifests those envs and skips the external
  gNB watcher whenever in-process arming is enabled.

For the next RF run, use `PAVONIS_GNB_INPROCESS_UL_SYMBOL_ARM_EVENT=rar_pdu` so
the bounded raw capture starts near post-RAR Msg3 instead of consuming raw
budget immediately after PRACH.
