## Source Changes

`ocudu/lib/phy/lower/processors/uplink/prach/prach_processor_worker.cpp`

- Added default-off `PAVONIS_PRACH_STRONG_PREDEMOD_CAPTURE`.
- Added bounded capture envs:
  - `PAVONIS_PRACH_STRONG_PREDEMOD_RAW_MAX`, default `16`
  - `PAVONIS_PRACH_STRONG_PREDEMOD_RMS_DB_FLOOR`, default `-70`
  - `PAVONIS_PRACH_STRONG_PREDEMOD_PEAK_DB_FLOOR`, default `-55`
  - `PAVONIS_PRACH_STRONG_PREDEMOD_ARM_FILE`, falling back to `PAVONIS_PRACH_DUMP_ARM_FILE`
- The capture computes RMS/peak at the PRACH predemod CF32 point and stores only matching windows in memory.
- At process exit it writes:
  - `/tmp/pavonis_prach_strong_predemod_manifest.tsv`
  - `/tmp/pavonis_prach_strong_predemod_%06u_p%u.cf32`
- The manifest includes timing, PRACH config, collection-delay/timing-compensation metadata, raw RMS/peak in linear and dB forms, and raw file paths.
