## Boundary Audit

The source boundary matters:

- Lower PHY owns the raw CF32 samples and the OFDM PRACH demodulator.
- Upper PHY owns the PRACH detector and receives only a pool-owned
  demodulated `shared_prach_buffer`.
- `shared_prach_buffer` is a reference-counted pointer that must come from the
  existing upper PRACH buffer pool; it cannot be safely wrapped around an ad hoc
  scratch buffer.
- `ocudu_lower_phy_prach_processor` currently links only lower modulation and
  instrumentation. Pulling `ocudu_prach_detector` into this library would cross
  the current lower/upper layering.

Therefore a true live bounded multi-candidate search cannot be safely
implemented as a simple lower-only loop that demodulates many CFO candidates and
notifies upper once per candidate. The next source step needs an
interface-aware design: either move a detector-capable bounded policy to a
shared/lower-safe component, or extend the lower-to-upper PRACH handoff so the
upper detector can request or evaluate transformed pre-demod candidates without
abusing buffer ownership.

## Frontier

Stay no-RF. The lower-PHY raw-CF32 transform insertion point is now
build-smoked and default-off. Do not use it as a static live CFO knob. The next
checkpoint should design and implement the smallest default-off multi-candidate
bounded-search path that preserves ownership/layering and emits strict trace
rows, then build-smoke it before any RF.
