## Purpose

CP1914 proved the correct raw-CF32 insertion point before OFDM PRACH
demodulation. CP1915 adds the smallest default-off multi-candidate source
prototype: scan a bounded CFO range, demodulate candidates into a scratch PRACH
buffer, run the PRACH detector with preamble 0 only, and if any p0 candidate is
accepted, demodulate the selected CFO into the normal pool-owned buffer before
the existing upper path sees it.

This is a diagnostic prototype, not a sanctioned RF setting. It preserves the
single normal lower-to-upper buffer notification, but it does add an explicit
lower PRACH dependency on the PRACH detector and DFT library.

## Behavior

When `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH` is unset, the live path is unchanged.

When enabled on the current format-zero/single-occasion path and `nof_ports==1`:

1. Build a scratch long-format PRACH buffer.
2. Build a local PRACH detector using the existing detector factory.
3. For each bounded CFO candidate, rotate the raw CF32 input, demodulate into
   the scratch buffer, and run p0-only detection:
   - `start_preamble_index=0`
   - `nof_preamble_indices=1`
   - `ra_scs=to_ra_subcarrier_spacing(prach_context.pusch_scs)`
4. Select the accepted candidate with the best p0 detection metric.
5. Apply only the selected CFO to the normal demod input and continue through
   the existing upper PRACH result path.
6. If no candidate accepts, fall back to the normal path unless the older
   explicit single-CFO env is also set.

The prototype intentionally does not search non-p0 preambles. That matches the
CP1913 false-positive gate where all accepted CP1909 variants were preamble 0
and the non-p0 control produced zero accepts.

## Limits

- Not RF-tested.
- Not deployed to [host-redacted].
- Only active when explicitly enabled.
- Currently limited to the single-RX-port path.
- It adds lower PRACH links to `ocudu_dft` and `ocudu_prach_detector`; this is
  acceptable for a diagnostic prototype but should be revisited before turning
  the approach into a permanent architecture.
