## Conclusion

CP1918 is a void RF checkpoint below Msg1. It validates that the CP1917 binary,
wrapper env plumbing, package path, and CFO-search trace file work in a live
run, but it provides no live detector result because the UE never reached SFN,
SIB1, or PRACH transmission.

Next: do not [interface-redacted] any RF, delay, or CFO constant from CP1918. Either retry the
same shape once for Msg1 supply, or first make the CFO-search trace/selection
late-armed or RSSI-gated so idle PRACH windows cannot consume the trace cap or
add avoidable pre-UE PRACH detector work. A valid next datapoint must have UE
Msg1 supply before judging the p0-only CFO search.
