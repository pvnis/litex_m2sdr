## Interpretation

`GNB_FIXED_SIB1_MCS=0` is not a usable SIB1 supply fixture in this current
shape. It did not expose a robust low-MCS SIB1 path; instead, the run fell back
to the weaker no-direct-SI-control class seen in CP1921/CP1923.

This leaves two plausible explanations:

- run-to-run SI coherence is still moving enough that a single config run can
  land in a no-direct-SI-control state;
- the fixed-MCS config path changes the SI scheduling/DCI/PDSCH relationship in
  a way that is not directly comparable to the CP1926 repeated-grant/no-TB
  failure.

In either case, CP1928 does not justify further PRACH/CFO RF work. SIB1 supply
is still the blocker.
