## Source coverage against CP1934

The CP1915/CP1919 implementation is CFO-only:

- Enabled by `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH`.
- Default CFO grid: `-25000..+25000 Hz`, step `250 Hz`.
- Default cap: `201` candidates.
- p0-only detector config:
  - `start_preamble_index=0`
  - `nof_preamble_indices=1`
- Energy gate envs from CP1919:
  - `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH_RMS_DB_FLOOR`
  - `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH_PEAK_DB_FLOOR`
- No integer/fractional timing-search loop exists.
- The older `PAVONIS_PRACH_DEMOD_INPUT_OFFSET_SAMPLES` is a single positive
  static input-origin shift, not a candidate search and not a per-window fix.

Against CP1934:

| CFO-only accepted idx4 at `-14000 Hz` | yes | In default `-25..+25 kHz` grid. |

## Decision

The existing CP1915/CP1919 source is sufficient for a narrow CFO-only diagnostic
but not a complete fix:

- It should recover CP1933-like late windows 4 and 5 if SIB1/Msg1 supply is
  present.
- It will not recover CP1933 window 3, which needs timing-shift search in the
  offline replay.
- It will not recover windows 0-2 under the current offline grid.
- A timing-shift live search should not be added yet: the CP1934 accepted timing
  grid is much larger than the CFO-only grid and would add substantial hot-path
  work unless narrowed by another no-RF analysis.

The next implementation should be the minimal diagnostic, not a broad new
policy:

1. Re-apply the CP1915/CP1919 CFO-only, p0-only, energy-gated search onto the
   current CP1925 restored source class, not by wholesale redeploying the old
   CP1920 binary/source.
2. Keep it default-off.
3. For the first RF trial, enable only:
   - `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH=1`
   - `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH_MIN_HZ=-25000`
   - `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH_MAX_HZ=25000`
   - `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH_STEP_HZ=250`
   - `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH_MAX_CANDIDATES=201`
   - `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH_RMS_DB_FLOOR=-70`
   - `PAVONIS_PRACH_DEMOD_INPUT_CFO_SEARCH_PEAK_DB_FLOOR=-55`
   - trace off or capped very low, to avoid repeating observer effects.
4. Judge the first RF run on SIB1/Msg1 supply first, then whether at least the
   late-window p0 accepts appear. A zero-SIB1 run is void for detector policy.

No timing-search source work should be added until the CFO-only diagnostic is
tested on the restored SIB1-stable source class.
