## Interpretation

CP1937 does not look like an obvious host, TX, USB, or PRACH-loop load
regression:

- host realtime state matches CP1933;
- native/all-timed TX readback matches CP1933;
- Soapy timeout and downlink-late counts remain in the same class;
- idle PRACH processing mean is slightly lower than CP1933, with one isolated
  outlier;
- EPRE is normal, but SI correlation never reaches the CP1933 direct-grant
  class.

The decisive difference is earlier than PRACH: CP1937 never gets SI-PDCCH
direct `n_dl=1`, SI-PDSCH grant/decode, RACH config, or UE Msg1. Therefore it
is still a no-SIB1/no-Msg1 supply void, not a detector-policy datapoint.
