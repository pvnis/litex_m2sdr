## Interpretation

CP1946 repeats the CP1943 no-SIB1/no-Msg1 class after CP1945 proved the same
hardware path can deliver a strong no-srsUE bladeRF raw DL capture:

- CP1945 no-srsUE raw DL: PBCH CRC `OK`, CSI SNR `+15.9 dB`, `51/847` PBCH OK windows.
- CP1946 live srsUE: PBCH/SFN/cell select succeed, but SI-PDCCH never crosses direct-grant class; max corr is only `0.457880`, SIB1 decode is zero, and no Msg1 is emitted.

This keeps PRACH collection blocked and moves the active downlink blocker away
from broad gNB TX/path/bladeRF-RX absence. The remaining suspect is the live
srsUE receive/SI decode/control path or a UE-orchestration effect that is not
present in independent raw capture.

Do not use CP1946 as a PRACH detector datapoint. It is a valid live-UE
downlink-supply failure after a valid raw-DL path pass.
