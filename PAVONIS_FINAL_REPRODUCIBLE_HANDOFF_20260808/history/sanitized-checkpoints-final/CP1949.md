## Interpretation

CP1949 proves the restored shape can still provide live SIB1/RACH/Msg1 supply:
the no-SIB1 CP1943/CP1946 class was not permanent.

It is not a valid candidate-trace datapoint. `result.env` and a full artifact
search showed no `PAVONIS_SRSUE_SI_CANDIDATE_TRACE` lines because the [host-redacted]
start helper had an explicit env allowlist and did not forward the new vars
into `srsue`.

The useful frontier result is RAR non-consumption: the UE sends Msg1, the gNB
accepts one preamble and encodes a RAPID-matching RAR, but the UE never logs
`Setting RAR Grant`, `Set TA RAR`, or Msg3. CP1949 did not enable
`PAVONIS_SRSUE_RAR_WINDOW_TRACE`, so its zero `rar_opportunity`,
RA-PDCCH, and RA-PDSCH counts only mean that high-volume RAR-window visibility
was not instrumented.
