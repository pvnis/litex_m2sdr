## Interpretation

CP1955 is a no-RF deployment checkpoint only. It does not test SIB1 supply,
Msg1 detection, RAR visibility, or detector policy. It establishes that [host-redacted] is
again running the CP1936 minimal CFO-search-capable `gnb` binary, with the
search path default-off unless explicitly enabled.

The next RF diagnostic may enable only this existing p0-only, energy-gated
CFO-search path:
