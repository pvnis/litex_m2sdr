## Interpretation

CP1959 rejects CFO-search enablement alone as the immediate cause of the
current no-SIB1 state. With CFO search disabled on the active CP1936 binary,
SIB1/Msg1 still do not return.

This run also changes class versus CP1956/CP1957: CP1959's SI EPRE falls to the
`~23.7 dB` class, matching CP1939/CP1940, whereas CP1956/CP1957 had normal EPRE
around `33 dB` but low SI correlation. The common fact is that the active
CP1936 binary class is not currently yielding SIB1, whether CFO search is on or
off.

Next split: restore the known no-search source/binary class again no-RF, then
run one restored no-search supply control with the same RF shape. If restored
no-search still fails, current downlink/path state is the blocker; if it passes,
the CP1936 binary/source class is the blocker and detector RF must stay parked.
