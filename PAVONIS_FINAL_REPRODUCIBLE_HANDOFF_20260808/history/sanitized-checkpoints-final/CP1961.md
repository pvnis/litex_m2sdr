## Interpretation

CP1961 is decisive for the SIB1-supply split. The same RF shape that failed on
the active CP1936 binary with CFO search off in CP1959 recovers SIB1, seven UE
Msg1 transmissions, and seven RAR windows after CP1960 restores the no-search
`30f0...` binary. Therefore the CP1936 binary/source class is the leading cause
of the current SIB1 supply collapse; CFO-search enablement itself is not
required, because CP1959 had it off and still failed.

The run does not solve PRACH detection. It returns us to the detector-input
frontier with a fresh rejected strong-window set: six CP1961 strong predemod
windows, zero gNB nonempty/accepted PRACH rows, and no RAR PDU. Next work should
stay no-RF and replay CP1961's strong windows through the CP1912/CP1954
live-compatible detector harness before any further RF.
