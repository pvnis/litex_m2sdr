## Conclusion

CP1967 is a valid mechanical RF checkpoint and a valid stage-1 trace packaging
check, but it is a PRACH-detector void. The UE did not decode SIB1 and emitted
no Msg1, so the stage-1 policy was not tested on real PRACH supply.

This single no-SIB1/no-Msg1 run should be treated as scatter unless repeated.
The next RF step is one unchanged CP1967-shape retry. If the retry also voids
before SIB1/Msg1, stop detector RF and split stage-1-enabled supply/load from
current downlink supply before blaming PRACH detector behavior.
