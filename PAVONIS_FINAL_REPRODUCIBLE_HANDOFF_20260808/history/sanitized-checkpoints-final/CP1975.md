# CHECKPOINT 1975 - No-RF FPGA Clock-Source Readback Probe

Date: [date-redacted]

## Purpose

Split the CP1973/CP1974 reference-clock branch one step further without RF:
prove whether the LiteX-M2SDR Soapy `clock_source=fpga` path can be selected,
read back, and then restored to internal-XO mode before spending a live RF run.

No gNB RF run, RX append, bladeRF capture, DMA test, `m2sdr_rf`, flash, or
streaming sample path was started. This checkpoint did open the LiteX-M2SDR
Soapy device with `SoapySDRUtil --probe`, which initializes the SI5351/AD9361
control path but does not create a TX/RX stream.

## Readback Results

Baseline internal-XO state:

- `Configured Mode  : SI5351B / internal XO`
- `LOL_B=Locked`
- `LOL_A=Locked`
- `LOS=Loss of Signal`
- `PLL Input Source : 0x00`
- `PLLB_SRC=XTAL`
- `PLLA_SRC=XTAL`

FPGA clock-source probe:

- Soapy printed `clock_source: fpga`.
- `SOAPY_FPGA_RC=0`.
- Post-probe readback changed to:
  - `Configured Mode  : SI5351C / 10MHz from FPGA`
  - `LOL_B=Locked`
  - `LOL_A=Locked`
  - `LOS=Valid Signal`
  - `PLL Input Source : 0x08`
  - `PLLB_SRC=CLKIN`
  - `PLLA_SRC=XTAL`

Internal restore:

- Soapy printed `clock_source: internal`.
- `SOAPY_INTERNAL_RC=0`.
- Final readback returned to:
  - `Configured Mode  : SI5351B / internal XO`
  - `LOL_B=Locked`
  - `LOL_A=Locked`
  - `LOS=Loss of Signal`
  - `PLL Input Source : 0x00`
  - `PLLB_SRC=XTAL`
  - `PLLA_SRC=XTAL`

## Conclusion

CP1975 proves the `clock_source=fpga` control/readback path is real and
reversible on [host-redacted]. Selecting it moves the SI5351 from internal-XO mode to
`SI5351C / 10MHz from FPGA`, clears LOS to `Valid Signal`, and sources PLLB
from `CLKIN`; selecting `internal` restores the original internal-XO readback.

This still does not prove RF coherence or SIB1 recovery. It only clears the
control-path gate needed before the next RF run.
