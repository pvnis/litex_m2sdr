Date: [date-redacted]

## Purpose

Spend the single RF run unlocked by CP1975: repeat the frozen CP1972
supply-control shape, changing only the M2SDR clock source to
`PAVONIS_M2SDR_CLOCK_SOURCE=fpga`.

This was intended to test whether the FPGA-derived SI5351C `10 MHz` input path
improves the current downlink coherence/SIB1 supply regression without changing
detector, delay, RX append, TX power, or binary/source policy.

## Conclusion

`clock_source=fpga` is a real, controllable, reversible clock path, but it is
not a recovery path for the current OTA ladder. Under the frozen CP1972 RF
shape it makes acquisition worse: the UE sees a much larger downlink CFO
(`-31.6 kHz` versus CP1972's `-3.7 kHz`) and fails SFN before any SI-PDCCH/SIB1
measurement can occur.

Do not rerun the CP1976 `fpga` RF shape unchanged, and do not treat it as a
sanctioned temporary working config. The reference-clock branch now splits to:

- external-reference path: only after a real external `10 MHz` reference is
  physically confirmed, then run the same controlled no-RF readback plus one
  frozen supply RF sanity;
- internal-XO/dynamic path: characterize and compensate the observed
  time-varying CFO/coherence drift without using the FPGA clock-source path.

Detector/delay/Msg3 RF remains frozen until SIB1/RACH/Msg1 supply returns.
