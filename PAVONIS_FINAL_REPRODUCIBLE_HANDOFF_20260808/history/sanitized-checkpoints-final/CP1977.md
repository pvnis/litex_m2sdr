# CHECKPOINT 1977 - No-RF Internal-XO Drift and Coherence Join

Date: [date-redacted]

## Purpose

After CP1976 closed `clock_source=fpga` as worse than internal-XO, continue the
non-hardware branch by joining existing same-day summaries and UE logs to test
whether the current SIB1/SI supply failures are explained by a simple static
downlink CFO offset, or whether additional dynamic/coherence instrumentation is
needed before more RF.

No RF was started. No source was rebuilt. No raw logs were bulk-read. The join
used the compact summary JSONs and the exact `srsue.stdout.log` paths referenced
by those summaries.

## Inputs

Input set:

- `19` summary JSON files matching same-day CP1933 through CP1976 Stage 6
  real-UE runs.
- `19` corresponding UE stdout logs referenced by those summaries.

Combined input manifest hash:

`724493276f1ea1b22d4157d4af65f8ee8a0eaed550e65f6e68a72c92ba5b48f8`

The join extracted:

- UE cell-search `snr`, `cfo`, `rsrp`, `epre`, PBCH CRC, and SFN result.
- UE SIB1/SI-PDCCH summary counts.
- Per-SI-summary `max_corr`, `max_epre`, and `n_dl_max` when present.
- SIB1/Msg1/RAR supply counts.
- gNB Soapy TX timeout and downlink-late counts.

- count: `18` internal/default-clock runs

- mean: `-3676.4405 Hz`
- population stdev: `39.5084 Hz`

- CP1976 cell-search CFO: `-31590.592 Hz`

## Interpretation

The existing data does not support a static downlink CFO/frequency knob as the
next move:

- Internal-XO initial acquisition CFO is already stable around `-3.68 kHz`.
- SIB1/SI failures occur at the same initial CFO class as SIB1/Msg1 passes.
- SI max-corr is essentially uncorrelated with initial cell-search CFO in this
  dataset.
- The large CP1961 PRACH detector-input recovery CFO ramp
  (`+25 kHz -> +45 kHz` over `5.6 s`, from CP1973) is not visible as UE
  downlink acquisition CFO.

This means the active problem is not proven to be one global static frequency
offset. The stronger interpretation is still coherence/timing drift or
presentation loss inside a narrower signal path and time window:

- SI correlation can collapse while initial PBCH/cell-search CFO remains normal.
- CP1972 had high SI EPRE but sub-decode SI correlation.
- CP1976 proved that selecting FPGA-derived `10 MHz` is not a cure and worsens
  downlink CFO/acquisition.

## Conclusion

CP1977 keeps the reference-clock branch alive but narrows the internal-XO path:
do not spend RF on a static downlink frequency/CFO knob, and do not rerun the
`fpga` RF shape. Existing summaries are insufficient to measure the time-varying
downlink tracking state because the SI-PDCCH summary rows include correlation
and EPRE but not the UE tracking CFO/delay at the same interval.

Next valid work should stay no-RF and add or locate low-impact instrumentation
that records UE downlink tracking CFO/delay or equivalent SSB/SFN tracking state
alongside the existing SI-PDCCH `max_corr/max_epre` summaries. Only after that
instrumentation is available should another RF run be spent to decide whether a
dynamic internal-XO correction is viable. The external-reference branch remains
parked until a real external `10 MHz` reference is physically confirmed.

Detector/delay/Msg3 RF remains frozen until SIB1/RACH/Msg1 supply returns.
