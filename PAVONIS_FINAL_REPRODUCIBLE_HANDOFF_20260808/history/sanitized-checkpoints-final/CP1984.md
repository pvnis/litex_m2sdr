## Findings

1. The CP1979 low-EPRE class is not monotonic same-day lab drift.

   High/phase-locked SI appears before and after low runs. CP1946 at 09:25 is
   restored-no-search and high/phase-locked. CP1979 at 09:45 is low/scattered.
   CP1949/CP1950/CP1953 later pass SIB1/Msg1. CP1951 at 10:40 is again low.

2. CP1978 UE tracking instrumentation is not necessary for the low-EPRE class.

   Several pre-CP1978 runs have the same low class: CP1959, CP1939, CP1940,
   CP1967, CP1968, CP1970, and CP1951. CP1978 can still be an immediate
   observer/timing perturbation for CP1979 versus CP1972, but it is no longer
   the only known path to low SI EPRE.

3. The strongest reusable discriminator is phase lock, not just mean EPRE.

   High SI runs have the EPRE maximum locked to `max_epre_slot % 160 == 1` on
   roughly `792-796/800` rows. Low SI runs have zero rows above
   `max_epre >= 30` and top EPRE slot buckets around `103/113/133/143` instead
   of `1`. CP1979's `113:100` pattern matches the low class.

4. TX timeout and downlink-late counters do not explain the class split.

   TX timeout counts stay in the same `~125k-126k` band across high, low, and
   pass runs. Downlink-late counts are not monotonic with failure: CP1979 is low
   with only `117` downlink-late lines, while high/phase-locked CP1946 has
   `1058`, and passing CP1949/CP1953 have `1166/1099`.

5. SIB1 pass runs often have no aggregate SI summary rows.

   That is expected because SIB1 can be decoded before the 200-sample summary
   window emits. Treat absence of SI summaries in pass runs as "decoded early",
   not as a missing artifact.

## Conclusion

CP1984 changes the active model from "CP1979 might be a one-off CP1978 reporting
or monotonic lab-drift event" to "the system has a recurring SI supply state
machine: high/phase-locked, low/phase-scattered, and early-pass." The
high-versus-low classifier should include:

- `max_epre >= 30` row count,
- `max_corr >= 0.4` row count,
- dominant `max_epre_slot % 160` bucket and count,
- SIB1/Msg1 early-pass status.

The CP1981-prepared pre-CP1978 RF A/B is still the right next RF gate because it
tests the immediate CP1972 -> CP1979 observer split. But the interpretation must
be narrowed:

- If high/phase-locked SI returns, CP1978 tracking instrumentation likely
  perturbed that immediate run shape.
- If low/phase-scattered SI persists, CP1978 is not the main cause.
- If the run early-passes SIB1/Msg1, it belongs to the early-pass class and is a
  valid supply recovery, even with few/no summary rows.
