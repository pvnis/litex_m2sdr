## Matched State

These surfaces do not explain the split:

- Normalized CP1950/CP1951 manifests are identical after replacing run tags.
- Generated gNB YAML hash is identical:
  `d77654ed536057d7d2213ffc2f461fd316691c2eb2357b672677138d209b7322`.
- UE RF config differs only in run-output paths. Radio-relevant fields match:
  `srate=11.52e6`, `freq_offset=6000`, `rx_gain=40`, `tx_gain=60`,
  `bands=3`, `max_nof_prb=52`, `nof_prb=52`.
- TX readback differs only in volatile `hardware_time_ns`; rate/frequency/gain
  and native-continuous/all-timed state match.
- Host realtime gates match: both hosts are in performance governor/EPP,
  [host-redacted] M2SDR PCIe is `5.0_GT/s_PCIe x1`, [host-redacted] bladeRF is present at
  SuperSpeed with power control `on` and runtime `active`.
- Initial cell-search quality is essentially identical.
- TX timeout class remains the usual `~125k-126k` band, and downlink-late is
  lower in the failing CP1951 than in the passing CP1950.

## Substantive Delta

The only substantive non-path result-env delta found was UE-side SI candidate
trace enablement:

| Env | CP1950 | CP1951 |
| --- | --- | --- |
| `PAVONIS_SRSUE_SI_CANDIDATE_TRACE` | `0` | `1` |
| `PAVONIS_SRSUE_SI_CANDIDATE_TRACE_LIMIT` | `200` | `400` |
| `PAVONIS_SRSUE_SI_CANDIDATE_TRACE_MIN_CORR` | `0.40` | `0.35` |

However, CP1951 emitted zero `event=si_pdcch_candidates` rows because its
`max_corr` never reached the `0.35` threshold. So this checkpoint does not prove
that heavy candidate-trace I/O caused the low/scattered class. It only proves
that the low run had the candidate-trace control path enabled, while the
early-pass run did not.

## Conclusion

CP1985 leaves two viable interpretations:

1. CP1951 is another instance of the recurring low/scattered supply state,
   independent of gross gNB/UE RF config and host realtime state.
2. The enabled SI candidate-trace control path may be a low-impact observer
   perturbation even without emitted candidate rows, but CP1951 does not provide
   enough evidence to prove that causal path.

This strengthens the CP1984 class model and weakens simple counter explanations:
same gNB YAML, same UE RF config, same native-continuous/all-timed TX state,
same host gates, and similar initial cell-search can still split into early-pass
versus low/scattered.
