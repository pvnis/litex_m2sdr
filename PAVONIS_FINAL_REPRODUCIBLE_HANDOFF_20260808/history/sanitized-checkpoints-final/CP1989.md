placement during that window is essentially the same across high and low
classes:

| Run | Class | SI duration | Timeout before/during/after SI | Timeout near SI +/-0.5s | Timeout near SI +/-2.5s |

the high/no-SIB1 CP1972 run has many more downlink-late events during SI than
the low/scattered runs.

CP1950 is an early-pass run, so its SI/SIB1 anchor is only about `1 ms` and is
not directly comparable to the 162 s aggregate SI windows. It still does not
show a local storm at SIB1 decode: timeout before/during/after the SI/SIB1
anchor is `29224 / 1 / 97082`, and downlink-late is `200 / 0 / 701`; within
`+/-2.5 s` of the anchor there are only `5` downlink-late lines.

## Conclusion

CP1989 closes the pending storm-placement suspicion for the SI supply split:

1. TX timeout placement is effectively invariant across high/no-SIB1 and
   low/scattered runs during the UE SI window.
2. Downlink-late events are not higher in the low/scattered runs; CP1972 has
   more downlink-late lines than CP1979/CP1951 while retaining high,
   phase-locked SI EPRE.
3. LiteX worker/release late, underflow, acquire errors, and Soapy errors remain
   zero at stop for all four runs.
4. The low/scattered SI state therefore is not explained by gNB-side timeout or
   downlink-late storm placement in the available artifacts.
