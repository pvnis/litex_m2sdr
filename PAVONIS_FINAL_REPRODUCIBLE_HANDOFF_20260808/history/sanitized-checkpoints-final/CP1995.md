# CP1995 RF Pre-CP1978 UE Supply A/B

Date: [date-redacted] Europe/Zurich

## Scope

Run the user-approved bounded RF A/B on the frozen CP1972/CP1979
supply-control shape, using the CP1981-staged pre-CP1978 UE binaries and
`PAVONIS_SRSUE_SI_CANDIDATE_TRACE=0`.

Judgment classes:

- `early-pass`: SIB1/RACH/Msg1 supply returns.
- `high/phase-locked`: no SIB1, but SI EPRE is high and dominated by scheduled
  `slot % 160 == 1`.
- `low/scattered`: no SIB1 and SI EPRE collapses to the CP1979 class.

If and only if this A/B returned low/scattered, the approved next run was a
CP1945-style independent bladeRF DL IQ capture aligned to scheduled SIB1 phase.

No rebuilds, source edits, deploys, or gateware changes were made.

## Classification

CP1995 is `high/phase-locked`, not `low/scattered`.

It matches the CP1972 high/no-SIB1 class more than CP1979:

- Scheduled phase dominates: `max_epre_slot % 160 == 1` on `789/800` rows.
- EPRE remains high: `789/800 max_epre >= 30`, mean `33.382196`.
- Decode still fails: `0` SI grants, `0` SIB1 decode, `0` Msg1.
- Correlation stays sub-decode: max `0.463626`, no rows `>=0.5`.

The CP1981 rollback therefore did not recover early-pass/SIB1, but it did
avoid reproducing CP1979's low/scattered SI-EPRE collapse in this run.

## Conditional Second Run Decision

The user-approved CP1945-style independent bladeRF DL IQ capture was conditional
on the A/B returning low/scattered. CP1995 returned high/phase-locked, so the
condition was not met and no second RF run was started.

This also means CP1995 does not test whether scheduled-phase energy is missing
from the air in the low/scattered state. It instead says the current immediate
frontier is the high/phase-locked no-SIB1 class: scheduled-phase energy is
present in the UE metric, but the SI-RNTI PDCCH still does not decode.

## Interpretation

CP1995 narrows the CP1979 provenance split:

- CP1979's low/scattered class was not reproduced after restoring the
  pre-CP1978 UE binaries and keeping candidate trace off.
- The CP1978 tracking-state instrumentation is therefore not exonerated for the
  specific CP1979 low/scattered regression.
- However, the pre-CP1978 rollback is not sufficient to climb the ladder:
  CP1995 remains no-SIB1/no-Msg1 with the same high/phase-locked signature as
  CP1972.

The next useful work should be no-RF unless new RF is explicitly approved:
compare early-pass runs (for example CP1933/CP1950/CP1953) against high/no-SIB1
runs (CP1972/CP1995) on SI-PDCCH correlation, candidate contents, and any
runtime/health deltas that distinguish `max_corr >= decode` from
high-EPRE/no-decode.
