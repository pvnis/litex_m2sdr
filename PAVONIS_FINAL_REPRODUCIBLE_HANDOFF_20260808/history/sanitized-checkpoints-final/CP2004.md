## `L` And `ncce` Meaning

`srsRAN_4G/lib/include/srsran/phy/phch/pdcch_nr.h`:

- Lines `94-106`: candidate location helper takes `aggregation_level` in
  logarithmic range `0..4` and returns `n_cce` locations.

`srsRAN_4G/lib/src/phy/phch/pdcch_nr.c`:

- Lines `71-74`: actual aggregation level is `1U << aggregation_level`.
- Lines `81-87`: `N_cce = coreset_bw * coreset_duration / 6`.
- Lines `97-103`: common search spaces use `Y_p_n=0`, so candidate locations
  are deterministic from CORESET size, candidate index, and aggregation level.
- Lines `117-130`: `locations[]` is filled by candidate index for the requested
  aggregation level.

`srsRAN_4G/lib/src/phy/ue/ue_dl_nr.c`:

- Lines `390-404`: the UE iterates aggregation index `L=0..4`, then candidate
  index within that aggregation level.
- Lines `405-415`: `ctx.location.L` is the logarithmic aggregation index and
  `ctx.location.ncce` is the CCE start returned by the location helper.

Thus in the candidate trace:

- `candN_L=2` means aggregation level `4`.
- `candN_L=3` means aggregation level `8`.
- `candN_ncce` is the starting CCE for that candidate.
- For current SearchSpace0, the expected trace order is four AL4 entries,
  followed by two AL8 entries, unless a future config changes SearchSpace0.

## Diagnostic Use

For the first approved RF run with the cached candidate trace, compare early-pass
and high/no-SIB1 rows on:

- Which `candN_L/ncce` carries `max_corr`.
- Whether the same candidate identity is near-gate in high/no-SIB1 and decoded
  in early-pass.
- Whether high/no-SIB1 spreads energy/correlation across multiple candidates.
- Whether fixed `cfo_hz` or `sync_error_us` separates the winning candidate
  from the rest.

If the same AL/ncce candidate is best in both early-pass and high/no-SIB1, the
problem is likely waveform/coherence quality at the expected candidate, not
candidate-location ambiguity. If high/no-SIB1 moves the best corr to a different
AL/ncce, then the trace points toward candidate/CCE mapping, timing/resource
alignment, or a competing false-correlation structure.
