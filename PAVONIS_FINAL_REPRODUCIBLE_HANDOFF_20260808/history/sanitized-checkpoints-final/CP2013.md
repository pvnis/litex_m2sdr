# CHECKPOINT [date-redacted] - No-RF Offline SI-PDCCH Parity Audit

Date: [date-redacted] Europe/Zurich

## Scope

No RF, rebuild, deploy, source edit, wrapper edit, gNB, Soapy, M2SDR, bladeRF,
or gateware change was made. This checkpoint is a source/report audit of what
CP2012's offline `ue_dl_nr_file_test` result can and cannot prove relative to
the live srsUE SI-RNTI PDCCH path.

## Question

CP2012 found strong scheduled SI-phase CORESET-like energy in the CP2011
independent bladeRF IQ file, but `ue_dl_nr_file_test` decoded no SI DCI/PDSCH.
The question here is whether that offline negative is equivalent to the live
srsUE SearchSpace0/Common0 SI-RNTI decode path.

## Findings

The live srsUE path uses the RRC/PHY config handed to `cc_worker`:

- `cc_worker::update_cfg()` calls `cfg.get_dci_cfg()` and
  `srsran_ue_dl_nr_set_pdcch_config(&ue_dl, &cfg.pdcch, &dci_cfg)`.
- `cc_worker::decode_pdcch_dl()` then searches the RNTI returned by
  `phy.stack->get_dl_sched_rnti_nr(dl_slot_cfg.idx)`.
- CP1992/CP1993/CP2004 establish that the live SI-RNTI path has six
  SearchSpace0 candidates, CORESET0 duration `2`, start RB `0`, and DCI format
  `1_0`.
- `make_phy_search_space0_cfg()` configures common SearchSpace0 with
  `nof_candidates[0]=0`, `nof_candidates[1]=0`, `nof_candidates[2]=4`,
  `nof_candidates[3]=2`, `nof_candidates[4]=0`, and one format:
  `srsran_dci_format_nr_1_0`.

The file-test path constructs its own PDCCH config instead of consuming the
live `phy_cfg_nr_t`:

- For SI/RA it derives CORESET0 from ARFCNs and `coreset0_idx` via
  `srsran_coreset_zero()`.
- It sets both search-space formats, `0_0` and `1_0`.
- It fills every aggregation level with
  `srsran_pdcch_nr_max_candidates_coreset(coreset, L)`.

In the representative CP2012 strongest snippet
`sfn0688_slot1_start2896453_d-1728.log`, that produced `15` measured
candidates:

```text
AL1/L=0: 8 candidates, strongest ncce=1 corr=0.888 EPRE=33.82 CRC KO
AL2/L=1: 4 candidates, strongest ncce=0 corr=0.674 EPRE=33.19 CRC KO
AL4/L=2: 2 candidates, strongest ncce=0 corr=0.662 EPRE=32.96 CRC KO
AL8/L=3: 1 candidate,  ncce=0 corr=0.241 EPRE=30.20 predecode reject
```

The lower search code also de-duplicates DCI sizes within a search space:
`ue_dl_nr_find_dci_ss()` iterates the configured formats, but skips a format if
the same DCI bit count has already been searched. Since common-search-space DCI
0_0 and 1_0 share the same bit count in this configuration (`37` bits in the
CP2012 log), the file-test does not independently run a clean "format 1_0 only"
live-style pass. That is another parity mismatch, even if the PDCCH CRC itself
is primarily tied to the recovered bits, RNTI, length, and candidate location.

## Interpretation

CP2012 remains valuable: it proves CP2011's independent bladeRF IQ contains
scheduled SI-phase CORESET-like energy, not just PBCH/SSB.

CP2012 is not a live-equivalent SI decoder. Its strongest correlations are in
broad file-test candidates that live SearchSpace0 does not ask for, especially
AL1/AL2. The visible live-class subset in the representative broad log does not
hide an obvious SI DCI either: the strongest AL4 candidate (`L=2`, `ncce=0`)
passes the predecode corr/EPRE gates but still returns CRC KO, while the AL8
candidate is below the corr gate.

So the current state is:

```text
Independent IQ contains scheduled SI-phase energy.
Broad offline file-test candidates do not decode SI DCI.
The exact live srsUE SearchSpace0/Common0 decode path has not yet been replayed
offline on those snippets.
```

## Frontier

Do not rerun CP2010-CP2013 unchanged. The next no-RF step should be an exact
live-parity offline probe: feed the CP2011/CP2012 snippets into a harness that
uses the same `phy_cfg_nr_t`/`make_phy_search_space0_cfg()`/`cfg.get_dci_cfg()`
setup as live srsUE, then report candidate identity, corr/EPRE, decode-attempted
state, CRC, and DCI/PDSCH outcome only for the live six-candidate SearchSpace0
set. That will decide whether the remaining gap is a live candidate/config
parity issue or a true SI DCI CRC/coherence failure in the independent IQ.
