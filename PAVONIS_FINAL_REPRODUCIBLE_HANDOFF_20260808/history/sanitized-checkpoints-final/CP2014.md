## Scope

No RF, rebuild, deploy, source edit, wrapper edit, gNB, Soapy, M2SDR, bladeRF,
or gateware change was made. This checkpoint derives a compact projection from
existing CP2012 `ue_dl_nr_file_test` logs.

CP2013 showed that CP2012 was not a live-equivalent decoder because the
file-test used a broad self-constructed common0 search space. CP2014 asks a
narrower question: inside those broad logs, what happens if we keep only the
AL4/AL8 candidate class that live SearchSpace0 is supposed to monitor?

## Method

Parsed the `54` CP2012 snippet logs:

```text

```

Kept only file-test candidate rows with:

```text

al=3  -> AL8 class
```

Decode-attempted was inferred using the default active PDCCH DMRS gates:

```text

epre_thr = -80.0 dBfs
```

Artifacts:

- `cp2014_live_subset_projection_from_cp2012_[date-redacted]/summary.json`
- `cp2014_live_subset_projection_from_cp2012_[date-redacted]/live_subset_by_file.tsv`

Important caveat: this is still a projection from the broad file-test logs, not
a full exact live `phy_cfg_nr_t` replay. It does not create missing duplicate
candidate attempts or any candidate locations not present in the CP2012 logs.

## Interpretation

CP2014 weakens the "offline decoder just looked at the wrong broad candidate"
explanation. In the CP2012 logs, the strongest overall correlations were mostly
AL1/AL2 broad-test candidates. When projected onto the AL4/AL8 live candidate
class, the evidence is much thinner:

- zero CRC-OK rows across `162` AL4/AL8 candidate rows;
- only `4/54` windows produce an AL4/AL8 decode attempt;
- all four decode attempts are CRC KO;
- only the `-1728` timing delta carries meaningful AL4/AL8 correlation.

This does not replace an exact live-parity offline harness, but it makes a
hidden valid SI DCI inside the existing CP2012 broad logs unlikely. The current
evidence is best read as:

```text
CP2011 independent IQ has scheduled SI-phase energy.
Most strong broad-test energy lands outside the live AL4/AL8 candidate class.
The visible AL4/AL8 subset is either below-gate or CRC-negative.
```
