## Interpretation

CP2016 revises the CP2015 interpretation. The existing CP2011/CP2012 snippets
are not purely SI-PDCCH CRC-KO in the live-style candidate set. When the
one-slot cut is shifted by `+32..+128` samples relative to the coarse `-1728`
delta, the same live-style AL4 `ncce=0` path finds SI DCI CRC OK in `13/150`
fine probes.

This means the `-1728` value should be treated as a coarse cut arithmetic
landmark, not a proven exact symbol boundary. It is close enough to show
scheduled SI-phase energy and near-gate DMRS correlation, but not always close
enough for PDCCH payload CRC.

The remaining failure after CP2016 is no longer "PDCCH never decodes offline."
It is:

```text
PDCCH can CRC OK at fine timing offsets, but this harness still does not decode
SIB1/PDSCH end-to-end from those DCI rows.
```
