## Interpretation

CP2023 is a valid RF mechanics and runtime-activation checkpoint, but it is not
a decisive SI PDSCH decode datapoint. The override was active and the gNB did
schedule SI-RNTI PDCCH/PDSCH, but the UE never decoded SI PDCCH: all 800
summary rows stayed below the SI-PDCCH correlation gate class, with best
`max_corr=0.221967` and zero rows above `0.40`.

Therefore the CP2018 `~ -9 dB` SI PDSCH-DMRS deficit was not remeasured in an
interpretable live run. There was no UE SI DCI/PDSCH grant to compare against,
and no SIB1/PDSCH CRC path was reached.

This run should be classified as a low/scattered no-SIB1/no-Msg1 supply
datapoint with the CP2021/CP2022 gNB override active, not as evidence that the
PDSCH power-sign hypothesis is wrong.

## Next Frontier

Do not rerun CP2023 unchanged. The next useful step should stay no-RF first:
compare CP2023's low/scattered SI class against the high/phase-locked
DCI-OK/live-IQ windows from CP2016/CP2017/CP2018, and decide whether the
power-sign override must be tested only under a high/phase-locked SI-PDCCH
state or whether a same-device/independent IQ diagnostic is needed to recover a
DCI-OK live window without depending on UE SI grant success.
