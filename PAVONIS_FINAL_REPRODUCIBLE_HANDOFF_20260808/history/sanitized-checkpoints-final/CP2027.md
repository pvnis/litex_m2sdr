# CP2027 No-RF Live-SS0 Scheduled-SI Analyzer Validation

Date: [date-redacted]

RF use: none.

## Scope

CP2027 prepares the offline analysis side of the CP2026 independent-IQ RF rung.
It adds a reusable helper that cuts scheduled SI slots from a timestamped
bladeRF SC16 capture, runs `ue_dl_nr_file_test -X`, and writes compact TSV/JSON
metrics matching the CP2017/CP2018 live-SearchSpace0 audit class.

No RF, remote deploy, rebuild, gNB, Soapy, M2SDR, or bladeRF action was run.

## New Helper

`cp2027_live_ss0_scheduled_si_from_sc16.py`

Function:

- input: raw SC16 bladeRF capture, PBCH/MIB SFN, PBCH `t_offset`
- derive scheduled SI occasions at `SFN % 16 == 0`, slot `1`
- cut one-slot CF32 snippets with `int16 / [date-redacted]` scaling
- sweep deltas, defaulting to the CP2017 broad class:
  `-2112..-1344` samples, step `32`
- run `ue_dl_nr_file_test -X -v` with PCI `1`, `52 PRB`, CORESET0 `0`,
  DL ARFCN `368500`, SSB ARFCN `367930`, SI-RNTI/common0
- emit per-probe logs plus:
  - `live_ss0_scheduled_si.tsv`
  - `live_ss0_scheduled_si_summary.json`

The helper preserves the CP2012/CP2017 timing model:

```text
base_sample = pbch_t_offset
            + (target_sfn_abs - pbch_sfn_abs) * 115200
            + slot * 11520
start_sample = base_sample + delta_samples
```

`-1728` is still treated as a coarse cut-arithmetic/timing-origin neighborhood,
not as air-side displacement. The verdict should come from DCI-OK rows after the
delta sweep.

## Frontier

CP2027 validates the offline analyzer needed after CP2026 RF. Once RF is
explicitly approved, run exactly one CP2026 independent-IQ capture. If PBCH/SSB
is present and the analyzer reaches DCI-OK SI windows, judge the power-sign
override by:

- PDSCH CRC recovery, and/or
- disappearance of the CP2018 `~ -9.4 dB` PDSCH-DMRS deficit toward
  PDCCH/PDSCH-DMRS EPRE parity.

If the CP2026 capture is PBCH-missing or never reaches DCI-OK SI-PDCCH rows,
treat it as void for the SI PDSCH power-sign hypothesis.
