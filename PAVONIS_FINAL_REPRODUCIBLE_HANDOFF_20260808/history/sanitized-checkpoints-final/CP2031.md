# CP2031 No-RF Candidate Sync-Error RF Runner Prep

Date: [date-redacted]

RF use: none.

## Scope

CP2031 packages the CP2030 payoff run into a reproducible, guarded RF wrapper
and adds the missing compact parser for SI candidate trace rows. No RF, remote
SSH, deploy, rebuild, gNB, srsUE, Soapy, M2SDR, bladeRF, or gateware action was
run.

This checkpoint exists so that, after explicit RF approval, the next run is a
single bounded shape instead of ad hoc environment edits.

## New Compact Parser

`cp2031_parse_si_candidate_trace.py`

Hash:

```text
236e650d086fb5c7efce589e1b6f82c39f70f41215a275a437dfb971d82adf5c
```

The parser reads `srsue.stdout.log` or a directory containing it, parses only:

- `PAVONIS_SRSUE_SI_CANDIDATE_TRACE event=si_pdcch_candidates`
- `event=si_pdcch_summary`
- a few marker counts for `phy_set_config_ok`, SIB1/BCCH, and PRACH-TX

It emits compact JSON with:

- supply-class judgment,
- candidate-trace row count,
- SI summary row count,
- best-candidate identity histogram,
- best-candidate `corr`, `epre`, `rsrp`, fixed `cfo_hz`, and
  `sync_error_us` statistics,
- decode-attempted and CRC-OK attempted counts,
- bounded first/last parsed row samples.

This avoids rereading raw UE logs for the CP2031 report.

## Frontier

RF remains parked until explicit approval is relayed.

Once approved, run exactly one CP2031 RF discriminator. Judge class first:

- early-pass: expect candidate rows with `cand_sync_error_us` near zero,
- high/phase-locked no-SIB1: expect stable displacement, roughly
  `100..200` samples equivalent,
- low/scattered: expect larger or unstable displacement.

Immediately after the RF run, run `cp2031_parse_si_candidate_trace.py` on the
new `srsue.stdout.log`, write the checkpoint report from compact JSON, and turn
candidate trace off again for later non-trace RF.
