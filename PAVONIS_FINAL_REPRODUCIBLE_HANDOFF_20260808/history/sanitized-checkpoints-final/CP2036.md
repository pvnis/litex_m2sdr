# Checkpoint [date-redacted]: No-RF CP2035 Report Generator

Date: [date-redacted]

## Purpose

Prepare the mandatory markdown checkpoint-report path for the next approved RF
run. CP2035 produces a manifest plus compact CP2033/CP2034 verdict artifacts;
CP2036 adds a generator that turns those compact artifacts into a checkpoint
report without reading raw logs.

## Actions

- Added `cp2036_write_cp2031_rf_checkpoint_report.py`.
- The generator takes:
  - `--manifest` pointing at a CP2035 manifest
  - `--out-md` for the generated report
  - optional `--checkpoint-id` and `--title`
- It reads only compact artifacts:
  - CP2035 manifest
  - CP1807/CP2031 summary JSON
  - CP2033 candidate trace summary JSON
  - CP2034 sync-error interpretation JSON
- It writes a markdown report with:
  - manifest paths and return codes
  - RF mechanics fields from the compact summary
  - candidate-trace class, counts, SI corr/EPRE stats
  - best identity, CFO, sync-error stats in us and samples
  - CP2034 interpretation/action
  - a note not to read long raw logs unless compact fields are missing or
    contradictory
