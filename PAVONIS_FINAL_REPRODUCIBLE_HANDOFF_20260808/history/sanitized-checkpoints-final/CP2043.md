## Purpose

Test whether CP2040's live SI-PDCCH correlation failure is explained by a
large printed PDCCH CFO distribution by comparing it against DCI-OK offline
`-X` windows from CP2016, CP2017, and CP2038.

## Instrument Validation

The local `dmrs_pdcch.c` source contains the CP2008 CFO store fix:
`measure->cfo_hz = cfo_avg_Hz / (float)(q->coreset.duration - 1)`.

The local `ue_dl_nr_file_test.cc` analysis harness was extended to print PDCCH
`cfo_hz` and `sync_error_us` in its `PDCCH:` lines, then rebuilt locally with:

```text
cmake --build srsRAN_4G/build-clion --target ue_dl_nr_file_test -j 8
```

The rebuilt binary contains the CFO-visible PDCCH format string. This was a
local no-RF analysis harness rebuild only; no live UE threshold, RF shape, or
gateware was changed.

The CP2027 live-SS0 parser was also extended to accept the added optional
`cfo=...Hz; sync=...us;` fields and to carry them into summary rows.

## Interpretation

The requested provenance split rejects the simple "large printed PDCCH CFO
causes the CP2040 gate failure" explanation. Offline DCI-OK windows from
CP2016, CP2017, and CP2038 already carry several-kHz PDCCH CFO in the same
range as CP2040, and in some rows larger absolute CFO, while still reaching
PDCCH CRC OK with `corr >= 0.516`.

Therefore CP2040's high-EPRE, sub-threshold SI-PDCCH state is not separated
from pass-era controls by the scalar printed PDCCH CFO estimate. The failure
must be in something this scalar does not capture: candidate/window coherence,
phase structure inside or across symbols, estimator semantics, or a PDSCH-side
coherence issue. This preserves the broader phase-coherence-defect theory, but
it closes printed PDCCH CFO magnitude as the unifying variable.

One side observation remains consistent with the prior power-sign work:
CP2016/CP2017 DCI-OK rows still show the old SI-PDSCH-DMRS EPRE deficit
(`23.58` and `23.64 dB` medians), while CP2038 with
`PAVONIS_GNB_SI_PDSCH_POWER_SIGN_COMPAT=1` shows restored PDSCH-DMRS EPRE
parity (`31.63 dB`). None of these runs recover PDSCH CRC.
