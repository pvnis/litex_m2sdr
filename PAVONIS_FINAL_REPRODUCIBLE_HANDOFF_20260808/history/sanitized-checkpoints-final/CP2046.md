gateware, or change product source. The purpose was to turn the CP2044/CP2045

LiteX-M2SDR timed-TX path.

## Interpretation

The local live path is not a single opaque continuous sample stream. It is a
sequence of DMA-frame descriptors whose `HAS_TIME`/no-time state, timestamp,
dedup result, remainder carry, ring-slot reuse, short-buffer zero padding, and
gateware WAIT/STREAM/DROP transitions all matter at frame boundaries.

That is the source-level shape expected from the CP2044 result: CP2038 had
valid DCI content, restored PDCCH/PDSCH EPRE parity, and enough energy in the
air, yet SI-PDSCH CRC recovered only after applying an offline phase ramp
before PDSCH decode. The defect is therefore best treated as coherent-cadence
loss across the TX presentation path, not as missing SIB1 scheduling,
thresholding, amplitude, or a UE timing-displacement issue.

The existing worker trace is close to the right no-RF instrument for the next
branch because it is metadata-only and already captures the main descriptor
state transitions. It does not, by itself, prove RF phase continuity, but it
can identify whether the live SI era is being presented as a dense sequence of
new timed descriptors, untimed continuations, duplicate timestamps, late
submissions, short/zero-padded frames, or ring-slot/header reuse anomalies.

## Branch Decision

CP2046 does not approve implementation, RF, deployment, gateware changes, or
live threshold/ramp work. It narrows the next approved work item to one of two
source branches:

1. Preferred, broader branch: a separately approved no-RF coherent-cadence
   migration/fix plan based on the upstream software-timed TX model identified
   in CP1982/CP2045. This branch should first map upstream knobs
   (`timed_tx`, `tx_latency_ns`, `tx_late_margin_ns`, lead buffers) to the
   local 30 ms lead/all-timed history and prove source/build compatibility
   before any RF validation.
2. Smaller local branch: keep the local driver/gateware architecture, but add
   or enable a default-off coherent-cadence mode and metadata gate that proves
   the SI era is emitted as one coherent continuation instead of segmented
   per-frame timed bursts. The first no-RF gate should be worker-trace based
   and should require zero unexpected `HAS_TIME` churn, zero duplicate-timed
   reopenings, zero late/short discontinuities in the SI era, and stable
   descriptor cadence before any RF run is requested.

Not recommended:

- A live UE PDSCH phase-ramp workaround.
- More RF repeats of CP2038/CP2040 shape without a cadence-path change.
- PDCCH/PDSCH threshold relaxation.
- Gateware changes or upstream migration without explicit approval.

## Frontier

Active frontier after CP2046: the evidence points at a LiteX-M2SDR live
timed-TX coherent-cadence defect. The next step should be an explicitly
approved no-RF source branch that either migrates toward upstream software
timed TX or locally proves/enforces coherent continuation across DMA-frame
boundaries using metadata-only instrumentation first.
