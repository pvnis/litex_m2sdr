## Scope

This checkpoint stayed no-RF. It did not rebuild, deploy, start radios, modify
product source, touch gateware, or change live thresholds. It converts CP2046's
LiteX-M2SDR timed-TX source audit into a reusable metadata-only gate for the
next coherent-cadence branch.

## Artifact

Added:

```text
cp2047_tx_worker_trace_cadence_gate.py
```

The script parses TSV files emitted by the existing
`M2SDR_SOAPY_TX_WORKER_TRACE_PATH` path in `LiteXM2SDRStreaming.cpp`. It reads
only worker/release metadata: stage, handle, ring slot, packet size, MTU,
pre/post flags, pre/post `HAS_TIME`, EOB, dedup suppression, source/release
time, hardware time/slip, late classification, reader state, DMA counters,
cleared-header counters, copy/zero-copy mode, and sample rate.

Supported modes:

- `report`: emit metrics only.
- `continuation`: strict gate for one timed anchor followed by untimed
  continuation. Default requirements are zero late rows, zero dedup rows, zero
  short non-EOB rows, no duplicate post-`HAS_TIME` release timestamps, and at
  most one post-`HAS_TIME` row in the selected window.
- `periodic`: gate for bounded re-anchor mode. It keeps the same hygiene checks
  and additionally checks post-`HAS_TIME` timestamp spacing against an expected
  interval/tolerance.

This is analysis tooling only. It does not prove RF phase continuity by itself,
but it can catch the descriptor-level failure classes CP2046 identified before
spending a run.

## Decision

CP2047 makes the next coherent-cadence branch measurable before RF:

- For a local continuation branch, a selected SI-era worker-trace window must
  pass `continuation` mode before RF is requested.
- For a periodic re-anchor branch, the same selected SI-era window must pass
  `periodic` mode with the branch's intended re-anchor interval and tolerance.
- A failure on duplicate post-`HAS_TIME` timestamps, dedup suppression, late
  releases, or short non-EOB rows should stop the branch before RF and be fixed
  at the source/driver presentation layer.

CP2047 does not approve source implementation, RF validation, deployment,
gateware changes, live threshold relaxation, or live PDSCH phase-ramp
workarounds. It supplies the no-RF acceptance gate those later approved steps
must clear.
