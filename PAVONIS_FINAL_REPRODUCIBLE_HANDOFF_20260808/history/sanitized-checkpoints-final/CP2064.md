- `PAVONIS_PRACH_DEMOD_INPUT_STAGE1_TRACE`, default off, row-capped.
- Cached-once stage-1 config object, so env parsing is not repeated per window.

  `PAVONIS_PRACH_DEMOD_INPUT_STAGE1_MAX_CANDIDATES` default `1024`.
- Energy gate defaults: RMS `>= -70 dB` or peak `>= -55 dB`.
- Accepted-candidate-only selection rule from CP1966: select best accepted
  preamble-index-0 detection metric, not highest raw/tail peak.
- Trace row now includes `search_time_us` and `candidates`.
- If stage-1 selects a candidate, the old CFO-only search and static CFO/phase
  transform are skipped for that window to avoid stacking transforms.

Not changed:

- PRACH detector thresholds.
- RAR payloads or scheduler behavior.
- PRACH collection delay constants.
- Gateware or LiteX/M2SDR timed-TX behavior.
- PDSCH phase-ramp behavior.
