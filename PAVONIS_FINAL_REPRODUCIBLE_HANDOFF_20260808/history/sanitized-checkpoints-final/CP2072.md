## Part A: gNB SI-Occasion Trace

Patched file:

Patch behavior:

- New default-off env gate: `PAVONIS_GNB_SI_OCCASION_TRACE`.
- Optional path: `PAVONIS_GNB_SI_OCCASION_TRACE_PATH`, default `/tmp/pavonis_gnb_si_occasion_trace.tsv`.
- Row cap: `PAVONIS_GNB_SI_OCCASION_TRACE_LIMIT`, default `4096`, hard cap `100000`.
- Envs are cached once. With the trace disabled, runtime returns after one cached boolean check and does not call `getenv()` per DL_TTI.
- Emits only scheduled SI lattice or SI-bearing DL_TTI rows:
  - `slot_summary` for `slot_abs % 160 == 1` or any SI-RNTI PDU.
  - `si_pdcch` for SI-RNTI PDCCH PDUs.
  - `si_pdsch` for SI-RNTI PDSCH PDUs.
- Fields include slot/SFN/lattice/cadence, SI PDCCH/PDSCH counts, PDU index/RNTI, PDCCH context, CCE/AL/payload, PDSCH RB/symbol/MCS/TBS/mapping, raw FAPI power fields, `PAVONIS_GNB_SI_PDSCH_POWER_SIGN_COMPAT` state, and `PAVONIS_GNB_POWER_CONTROL_OFFSET_SS_DB` state.
- The trace is inserted after `log_dl_tti_request(msg, ...)` and before `p7_gateway.send_dl_tti_request(msg)`. It does not change scheduler output, FAPI PDUs, power fields, thresholds, RAR/PRACH, or gateware.
