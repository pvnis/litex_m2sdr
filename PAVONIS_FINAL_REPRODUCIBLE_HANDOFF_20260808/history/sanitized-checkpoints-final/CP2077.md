## Verdict

CP2077 is descriptor-clean but mechanism-incomplete.

It proves that simply restoring `M2SDR_SOAPY_TX_TIME_OFFSET_NS=30000000` and
`write_timeout_us=1000` in the detached [host-redacted] helper is not sufficient to
exercise the CP2073 failure mechanism. The CP2074B marker branch still did not
fire, and the old release marker also did not fire. Since the descriptor stream
remains sparse/full-MTU rather than CP2073-like, the remaining mismatch is the
broader full-wrapper/prearm/runtime path, not marker routing.

Do not start the full ladder RF run yet. The next no-RF step should add a
default-off true gNB-only stop-before-UE mode to the full CP1807 wrapper path,
so the next bounded gate can use the real prearm/wrapper sequence while still
starting no UE.
