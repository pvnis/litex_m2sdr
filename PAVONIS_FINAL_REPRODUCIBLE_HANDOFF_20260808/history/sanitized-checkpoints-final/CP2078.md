# CHECKPOINT [date-redacted] - No-RF Full Wrapper Stop-Before-UE Mode

Date: [date-redacted]

## Intent

Add a default-off way to run the real CP1807 full wrapper path through its
pre-UE gNB gates and then stop/package without touching the arm file or
starting srsUE. This is needed because CP2077 proved that a detached [host-redacted]
helper, even with exact time-offset/write-timeout readback, still did not
reproduce CP2073's full-wrapper descriptor shape.

No RF was run in this checkpoint.

## Patch

File:

`cp1807_run_stage6_raresp40_realue_rar_msg3.sh`

Added:

- `PAVONIS_GNB_ONLY_STOP_BEFORE_UE="${PAVONIS_GNB_ONLY_STOP_BEFORE_UE:-0}"`
- If `PAVONIS_GNB_ONLY_STOP_BEFORE_UE=1` and the pre-UE TX gates pass, the
  wrapper logs:
  `STOP_BEFORE_UE enabled after pre-UE TX gates; leaving ARM untouched and starting no UE`
- The stop-before-UE branch is inserted before `prearm_nuc4` and `start_ue`.
- Normal behavior is unchanged when the flag is unset.
- The final run summary now prints `PAVONIS_GNB_ONLY_STOP_BEFORE_UE`.
