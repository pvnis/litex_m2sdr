## Scope

No RF was run. This checkpoint turns the CP2085 RF-gated ladder run plus the
CP2086 post-run analyzer into one approval-gated wrapper so the next RF
checkpoint cannot be interpreted from partial PRACH/RAR evidence.

## Rationale

As of CP2086, the next ladder movement is one bounded signed-stage1 RF run, but
the result must be analyzed with the CP2086 artifact join before any conclusion:

- CP2085 supplies the frozen RF shape and signed stage-1 envelope.
- CP2086 supplies the correct post-run analysis over the generated summary JSON.

CP2087 preserves both gates and only automates their sequence.

## Added Wrapper

Created:

```text
cp2087_run_signed_stage1_policy_rf_with_analysis.sh
```

The wrapper has its own approval guard:

```text
PAVONIS_CP2087_RF_APPROVED=1
```

Without that flag it exits before creating analysis output or calling CP2085:

```text
ABORT_NO_RF: set PAVONIS_CP2087_RF_APPROVED=1 only after explicit CP2087 RF approval is relayed.
```

If approved, it:

1. exports `PAVONIS_CP2085_RF_APPROVED=1`;
2. sets a fresh default stamp ending in
   `CP2087_SIGNED_STAGE1_POLICY_RF_ANALYZED`;
3. runs `cp2085_run_signed_stage1_policy_rf.sh` unchanged;
4. looks for the exact generated summary:
   `cp1733_stage6_realue_sib1_rachcfg_summary_${STAMP}.json`;
5. runs `cp2086_analyze_signed_stage1_ladder.py` into a CP2087 analysis
   directory;
6. writes `cp2087_result.env` with `RF_RC`, `ANALYSIS_RC`, `SUMMARY_JSON`,
   `ANALYSIS_JSON`, and `ANALYSIS_MD`.

The wrapper returns the RF rc first if RF fails, then the analysis rc if RF
passes but analysis fails.
