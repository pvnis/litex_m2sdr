## Scope

No RF was run. This checkpoint extends CP2087 so the result env contains a
compact summary of the CP2086 analyzer JSON. The goal is to make a future RF
result triageable from one small file before opening the larger analyzer JSON.

## Patch

Patched:

```text
cp2087_run_signed_stage1_policy_rf_with_analysis.sh
```

When `ANALYSIS_JSON` exists, CP2087 now writes:

```text
cp2087_analysis_summary.env
```

and embeds that file in `cp2087_result.env`.

Extracted fields:

- `ANALYSIS_VERDICT_CLASS`
- `ANALYSIS_STAGE1_ROWS`
- `ANALYSIS_STAGE1_SELECTED_COUNT`
- `ANALYSIS_STAGE1_CANDIDATES_SUM`
- `ANALYSIS_STAGE1_CAP_HIT`
- `ANALYSIS_DETECTOR_ROWS`
- `ANALYSIS_DETECTOR_ACCEPTED_ROWS`
- `ANALYSIS_STRONG_WINDOWS`
- `ANALYSIS_UE_PHY_SET_CONFIG_OK`
- `ANALYSIS_UE_PRACH_TX`
- `ANALYSIS_GNB_RAR_ENCODED`
- `ANALYSIS_GNB_SOAPY_TX_TIMEOUT_LINES`
- `ANALYSIS_GNB_DOWNLINK_LATE_LINES`

Missing fields are emitted as empty values. This is metadata extraction only;
it does not change RF shape, thresholds, scheduler, RAR, delay constants, or
gateware.
