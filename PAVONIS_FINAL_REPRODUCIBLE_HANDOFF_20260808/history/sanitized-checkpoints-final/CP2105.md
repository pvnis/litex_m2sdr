## Decision

CP2105 is a valid downlink/Msg1-supply datapoint and another void datapoint for
the RAR path trace question because no RAR was transmitted.

The CP2104 `+128/+18 kHz` point did not transfer live. CP2105's own replay
moves the useful class back into the negative-shift/high-positive-CFO region.
The next low-cost RF grid should cover the two strongest delay-centered CP2105
accepts:

- `SHIFT_MIN=-192`
- `SHIFT_MAX=-96`
- `SHIFT_STEP=96`
- `CFO_MIN_HZ=37000`
- `CFO_MAX_HZ=42000`
- `CFO_STEP_HZ=5000`
- `MAX_CANDIDATES=12`

This gives a small rectangle covering `-192/+37 kHz` and `-96/+42 kHz`, while
keeping search cost bounded. Continue to keep thresholds, delay constants,
scheduler/RAR payloads, source timing branches, gateware, and downlink knobs
frozen.
