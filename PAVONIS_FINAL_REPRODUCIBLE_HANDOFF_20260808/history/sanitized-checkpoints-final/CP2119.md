## Current Frontier

The ladder frontier is no longer SIB1 or first Msg1 supply. It is RAR
production reliability and then the UE RAR-to-Msg3 path:

1. Run the already-prepared CP2116 wrapper unchanged with a fresh stamp.
2. Judge health first: Soapy timeout/downlink-late counts must stay same-class.
3. Compare stage-1 `candidates` and `search_time_us` to CP2113's `9` and
   `5186 us`; stop-on-accept should reduce the accepted path latency.
4. If gNB RAR transmits, use the armed UE RAR candidate/path trace and ensure
   the trace window covers the actual RAR slot. CP2101 proved that a capped
   trace can miss the key slot.
5. If RAR reaches UE, push to Msg3 and judge gNB Msg3 CRC.

If stop-on-accept plus source-slot reporting still yields no RAR despite a
clean accepted PRACH, the next discriminator is direct instrumentation of
RACH-indication arrival slot/time versus scheduler slot/time. That splits
"late/stale at scheduler" from "dropped before scheduler" without guessing.
