# CHECKPOINT 2139 - Bounded Stage-1 Envelope Design

Date: [date-redacted] Europe/Zurich

Purpose: use CP2138's offline replay evidence to design a live-safe PRACH
stage-1 envelope before any further RF.

No RF, source edit, rebuild, deploy, threshold change, gain/attenuation change,
delay-constant change, scheduler change, payload change, or gateware work was
performed.

## Inputs

- CP2138 replay JSONL from CP2137 saved strong predemod windows.
- Current deployed source surface in `prach_processor_worker.cpp`.

The source check matters: the live code can express only one rectangular
min/max/step grid. It evaluates baseline first, then shift ascending, frac
`-0.5` before `+0.5`, and CFO ascending. It cannot express an arbitrary list of
the five CP2138 accepted points without a new patch.

## Cost Basis

Existing high-energy stage-1 traces:

| Run | Energy rows | Candidates | Search time |
| --- | ---: | --- | --- |
| CP2124 | `7` | median/max `9/9` | median/max `5148/5390 us` |
| CP2130 | `3` | median/max `3/3` | median/max `1458/1759 us` |
| CP2137 | `19` | median/max `9/9` | median/max `5101/5395 us` |

That puts detector-evaluation cost near `0.57 ms/candidate` on energy-gate
rows. A broad 100+ candidate grid would be too risky for this real-time path.

## Verdict

This is the smallest current-env rectangle found that recovers all five CP2138
offline-accepted windows. It is materially better than rerunning the old CP2127
compact RF shape, which recovered only one CP2137 window offline.

Next RF, if run, should use this envelope as a health-first diagnostic while
keeping the CP2124/CP2137 ladder controls frozen. Interpretation order:

1. Health first: compare stage-1 search times, Soapy TX timeouts, and
   downlink-late counts against CP2137/CP2130/CP2124. If materially degraded,
   void the ladder result and reduce cost before interpreting PRACH/RAR.
2. If health is same-class, judge PRACH acceptance and gNB RAR production.
3. If RAR is transmitted, resume the parked CP2057/RAR-path questions.
4. If UE decodes RAR and sends Msg3, judge gNB Msg3 CRC with TA compensation
   already armed.
