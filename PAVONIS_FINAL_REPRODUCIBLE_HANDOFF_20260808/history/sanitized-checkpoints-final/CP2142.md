Status: no-RF, local build only, not deployed to [host-redacted].

## Purpose

CP2140 showed the CP2139 positive-shift/low-CFO envelope did not transfer to
the next live PRACH phase. CP2141 then proved the CP2140 saved strong windows
recover offline, but in a different family: negative shift and higher CFO.
A broad rectangular live grid would be too expensive, so this checkpoint adds a
default-off explicit candidate-list surface.
