## Independent Capture Config Audit

The CP2135 independent bladeRF DL capture helper is not a channel swap:

- It hardcodes bladeRF RX channel `0` / RX1.
- It sets manual gain mode, uses metadata `RX_NOW`, and captures SC16 Q11.
- CP2135 ran normal filter, `1842500000 Hz`, `11.52 Msps`, `10 MHz`,
  requested gain `36`.

The srsUE RF path differs:

- `device_name=bladeRF`, `nof_antennas=1`, `srate=11.52e6`,
  `freq_offset=6000`, `rx_gain=40`, `tx_gain=60`.
- Runtime CP2140 set RX rate `11.52 Msps` with requested bandwidth `9.216 MHz`;
  requested RX gain `40` read back as high-gain class.

Verdict: RX1/RX2 drift is ruled out, but CP2135's 25-31 dB independent-capture
deficit remains plausibly a capture-helper/config-stack issue rather than a
dead path. The controlled tones exonerate the physical path for CW.
