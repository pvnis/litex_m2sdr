# CP2191: PUSCH estimator CSI trace, no RF

Date: [date-redacted] Europe/Zurich

## Patch

The existing PUSCH logging decorator now has a default-off, env-cached,
result-level trace:

- `PAVONIS_PUSCH_CSI_TRACE`
- `PAVONIS_PUSCH_CSI_TRACE_LIMIT` (default 128)

One row is emitted from `on_sch` per decoded PUSCH result, after the estimator
has already populated CSI. It records slot/system-slot, RNTI, CRC, EPRE,
selected SINR, residual time alignment in microseconds, and CFO, with explicit
valid flags. The patch adds no sample scan, lower-PHY work, file output, timing
constant, or decode behavior. The established CP1807 runner forwards and
records both controls.
