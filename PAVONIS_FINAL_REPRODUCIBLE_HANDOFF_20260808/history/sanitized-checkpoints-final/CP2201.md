# CP2201: scheduled-Msg3 target capture, no RF

Date: [date-redacted] Europe/Zurich

## Purpose

CP2200 proved the first-RAR raw window was observed 61 slots late because the
lower PHY polled its arm file every 1024 symbols. It also showed that a
first-RAR-only window is insufficient when that RAR is UE-blind.

## Implementation

The default-off `PAVONIS_UL_SYMBOL_MSG3_TARGET_CAPTURE` path now publishes each
initial Msg3 allocation from the RAR scheduler into a fixed eight-entry atomic
table. Each entry carries the exact system slot, PUSCH symbol start/stop, and
temporary C-RNTI. The lower PHY checks this metadata once per completed symbol
and writes CF32 only when the current slot/symbol matches a published target.

The target is cleared after its last symbol. An unmatched target expires after
256 lower-PHY slots, preventing a stale entry from firing when the same
SFN/slot recurs 10.24 seconds later. The path performs no sample scan or file
write outside an exact target. The existing global raw cap remains `128`, which
covers all fourteen symbols for up to seven Msg1/RAR attempts.

The runner uses a dedicated `scheduled_msg3` arm mode, metadata-only summaries,
and disables the old RAR-PDU file touch. Raw RMS/peak thresholds are set to
`1e9`, so only the explicit scheduled target can write raw samples. Existing
RF, timing, stage1, power, scheduler, payload, and gateware settings are
unchanged.

- With the feature unset, deployed `gnb --help` returns `0` with 41 stdout
  lines, zero stderr lines, and zero target markers.
- `bash -n` passes for CP1807, CP2192, and the CP2201 wrapper.

## Verdict

PASS, no RF. One bounded RF run is eligible. Judge health first, then require
each gNB RAR allocation to produce one target publish and exactly fourteen raw
symbol files at its scheduled Msg3 slot. If any RAR reaches the UE, correlate
that target's raw waveform against the exact UE host Msg3 file and the gNB EVM
row. If all RARs remain UE-blind, the capture plumbing is still judged on exact
slot coverage but Msg3 coherence remains void.
