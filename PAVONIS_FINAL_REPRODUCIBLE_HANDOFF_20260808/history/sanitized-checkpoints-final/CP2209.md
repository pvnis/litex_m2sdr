Date: [date-redacted] Europe/Zurich

## Purpose

CP2207/CP2208 are consecutive no-SIB1 voids, and CP2208 has good PBCH SNR.
CP2209 prepares an instrumented run that can separate scheduler/FAPI supply,
Soapy descriptor presentation, and UE candidate/CFO behavior without changing
the radio shape.

## Shape

New alias `cp2209_run_si_supply_discriminator.sh` retains the complete CP2206
measured-offset target ladder and adds only existing default-off metadata
traces:

- gNB SI-occasion/FAPI trace, limit 4096;
- M2SDR TX worker descriptor trace from stream start, limit 65536;
- UE SI candidate trace, limit 1200, minimum correlation 0.20;
- UE SI applied-CFO provenance trace.

CP2188 now permits an explicit empty worker arm-file override. Its default
remains the RAR-event arm file for every existing caller. The CP2209 empty
override starts the bounded descriptor trace immediately, covering the first
timed anchor and first SI occasions where this run class is decided.

The Msg3 target capture, non-PRACH `-241118`, PRACH/stage1/TA, TX, RF,
scheduler, payload, and threshold controls are unchanged.
