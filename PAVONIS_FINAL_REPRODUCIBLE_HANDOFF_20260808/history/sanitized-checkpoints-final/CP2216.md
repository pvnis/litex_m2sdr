# CP2216: accepted-PRACH energy-edge dynamic non-PRACH offset, no RF

Date: [date-redacted] Europe/Zurich

## Purpose

CP2215 closed the per-burst UE transmit-guard jitter and left one run-stable
observable: the accepted PRACH window's 8-sample energy edge. Across
CP2205/2210/2212/2215, that edge predicts the required Msg3 collection offset
with the TA0 formula `offset = -237332 - edge`. CP2216 implements that formula
at the existing generic non-PRACH offset publisher without changing PRACH
collection, stage-1 selection, TA compensation, slot attribution, or PUxCH
semantics.

## Implementation

`pavonis_dynamic_non_prach_ul_offset.h` adds a default-off edge mode behind:

- `PAVONIS_NON_PRACH_UL_RX_OFFSET_FROM_PRACH_EDGE`
- `PAVONIS_NON_PRACH_UL_RX_OFFSET_EDGE_CALIBRATION_SAMPLES` (default `-237332`)
- `PAVONIS_NON_PRACH_UL_RX_OFFSET_EDGE_SCHEDULER_ERROR_SAMPLES` (default `0`)
- `PAVONIS_NON_PRACH_UL_RX_OFFSET_EDGE_BLOCK_SIZE` (default `8`)
- `PAVONIS_NON_PRACH_UL_RX_OFFSET_EDGE_HOST_ACTIVE_STOP_SAMPLES` (default `10404`)

Configuration remains cached once. The PRACH worker measures the edge only
after stage-1 has accepted a preamble-0 candidate and only when edge mode is
enabled. It computes 8-sample RMS blocks, the exact p20/p80 geometric-mean
threshold used by the offline reference, and the longest active run. The
result publishes through the existing packed atomic generation consumed by
the shifted non-PRACH lower-PHY path. Edge mode has priority over the rejected
stage-1 sign map; the old sign publisher remains the fallback when edge mode
is off.

This complies with CP1860: no per-sample work occurs on rejected windows or on
the disabled path. The accepted-event scan is bounded to one PRACH window and
records its wall time in the capped publisher trace.

Mean measurement time is `239.4 us` with edge mode disabled in the harness and
`240.2 us` with publication enabled. Both executions pass. With both the old
sign flag and edge flag set, the sign publisher returns false and only edge
updates advance the generation.
