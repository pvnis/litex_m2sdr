## Offline Replay

The unchanged CP1965 detector harness first replayed the six saved windows over
the broad stage-1 policy grid:

```text
shift -448..-96, step 32
fractional shift -0.5 / +0.5
CFO +20..+50 kHz, step 1 kHz
745 rows per window including baseline
```

That grid accepts only windows 0, 3, and 4. Windows 1, 2, and 5 peak at the
`+50 kHz` boundary with ratios `0.904`, `0.890`, and `0.957`, respectively.
This is a bounded-grid miss, not evidence for lowering the live detector
threshold.

An offline-only `+20 kHz` bulk rotation followed by the unchanged policy tests
an effective `+40..+70 kHz` range. All six windows then have hundreds of
accepted variants. A single common point covers all six:

```text
integer shift       -224 samples
fractional shift    -0.5 samples
CFO                  +60000 Hz
minimum p0 ratio      3.139
```

The single point was then validated directly, without composed transforms, by
applying exactly `shift=-224`, `frac=-0.5`, `cfo=+60000` to each original CF32
window and running the unchanged detector in baseline mode:

| Window | Preamble | Ratio | Delay | Accepted |
|---:|---:|---:|---:|:---:|
| 0 | 0 | 3.139 | 48 | yes |
| 1 | 0 | 7.078 | 48 | yes |
| 2 | 0 | 4.955 | 53 | yes |

The resulting detector RSSI is tightly grouped at `-49.43..-49.75 dB`.

## Verdict

CP2220 is a valid healthy downlink/SIB1/UE-Msg1-supply run and an invalid
edge/RAR/Msg3 datapoint. The live failure is fully explained by the fixed
ten-candidate envelope ending below the run's recoverable class. A single
additional candidate, `-224:-0.5:+60000`, recovers every saved CP2220 window
with substantial margin while preserving the detector threshold and delay
gate.

Before another RF run, add this candidate through the existing default-
preserving candidate-list override and raise only the list cap as required.
Do not widen the full live grid, lower a threshold, or alter timing/RAR/TA
semantics. The next RF run should otherwise remain the frozen CP2218 shape and
be judged health-first, then Msg1 acceptance, edge publication, RAR visibility,
and finally Msg3 CRC.
