## CP2244 correction

CP2244's report interpreted the FAPI field `pdcch_al=2` as two CCEs. That
field is the aggregation index; the adjacent runtime field is
`pdcch_al_cces=4`. The UE candidate's `L=2` has the same meaning because its
decoder uses `1U << L`. The exact geometry is therefore:

```text
SearchSpace1 / CORESET0 / NCCE0 / aggregation level 4 / 37 DCI bits
```

This reproduces and preserves CP2159's prior geometry conclusion. CP2244's
statement that gNB and UE geometry match remains true, but every `AL2`
reference in that report/summary must be read as `AL4` (`L=2`).

## Exact runtime payload

All five CP2244 FAPI RAR rows are byte-identical at the DCI boundary:

```text
RA-RNTI=0x39 BWP=0+24 symbols=0+2 CCE=0 AL=4
bits=37 payload=0300000000 powerControlOffsetSS=+6 dB
```

The payload is exactly what both implementations require:

- CORESET0 width `24` gives a frequency-assignment width of
  `ceil(log2(24*25/2)) = 9` bits.
- `RB=[0..3)` gives RIV `24*(3-1)+0 = 48`, or nine bits `000110000`.
- time resource `0`, non-interleaved VRB mapping, MCS `0`, TB scaling `0`,
  and the 16 reserved bits are all zero.
- total size is `9+4+1+5+2+16 = 37` bits.
- packing `48` followed by 28 zero bits is `0x0300000000`, exactly the FAPI
  payload.

srsUE derives the same 37-bit common-search-space size from CORESET0 width 24
and unpacks the fields in the same order. Payload size, field ordering, RIV,
and reserved padding therefore match end to end.

## CRC and scrambling

The active OCUDU encoder and srsUE decoder implement the same PDCCH chain:

- prepend 24 ones for CRC calculation;
- calculate CRC24C over payload plus that prefix;
- mask/unmask the final 16 CRC bits with RA-RNTI `0x39`;
- for common SearchSpace1, scramble/descramble PDCCH data with
  `n_RNTI=0`, `n_ID=PCI=1`;
- use the same RA-RNTI separately for CRC masking.

The gNB FAPI row carries RNTI decimal `57` (`0x39`), while the UE trace searches
the same RNTI. No source or runtime evidence supports a CRC-mask, data
scrambling, payload, size, or SearchSpace/CORESET mismatch.
