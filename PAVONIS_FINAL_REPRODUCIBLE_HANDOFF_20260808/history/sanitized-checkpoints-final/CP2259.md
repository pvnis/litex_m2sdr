## Verdict

CP2259 is a valid supply and RAR-hole datapoint. It is void for the new lattice's
Msg3 timing/CRC criterion because the UE never received a RAR and never emitted
Msg3. The lattice changes only UE transmit timestamp generation and cannot
explain the downlink RAR candidate correlation gate.

Use the standing scatter rule once: retry this exact frozen shape with a fresh
stamp. The first Msg3-bearing run must be judged with the CP2256 saved-waveform
join: requested timestamp residual must remain within the slot-count slew bound,
and the gNB target lag must land in the modeled `-44..+44`-sample envelope before
CRC is interpreted.
