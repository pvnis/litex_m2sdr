# CP2262 - Correct stage-1 TA units and non-PRACH timestamp sign

Date: [date-redacted]

## Purpose

Fix the two source-level TA semantics defects proven by CP2261, with no RF,
then build/deploy under the standard rollback and disabled-path gates.

## Changes

Three exact source files change:

- `pavonis_prach_stage1_ta_compensation.h` adds a pure conversion from raw
  lower-PHY samples to PRACH detector time-resolution units.
- `prach_processor_worker.cpp` uses that conversion both when computing the
  edge publisher's RAR TA and when recording the slot-side-table compensation
  consumed by upper PHY.
- `pavonis_dynamic_non_prach_ul_offset.h` extracts the edge-offset equation
  into a pure helper and changes the TA term from negative to positive.

The corrected equations are:

```text
ta_units = raw_shift_samples / lower_phy_sample_rate / detector_time_resolution
offset = calibration - edge - scheduler_error + rar_ta_samples
```

Default behavior remains unchanged. The conversion only runs when the existing
default-off `PAVONIS_PRACH_STAGE1_TA_COMPENSATE_SELECTED_SHIFT` path is active;
the sign term is zero unless the existing default-off edge and
`EDGE_INCLUDE_RAR_TA` paths are active.

| raw shift `-192` | `-32` detector units | pass |
| CP2261 calibration `-237332`, edge `-868`, TA `1092` | offset `-235372` | pass |
| same row with TA excluded | offset `-236464` | pass |

The first standalone compile attempted C++20 and exposed an unrelated fmt
toolchain incompatibility. Re-running with the repository's actual GNU C++17
flags resolved it; both assertion-enabled unit execution and the real gNB build
pass.
