# CP2283 - non-PRACH pre-OFDM CFO correction built and deployed

Date: [date-redacted]
RF: none

## Implementation

CP2283 adds the default-off `PAVONIS_NON_PRACH_UL_RX_CFO_HZ` control to the
lower-PHY uplink processor. The value is parsed once and, when finite and
nonzero, scheduled on the already-separated shifted non-PRACH CFO processor.
The correction therefore runs before OFDM on PUSCH, PUCCH, and SRS samples;
the primary PRACH processor and stage-1 input are unchanged.

The enabled startup marker is:

```text
PAVONIS_NON_PRACH_UL_RX_CFO_HZ active value=... scheduled=... scope=shifted_non_prach_pre_ofdm prach_unchanged=1
```

There is no per-call `getenv`, formatting, or new sample scan on the runtime
path. Invalid or zero values leave the new processor unscheduled. The CP1807
runner now propagates the setting through the remote environment, settings
log, and `result.env`; the CP2283 wrapper freezes it at `-4000 Hz` on top of
the unchanged CP2280/CP2281 SFN-handoff, candidate2/3, lattice, corrected-TA,
and decoder10 shape.
