# CP2285 - production CFO processor recovers saved Msg3

Date: [date-redacted]
RF: none

## Purpose

CP2283 deployed the non-PRACH correction using OCUDU's production
`baseband_cfo_processor`, while CP2282's saved-capture result used a manual
sample rotator. CP2285 closes that implementation-to-replay gap before the
pending RF run.

The local `pavonis_pusch_capture_replay` harness now accepts an optional
`CFO_MODE=manual|processor`. `manual` remains the default and preserves CP2282
behavior. `processor` instantiates the exact production class, schedules the
CFO command once, calls `next_cfo_command()` at slot start, and advances phase
continuously after each captured OFDM symbol, matching the live shifted
non-PRACH path. This is test-harness-only; no gNB runtime source or deployed
binary changed.
