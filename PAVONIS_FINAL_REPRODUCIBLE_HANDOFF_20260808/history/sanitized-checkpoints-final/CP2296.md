## Scope

The existing `PAVONIS_PUCCH_RESULT_TRACE` now also records:

- BWP start/size and optional second-hop PRB.
- `n_id`, port count, initial cyclic shift, and time-domain OCC.

The new `PAVONIS_PUCCH_F1_GRID_CAPTURE` path runs only after an SR-only
format-1 result is both invalid and above its EPRE floor. It stores the 12 REs
for each allocated symbol and configured port in symbol-major CF32 order.
Defaults are off, at most four grids, and `-60 dB` minimum EPRE. At CP2295's
one-port/14-symbol geometry, each file is only `1344` bytes.

This is bounded upper-PHY event work. It does not scan the lower-PHY stream,
poll a growing log, or perform continuous per-sample instrumentation.
