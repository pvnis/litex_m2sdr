Date: [date-redacted] (Europe/Zurich)

## Verdict

NO-RF PASS. OCUDU's production format-1 detector now supports a default-off,
environment-cached input phase correction using precomputed symbol and
subcarrier phasors. The enabled CP2304 values are exactly the CP2303 four-grid
midpoint control: `+12.2 degrees/symbol` and `-72.0 degrees/subcarrier`.

The patch is active in a [host-redacted]-native gNB build. No RF ran in this checkpoint.

## Scope and hot-path discipline

- New variables:
  - `PAVONIS_PUCCH_F1_SYMBOL_PHASE_STEP_DEG`
  - `PAVONIS_PUCCH_F1_SUBCARRIER_PHASE_STEP_DEG`
- Both are read once. Unset/zero leaves the samples unchanged and emits no
  marker.
- Enabled phasors are precomputed once; runtime work is one bounded multiply
  per extracted format-1 RE.
- Scope is only the production PUCCH format-1 detector input.
- PRACH, PUSCH, SRS, other PUCCH formats, slot attribution, shared non-PRACH
  CFO, dynamic offset, thresholds, scheduler, and UE code are unchanged.

## Replay gates

four CP2303 baseline metrics reproduce exactly:

`0.176236 / 0.228812 / 0.239153 / 0.225495`, all invalid.
