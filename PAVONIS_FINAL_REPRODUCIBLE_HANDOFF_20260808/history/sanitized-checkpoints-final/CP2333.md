## TA verdict

The trace observed two real RAR timing-advance handoffs that each reached a
strong CRC-OK Msg3, yet queued TA equaled worker-end current TA every time.
Therefore the specific CP2331 theory that a worker is queued before the RAR TA
update and transmitted after it is rejected for this run. The `+301..+343`
post-Msg4 timestamp class cannot be credited to a queued/current mismatch.

The trace emits only mismatches, so this run does not record the absolute TA
included in each transmitted worker. One unchanged supply retry remains useful:
it can confirm the zero-mismatch result in a run that reaches Msg4/data. If it
again has no mismatch, the next no-RF source audit must explain the Msg3 versus
connected-mode timestamp lattice through a different path rather than restoring
the commented worker-end TA subtraction.
