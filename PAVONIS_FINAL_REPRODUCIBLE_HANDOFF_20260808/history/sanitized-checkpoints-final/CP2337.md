## Patch

The TA controller now tracks the fixed `N_TA_offset` component separately from
the total TA. `add_ta_offset()` accepts a default-false `preserve_command`
argument. Historical/default behavior still replaces total TA with the new
fixed offset. When preservation is enabled, it computes:

```text
command_nta = previous_total_nta - previous_offset_nta
new_total_nta = new_offset_nta + command_nta
```

`set_base_sec()` clears the tracked offset component because it explicitly
replaces the complete base. Positive RAR/MAC command contributions remain
unchanged across repeated RRC PHY configuration; changing the fixed offset
replaces only that component.

The NR `phy_nr_sa::set_config()` path enables preservation only under the
cached/default-off `PAVONIS_SRSUE_TA_OFFSET_PRESERVE_COMMAND` flag. Enabled
configuration and each low-frequency offset update emit metadata-only rows
with previous total/offset, preserved command, new offset, and new total. The
CP2337 wrapper keeps CP2335's in-flight delta correction enabled and adds the
preservation flag over the frozen shape.
