## Change

The frozen ladder runner now exposes OCUDU's existing
`cell_cfg.pdsch.max_ue_mcs` setting as `GNB_MAX_UE_MCS` locally and
`PAVONIS_GNB_MAX_UE_MCS` on [host-redacted]. The remote YAML patch validates an integer
range `0..28`, emits one shared `pdsch` section with any existing SIB1 setting,
and records the value in launch/result output. The default remains empty.

New wrapper `cp2343_run_pdsch_max_ue_mcs9.sh` sets only
`GNB_MAX_UE_MCS=9` and delegates to the complete CP2341/CP2337 frozen shape.
There is no OCUDU/srsUE source, binary, PHY threshold, power, TA, timing,
stage1, or scheduler-algorithm change.
