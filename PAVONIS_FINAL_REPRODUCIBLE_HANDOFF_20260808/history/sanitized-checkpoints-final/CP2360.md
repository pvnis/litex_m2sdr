# CP2360 - Bounded lower-PHY RAR-slot capture deployed

Date: [date-redacted] Europe/Zurich

## Question

Can exact host-side RAR slot samples be retained below modulation without
continuous dumping or violating the lower-PHY observer-effect rules?

## Implementation

`lower_phy_baseband_processor.cpp` now has a default-off capture immediately
after downlink baseband generation and before `transmitter.transmit()`.
Configuration is cached once. With `PAVONIS_DL_SLOT_CAPTURE` unset or zero,
the path returns before arm polling, matching, formatting, allocation, sample
access, or file IO.

When enabled, it polls a configured arm file once per 64 lower-PHY buffers
until armed, matches only `system_slot % 160 == 47`, and writes the selected
port's existing CI16 span directly. It performs no sample scan or conversion.
The cap is 64 one-millisecond slots, about 2.81 MiB of raw data for one port at
11.52 Msps. A small TSV manifest records system/absolute slot, phase, relative
and TX sample timestamps, port, sample count, actual write count, and path.

The CP1807 runner now defaults all capture settings off, exports them through
the quoted remote child, records settings/result-manifest values, checks binary
capability when enabled, cleans only the fixed capture paths, and touches the
capture arm in the existing pre-UE step. The [host-redacted] packager includes the
manifest and bounded `.ci16` files. New wrapper
`cp2360_run_rar_lower_phy_capture.sh` enables max64 phase-47 capture while
retaining the diagnostic-only target-47 scheduler and frozen CP2353 shape.

## Verdict and next

PASS no-RF. Run one bounded diagnostic with fresh stamp. Health remains the
first gate; require arm/cap/manifest completeness and exact FAPI-to-capture
slot joins. Convert only joined RAR CI16 files offline and run the RA-RNTI
`0x39` common-search harness. If host-side DCI decodes while the simultaneous
UE row is low, the defect is below lower PHY. If the exact host-side slot is
also low/KO, investigate lower-PHY modulation/baseband generation. Do not use
the 64 background phase slots as RF datapoints and do not change the UE gate,
RAR payload, power, TA, MCS, or PRACH shape.
