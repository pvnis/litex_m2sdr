# CP2362 - PUCCH ACK ordering trace deployed

Date: [date-redacted] Europe/Zurich

## Question

Why did CP2361 discard the exact `k1=4` contention-resolution HARQ-ACK slot
before the already-enabled format-1 detector and phase bank could process it?

## No-RF audit

CP2361's RRCSetup grant at slot `568.0` transmitted only the 9-byte
contention-resolution CE and scheduled feedback at slot `568.4`. The UE
decoded the PDCCH/PDSCH and declared Random Access Complete, but the gNB's only
`Discarded uplink slot` warning names exactly `568.4`. There is no format-1
result for that slot. The full phase bank was configured but unexercised.

CP2328 is the positive control. Its combined contention-resolution plus
297-byte RRCSetup PDSCH at slot `551.7` scheduled `k1=4`; the gNB processed
format-1 at `552.1` and returned `ack=1`, after which the UE reached RRC
Connected. This isolates CP2361 to slot delivery/order before PUCCH decoding,
not a generic HARQ, format-1, or credential failure.

## Instrumentation

The existing default-off `PAVONIS_PUXCH_ORDER_TRACE` now adds three
metadata-only events in `uplink_processor_impl.cpp`:

- `upper_pucch_f1_enqueue` when a format-1 collection is queued;
- `upper_pucch_f1_task_start` and `upper_pucch_f1_task_return` around the
  existing detector call;
- `upper_ul_slot_discard` with slot and processed-symbol count when a pending
  uplink slot is retired.

The lower-PHY `puxch_grid_symbol_written` events are unchanged. With the trace
disabled, every new call returns through the existing cached flag before
formatting or IO. No sample scan, payload copy, scheduler behavior, grid
semantics, PUCCH geometry, detector, threshold, or timing value changes.

`cp2362_run_pucch_ack_order_trace.sh` uses the frozen CP2353 ladder chain,
enables the existing late arm and a bounded 2,048-row cap, and explicitly
disables the closed phase-47 scheduler target and CP2360 lower-PHY capture.
RAR PDU assembly performs the existing once-per-run in-process arm.

## Verdict and next

PASS no-RF. Run one fresh bounded CP2362 diagnostic. Health is first. A
RAR/Msg3/decoded contention-resolution run is required to judge the ACK axis.
For its exact `k1` slot:

- lower grid rows absent, then discard: shifted collection skipped the slot;
- lower grid complete, no PUCCH enqueue, then discard: PDU/grid repository
  handoff is late or mismatched;
- enqueue/task present: return to format-1 result and phase-bank judgment.

Do not retune TA, PRACH, MCS, power, thresholds, payloads, timing constants, or
credentials in the same run.
