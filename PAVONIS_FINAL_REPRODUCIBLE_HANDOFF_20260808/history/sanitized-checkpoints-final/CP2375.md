no packet.

## Cross-run observer finding

`[ip-redacted]`. All three runs with the 1 Hz pre-armed
`sudo ip netns exec ... ip addr` loop, CP2373-CP2375, fail before address
activation despite otherwise clean health. The loop repeatedly forks `sudo`,
`ip`, and namespace processes on the real-time UE host. It is not proven
causal, but three consecutive failures make another identical run unjustified.

## Verdict and next

event-driven probe: cheap shell wait for `/var/run/netns/[interface-redacted]`, then one blocking
`ip monitor address` process inside the namespace, followed immediately by the
ten-packet ping on the `[ip-redacted]` event. Syntax/deploy-smoke it without RF,
then run the frozen stack unchanged.
