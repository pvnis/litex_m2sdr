# CP2377 - RF void exposes missing OTA UE network namespace

Date: [date-redacted] Europe/Zurich
RF: bounded private Pavonis OTA run
Stamp: `[date-redacted]CP2377_NETLINK_OTA_USERPLANE_DATA_RF`

## RF result

Health and SIB1 pass. The gNB accepts six Msg1 windows and emits six RARs, but
the UE decodes none. No Msg3, InitialUE, or address follows. This RF roll is
RAR-supply void for data; retention/TX health remains clean.

Both event-driven probe windows report `NO_NETNS`, which triggers the no-RF
gateway audit below.

## Missing prerequisite

srsUE source `gw::init_if()` does not create a configured network namespace.
It opens `/run/netns/<gw.netns>` and returns `SRSRAN_ERROR_CANT_START` if the
path is absent. The frozen OTA config sets:

```text
gw.netns = [interface-redacted]
gw.ip_devname = [interface-redacted]
```

The OTA runner never creates `[interface-redacted]`. The prior CP2370 and CP2372 detail logs,
which qcore classified as PDU-session activations, both contain the exact UE
gateway failure:

`Failed to find netns [interface-redacted] (/run/netns/[interface-redacted]): No such file or directory`

Therefore those checkpoints prove complete control-plane attach and qcore PDU
activation, but not a configured UE [interface-redacted]. This also explains why every packet
probe saw no namespace/address.

The proven ZMQ dataplane harness explicitly executes `sudo ip netns add [interface-redacted]`
before launching srsUE, then reads `[interface-redacted]`, installs its default route, and
pings `[ip-redacted]`. The OTA path omitted that prerequisite.

## Verdict and next

The active data blocker is missing ephemeral UE network namespace setup, not
credentials or the CP2368 radio retention fix. Add an idempotent no-RF
prepare/cleanup helper that creates `[interface-redacted]` before the frozen OTA wrapper, brings
loopback up, verifies the namespace, and deletes it after the run. With the
namespace present, pre-arm the CP2376 netlink watcher and rerun frozen. The
first `[ip-redacted]` event must trigger the ten-packet dataplane test.
