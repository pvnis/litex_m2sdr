## Runtime no-transmit proof

All valid runs used `PAVONIS_SOAPY_TX_SKIP_STREAM_SETUP=1` and
`PAVONIS_SOAPY_TX_SKIP_STREAM_IO=1`. Neither logger file contains a
`writeStream` call.

| Case | Verdict | Runtime proof |
| --- | --- | --- |
| Offset `2` | Rejected | `PAVONIS_SOAPY_PHYSICAL_CHANNEL_OFFSET must be 0 or 1`; invalid radio configuration. |
| Offset `1` | Pass | Active marker reports offset 1; TX config targets channel 1; RX readback is channel 1 at 1747.5 MHz/11.52 Msps/gain 40/manual; RX setupStream selects channel 1; zero TX writes. |
| Offset unset | Pass | No active marker; TX config targets channel 0; RX readback is channel 0 with matching geometry; RX setupStream selects channel 0; zero TX writes. |

The first diagnostic attempt was harness-invalid because it omitted the
frozen shape's `PAVONIS_ALLOW_EXTENDED_RA_RESP_WINDOW=1`; all cases therefore
stopped at the Band-3 40 ms RA-window validator. The corrected attempt included
that established private-lab flag. The valid cases then initialized the radio
before the expected AMF refusal, which was sufficient for the mapping proof.
