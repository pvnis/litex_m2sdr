# CP2395: isolated phone runner passes no-RF gate

Date: [date-redacted] Europe/Zurich

## Result

PASS. The certified CP2392 runner chain can now select the separate CP2394
phone gNB and physical M2SDR channel 1 through two default-off environment
values:

- `PAVONIS_OCUDU_GNB_BIN_OVERRIDE`
- `PAVONIS_SOAPY_PHYSICAL_CHANNEL_OFFSET`

When unset, the remote validation environment retains its existing preferred
gNB binary and the Soapy remap remains disabled/channel0. The mature runner,
its frozen radio/timing fixtures, and the active CP2392 binary are otherwise
unchanged.

## Phone controller

`cp2395_run_phone_channel1_registration_smoke.sh` wraps the CP2389/CP2392
shape with:

- the separate CP2394 binary `ac1b6acb...`;
- physical offset 1;
- `PAVONIS_GNB_ONLY_STOP_BEFORE_UE=1`, so no srsUE/bladeRF UE starts;
- a bounded 180-second post-ready phone observation window;
- fresh-stamp artifact guards and an explicit
  `PAVONIS_CP2396_RF_APPROVED=1` execution gate;
- runtime proof of the process executable hash, channel-1 TX/RX readbacks,
  active remap marker, and absence of channel-0 readbacks before interpreting
  phone results.

The remote ADB monitor records only timestamp, operator numeric, RAT,
voice/data registration state, NR availability, data state, and cellular
interface/IP. It deliberately does not retain raw telephony dumps, cell
identities, or neighboring-network details. If the private `00101` PLMN and a
cellular interface appear, it sends one bounded five-packet ping to the private
qcore gateway `[ip-redacted]` over that interface.
