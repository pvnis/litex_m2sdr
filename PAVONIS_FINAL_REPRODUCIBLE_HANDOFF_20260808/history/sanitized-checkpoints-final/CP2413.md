## Interpretation

This is a valid 7 dB datapoint, unlike CP2411. It is indistinguishable from the
10 dB controls: CP2410 is `-18.01 dBFS`/max979 and CP2411 is
`-18.136 dBFS`/max896. The 3 dB baseband increase changes observed total RX2
power by less than 0.13 dB and does not produce any decodable SSB window. The
receiver remains dominated by its antenna-side floor, so this bracket cannot
resolve the wideband NR signal.

Do not repeat backoff7. The next bounded remote lever should avoid further
baseband peak pressure: retain backoff7 and reduce M2SDR TX attenuation from 5
to 0 dB, giving 5 dB more RF drive, with the same independent RX2 PBCH/CSI and
clipping gates. If that is still floor-class, channel1 needs physical link gain
or a cabled phone-path calibration; baseband power [interface-redacted] is no longer a useful
remote branch.
