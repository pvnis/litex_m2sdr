6 dB is insufficient at the current antenna-side path loss. CP2413 already
consumed the safe global baseband headroom; CP2414 proved no lower hardware-
attenuation axis exists; CP2415 closed config-only SSB power. Do not continue
software power escalation or threshold [interface-redacted].

The phone branch is now physically gated. Improve the channel1 Band-3 path
before another phone attempt: reduce antenna-to-phone path loss, use a known
Band-3-matched antenna/coupler, or establish a calibrated shielded/cabled
coupling path. Re-baseline first with the CP2409/CP2410 partial-write-safe
TX1-to-RX2 PBCH replay at gain56. A physical change is accepted only when that
independent control produces PBCH/CSI; then rerun the unmodified CP2401 phone
binary/backoff10 first, keeping the CP2416 boost as diagnostic-only.

CP2409's TX0/TX1 observation delta was `24.73 dB`, but TX0 clipped, so it is a
directional severity indicator rather than a calibrated required-gain number.
