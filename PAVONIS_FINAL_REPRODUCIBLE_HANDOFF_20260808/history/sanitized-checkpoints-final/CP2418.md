# CP2418: Custom gNB cleanup and self-kill protection pass no-RF

Date: [date-redacted] Europe/Zurich
RF transmitted: no

## Result

CP2417's residual process is traced to the mature stop helper matching only the
active build-tree gNB path. Separate phone/diagnostic binaries such as
`gnb.cp2416_phone_ch1_ssbboost -c .../gnb-run.yml` were not selected when their
command line did not contain the run tag.

The stop helper now:

- matches any executable basename beginning with `gnb` only when it has the
  exact gNB config shape `-c .../gnb-run.yml`;
- excludes its complete ancestor PID chain, including PID 1;
- excludes its direct process-inspection children and the `ps/awk/sort/uniq`
  tooling, preventing tag text in helper command lines from selecting the
  observer itself;
- adds bounded KILL fallback and a final no-survivor assertion.

This also closes the long-standing CP1945-family self-kill mechanism in this
stop helper: excluding only `$$` was insufficient when an SSH/helper ancestor
contained the tag.

The fixture deliberately required TERM, exercising more than the initial
matcher.
