# CP2427: TX2 gateware channel-mask fix passes the no-RF gate

Date: [date-redacted] Europe/Zurich
RF transmitted: no

## Change

`LiteXM2SDRStreaming.cpp::activateStream()` no longer uses `0x1` for every
single-channel stream. It derives `CSR_AD9361_CH_EN` from the stream's selected
channel indices:

- channel 0 only: `0x1` (unchanged)
- channel 1 only: `0x2` (fixed from `0x1`)
- channels 0 and 1: `0x3` (unchanged)

This matches the invariant that DMA frames always contain channel A and B
lanes, while Soapy channel selection controls which lane receives samples.
