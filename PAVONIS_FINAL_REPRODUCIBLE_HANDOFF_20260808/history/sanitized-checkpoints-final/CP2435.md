# CP2435: Live gNB remains PBCH-incoherent on TX2 after the lane fix

Date: [date-redacted] Europe/Zurich
RF transmitted: yes, one bounded paired phone/capture run

## Validity

The exact CP2434 fixed-module phone shape was paired with independent 250 ms
bladeRF RX1/RX2 captures at gain36. Channel1 propagation, phone controller,
both captures and fetches, both one-shot analyzers, both 847-window aligned
sweeps, realtime gates, and cleanup all pass. TX health is zero timeout,
downlink-late, release-late, and error, with final stream deficit zero. The one
recovered 480-sample partial-return deficit repeats CP2434.

## Result

| Metric | RX1 | RX2 |
| --- | ---: | ---: |
| RMS | `-42.41 dBFS` | `-33.06 dBFS` |
| component max | `195` | `668` |
| clip count | `0` | `0` |
| one-shot PBCH/CSI | none | none |
| aligned PBCH CRC OK | `0/847` | `0/847` |
| aligned CSI PCI1 | `0/847` | `0/847` |

RX2 has a clear `9.35 dB` level advantage over RX1 and time-varying scheduled-
scale energy, but none of the captured windows has a recognizable PCI1 SSB.
The phone independently remains no-cell across 46 rows, with zero private
PLMN, service, NR, or cellular IP; gNB PRACH and RAR remain zero.

The matched fixed-lane helper control CP2432B used the same TX2/RX2 ports,
ATT5, gain36, sample rate, and source waveform class and produced
`-30.34 dBFS`, max611, zero clips, CSI PCI1 `+5.2 dB`, and PBCH CRC OK. The
live capture is only `2.72 dB` lower in aggregate RMS and reaches a comparable
component maximum, so this is not a simple link-budget loss.

## Verdict

The current phone blocker lies in live timed/cadence presentation below the
host-visible gNB waveform, not in TX2 lane selection, physical RF power,
bladeRF gain, or handset settings. This is the fixed-lane form of the historical
helper-vs-live split, now demonstrated directly on the actual phone RF port.

Stay no-RF next. Compare the CP2435 all-timed worker path and its single
recovered partial return with CP2432B's continuous helper path at the source and
descriptor/copy level. Confirm that every live worker copy uses the corrected
1R1T frame lane and identify whether timed descriptor boundaries or the
partial-remainder path can still alter sample continuity. Do not repeat power,
gain, antenna, or phone-setting sweeps.
