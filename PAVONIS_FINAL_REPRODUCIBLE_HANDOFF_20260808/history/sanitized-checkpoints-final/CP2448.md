## Verdict

The current stack does not reproduce CP1666's clean 1 ms one-anchor behavior.
The difference is no longer an unpropagated wrapper value or deadline-write
policy: the live producer/Soapy path itself still misses deadlines at 1 ms.
Do not revive the timeout retry/carry/deadline family: CP1695-CP1715 already
showed those policies either retain deficits, build stale SI-era backlog, or
drop/abandon nearly the stream.

Next use the clean 20 ms one-anchor shape and capture scheduled SSB slots at the
bounded lower-PHY tap. Decode those files offline and compare against external
RX2. A clean lower-PHY SSB with air-side PBCH absent localizes the active defect
below lower-PHY generation without another backpressure policy.
