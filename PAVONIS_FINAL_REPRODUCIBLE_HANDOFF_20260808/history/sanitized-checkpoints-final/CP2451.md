## Change

The CP1807 controller now has one narrow prearm branch after successful gNB TX
readback and before the delayed hold:

- requires both `PAVONIS_GNB_ONLY_STOP_BEFORE_UE=1` and
  `PAVONIS_DL_SLOT_CAPTURE=1`;
- touches and verifies only `PAVONIS_DL_SLOT_CAPTURE_ARM_FILE`;
- emits `DL_SLOT_CAPTURE_STOP_BEFORE_UE_PREARM=PASS`;
- leaves the shared PRACH arm, UL-symbol arm, RX-append arm, and UE-start path
  untouched.

The existing stop-before-UE log now explicitly says it leaves the shared ARM
untouched. With capture disabled, control flow is unchanged. Normal UE ladder
runs continue using their existing combined prearm branch.
