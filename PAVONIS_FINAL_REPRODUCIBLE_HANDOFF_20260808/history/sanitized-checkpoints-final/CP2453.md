## Existing hook

`radio_soapy_tx_stream` already provides a default-off accepted-write dump:
`PAVONIS_SOAPY_TX_WRITE_DUMP_CF32_PATH`. It records the exact selected logical
port after OCUDU chunking and CI16-to-CF32 conversion, using only samples
accepted by `writeStream()`. `MAX_SAMPLES` caps the sample conversion/file
writes; leaving the metadata path empty avoids per-write metadata I/O for the
rest of the run.

The next cap is `241920` samples, exactly 21 ms at 11.52 Msps. This spans at
least one full 20 ms SSB period plus boundary margin while limiting the dump to
about 1.85 MiB. It is bounded/event-limited and does not add new hot-path code.
