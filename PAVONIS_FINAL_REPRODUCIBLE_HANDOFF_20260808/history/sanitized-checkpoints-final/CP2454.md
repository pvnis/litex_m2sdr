# CP2454: Live SSB is clean through OCUDU's accepted-write boundary

Date: [date-redacted] Europe/Zurich  
RF transmitted: yes, bounded private-lab gNB-only run

## Shape and gates

The run repeated CP2452's healthy phone-TX shape on logical port0 mapped to
physical M2SDR TX2/RX2: one timed anchor, `20 ms` lead, all-timed off,
deadline-write on, power-sign compatibility on, dedicated lower-PHY SSB capture
prearmed, and no UE process. The only addition was the CP2453 accepted-write
CF32 dump on logical port0, capped at `241920` samples (`21 ms`).

Runtime channel/timing propagation passed. TX health remained valid:

- Soapy timeout/error/downlink-late lines: `0 / 0 / 0`
- final stream deficit: `0` samples
- accepted-write dump: exactly `1935360` bytes (`241920` CF32 samples)
- lower-PHY capture: exactly `64` files, each `11520` CI16 samples

## Decoder results

All `64/64` bounded lower-PHY SSB-slot files decode PBCH CRC OK for PCI1. Every
file has `search_t_offset=1650`; decoded MIB fields remain the expected SCS15,
CORESET0 index0 and SearchSpace0 index0, with SFN progressing consistently
with the captured slot sequence.

The exact accepted-write CF32 dump also decodes directly:

```text
measure pci=1 snr=+72.2 dB cfo=+0.0 Hz
search t_offset=139740 pci=1 crc=OK
MIB sfn=805 ssb_idx=0 scs=15 coreset0=0 ss0=0
```

The simultaneous independent bladeRF RX2 capture remains externally blind:
`-32.68 dBFS`, component max `663`, no clipping, `0/847` PBCH and `0/847` CSI
PCI1 windows. The phone monitor has `46` rows with no private PLMN, service,
NR, or cellular IP state.

## Verdict

The live waveform is valid at both the lower-PHY output and the exact OCUDU
logical-port stream accepted by `writeStream()`. The defect is therefore after
OCUDU chunking and CI16-to-CF32 conversion. Remaining locations are the LiteX
Soapy plugin's conversion/framing/submission path, kernel/gateware timed-DMA
presentation, or RF emission. This does not justify another lead,
backpressure, attenuation, or phone-setting sweep.

## Next

Use the existing bounded LiteX plugin input and post-framing DMA dump hooks in
one otherwise identical run. Decode the pre-plugin SC16 stream and reconstruct
physical lane1 from the DMA buffers using their metadata. A clean plugin input
but bad lane1 identifies plugin framing; a clean lane1 with dead RX2 moves the
fault below DMA framing/visibility and makes descriptor/timestamp presentation
the next discriminator.
