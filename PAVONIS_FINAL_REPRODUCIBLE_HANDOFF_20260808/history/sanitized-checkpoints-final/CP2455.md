## Existing hooks

The deployed LiteX Soapy module already contains two default-off bounded hooks:

- `M2SDR_SOAPY_TX_DUMP_PATH` records plugin input as SC16 and emits one compact
  JSONL row per accepted fragment, capped by `M2SDR_SOAPY_TX_DUMP_SAMPLES`.
- `M2SDR_SOAPY_TX_DMA_DUMP_PATH` records exact framed DMA buffers plus metadata
  containing header/timestamp, `numElems`, channel count, sample width and zero
  padding, capped by `M2SDR_SOAPY_TX_DMA_DUMP_BUFFERS`.

No plugin source, gNB source, or runtime policy was changed. For the next run,
the input cap is `241920` samples (21 ms) and the DMA cap is `256` buffers,
enough to cover more than one 20 ms SSB period at the current full-buffer
geometry while remaining bounded.
