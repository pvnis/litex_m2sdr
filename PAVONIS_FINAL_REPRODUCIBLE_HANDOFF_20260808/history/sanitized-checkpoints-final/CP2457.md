## Patch

The LiteX Soapy `writeStream()` fresh-buffer branch now advances the caller
source pointer by `samp_avail`, then invokes `interleave()` with offset zero so
the newly acquired DMA destination starts at frame zero. The patch adds one
format-aware pointer helper and changes only that fresh-buffer call.

The contiguous-untimed CP2074B behavior, one-channel/TX2 selection, SC16-to-
SC12 conversion, timed headers, worker queue, and all dump hooks are unchanged.
