## Untimed `timeNs` audit

The live/helper trace difference in source/release `timeNs` cannot affect the
current untimed transmit path. In source `06244497...`:

- the worker calculates a timing offset, reads hardware time, and records late
  state only under `pkt->flags & SOAPY_SDR_HAS_TIME` with positive `timeNs`
- `_dmaReleaseWrite()` writes timestamp samples only when HAS_TIME remains set;
  every untimed DMA header receives timestamp zero
- the existing timed-TX gateware sends an untimed descriptor directly to
  STREAM without comparing its timestamp

This closes advancing live `timeNs` as an executable pre-DMA scheduling or
FPGA-arbiter difference for CP2468 versus CP2471.

## Startup-arm gate

CP2246 previously used `:-`, so an explicit empty worker-arm override was
replaced by its historical RAR-event arm. Its assignment now uses `-`:

```bash
${M2SDR_SOAPY_TX_WORKER_TRACE_ARM_FILE_OVERRIDE-/tmp/pavonis_cp2246_rar_tx_worker_${STAMP}.arm}
```

This preserves all three intended states: unset selects the historical arm,
explicit nonempty selects a diagnostic arm, and explicit empty disables arm
gating so the already-existing metadata trace opens at stream startup. CP2209
and CP2188 already preserve an explicit empty override. No source module,
binary, waveform, power, timestamp, buffer, or scheduler behavior changes.
