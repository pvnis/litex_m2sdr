## Patch

`M2SDR_SOAPY_TX_ZERO_COPY_PRIME_BUFFERS` valid buffers have been published.
The env value is read and cached once, is clamped to the runtime ring size, and
defaults to `1`. Default1 executes the historical condition on the first
released buffer, so the disabled path preserves deployed behavior.

The frozen wrappers validate `1..256`, propagate and record the value, and
CP2395 process-proves it before capture. Unset defaults to1. No waveform,
timestamp, scheduler, power, gateware, gNB binary, or phone setting changes.

## Acceptance gate

Run one bounded force-continuous1 TX2/RX2 diagnostic with zero-copy1,
prime128, and a 65,536-row startup trace. Require process proof and marker,
CP2047 descriptor health, reader disabled through row126 then enabled on
row127, no reader-lap handle jumps after enable, normal TX health, and external
PBCH/CSI recovery. A failure to remove jumps rejects priming as insufficient;
a jump-free but PBCH-negative result moves the fault beyond stale-loop replay.
