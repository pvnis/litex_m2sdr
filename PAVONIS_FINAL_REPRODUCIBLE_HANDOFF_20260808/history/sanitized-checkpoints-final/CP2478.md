# CP2478: Prime128 works mechanically but startup trace still induces laps

Date: [date-redacted] Europe/Zurich
RF transmitted: yes, bounded private-lab TX2/RX2 acceptance run

## Configuration and health

Process proof and the live marker confirm zero-copy1/prime128. The frozen shape
uses channel1/TX2, ATT5, all-timed0, force-continuous1, 20 ms configured offset,
deadline-write1, and a 65,536-row startup trace. Controller/capture/monitor/
analysis/cleanup pass; binary-safe timeout, downlink-late, and release-late
counts are zero.

## Prime behavior

The implementation behaves exactly as specified. Rows0..126 report the reader
disabled, and handle127 enables it after 128 valid descriptors at 24.173 ms.
CP2047 passes descriptor shape with zero HAS_TIME, short, late, or dedup rows.

Prime128 materially reduces but does not eliminate reader laps under startup
trace load. There are 74 resync jumps skipping 872 handles, versus CP2474's
122/1204. The first is at handle248/46.100 ms and the last at
handle7105/654.380 ms. The remaining 5.260 seconds of the trace are jump-free.

## RF and phone

RX2 remains `-32.26 dBFS`, max681, unclipped, `0/847` PBCH/CSI. One phone row
reports NR_SA mode, but it is OUT_OF_SERVICE with invalid NR signal and no
private PLMN; it is not cell detection. The other ladder metrics remain zero.

## Verdict

Prime128 fixes the intended enable point and confines the stale-loop class to
startup, but this trace-bearing run does not recover RF. It does not yet reject
priming: the metadata trace is the direct throughput delta relative to the
desired production run, and its first 0.654 s still contains 872 stale-buffer
insertions that can perturb stream state.

Repeat the exact prime128 shape with the worker trace behind an untouched arm
file. If PBCH recovers, prime128 becomes the production fixture and a later
short diagnostic can prove normal untraced health indirectly. If it remains
negative, priming/stale-loop cleanup is insufficient and the next discriminator
is actual same-device post-reader RF capture rather than a larger prime.
