# CP2480: Phone-channel1 immediate self-RX discriminator gated no-RF

## Purpose

CP2479 remained externally RF-blind but did not prove that the prime128 reader
activated. Reuse the CP2271 same-device readStream discriminator on the current
phone binary and physical M2SDR channel1, without changing any RF default.

## Changes

The CP1807 local controller now forwards three already-supported controls to
the detached [host-redacted] process: immediate RX append, forced RX center, and RX
bandwidth. The detached starter exports the latter two into the generated gNB
runner. Empty values remain inactive according to OCUDU's existing optional
frequency/bandwidth parsers.

A dedicated bounded runner fixes the intended CP2481 shape:

- phone gNB and physical channel offset1;
- zero-copy1, prime128, force-continuous1, all-timed0;
- immediate 2,880,000-sample/250 ms readStream append on logical port0,
  which maps to physical RX2;
- RX center `1839650000 Hz`, rate `11.52 Msps`, bandwidth `7.68 MHz`;
- 256 startup worker rows, enough to prove handle127 reader activation while
  avoiding CP2478's 65,536-row observer load;
- concurrent established bladeRF RX1/RX2 capture for an external comparison.

## No-RF proofs

Both modified wrappers and the dedicated runner pass `bash -n`. The dedicated
runner exits rc2 before any remote or RF action unless
`PAVONIS_CP2480_RF_APPROVED=1` is present. No gNB, plugin, scheduler, gain, or
RF default changed in this checkpoint.

## Acceptance

CP2481 must prove channel1 RX readback at the requested DL center/rate/BW and
prime128 reader activation. Same-device PBCH pass places the remaining failure
outside the M2SDR TX path; same-device PBCH failure keeps the fault below the
host-visible DMA boundary. External PBCH is judged separately.
