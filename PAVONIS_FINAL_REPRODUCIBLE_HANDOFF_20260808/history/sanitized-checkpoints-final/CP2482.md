# CP2482: Inherited self-RX instrumentation values preserved no-RF

## Root cause

CP2481's force-center/BW controls reached physical RX2 correctly, but the
historical CP2188 wrapper hard-set append-enable to `0` and worker trace limit
to `65536` after the CP2480 runner supplied `1` and `256`.

## Change

Only those two CP2188 assignments now use inherited-or-default forms. Unset
runs retain the historical `append=0`, `trace_limit=65536` shape. Explicit
callers can select bounded diagnostic values without adding a new policy or
changing any gNB/plugin binary.

- Unset expansion: `trace_limit=65536`, `append_enable=0`.
- Explicit expansion: `trace_limit=256`, `append_enable=1`.
