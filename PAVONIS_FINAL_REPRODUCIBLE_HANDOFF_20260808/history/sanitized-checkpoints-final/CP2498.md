# CP2498: CP2497 on-air SIB1 is proven no-RF

The exact CP2497 external RX1 capture contains an end-to-end decodable MIB,
SI-RNTI DCI, and SIB1/PDSCH. This moves the phone frontier above broadcast
waveform availability.

## Baseline SI audit

The CP812 result provides:

- PCI `1`, PBCH CRC OK;
- MIB SFN `950`, CORESET0 `0`, SearchSpace0 `0`;
- `cellBarred=notBarred`, intra-frequency reselection allowed;
- PBCH timing origin sample `1581169`.

The validated CP2027 live-SearchSpace0 sweep over the 250 ms capture tests 50
slot/timing probes. It finds the expected SI-RNTI DCI in five probes, with ten
PDCCH CRC-OK rows and maximum correlation `0.849`. The baseline file harness
does not decode PDSCH because the independent bladeRF capture retains a bulk LO
offset; median PDSCH DMRS CFO is about `-1.4 kHz`.

## Bulk-CFO control

The previously validated CP2048 full-snippet control sweeps
`-4000..+4000 Hz` in 250 Hz steps, with all PDSCH-stage ramp overrides unset.
Across five DCI-positive windows:

- trials: `165`;
- DCI found: `154/165`;
- PDSCH/SIB1 CRC OK: `55/165`;
- windows with at least one SIB1 decode: `5/5`;
- every window decodes at every correction from `-3000` through `-500 Hz`.

At the representative `-1750 Hz` correction, the best timing window has:

- PDCCH CRC OK, correlation `0.855`, residual CFO `-23.7 Hz`;
- SI grant on PRBs `0..7`, symbols `2..13`, TBS `80 B`;
- PDSCH DMRS CFO `+6 Hz`, SNR `20.3 dB`, EVM `0.41`;
- PDSCH/SIB1 CRC OK in one iteration.

The live gNB log also proves `PAVONIS_GNB_SI_PDSCH_POWER_SIGN_COMPAT active`.
The required correction is a normal inter-device capture offset already shown
by CP2048, not an on-air phone workaround; a live modem performs its own CFO
tracking.

## Tooling note

Two append-only attempts are tooling-void and retained. The first resolved the
UE test path relative to the artifact directory. The second misread CP2028's
`--analyzer` option as the UE binary rather than the CP2027 Python analyzer.
The successful run invokes CP2027 directly with the same CP2028-generated
manifest and the absolute validated UE-test path. No IQ or timing input changed.

## Decision

Raw SSB/PBCH and over-air MIB/SIB1 are now proven on the physical channel1
phone signal. Do not [interface-redacted] gNB power, timing, SI thresholds, or payloads.

Next audit the Android modem's actual Band-3/NR-SA scan and cell-selection state
read-only, including bounded radio-buffer evidence. Then run one clean
append-off phone attempt with that bounded modem trace. The splitter is now
"modem did not scan/consider n3" versus "modem considered the cell and rejected
it for a stated selection/registration reason."
