# CP2499: Android NR-SA state audit no-RF

The read-only Android audit confirms that the modem and user policy are not
globally NR- or SA-disabled, but the phone's concrete NR cell state is not the
Pavonis Band-3 cell.

## Current state

- ADB remains authorized on CPH2409 / Android 14.
- User allowed-network types include NR.
- Preferred network modes remain `23` and active-sub `33`.
- Airplane mode is off; mobile data is on.
- Vendor state has `persist.radio.is_vonr_enabled_0=true`.
- Telephony reports data RAT `20 (NR_SA)` while out of service.
- The WWAN PS registration entry is `DENIED` on NR for private PLMN [network-id-redacted].

The only concrete Android NR identity is:

- PCI `1`, TAC `1`, PLMN [network-id-redacted];
- NR band `78`, NR-ARFCN `623712`.

That is not Pavonis, which is band n3 with DL ARFCN `368500` and SSB ARFCN
`367930`. Other registration fields remain invalid sentinels, and the current
NR signal-strength object is invalid. This n78 identity may be stale or another
private `SENS` lab cell; it is evidence that the modem supports SA and has
considered an `00101` NR cell, but it is not evidence that it scanned or
rejected Pavonis n3.

Android exposes no carrier-NR config rows through `cmd phone cc get-value` on
this build. The CP2497 radio-log interval is no longer retained, so it cannot
resolve scan versus rejection retrospectively.

## Tooling notes

The first collector attempt stopped when the unsupported carrier-config query
returned nonzero under `pipefail`. The script now treats unsupported read-only
sources as optional. One corrected invocation used an output name rejected by
the script's safety pattern and made no artifact. The final fresh invocation
completes and is redacted. No phone setting, modem state, log buffer, or RF
configuration changed.

## Decision

Run one clean append-off phone attempt with the frozen CP2497 TX shape. Clear
only the Android radio diagnostic buffer immediately before the run and dump it
immediately afterward through a bounded/redacted parser. Judge whether n3/
ARFCN368500 is scanned or considered and, if so, capture the exact NAS/RRC/
registration rejection. Do not change the cell, power, PLMN, SIM, APN, or phone
network-selection settings in that run.
