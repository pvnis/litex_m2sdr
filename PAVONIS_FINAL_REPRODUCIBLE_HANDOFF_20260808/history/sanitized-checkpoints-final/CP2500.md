# CP2500: Clean append-off phone radio trace gated no-RF

The next phone discriminator is gated without transmitting RF. It preserves the
CP2497-proven phone-gNB TX shape:

- physical channel offset1, TX attenuation 5 dB;
- all-timed off, force-continuous on, 20 ms TX lead;
- deadline writes on;
- LitePCIe zero-copy on, copy prime8, zero-copy prime128;
- bounded 256-row startup worker trace.

The sole runtime change from CP2497 is `PAVONIS_SOAPY_RX_APPEND_ENABLE=0`, so
the run is no longer observer/detection-void. The controller verifies that
append-off and the frozen TX values are present in the live gNB environment.

Before startup it clears only Android's radio diagnostic buffer. It does not
change RATs, bands, selection mode, SIM, APN, airplane mode, data state, or any
modem setting. No process polls the buffer during RF. After the bounded run, a
deployed helper captures the radio buffer once, records compact keyword counts,
retains at most 600 relevant redacted lines, and appends a bounded telephony
service-state snapshot.

Syntax, usage rc2, closed RF gate rc2, atomic remote deploy, remote hash, ADB
device state, and remote usage rc2 all pass. No production binary, plugin,
gateware, gNB source, or RF default changed.

Run CP2501 once with a fresh stamp. Judge first on private-PLMN/NR/service rows,
then on whether the radio evidence names n3/368500 or an explicit rejection.
