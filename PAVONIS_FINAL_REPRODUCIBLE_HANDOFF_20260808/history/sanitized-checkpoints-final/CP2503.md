editing the established CP2500 runner or any production component. It requires
the phone's exact CP2502 full-RAT mask before doing anything, clears only the
radio diagnostic buffer, sets slot0 to NR-only, and proves the `NR` readback
before starting the gNB.

The gNB remains physical offset1, TX attenuation 5 dB, all-timed off,
force-continuous on, 20 ms lead, deadline writes, LitePCIe zero-copy, copy
prime8, zero-copy prime128, and full RX append off. Radio evidence is collected
once while the phone is still NR-only. Normal exit, errors, SIGINT, and SIGTERM
all run the restore path, which restores binary mask
`[hex-value-redacted]` and requires both preferred-mode mirrors to read 33.

Shell syntax passes, the closed RF gate returns rc2 before any phone access,
and static gates prove the NR-only/full masks, restoration traps, append-off,
and explicit CP2503 approval flag. CP2502 already exercised the same set/read/
restore commands against the live device and proved exact restoration. No RF,
phone setting, source, binary, plugin, core, or subscriber changed in this
checkpoint.
