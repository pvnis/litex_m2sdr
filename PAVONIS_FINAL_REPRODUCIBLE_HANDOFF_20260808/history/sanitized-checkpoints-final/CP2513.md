# CP2513: Read-only NR-only operator scan gated no-RF

`cp2513_run_phone_nr_only_operator_scan.sh` composes the frozen CP2503/CP2506
NR-only phone shape with the CP2512 remote screen control. It waits for the
existing live gNB propagation proof, verifies automatic selection, opens the
standard OnePlus operator screen, and captures twelve UI trees at ten-second
intervals. It sends no tap, does not toggle `Auto-select`, and does not select
a carrier.

The underlying CP2503 runner remains the sole owner of the NR-only state and
trap-restores the exact full RAT mask. The new wrapper additionally requires
at least eight valid TeleService snapshots plus automatic selection and the
full RAT mask after the run. It uses only the known-good
`[host-redacted]@[host-redacted]` route.
