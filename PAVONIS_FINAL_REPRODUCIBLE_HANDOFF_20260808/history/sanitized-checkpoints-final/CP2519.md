# CP2519: Carrier-policy shell override remains permission-blocked

The bounded read-only audit confirms the exact active split: Android default
`carrier_nr_availabilities_int_array=[1,2]`, OnePlus MCC/MNC00101 value `[1]`,
and null persistent/runtime overrides. `com.android.carrierconfig` is the
enabled-default system package at
`/system_ext/priv-app/CarrierConfig/CarrierConfig.apk`.

This Android build advertises `cmd phone cc get-value/set-value/clear-values`,
but even `get-value` returns `cc: Permission denied.` for the authorized shell.
That surface is not usable and no write was attempted. The only remaining
standard reversible remote discriminator is package-manager fallback: put the
CarrierConfig package in `disabled-user`, observe effective config, and restore
its exact original `default-state` in a trap. Gate that transaction separately
and keep RF off.
