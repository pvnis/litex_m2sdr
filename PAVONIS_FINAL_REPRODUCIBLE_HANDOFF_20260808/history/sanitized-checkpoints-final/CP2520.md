# CP2520: Trap-restored CarrierConfig fallback transaction gated no-RF

`cp2520_test_carrierconfig_fallback_remote.sh` is a no-RF package-state
transaction for the authorized phone. It requires a separate approval flag,
records the original package/config/selection/RAT state, attempts standard
`pm disable-user`, and installs an EXIT/INT/TERM trap that restores
`pm default-state --user 0 com.android.carrierconfig`. It verifies the exact
original enabled state, automatic selection and full RAT mask after restoration.

The test does not reboot, transmit, alter the immutable APK, use root, or call
the permission-blocked carrier-config override API. Shell syntax and the closed
package-state gate pass. Execute once on [host-redacted]; a denied disable cleanly
closes the route, while a successful default-only interval determines whether
Android's `[1,2]` fallback is available for a later separately gated RF run.
