# CP2522: Boot-time CarrierConfig fallback transaction gated no-RF

`cp2522_test_carrierconfig_reboot_fallback_remote.sh` performs the remaining
phone-policy discriminator entirely on [host-redacted]. It requires USB power and at
least 20% battery, disables CarrierConfig, reboots and measures the boot-time
effective NR values, restores exact package `default-state`, reboots again, and
requires original package state, automatic selection and full RAT mask.

EXIT/INT/TERM/HUP all run recovery. If interrupted during a phone reboot, the
trap waits for ADB, restores package state, and performs the required recovery
boot. No gNB/RF process is started. The script changes no APK, credential,
carrier XML, network selection, or RAT setting. Syntax and the closed reboot
gate pass.

Execute once. `FALLBACK_DEFAULT_ONLY=1` unlocks a separately gated frozen
NR-only operator/attach run with the package disabled for that boot; zero
closes this remote fallback and requires an operator decision on SIM/firmware.
