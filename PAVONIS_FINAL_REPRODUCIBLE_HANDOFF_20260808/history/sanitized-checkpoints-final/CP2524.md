# CP2524: User-0 CarrierConfig uninstall fallback gated no-RF

`cp2524_test_carrierconfig_user_uninstall_remote.sh` is the final reversible
remote policy fallback. It uses standard `pm uninstall -k --user 0`, preserving
the immutable system APK and package data, then reboots and measures whether
only Android default `[1,2]` remains. It restores with
`cmd package install-existing --user 0`, exact `default-state`, and a recovery
boot.

EXIT/INT/TERM/HUP recovery, USB/battery/ADB preconditions, automatic/full-RAT
postconditions, syntax and closed gate pass. No gNB/RF, root, APK change,
credential change, carrier XML write, or network-selection action is involved.
Execute once. Success of default-only fallback unlocks a separate frozen RF
run; failure exhausts safe remote firmware-policy controls.
