# CP2542: Runtime userdebug zygote read control gated

The remaining read-only discriminator is prepared without execution. The phone
uses `zygote64_32`; `com.android.phone` and `system_server` are children of the
primary `zygote64`, while ADB is init-managed separately.

The default-closed helper starts only from `user`, full RAT, both mode33, and
the expected zygote layout. It sets runtime-only `ro.build.type=userdebug`,
requests a primary zygote restart, and requires distinct new PIDs for
`zygote64`, `system_server`, and `com.android.phone` plus a functional
telephony read. It then performs one CarrierConfig read and no write.

Recovery sets runtime `ro.build.type=user`, restarts the primary zygote again,
requires the same three PID transitions and telephony readiness, then proves
cc is denied, full RAT is restored, and both mode keys are33. EXIT/INT/TERM/HUP
all invoke that recovery while the temporary state is active.

Local and [host-redacted] syntax/hash/closed-gate checks pass at SHA-256
`50d3f3bbfc85f13cf7ebc3ff9c4066cbd542418ff34ed303e7d8d5ed4f06f33d`.
No RF, restart, property change, or config write occurs here. Execute once
no-RF with `PAVONIS_CP2542_ZYGOTE_READ_APPROVED=1`; do not write a value until
the read and restoration pass.
