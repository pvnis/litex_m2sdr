# CP2548: NGRAN-aware manual PLMN retry is gated no-RF

The CP2547 ambiguity is removed in the revised Binder helper. Manual syntax
now accepts an explicit RAN and constructs the phone's live four-argument
`OperatorInfo`; the bounded run requests `persist=true`, matching the stock
OnePlus operator flow, and RAN 6 (`NGRAN`). The helper still reports the Binder
boolean, but mode 2 is the hold criterion so a vendor return-value mismatch
cannot cause another immediate controller restore.

The live no-RF constructor probe passes without calling manual selection:

```text
OperatorInfo SENS/SENS/00101/UNKNOWN/6/1/null/null
```

Deployment and disabled-path gates pass. The root-only device jar is
`root:shell 600` and hash-matches `66e82f1f...`; the remote control matches
`fbcfa2bc...`. Get/automatic/get remains mode 1 throughout, build remains
production `user`, full RAT includes NR, both mode keys remain 33, and the
closed RF gate exits 2 without creating run artifacts.

One fresh bounded RF retry is unlocked. The mandatory live proof is a radio
request with `operatorNumeric=00101, ran=6`; hold manual mode for the complete
observation window even if the Binder boolean is false, then perform the same
automatic/full-RAT restoration. Judge non-empty PRACH/Msg1 first.
