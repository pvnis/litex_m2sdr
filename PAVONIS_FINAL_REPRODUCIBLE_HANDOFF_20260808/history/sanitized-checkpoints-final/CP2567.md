helper pair, not the older CP1660/CP1733 pair modified in CP2565. The same
default-off calibration passthrough is now implemented in the actual live
pair:

rebuilt.

normal [host-redacted] staging path and run twice with `PAVONIS_GNB_CONFIG_ONLY=1`:

  `04ea3f95fe27721cff3619d5fbefbcaa877fb9b2e7b479af0134bbd4735d70c7`.

The complete config diff contains exactly one inserted line:

```yaml
  clock_ppm: -0.548059701
```

Both configs parse with the deployed CP2401 phone gNB binary under
`--dryrun`, return zero, and open no radio. The disabled hash exactly matches
the CP2565 disabled config, so this port introduces no baseline YAML drift.

## Decision

Repeat only the CP2566B calibrated RX1 capture with a fresh stamp and
`-0.548059701 ppm`. Before interpreting CFO, require three propagation proofs:
the CP1807 sequence log contains the requested value, the packaged generated
YAML contains the exact `clock_ppm` key, and runtime TX readback/log shows the
calibrated center presented to Soapy. Keep every other run variable frozen.
