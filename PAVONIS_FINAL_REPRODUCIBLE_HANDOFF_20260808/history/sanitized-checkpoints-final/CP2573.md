## Objective

After CP2572 closed coherent clock calibration as a standalone phone Msg1
fix, identify one specific handset-policy discriminator that has not already
been exhausted and can be implemented without changing the CP2392 golden
srsUE path.

## Current phone state

Read-only ADB shows:

- active SIM/operator: `00101` / `SENS`;
- no currently registered operator;
- mobile data enabled for the active subscription;
- `data_roaming6=0`;
- full RAT/mode33, automatic selection, and voice true/true remain restored.

Data roaming cannot explain failure on the present home-PLMN shape because the
SIM and RAN both use `00101`. It becomes relevant only if the RAN PLMN differs
from the SIM PLMN.

## External provenance

Official srsRAN COTS documentation provides a concrete OnePlus-specific
alternative:

- the tested OnePlus Nord 5G n3 setup uses IMSI PLMN [network-id-redacted] with gNB PLMN
  [network-id-redacted] and notes that the phone appears not to like a test PLMN;

## Local feasibility

CP2572's generated gNB YAML has exactly two serving-PLMN locations:
`cu_cp.amf.supported_tracking_areas[0].plmn_list[0].plmn` and
`cell_cfg.plmn[network-id-redacted]00101`. The active OTA-stage script starts
qcore with hard-coded `--mcc [network-id-redacted] --mnc [network-id-redacted]`. The private subscriber file is
separate and can retain the phone's `00101...` IMSI and credentials while
qcore derives NAS serving-network authentication from `901/70`.

The clean implementation is default-off and isolated:

1. Add an optional generated-gNB PLMN override to the CP1807 phone path,
   changing both YAML fields only when set.
2. Add an optional OTA-stage script path override to CP1807.
3. Deploy a separate CP2574 OTA-stage copy that accepts validated qcore
   MCC/MNC values; leave the repository's normal stage script untouched.
4. Wrap CP2552 with a trap-guarded `data_roaming6: 0 -> 1 -> 0` transaction.
5. Prove disabled YAML byte identity, enabled two-field YAML diff, qcore
   command construction, gNB dry-run, and phone roaming restoration before RF.

## Verdict

The `SIM 00101 + serving PLMN [network-id-redacted] + data roaming on` branch is the first
specific, externally grounded OnePlus policy discriminator not already tested.
Proceed with the no-RF default-off gate. No RF is approved by this checkpoint
until disabled-path identity and all restoration proofs pass.
