# CP2592: Oplus production operator scan passes its no-gNB control

Date: [date-redacted] Europe/Zurich

## Production-path control

With the private gNB off, the standard Oplus SIM settings path reaches
`com.android.phone/.OplusNetworkSetting`, displays `Searching`, completes, and
renders a real operator list:

- `Sunrise 4G`
- `Salt 4G(Forbidden)`
- `Swisscom 4G(Forbidden)`
- `Salt 3G(Forbidden)`

This proves the phone's production asynchronous scan works and renders
forbidden state. It is materially different from CP2591's rejected deprecated
API. Entering the page leaves its auto-select switch off; the control therefore
explicitly restores ITelephony automatic mode1 and returns home. Restoration
passes.

## Source audit

The live TeleService source confirms `OplusNetworkSetting` constructs
`NetworkScanHelper` and calls `startNetworkScan(2)`, consumes `CellInfo`
callbacks, converts each result to `OperatorInfo`, applies the actual USIM
forbidden-PLMN list, logs the full numeric cell list and each resolved state,
then renders 2G/3G/4G/5G labels. Slot extra `subscription=0` maps to live subId
6. This path provides the classification CP2587 requested.

## CP2593 gate

A bounded remote controller now launches the direct exported component, waits
up to 180 seconds for both `Network scan complete` and the rendered list,
captures the compact UI titles plus numeric/state source logs, and restores
automatic selection in its own trap. The outer wrapper:

- pins exact CP2577 and leaves its RF/policy semantics unchanged;
- changes only hold/monitor duration to 300/270 seconds;
- fresh-stamps every artifact and deploys/hash-checks the remote controller;
- waits for n3, roaming-on, and voice-off before opening the operator page;
- requires the scan to complete and automatic mode restoration before waiting
  for normal CP2577 cleanup;
- has an independent outer automatic-selection restore on abnormal exit.

Local/remote `bash -n`, direct activity resolution, deployed hash, automatic
mode1, and default-closed rc2/zero artifacts all pass. ShellCheck is
unavailable. Run CP2593 once; classify Pavonis from the Oplus numeric/state log
and UI result. Do not issue a manual selection in the same run.
