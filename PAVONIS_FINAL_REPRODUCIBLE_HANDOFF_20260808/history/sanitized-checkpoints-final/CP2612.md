## Wrapper rc1 classification and repair

The top-level CP2611 wrapper exited rc1 only after the RF run because its final
invariant required `PAVONIS_ALLOW_EXTENDED_RA_RESP_WINDOW=0`, while the old
CP2188 ladder layer unconditionally reset it to1. The nested CP2606 runner
returned rc0 and its structured YAML/hash assertions passed.

The variable is read only in OCUDU's RA-response-window validator; it does not
modify the broadcast or runtime RA configuration. Response window10 is valid
without the bypass, so this propagation mismatch cannot alter the CP2612 Msg1
verdict. CP2188 now preserves an explicit caller value while retaining default1:

```bash
export PAVONIS_ALLOW_EXTENDED_RA_RESP_WINDOW="${PAVONIS_ALLOW_EXTENDED_RA_RESP_WINDOW:-1}"
```

The repaired CP2188 wrapper passes `bash -n` and has SHA-256
`e0d85c23e323e79c8d6071a533d78d73d94b4e9ae4d1f190995cba80158e3a3d`.
