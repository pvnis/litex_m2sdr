## Remaining Pre-Msg1 Mismatch

CP2616 exhausted the known OnePlus identity and common-RACH fields. CP2618
then proved the reciprocal TX2/RX2 OTA path. A full source-level SIB1 comparison
finds one remaining pre-Msg1 power-control mismatch:

- the local known OnePlus-era srsRAN profile sets SIB1
  `ss-PBCH-BlockPower` from `pdsch_rs_power`; the production parser derives it
  from `sib.conf` `rs_power`, whose reference profile value is `0 dBm`;
- OCUDU defaults `ssb_block_power_dbm` to `-16 dBm`;
- CP2616 omits the key, so it broadcasts the OCUDU `-16 dBm` default.

This field is signaling-only in this OCUDU PHY path, as established at CP2415.
Changing it does not increase actual M2SDR transmit amplitude. It changes the
UE's inferred path loss and therefore its PRACH power calculation.

At CP2616's measured phone RSRP of about `-71 dBm`, the two advertised values
imply approximately:

- current: `-16 - (-71) = 55 dB` path loss;
- known-profile value: `0 - (-71) = 71 dB` path loss.

The discriminator should therefore request about `16 dB` more phone PRACH
power before UE/hardware limits. This is a testable mechanism for strong DL
with no observable Msg1.
