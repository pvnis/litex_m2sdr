An open/close-only probe links the isolated plugin but contains no stream-enable

The isolated config uses the official COTS geometry: PLMN [network-id-redacted], PCI `500`,
TAC `7`, Band 3, DL ARFCN `368500`, 10 MHz/52 PRB, CORESET0 index `6`, and

Running the config with selector `2` reaches the RF-open boundary, emits the
expected selector error, and exits `255` without `Opening bladeRF`. This proves
all four config files parse and the invalid-path guard precedes hardware open.

Final state passes: bladeRF serial `5c750e8e...` is present, the authorized
CPH2409 phone is visible through ADB, both hosts are mutually reachable, and
there is no `srsenb`, `srsue`, qcore, OCUDU gNB, or CP2628 SCTP listener left.
