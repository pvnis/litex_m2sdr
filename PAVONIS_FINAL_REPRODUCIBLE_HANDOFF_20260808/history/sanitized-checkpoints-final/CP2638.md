## Result

Gap-fill improves but does not restore the logical RX contract:

- 43/64 RX calls return success with `actual_count=11520`;
- 22 have no inserted zeros and 21 insert 650 zeros;
- 21/64 calls insert 975 zeros, stop after 3 segments at
  `actual_count=3113`, and return `BLADERF_ERR_INVAL`;
- RX start-timestamp deltas repeat `10870`, `10545`, and `3113`.

TX remains malformed: 63 rows carry 11,520 samples, 62 carry 13,008, with one
each at 10,870, 30,720, and 3,840. The first SOB is still 37,917 samples late.

M2SDR remains floor-class at RMS `0.00733631`. The validated 48-case PCI500
sweep reports `0/48` PBCH CRC OK and no PCI500 CSI rows. The RF acceptance
therefore fails and no phone run is unlocked.

## Root Cause

The installed libbladeRF is commit `0bf98844`. Its `sync_rx()` rejects an X2
request unless `num_samples` is divisible by two. The +975 inserted gap leaves
an odd remainder, explaining the deterministic `BLADERF_ERR_INVAL` every third
logical RX call.

The more important source audit finds that CP2628's physical-channel overlay
uses one `bladerf_channel` field for two different API concepts:

- channel controls need `BLADERF_CHANNEL_RX(1)` / `TX(1)`, numeric `2/3`;
- `bladerf_sync_config()` needs a stream layout; numeric `2/3` means
  `BLADERF_RX_X2` / `TX_X2`.

Consequently, selecting physical RX2/TX2 accidentally configures two-channel
interleaved streams while the gNB provides and consumes a single-channel
buffer. Nuand's same-commit bladeRF CLI selects X1 stream layout whenever one
channel is active and separately enables channel index 1. This directly
explains the halved/malformed timeline and makes RX accumulation a symptom
workaround, not the correct fix.

## Decision

Retire the accumulator branch. Build a new isolated, cached default-off policy
that keeps control channels at `BLADERF_CHANNEL_RX/TX(physical_index)` but uses
`BLADERF_RX_X1` and `BLADERF_TX_X1` for every sync configuration because only
one channel is active. Gate source/build/loader no-RF, then repeat the same
bounded M2SDR PBCH acceptance before touching the phone.
