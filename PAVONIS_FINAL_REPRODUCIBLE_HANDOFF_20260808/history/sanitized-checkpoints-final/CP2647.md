## Change

Added `PAVONIS_NR_SETUP_UL_TRACE`, default off and cached on first use, at two
existing MAC metadata boundaries:

- scheduled PUCCH opportunities carrying SR configuration: slot, RNTI,
  validity, SR value, ACK count, CSI count, and SNR;
- every PUSCH result: slot, RNTI, HARQ PID, CRC, byte count, ACK count, UCI
  validity, and SNR.

Each event class has an independent process-lifetime atomic cap of 64 rows.
There is no sample scan, allocation, or file IO. CP2645's 64-row HARQ-ACK
trace and CP2644's cleanup remain intact. No scheduler, PUCCH/PUSCH config,
RRC payload, MCS, RF, threshold, or timing behavior changed.
