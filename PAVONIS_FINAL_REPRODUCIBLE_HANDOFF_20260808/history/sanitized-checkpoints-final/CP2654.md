# CP2654: post-ACK proactive UL-grant discriminator gated no-RF

Date: [date-redacted] Europe/Zurich

## Patch

`srsgnb/src/stack/mac/mac_nr.cc` now contains a default-off diagnostic behind
`PAVONIS_NR_SETUP_ACK_UL_GRANT`. The environment is read once through a
function-local static. On a valid positive HARQ ACK, the enabled path calls the
existing scheduler `ul_sr_info(rnti)` once per new RNTI and emits at most 32
metadata-only markers:

```text
PAVONIS_NR_SETUP_ACK_UL_GRANT active rnti=... pid=...
```

The transmitted RRCSetup, PUCCH configuration, scheduler rules, and disabled
path are otherwise unchanged. This is a discriminator, not a production fix.
