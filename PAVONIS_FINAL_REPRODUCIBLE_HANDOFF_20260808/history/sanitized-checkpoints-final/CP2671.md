## Patch

The current CP2656 srsENB baseline gains a default-off
`PAVONIS_NR_USERPLANE_TRACE` at four existing handoff points:

1. `pdcp_input`: RNTI, LCID, byte count, PDCP header, and user existence;
2. `adapter`: bearer validity, EPS bearer, RAT, byte count, and IP-version byte;
3. `gtpu_lookup`: EPS bearer, byte count, and active [interface-redacted] count;
4. `sendto`: TEID, payload/wire byte counts, return value, and errno.

Each environment lookup is cached in a function-local static. Tracing is
metadata-only, omits subscriber values and packet payload, and is independently
row-capped at 128/128/256 events for PDCP, adapter, and combined GTP stages.
The disabled path performs only the cached boolean check at the affected call
sites.
