# CP2681: MIB intra-frequency reselection override passes the no-RF gate

Status: PASS, NO RF. The CP2680 discriminator is implemented as one default-off
MIB enum override, built natively on [host-redacted], deployed at an isolated path, and
propagated through a fresh CP2681 runner. The CP2392 golden binary and source
tree are restored and hash-identical.

## Patch

`asn1_sys_info_packer.cpp` now reads
`PAVONIS_GNB_MIB_INTRAFREQ_RESELECTION_ALLOWED` once while packing the MIB. The
unset/default `0` branch retains OCUDU's original `notAllowed`; exact value `1`
selects `allowed` and emits one stderr marker. No scheduler, SIB1, RACH, RF,
timing, threshold, or hot-path behavior changes.

Local build passed. Its binary was not used on [host-redacted] because the laptop links
`libmbedcrypto.so.16` while [host-redacted] provides ABI 7. That first ZMQ launch returned
127 before program start and is tooling-void. The source was then backed up,
built in [host-redacted]'s existing tree, and both [host-redacted] source and active golden binary
were restored under a trap.

## Enabled/disabled runtime proof

The native isolated binary was run twice for eight seconds against the exact
CP2677 ZMQ/NCI105217 configuration and private qcore, with no RF device opened:

- flag `0`: timeout exit 124, marker 0, Soapy 0, M2SDR 0, MIB pack errors 0;
- flag `1`: timeout exit 124, marker 1, Soapy 0, M2SDR 0, MIB pack errors 0.

The marker split proves the environment reaches the actual MIB packing branch,
while source inspection proves the only encoded difference is
`intraFreqReselection allowed` versus `notAllowed`.

All three scripts pass `bash -n`. The stage and starter each default the flag to

The first CP2682 invocation stopped before entering the RF wrapper because the
preflight used end-of-line anchors against helper-preserved CRLF. Both expected
hash/path pairs were present. The gate now uses fixed-substring matching; no RF
or remote process started in that tooling-void attempt.

## Decision

Run one bounded CP2682 phone discriminator with a fresh stamp through the
CP2681 wrapper. Judge health first, require the enabled marker and exact NCI,
then phone camp/registration and gNB Msg1. A negative closes the MIB bit and
moves directly to the independent bounded bladeRF uplink observer.
