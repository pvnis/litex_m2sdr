# CP2687: Old and native gNB binaries produce identical floor-class external DL captures

CP2687 runs the CP2686 discriminator with the CP2497-validated bladeRF RX1
instrument. The old phone-era `9cbf0969...` executable and the native MIB-test
`052c9e31...` executable use the same frozen channel-1 configuration and are
captured independently for 250 ms at 11.52 Msps, 10 MHz bandwidth, and gain 36.

| Median window RMS, rel2048 | -45.0321 dBFS | -45.0025 dBFS |
| Raw SHA256 | `a04a77f4...` | `8319af01...` |

Both packaged gNB YAML files hash to the frozen `fcf77cc8...` value. Start-log
proof names the intended executable in each leg, physical channel offset 1 is
active, and both legs report zero stream deficit, timeout, error,
deadline-write timeout, binary-safe TX timeout, downlink-late, and release-late
counts. The native live process was additionally read back as `052c9e31...`
with channel-1 gain 5 dB and the expected sample rate/frequency.

This is a valid external-DL comparison even though the enclosing phone wrappers
return nonzero on unrelated Android UI automation. The RF capture starts only
after the direct/channel propagation proof and does not use M2SDR self-RX,
full-rate append, srsUE, or any uplink conclusion.

## Tooling attempts

- Attempt A started the old gNB but captured nothing because an exact EOL match
  rejected the CRLF propagation sidecar. It is capture-void. Its forced teardown
  left reversible phone voice/roaming state active; both were restored and
  verified before the valid legs.
- Attempts B and C stop before RF on those voice and roaming baseline guards.
- The valid old leg completed capture and both analyzers, then hit a post-analysis
  `tar|awk` SIGPIPE. The package/YAML were subsequently verified directly.
- The native-only retry uses a consuming `awk` parser, completes with rc0, and
  restores the canonical stage and selection helper hashes exactly.

## Verdict

The native rebuild is exonerated as the splitter for the current no-cell state:
old and native outputs are indistinguishable at the external observer. The
active fault has moved below that executable comparison. Relative to CP2497's
strong external baseline (`-42.36 dBFS`, max 200, 105/847 PBCH), both current
captures are floor-class despite clean software TX health.

Before another phone, MIB, PRACH, or UL run, execute the byte-identical CP2143
M2SDR-TX to bladeRF-RX1 CW control. A reference-class tone blames live gNB
waveform presentation/cadence; a weak tone blames the current RF path or RX1
instrument and requires that baseline to be restored first.
