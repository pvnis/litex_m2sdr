# CP2688: DL CW proves RX1 works and M2SDR channel 1 is degraded but present

CP2688 reruns the byte-matched CP2143 downlink CW shape after CP2687 found
identical floor-class live-gNB captures. The historical vector hash remains
`12a9a975...`; TX is 1842.5 MHz, 11.52 Msps, 7.68 MHz, attenuation 5 dB,
and RX is bladeRF RX1/RX2 at 1839.65 MHz, 7.68 Msps, 3.84 MHz, gain 32,
normal filter. Each leg changes only the M2SDR TX channel.

## Results

| TX channel / receiver | RMS rel2048 | Peak rel2048 | Median tone SNR |
| --- | ---: | ---: | ---: |
| channel 0 -> RX1 | 0.0163458 | 0.0485392 | 72.6266 dB |
| channel 0 -> RX2 | 0.0046403 | 0.0265878 | 15.7598 dB |
| channel 1 -> RX1 | 0.0055182 | 0.0265294 | 32.6414 dB |
| channel 1 -> RX2 | 0.0044563 | 0.0249788 | 16.5309 dB |

Both executions return rc0 and finish cleanup. Channel 0 RX1 is reference
class: it is only 4.42 dB below CP2143's 77.05 dB tone-SNR golden. The RX1
capture instrument is therefore healthy.

Channel 1, used by the phone gNB, is not dead: RX1 sees the expected CW with
32.64 dB tone SNR. It is nevertheless degraded relative to channel 0 by
39.99 dB in narrowband tone SNR and 9.43 dB in total RMS. This is a real
channel/path asymmetry, not helper invocation drift, but it does not explain
the complete absence of decoder-visible SSB energy in both CP2687 gNB files:
the same RX1 instrument resolves a channel-1 tone clearly.

## Verdict

The bladeRF RX1 calibration instrument and at least one M2SDR transmit output
are healthy. Physical TX channel 1 remains usable but materially weaker than
channel 0. The live gNB fault is now specifically waveform presentation versus
the channel-1 RF path, below the old/native executable split and above the
external receiver.

Next run one synchronized, bounded live-gNB capture with both the CP2497
external RX1 instrument and M2SDR same-device self-RX. If self-RX decodes while
RX1 remains floor-class, the fault is after/on the channel-1 RF output path. If
both are floor-class while this CW remains visible, the live runtime/cadence
path is suppressing or corrupting the waveform before RF.
