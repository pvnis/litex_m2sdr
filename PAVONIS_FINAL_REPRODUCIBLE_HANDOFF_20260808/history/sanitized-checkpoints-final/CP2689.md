# CP2689: Live gNB self-RX passes while the external phone-facing leg is weak

CP2689 reruns the unchanged CP2497 synchronized discriminator with the
phone-era `9cbf0969...` gNB on physical channel 1. External bladeRF RX1 and
M2SDR self-RX overlap for `247.496862 ms`. Full append is enabled deliberately,
so the run is detection-void and is judged only on downlink visibility.

## Shared-window result

M2SDR self-RX is coherent:

- exactly 2.88M CF32 samples, SHA256 `508c651f...`;
- `24/24` Pattern-A cases decode expected PCI1 PBCH;
- measured PCI1 CSI rows span `+7.3..+8.5 dB`;
- median window RMS is `0.0003943`.

The simultaneous external RX1 file is weak:

- capture start error `+240446 ns`;
- RMS `-44.8404 dBFS` rel2048 and maximum component `64`;
- expected PCI1 PBCH `0/847`;
- PCI1 CSI footprint `75/847`, best only `-3.5 dB`.

CP2497 used the same controller/instrument and produced self-RX `24/24` at
`+10.9..+14.4 dB` plus external `105/847` PBCH with best CSI `+21.0 dB`.
The current self-RX has lost some margin but remains perfectly decodable; the
external leg has lost more than 20 dB of best-CSI margin.

All TX health fields remain zero: stream deficit, timeout, error,
deadline-write timeout, binary-safe timeout, downlink-late, and release-late.
Direct channel-1 propagation passes. The Android monitor has 46 rows and zero
NR/private-service/IP rows, consistent with the external deficit.

## Verdict

The live gNB waveform is coherent inside the M2SDR. CP2687's old/native
executable theory and the MIB branch remain closed. CP2688's channel-1 CW is
visible but degraded; CP2689 now proves the wideband NR waveform falls below
PBCH decode margin only on the phone-facing/external RF leg.

Do not [interface-redacted] PRACH, RAR, NAS, thresholds, scheduler, or waveform source. First
audit the durable port map and run a bounded phone-facing port discriminator:
preserve channel 1, compare a channel-0 phone attempt using the same frozen gNB
shape, and keep an external RX1 capture in the window. If the phone or external
PBCH recovers on channel 0, use that output temporarily or arrange the antenna
there; if not, raise channel-1 drive from attenuation 5 to 0 dB as the next
single safe link-budget control.
