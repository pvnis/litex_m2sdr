# CP2695: Capture-epoch worker stream is clean while external SSB stays blind

CP2695 repeats the exact CP2693 continuous live-gNB shape and adds only the
CP2694 worker-only metadata arm. The arm is process-proven and touched
immediately before the dual bladeRF capture. No raw TX probe is enabled.

All wrapper, propagation, capture, analyzer, phone-monitor, package and
cleanup gates pass. TX health remains zero-defect: 2,222,292 data writes,
zero all-timed/HAS_TIME continuation writes, zero partial returns, zero write
deficit, zero timeout/error and zero downlink-late events.
