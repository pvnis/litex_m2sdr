# CP2708: actual-air SIB1 diff leaves MIB `allowed` as the open pre-access A/B

Status: PASS, no RF. Existing CP2701 and CP2674 artifacts only.

## Actual-air decode

The validated CP2702 SI harness recovered the complete 80-byte CP2701 PDSCH
payload with CRC OK. A small offline decoder built against the current OCUDU
RRC ASN.1 libraries unpacks those exact air bytes as BCCH-DL-SCH/SIB1.

Comparing the decoded air SIB1 against the successful CP2674 srsENB SIB1 gives
the same `112/118` named-token overlap as CP2677. This independently confirms
the config-time comparison and leaves exactly six token pairs:

| OCUDU air | srsENB golden | Access relevance |
| --- | --- | --- |
| `aggregationLevel8=n1` | `n0` | Common-search candidate budget; not a reason to suppress Msg1. |
| `msg3-DeltaPreamble=6` | absent | Msg3 power, after Msg1. |
| `n-TimingAdvanceOffset=n25600` | `n0` | UL timing after random access begins. |
| PLMN outer-list naming | alternate list naming | Same 90170/TAC/NCI semantics; schema representation. |
| `t311=ms3000` | `ms30000` | Connected-mode RLF timer. |
| `txDirectCurrentLocation=312` | absent | RF DC-location declaration, not cell suitability. |

The srsENB-only `p-Max=10` does not lower Srxlev for this power-class UE, and
`searchSpaceOtherSystemInformation=1` concerns other SI, not the already decoded
SIB1 or initial Msg1 transmission.

## MIB provenance

The actual CP2701 PBCH decodes as nonbarred, CORESET0 `6`, SS0 `0`, and
`intra_freq_reselection=n`. The run manifest independently records
`PAVONIS_GNB_MIB_INTRAFREQ_RESELECTION_ALLOWED=0`.

Therefore CP2701 did not test the srsENB value. CP2683/CP2684 used `allowed=1`
but both were no-cell runs, so they were correctly void. CP2686's flag-0
no-cell control closed the rebuilt-binary theory but did not create an
exact-identity, phone-visible `allowed=1` datapoint. CP2701 later supplied the
first valid exact-identity observation only with value `0`.
