# CP2714: actual-air SIB1 structural path audit

Status: PASS, no RF. Existing CP2701/CP2702 and CP2674 artifacts only.

## Result

A new parser retains complete field ancestry and array indices across the two
ASN.1 JSON-like renderings, including anonymous CHOICE braces. It compares the
retained CP2701 80-byte, CRC-OK air payload against the CP2674 successful
srsENB phone-golden SIB1.

Both sides contain `118` structural path tokens; `101` match exactly. The
`17` tokens unique to each side contain no hidden field placement, array
ordering, identity, TAC, MCC/MNC, cell-reservation, carrier, PRACH, PUCCH,
PUSCH, paging, timer, or bit-string mismatch. They collapse exactly to the
already known differences:

- the equivalent outer PLMN container name;
- SearchSpace1 aggregation-level-8 candidates `n1` versus `n0`;
- `n-TimingAdvanceOffset` `n25600` versus `n0`;
- OCUDU-only `msg3-DeltaPreamble=6`;
- srsENB-only `p-Max=10` and `searchSpaceOtherSystemInformation=1`;
- `t311` 3000 versus 30000 ms;
- OCUDU-only `txDirectCurrentLocation=312`.

Android's retained radio log independently proves that it decodes MCC/MNC
[network-id-redacted], NCI105217, PCI500, TAC7, ARFCN368410, Band3 and operator `QCore`,
with registered-PLMN field `90170` and `reasonForDenial=NONE`. Its NR data
registration state remains `NOT_REG_MT_SEARCHING_OP_EM` for all 67 radio
records. The CP2674 golden has the same search state for three records and then
ten `REG_ROAMING` records, so the state itself is the immediate pre-access
frontier rather than a parser artifact.

## Decision

The token comparator did not conceal a structural SIB1 blocker. Before another
RF run, map every residual field to OCUDU config/source and determine whether a
single isolated, default-off srsENB-semantic compatibility profile can remove
all known differences. If feasible, that combined A/B is preferable to serial
single-field RF guesses; if not, move below SIB1 to broadcast timing/cadence
and modem cell-selection provenance.
