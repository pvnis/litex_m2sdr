# CP2716: maximal srsENB SIB1 compatibility profile passes no-RF gate

Status: PASS, no RF.

## Patch

`asn1_sys_info_packer.cpp` now has one cached, default-off environment switch:

```text
PAVONIS_GNB_SRSENB_SIB1_COMPAT=1
```

When enabled it sets SIB1 TA offset to `n0`, advertises
`searchSpaceOtherSystemInformation=1`, and omits the DL
`txDirectCurrentLocation` extension. The switch is read once. The existing
CP2681 MIB override remains intact and independent.

The compatibility YAML additionally uses existing controls for SearchSpace1
candidate counts `[0,0,1,0,0]`, `p-Max=10`, and `t311=30000` ms. Radio,
identity, PLMN, cell, SSB, PRACH, PUCCH, PUSCH, scheduler and power settings are
otherwise unchanged.

## ZMQ Proof

Three qcore-connected ZMQ-only gNB generations ran without M2SDR access:

1. CP2681 old binary, baseline config, compatibility off;
2. CP2716 new binary, same baseline config, compatibility off;
3. CP2716 new binary, compatibility config, compatibility on.

The old versus new-disabled outputs have `118/118` common structural tokens,
zero old-only and zero new-only tokens. This proves default-off behavior at the
encoded SIB1 level.

The enabled output has `119` tokens versus srsENB's `118`, with `106` common.
Every non-wrapper srsENB token is present. The only non-PLMN token unique to
OCUDU is `msg3-DeltaPreamble=6`, which is post-Msg1. Direct enabled-log proof:

```text
aggregationLevel8=n0
searchSpaceOtherSystemInformation=1
p-Max=10
n-TimingAdvanceOffset=n0
t311=ms30000
txDirectCurrentLocation absent
```

Qcore is stopped after the proof. No RF stream opened.

## Decision

Gate one exact CP2712-shape RF run using the isolated CP2716 binary, MIB
allowed, the compatibility switch, and the three compatibility YAML controls.
Judge health, exact phone identity, camping and independent/gNB Msg1 evidence
in that order. A valid no-Msg1 result closes all feasible SIB1 semantic
differences and moves the investigation below SIB1 to broadcast timing/cadence
or modem-selection provenance.
