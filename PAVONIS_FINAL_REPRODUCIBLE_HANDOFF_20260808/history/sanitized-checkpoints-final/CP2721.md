# CP2721: OCUDU 20 ms SIB1 retransmission override passes no-RF gate

Status: PASS, no RF.

## Patch

`sib1_scheduler.cpp` now supports:

```text
PAVONIS_GNB_SIB1_RETX_PERIOD_MS=20
```

The value is read and validated once through a function-static cache during
scheduler construction. Unset keeps the existing expert configuration; the
slot hot path performs no environment read or extra work. Values other than
`20` are rejected with an explicit error and fall back to the configured
period. Enabled mode changes only the derived SIB1 retransmission period; SSB,
new-transmission period, payload, MCS, aggregation, power and all other channel
schedulers are untouched.

## Scheduler Proof

The ZMQ gNB smoke is explicitly void for cadence because no peer supplied a
sample clock; it opened no RF device and produced no SI rows. The deterministic
scheduler unit harness supplies the decisive proof instead:

- unset/default test: PASS, marker count `0`, all existing periodicity cases;
- enabled test with expert default still `160 ms`: PASS, marker count `1`;
- enabled trace: `500` SIB1 allocations, all `499` positive context deltas are
  two frames, i.e. `20 ms` / 20 slots at 15 kHz SCS.

The enabled test directly asserts 20-slot scheduling over 10,000 slots. qcore
was used only for the ZMQ startup smoke and is stopped afterward.
