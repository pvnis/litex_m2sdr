# CP2725: OCUDU SIB1 n0 plus 20 ms override no-RF gate

Date: [date-redacted]

Status: PASS, no RF.

## Patch

`sib1_scheduler.cpp` now has a cached, default-off
`PAVONIS_GNB_SIB1_USE_N0` selector. Unset or `0` retains the existing
`precompute_type0_pdcch_css_n0_plus_1()` path. Value `1` selects the already
existing `precompute_type0_pdcch_css_n0()` helper and emits one constructor-time
marker. Invalid values are rejected to the default path with an error. There is
no environment lookup in `run_slot()`.

The CP2721 `PAVONIS_GNB_SIB1_RETX_PERIOD_MS=20` switch remains independent and
unchanged.

## Tests And Build

The local `gnb` and `common_scheduler_test` targets build successfully.

- default filtered allocation test passes with no n0 marker, preserving
  `n0+1`;
- enabled filtered test runs with both period20 and n0 enabled, emits the n0
  marker once, and its slot-0 assertion passes for the live profile geometry
  (`15 kHz`, `10 MHz`, `pdcch_config_sib1=96`, beam 0).

The tests were redirected to retained logs and summarized by counters; verbose
scheduler output was not loaded into context.
