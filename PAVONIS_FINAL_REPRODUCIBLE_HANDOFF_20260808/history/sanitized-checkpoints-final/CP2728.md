## Final Decoded SIB1 Difference

CP2716's structural control proves the maximal compatibility payload differs
from successful srsENB only by the release-specific PLMN container path name
and OCUDU's actual field
`initialUplinkBWP.pusch-ConfigCommon.msg3-DeltaPreamble=6`.

The latter has a narrow source/config path that CP2715 did not exploit:

- the application schema explicitly accepts `msg3_delta_preamble` in
  `[-1,6]`;
- scheduler config stores it as `bounded_integer<int,-1,6>`;
- the ASN converter nevertheless unconditionally sets
  `msg3_delta_preamb_present=true` and writes `.value()`.

Thus the supported `-1` sentinel cannot currently omit the optional ASN field.
This is a concrete default-neutral fix, not another arbitrary semantic knob.
