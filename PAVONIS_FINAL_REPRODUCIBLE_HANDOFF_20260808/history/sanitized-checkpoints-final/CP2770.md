# CP2770 - Event-spanning phone UL capture identifies a 22.9 ms collection lead

Date: [date-redacted]

The 65-second independent bladeRF RX2 observer completed over the unchanged
CP2769/frozen M2SDR phone ladder shape. The capture is valid despite the outer
wrapper returning rc 1: it produced 748,800,000 samples (2,995,200,000 bytes),
bladeRF rc 0, and 65,000 analyzed 1 ms blocks. The rc 1 came only from the old
hard-coded 50,000-block postcondition after all data had been secured.

The ladder remained pre-Msg1: the phone monitor recorded 80 rows and 66 NR
rows, QCSuper decoded 64 MIB, 64 SIB1, and one PCI500 UL-CCCH record, while the
gNB reported 1,903 empty PRACH rows, zero nonempty rows, zero stage-1
selections, and zero RAR. Sixty-four strong predemod windows were retained.
TX health was clean: zero Soapy timeout, downlink-late, and release-late rows.

## Event join

The first UL-CCCH timestamp is 20.744386 seconds after capture start, so this
run covers the modem's access epoch. Its exact 1 ms block is quiet at
`-41.426 dBFS`, but a narrow burst class begins 155 ms later and repeats at
160 ms intervals:

| Capture block | Relative time | PRACH-band level | Event-to-collection |
| --- | ---: | ---: | ---: |
| 20899 | 20.899 s | -21.486 dBFS | about -22.8 ms |
| 21059 | 21.059 s | -24.995 dBFS | about -22.9 ms |
| 21219 | 21.219 s | -26.147 dBFS | about -23.0 ms |

The same burst class reappears later on the 160 ms lattice. The independent
capture therefore shows physical phone UL activity after the RRC UL request,
but the gNB's corresponding collection windows are presented roughly 22.9 ms
later. This is the first direct explanation for strong phone-side access
activity coexisting with 1,903 empty live detector inputs.

The frozen sequence uses
`gnb_prach_timing_compensation_samples=237336`, which delays collection by
20.602083 ms at 11.52 Msps. Removing it should eliminate most of the observed
gap. The remaining roughly 2.3 ms is below the accuracy justified by the two
hosts' approximately 4.3 ms NTP root-distance readbacks, so it must be measured
again in sample-domain evidence rather than [interface-redacted] from this wall-clock join.
