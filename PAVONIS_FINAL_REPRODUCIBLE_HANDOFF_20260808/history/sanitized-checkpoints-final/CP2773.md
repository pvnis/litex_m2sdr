physical burst.

## Physical phase join

Independent-capture blocks above the run median by at least 10 dB have a
dominant two-block modulo-160 lattice at residues 126/127. Grouping those rows
produces 29 physical UL events. Joining each event to the nearest gNB detector
window gives:

- mean event minus collection: `+10.249 ms`
- minimum: `+9.902 ms`
- maximum: `+10.600 ms`

The sub-ms spread proves a stable within-run phase, while CP2770's corresponding
class mapped to roughly `-2.3 ms` on the nominal timeline after removing its
20.602 ms configured delay. The phone/M2SDR UL displacement is therefore chosen
at run start and varies by about 12.5 ms between these runs. Zero compensation
is not sufficient, and replacing it with another static delay would recreate
the lottery.

One propagation issue is recorded for the Msg3 frontier: despite the outer
request for zero, the full chain logged static non-PRACH offset `-241118`.
`cp2212_run_dynamic_nonprach_offset.sh` overwrites the inherited value. This is
irrelevant to CP2773's pre-Msg1 verdict but must be made default-preserving
before a phone Msg3 can be judged.

Next: use a bounded multi-phase PRACH window spanning the observed run classes,
with a small fixed candidate bank and stop-on-accept. Keep all changes
default-preserving and compensate the global pre-roll out of non-PRACH UL.
