# CP2774 - Bounded multi-phase PRACH native no-RF gate passes

Date: [date-redacted]

CP2773 proved that the phone UL phase is tight within a run but moves by about
12.5 ms between runs. CP2774 prepares one bounded search that spans both known
phase classes without multiplying every detector candidate by the full wide
collection window.

The PRACH worker now limits each non-baseline stage-1 transform to
`min(input_samples, nominal_window + 12000)`. Existing 23,520-sample windows
therefore retain the exact prior span, while the planned 195,840-sample input
uses only 23,520 transformed samples per candidate. The trace adds
`input_samples` and `candidate_span_samples` so the live run can prove this
directly.

- the [host-redacted] golden gNB and source were backed up, then restored byte-for-byte
- all five nested wrappers preserve their old defaults and accept the planned
  overrides; all pass `bash -n`

- no RF was transmitted

The planned live shape is:

- lower-PHY UL timestamp offset `+46080` samples
- non-PRACH counter-offset `-46080` samples, with both dynamic overwrite paths
  disabled
- PRACH timing compensation `0`
- PRACH extra collection `184320` samples, yielding 195,840 input samples
- 12 explicit coarse candidates covering the CP2770 and CP2773 phase classes,
  capped at 13 evaluations with stop-on-accept
- selected-shift TA compensation disabled, because the coarse stage-1 shift is
  a search coordinate rather than physical UE timing advance
