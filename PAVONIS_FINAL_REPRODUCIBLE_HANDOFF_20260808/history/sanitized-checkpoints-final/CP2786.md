# CP2786 - Strong phone UL exposes global-offset PRACH-late storm

Date: [date-redacted]

Stamp: `[date-redacted]CP2786_M2SDR_PHONE_MULTIPHASE17MS_RADIO_CYCLE`

The underlying frozen ladder run completes with rc 0, clean realtime host
state, zero Soapy TX timeouts, zero downlink-late events, and zero write
deficit. The CP2782 isolated `gnb` hash and all requested timing/search values
propagate. The phone is restored afterward to full modes `33/33`, automatic
selection, and roaming off.

The planned UI radio cycle is not proven: it reaches
`RADIO_CYCLE_ALLOWED=NR`, then the remote helper exits rc 1 before any
`RADIO_POWER_BEFORE`, off/on, or final PASS marker. CP2786 is therefore void
for the CP2785 trigger mechanism.

It is nevertheless a decisive RF datapoint. The independent 65-second UL
capture contains strong supply:

- PRACH-band median `-41.95 dBFS`, max `-2.28 dBFS`
- `1557` one-millisecond blocks at least 10 dB above median
- QCSuper: 70 MIB, 70 SIB1, one UL-CCCH

Despite that supply, the gNB has zero stage-1 rows, zero completed predemod
windows, zero accepted PRACH, and zero RAR. A binary-safe no-RF count explains
why: `1910` lower-PHY `PRACH request late` events. Cross-run counts are:

| Run | Global UL timestamp offset | PRACH request late |
| --- | ---: | ---: |
| CP2773 | 0 | 1 |
| CP2781 | +46080 | 1904 |
| CP2783 | +46080 | 1904 |
| CP2784 | +46080 | 1911 |
| CP2786 | +46080 | 1910 |

CP2773 simultaneously completed 1902 empty detector windows. The `+46080`
global pre-roll therefore moved the lower-PHY symbol context past nearly every
nominal PRACH request. The 17 ms worker was not hanging and the CP2783/CP2784
zero-row results were not merely weak phone supply; those runs passed binary,
capture, and TX infrastructure but were collection-void due to stale requests.

Decision: remove the global shift and its compensating non-PRACH shift together
(`0/0`, preserving the prior net non-PRACH timeline). Translate only the
positive-phase candidates by `-46080`: `118160`, `118016`, `114064`,
`113920`, `122256`, `122112` samples, plus the automatic baseline candidate.
This covers CP2773's +9.9 to +10.6 ms class in the unshifted 17 ms buffer.
Do not attempt another UI radio cycle yet; first require completed native
`195840/23520` rows and judge actual phone energy/acceptance.
