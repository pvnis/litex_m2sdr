worker: `PAVONIS_PRACH_COLLECTION_PHASE_SEQUENCE`, encoded as comma-separated
`delay_samples:report_slot_offset` pairs. When absent, the existing delay
sequence and static-delay paths execute unchanged. When present, each accepted
PRACH request cycles one pair. Delay zero is now representable, and a collector
that wraps to the next 160 ms phone occasion can report that next occasion
coherently instead of attributing the result to an expired request.
