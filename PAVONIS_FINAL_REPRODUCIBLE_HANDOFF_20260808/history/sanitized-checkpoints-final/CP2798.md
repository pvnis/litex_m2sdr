# CP2798 - Late-armed TX descriptor timeline diagnostic no-RF gate

CP2798 prepares the single-variable repeat required by CP2797. It wraps the
hash-pinned CP2796 RF diagnostic rather than copying or modifying its RF shape.
The only runtime addition is the existing M2SDR Soapy TX worker descriptor
trace, configured metadata-only with a 65,536-row cap and 256-row flush period.

The wrapper starts CP2796 with a fresh trace and arm-file path on [host-redacted]. It
watches only CP2796's small local capture-start marker, then creates the arm
file on [host-redacted] and records the arm epoch. After the unchanged 65-second capture
finishes, it fetches the trace, runs the existing CP2047 metadata cadence
parser in report mode, and runs a new compact SFN residual-transition parser.
It never scans IQ or a growing remote RF log during the live run.

The transition parser independently validates CP2797: 124 decoded rows contain
one residual-state change from 0 to -1, across four failed slices. Using the
last decoded row before the outage and first decoded row after it gives an
`8.247656 ms` sample/SFN discrepancy, consistent with the approximately
8.3 ms event recorded in CP2797.

The deployed [host-redacted] module gate passes. Soapy's active system search path
contains `/usr/lib/x86_64-linux-gnu/SoapySDR/modules0.8/libSoapyLiteXM2SDR.so`
with hash `adde048f2b6a202b50f46181f3021f10fa7863c8f4992dcbf46b83fe61783418`.
Strings prove the worker trace path, arm file, limit, flush period, arm marker,
and CP2074B `keeping contiguous untimed buffer` marker. A stale
`/usr/local/lib/SoapySDR/modules0.8/libSoapyLiteXM2SDR.so` is also discovered
but contains neither marker; the `/usr` module is the first registered
LiteXM2SDR module and is the deployed working baseline.

Local shell syntax and Python compilation pass. The wrapper is default-closed:
without `PAVONIS_CP2798_RF_APPROVED=1` it exits rc2 before creating run
artifacts. The hash-pinned inner CP2796 wrapper and CP2047 analyzer are
unchanged. New hashes are:

- SFN transition parser: `4c6cab55966a317967d1c39ad79266b4e107930779c33914af27d205d6e23368`;
- CP2798 wrapper: `f4ad2aef40260d46091587bbd146d9b6d0b3c422522c413af17b6a7634931683`.
