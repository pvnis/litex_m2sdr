# CP2808 - Stale zero-fill stderr-proof module no-RF gate

CP2808 changes telemetry only. The two already bounded stale-zero-fill messages
move from `SoapySDR_logf(SOAPY_SDR_INFO, ...)`, which OCUDU suppresses, to the
established stderr route used by the worker/release diagnostics. The active
message occurs once per stream activation and the overtake message retains its
16-row cap. Zeroing logic, synchronization, env semantics, and defaults are
unchanged.
