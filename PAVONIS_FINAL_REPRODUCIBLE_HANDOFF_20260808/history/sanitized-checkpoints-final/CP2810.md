# CP2810 - One-shot DMA reader kernel and zero-data gate

CP2810 moves ownership below the CP2809 race. LitePCIe's authoritative
scatter-gather implementation defines program mode as one execution per
software-published descriptor; when the FIFO is empty, DMA stops until refill.
Its loop-status index remains monotonic in program mode. The current AD9361 PHY
explicitly latches zeros when TX valid is absent, so an empty descriptor table
cannot replay old IQ.

The default-off kernel parameter `dma_reader_program_mode` snapshots into the
TX DMA reader at stream start. With it off, the existing 256-descriptor LOOP
path is unchanged. With it on:

- pre-start zero-copy releases accumulate only the published count;
- stream start flushes the table, retains that count, and queues those ring
  slots once in program mode;
- every later mmap release queues only the newly published descriptor;
- copy-mode writes use the same one-shot publisher;
- completion accounting interprets program-mode loop status as a monotonic
  32-bit count rather than a 256-entry loop count;
- stop/open reset the program-mode state.
