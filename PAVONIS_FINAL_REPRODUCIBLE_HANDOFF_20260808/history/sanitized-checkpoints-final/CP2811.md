# CP2811 - One-shot DMA long-continuity no-RF gate

CP2811 prepares the marker-proven RF verdict for the CP2810 kernel without
changing the frozen phone or gNB shape.

The wrapper hash-pins CP2796 at
`46e1dc746b524e56638c294940b950e33bf1cb50e057f2ad44033bfd14a6ca09`
and the deployed one-shot-capable kernel at
`3ded84bbc2ac7ff26a8192666c4083041ae54ebdfd808b48633ccedc91261ead`.
It requires [host-redacted] idle and the module parameter initially off, records the
existing kernel marker count, enables one-shot mode, and restores it to off on
all normal or trapped exits. After the run it requires a strictly increased
kernel marker count before interpreting data.

The only TX selections are one-shot mode on, stale-payload zero-fill off,
prime128, and worker trace off. The established 65-second independent RX2
capture, phone/QCSuper observer, gNB config, power, timing, and detector shape
remain inherited from CP2796.

[host-redacted] resume-state preflight passes: parameter `N`, no gNB, no `/dev/m2sdr0`
owner, and exact kernel hash. Wrapper `bash -n` passes; hash is
`da811d57efc1d2d03c59c70b32fbfb202d25e36908eacf5ac906dc4f2f38eb28`.
With approval unset it returns rc2 and creates no artifact. `shellcheck` is not
installed, so that optional check was unavailable.
