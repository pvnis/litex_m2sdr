# CP2817 - Contiguous remainder timestamp backfill no-RF gate

CP2817 implements the CP2816 source-level repair in the LiteX Soapy module.
The new `M2SDR_SOAPY_TX_BACKFILL_CONTIGUOUS_TIME` feature is default-off and
cached once per process. When enabled and a timed caller write lands inside a
contiguous untimed partial DMA buffer, `writeStream()` subtracts the existing
remainder offset from the incoming timed sample and stores that derived start
timestamp on the full descriptor. It does not release or zero-pad a short
non-EOB descriptor. The CP2074B keep-untimed behavior is unchanged when the
flag is absent.
