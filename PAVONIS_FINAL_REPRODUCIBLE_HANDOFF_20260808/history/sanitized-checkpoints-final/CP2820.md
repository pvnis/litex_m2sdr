# CP2820 - Long-run post-parser no-RF repair

CP2820 changes only the CP2818 wrapper's completed-artifact parser. The tar
member selector now consumes the full listing, so `pipefail` no longer turns an
intentional early `awk` exit into `rc=141`. Descriptor timestamp acceptance now
compares released HAS_TIME packets to OCUDU's `has_time_writes`: it requires at
least 100,000 timed descriptors and 90% delivery. Legitimate untimed
continuation packets are no longer treated as a failed majority vote.

The corrected parser replays CP2819's existing package without RF and passes:
938,532 caller timestamp writes, 929,281 released timed descriptors, 99%
integer delivery. Syntax and default-closed rc2/no-artifact gates pass. The
wrapper hash is
