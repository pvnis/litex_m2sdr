# CP2821 - PRACH phase sequence override proven no-RF

CP2821 resolves the CP2819 contradiction without RF. The advertised collection
sequence reached the gNB environment, but `prach_processor_worker::handle_request()`
applies `PAVONIS_PRACH_TIMING_COMPENSATION_SAMPLES` after parsing that sequence.
Any nonzero value replaces `collection_delay_samples` and explicitly clears the
sequence-active, length, index, and request-index fields.

The CP2819 package proves that branch fired on every saved window: all 64 rows
have `collection_delay_sequence_active=0`, `collection_delay_samples=237336`,
and `timing_compensation_collection_override=1`. By contrast, the CP2795
positive mechanism control has 11/11 rows sequence-active, split across indices
0/1/2 as 1/6/4 rows with delays 0/1474560/1647360 and timing override 0.

The wrapper provenance explains the regression. CP2774, which is in CP2795's
call chain, explicitly exports
`GNB_PRACH_TIMING_COMPENSATION_SAMPLES_OVERRIDE=0`. CP2796 bypassed that wrapper
while retaining the phase-sequence variables, so its deeper frozen baseline
restored the legacy 237336-sample compensation. CP2819 therefore never tested
the intended three-phase collection on its newly coherent downlink timeline.

A compact QCSuper NR-RRC parser was also added and run against CP2819. It finds
127 NR-RRC records: 63 BCCH-BCH, 63 BCCH-DL-SCH, one UL-CCCH, and no DL-CCCH.
The phone generated one access message, but the nearest saved M2SDR window is
18.418 ms before that event and is floor-class (`-67.569 dB` RMS). This does
not prove over-air Msg1 and does not justify detector [interface-redacted] against CP2819's
mistimed windows. The parser hash is
`0fc77d644a5689ae00abf1ab00e9f65d1473fad28e39eb646be33d48b1e71b55`.

Verdict: do not replay or [interface-redacted] CP2819 as though it exercised the phase cycle.
Preserve one-shot DMA, all-timed writes, timestamp backfill, stage-1 selected
shift TA compensation, and the frozen RF shape. The next gate must explicitly
set `GNB_PRACH_TIMING_COMPENSATION_SAMPLES_OVERRIDE=0`, prove the three sequence
indices at runtime, then run one corrected coherent-downlink phone attempt.
