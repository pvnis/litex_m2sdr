# CP2825 - Coherent independent UL observer no-RF gate

CP2825 gates the next discriminator without RF. It wraps the established
CP2758 65-second bladeRF RX2 uplink observer around the exact CP2823 M2SDR
shape: one-shot DMA, all-timed writes, timestamp backfill, the active paired
phase sequence, timing-compensation override zero, and selected-shift TA
compensation. The observer remains at its historical documented gain 32 for a
presence/epoch comparison; no RF gain, detector threshold, or scheduler value
changes.

The wrapper pins the current CP2758 and CP2822 propagation paths plus the
kernel, Soapy source/module, gNB, and QCSuper parser. Its propagation probe
passes, syntax passes, and a fresh default-closed invocation returns rc 2 with
zero artifacts. Cleanup restores `dma_reader_program_mode=N` on every exit.
The live gate requires all three sequence indices in the packaged predemod
manifest and fetches only the independent observer JSON/1 ms TSV, retaining
the remote raw capture temporarily for bounded slices if an event is found.
