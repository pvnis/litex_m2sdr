# CP2833 - Coherent M2SDR SSB plus 6 dB no-RF gate

CP2833 gates one isolated SSB-level diagnostic on the promoted coherent
M2SDR phone fixture. It adds no source, binary, protocol, scheduler, PRACH, or
RF-path change. The new outer wrapper pins CP2822, the production CP2730 stage,
and the current SSB source, then sets only
`PAVONIS_GNB_SSB_AMPLITUDE_DB=6`.

The current source hash `2d6ee23a...` coherently scales PBCH, PBCH DMRS, PSS,
and SSS and accepts only 0 or +6 dB. The deployed phone gNB contains the
feature; `cp2833_nuc4_binary_ssb_capability_retry2.log` is the authoritative
proof. The first two capability logs are append-only command-shape voids:
`strings | grep -q` under `pipefail` stopped on SIGPIPE before the PASS marker.

Wrapper `d2b0a83594f1a5e2f3d974c2959a0f8687127dc26d56f5f6f53c0557bfc9c687`
passes syntax, pinned-source propagation, the CP2822 phase-cycle probe, and a
fresh approval-closed rc2/zero-artifact gate. A live run additionally requires
the runtime environment value `6` and at least one direct active marker in the
packaged gNB log, then reports Android NR RSRP/RSRQ/SINR and the existing
PBCH/SFN/QCSuper gates.

This does not repeat CP2417 unchanged. CP2417 preceded the CP2429 1R1T digital
lane fix and the CP2819 coherent cadence fix, so its negligible observed lift
was measured on the superseded presentation path. Run CP2834 once. Primary
judgment is whether the phone obtains valid NR measurements; ladder access is
secondary and may remain void if the handset stays `NOT_REG_SEARCHING`.
