# CP2842 - Pre-gNB NR-only phone mode no-RF gate

CP2842 implements the CP2841 control as a new outer wrapper. It pins the exact
CP2836 coherent SSB+6 base and the established phone mode helper, applies
`NR only` before the base starts, requires allowed mask `NR`, preferred mode6
`23`, and Oplus mode6 `33`, then restores the full all-RAT mask and modes
`33/33` on every normal, error, signal, or interruption exit.

The wrapper passes `bash -n`, the CP2833 propagation probe, and a fresh closed
RF gate with rc2 and zero artifacts. A live no-RF phone mode cycle through the
same installed app and helper passes both directions: NR-only reads back
`NR/23/33`, then full mode reads back the complete RAT mask and `33/33`.

Verdict: one bounded RF run is ready. The only intended behavioral difference
is that the phone cannot take the CP2838/CP2840 early LTE branch before the gNB
starts. The coherent M2SDR, SSB+6, downlink classifier, PRACH phase cycle,
detector, and scheduler remain frozen. Judge valid NR measurement first; if it
passes, judge Msg1/RAR and continue toward Msg3.
