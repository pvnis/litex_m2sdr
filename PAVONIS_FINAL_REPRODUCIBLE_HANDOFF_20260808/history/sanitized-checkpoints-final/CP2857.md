# CP2857 - Continuous srsENB-to-OCUDU transition passes no-RF gate

CP2857 adds a new default-closed transition wrapper without changing any RAN,
qcore, phone, or SDR binary. Its enforced sequence is:

1. start one qcore epoch;
2. start the preserved srsENB/bladeRF positive RAN;
3. prepare the phone and start the established operator scan in the background;
4. require a real private phone interface, srsENB RACH, and qcore user-plane
   activation;
5. stop only srsENB while keeping qcore and phone policy live;
6. start OCUDU/bladeRF and use a fixed observation interval;
7. read status once, then restore/stop/package through trapped cleanup.

The fixed interval avoids CP1901-style polling of a growing gNB log. Separate
fresh phase stamps prevent artifact collisions. The cleanup trap stops the
selector, either RAN, phone policy, and qcore in dependency order on every exit
path.

No-RF proofs pass:

- shell syntax and explicit sequence/invariant probe;
- closed RF gate returns rc2 with zero run artifacts;
- [host-redacted]/[host-redacted] idle and performance preflights;
- ADB and bladeRF enumeration;
- exact active helper hashes;
- selected-USIM FPLMN count 13, zero `90170`, repaired hash.

The active remote selector is intentionally newer than the old local CP2595
copy. Its hash `0b1fdaf2...` adds the proven OnePlus roaming-overlay acceptance
and clear-top relaunch behavior. CP2857 snapshots and pins that live helper; it
does not overwrite it with the older local file.
