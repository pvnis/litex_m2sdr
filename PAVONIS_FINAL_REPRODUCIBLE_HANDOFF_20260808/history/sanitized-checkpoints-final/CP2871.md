# CP2871 - Post-handoff modem epoch makes primer void

The first data-probe run never reaches OCUDU. The mandatory srs private-interface
gate times out and cleanup passes. Its two audited registration identities are
one unique 15-digit exact configured member, so this is the same missing
AuthenticationResponse/service-supply class as CP2867, not identity lookup.

The controlled contrast is now repeatable: CP2868 full phone reboot is followed
by CP2869 srs service and OCUDU attach; the immediate subsequent CP2871 run after
normal phone restore fails its srs primer. Treat a fresh full modem reboot/reload
as a prerequisite for each current phone ladder attempt until attach teardown
state is fixed separately.

CP2871 is void for OCUDU and data; the CP2870 probes never execute. Perform the
same proven no-RF reboot/reload once, then rerun CP2870 unchanged. Do not change
RF, identity, qcore, or data-probe semantics.
