# CP2904 - Post-start operator-reselect no-RF gate

CP2904 adds a default-off post-start reselection branch to the continuous
coherent-M2SDR wrapper. It invokes the established, hash-pinned CP2595 Oplus
`901 70 5G` selector after OCUDU/M2SDR is on air and before consuming the
prearmed qcore activation event. The selector uses its existing bounded scan,
tap, and automatic/full-RAT restore trap; observe time is `30` seconds.

Only when this branch is enabled, the activation and HTTP-server timeout
extends from the unchanged default `90` seconds to `240` seconds so the UI scan
cannot make a valid target attach invisible. Wrapper syntax, disabled/enabled
ordering and timeout propagation, both RF-closed rc2/zero-artifact gates, and
deployed selector hash/syntax/ADB/quiescence checks pass.
