# CP2907 - Post-start airplane-cycle no-RF gate

CP2907 adds a default-off, trap-safe phone airplane cycle after M2SDR startup.
It is mutually exclusive with the CP2901 traffic and CP2904 scan branches.
The cycle holds radio off for `5` seconds, turns it back on, settles `15`
seconds, and verifies airplane disabled, automatic selection, full RAT, and
mode `33/33`. The enabled branch uses the existing `240`-second activation and
HTTP timeout.

Local/helper syntax, on/off ordering, mutual exclusion, and both RF-closed
rc2/zero-artifact gates pass. The deployed no-RF roundtrip passes and proves it
removes the stale private interface (`before=1`, radio-on hold `0`, after=0`)
while preserving automatic selection and mode `33/33`.
