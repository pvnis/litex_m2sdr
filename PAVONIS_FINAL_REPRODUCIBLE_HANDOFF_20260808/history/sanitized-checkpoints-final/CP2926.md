# CP2926: near-zero M2SDR attenuation and post-ready capture gated no-RF

Date: [date-redacted]

CP2926 preserves the CP2924 binary, config, RF plugin, Soapy module, kernel
module, and all pinned hashes. A separate default-closed helper adds only the
srsENB command-line override `--rf.tx_gain=0.1`.

This value is deliberately positive so srsENB takes its explicit-gain branch
instead of substituting `rx_gain=40`; the LiteX driver then interprets it as
`0.1 dB` TX attenuation. The live gate requires the override in `/proc` and
requires the `TX gain was not set` warning to be absent before reporting ready.

Local syntax passes. The deployed helper SHA-256 matches local:
`2f192f855fb67bd87cb175683ee5740ae08613fa0b64b13ca24c9a5da51ecb83`.
Its disabled path returns `rc=2` and leaves zero srsENB process, no temporary
`.52` address, and M2SDR program mode `N`.
