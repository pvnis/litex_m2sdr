# CP2931: consistent srsRAN Soapy physical-channel map gated no-RF

Date: [date-redacted]

CP2931 adds one startup-only, default-off environment control to the srsRAN
Soapy adapter: `PAVONIS_SRSRAN_SOAPY_PHYSICAL_CHANNEL`. With no value or `0`,
logical channels map exactly as before. Value `1` is accepted only for a
single-channel stream and maps RX/TX setup, gain, sample rate, bandwidth,
frequency, antenna, sensor, and readback operations to physical channel 1.
