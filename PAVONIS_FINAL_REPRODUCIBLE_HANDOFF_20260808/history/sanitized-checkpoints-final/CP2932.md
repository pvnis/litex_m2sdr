# CP2932: channel-1 air gate is pre-RF void on library path

Date: [date-redacted]

The bounded channel-1 air gate stopped before opening the SDR. The isolated
plugin directory replaced, rather than augmented, the original srsRAN RF
library directory in `LD_LIBRARY_PATH`; `srsenb` therefore could not resolve
`libsrsran_rf.so.0`.

No RF was emitted and no capture or phone action began. The helper restored
program mode/address state, qcore was stopped explicitly, and the final gate
proved zero srsENB/qcore processes, program mode `N`, and no `.52` alias.

This is an orchestration-only preflight void. CP2933 adds the missing base RF
library directory; do not interpret CP2932 against channel 1.
