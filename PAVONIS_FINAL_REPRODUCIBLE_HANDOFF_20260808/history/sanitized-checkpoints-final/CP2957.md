## Verdict

The isolated RX-gain control is negative as a fix. Live startup proves physical
channel 1, logical control channel 0, and requested/readback `50.00 dB`; all
Soapy timeout, time-error, underflow, and late counters remain zero. The phone
again reaches Registration Request and Authentication Response, but the first
qcore context is released for inactivity while NAS security is being activated.
No Security Mode Complete, private interface, or data follows.

RX50 raises measurements only in already-good opportunities. It does not lift
the floor class and does not improve sustained uplink reliability. Stop RX-gain
sweeping.
