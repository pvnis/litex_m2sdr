## Patch

`mac_nr.cc` adds:

- cached env `PAVONIS_NR_TX_WORKER_TRACE_ARM_FILE_ON_SETUP_ACK`;
- an atomic once-only guard;
- `open(O_WRONLY|O_CREAT|O_EXCL|O_CLOEXEC, 0600)` and `close()`;
- one capped existing-logger event with success or negative errno result.

With the env absent, the cached path is empty and no file operation occurs.
The env lookup is in a function-local static and cannot run per ACK. With an
env path supplied but no setup ACK, `srsenb --version` creates no arm file.
