# CP2967: bounded setup-follow-up UL grants gated no-RF

Date: [date-redacted] Europe/Zurich

## Verdict

The CP2966 PUCCH-SR blocker now has an isolated, default-off diagnostic branch.
After the first valid setup ACK for an RNTI, the branch arms a bounded grant
budget. At each configured SR opportunity where the decoded SR is not valid and
positive, it invokes the existing scheduler `ul_sr_info()` path for that RNTI.
Native valid SR handling is unchanged.

The helper enables `512` opportunities, about 20 seconds at CP2966's observed
SR cadence. This is bounded and long enough to cover the phone's prior Android
data-call setup interval. It is event-level MAC work and adds no lower-PHY
sample processing.

## Implementation

- env: `PAVONIS_NR_SETUP_FOLLOWUP_UL_GRANTS`, cached once and clamped to
  `0..[date-redacted]`; unset/invalid is zero and preserves baseline behavior;
- arm state: atomic RNTI plus remaining-budget counters;
- arm event: first valid setup ACK for a new RNTI;
- injection event: configured SR opportunity for that RNTI with no valid
  positive SR;
- telemetry: one arm marker and at most 128 injection markers;
- the CP2966 TX worker trace is disabled in this helper because that descriptor
  mechanism is already proven and its 12.8 MB output is unnecessary here.
