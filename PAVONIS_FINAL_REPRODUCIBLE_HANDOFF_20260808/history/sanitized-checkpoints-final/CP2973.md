# CP2973: one-shot post-setup DL HARQ retransmission gated no-RF

Date: [date-redacted] Europe/Zurich

## Verdict

The CP2972 discriminator is implemented in an isolated, default-off native
srsENB branch. A cached `PAVONIS_NR_SETUP_FOLLOWUP_DL_HARQ_RETX_ACKS` budget is
armed after the first valid setup ACK. For the same RNTI, the next decoded
positive downlink HARQ ACK is passed to the scheduler as NACK once, forcing one
normal HARQ retransmission. The decoded ACK value remains available to the
setup-ACK logic and telemetry; all later ACKs are handled normally.

The live helper selects a budget of one and retains CP2967's bounded 512 UL
follow-up grants. Unset/zero/invalid values preserve prior behavior. The new
work is MAC-event metadata/control only and adds no lower-PHY sample work.
