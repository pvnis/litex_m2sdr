# CP3023: OCUDU SIB1 compatibility was configured but never reached the gNB

Date: [date-redacted]

CP3021 was reduced no-RF before another phone roll. Its last stage-1 trace
segment contains 1384 PRACH opportunities, only one energy-gated search, seven
candidate evaluations total, zero selections, maximum RMS `-68.692 dB`, and
maximum peak `-58.973 dB`. The gNB did not merely reject a strong phone Msg1;
its configured PRACH windows were effectively empty.

Existing CRC-OK SIB1 transport blocks from the phone-working srsENB/M2 branch
and preserved OCUDU/M2 branch were decoded with a small offline ASN.1 tool built
against the existing srsRAN NR ASN.1 library. The access, selection, PLMN, cell,
and PRACH fields match, including PRACH index 0, frequency start 1, eight
preambles, and the same RACH SearchSpace. Four air fields differ:

- srsENB omits `txDirectCurrentLocation`; OCUDU advertises 312;
- srsENB includes `searchSpaceOtherSystemInformation=1`; OCUDU omits it;
- OCUDU adds `msg3-DeltaPreamble=-1`;
- srsENB advertises `n-TimingAdvanceOffset=n0`; OCUDU advertises `n25600`.

The first two and the timing-offset difference are exactly what the existing
default-off `PAVONIS_GNB_SRSENB_SIB1_COMPAT` source path changes. CP2892 had
set that flag to 1, but the CP2730 stage generator used it only for YAML edits
and omitted it from the detached runner environment. More importantly, the
preserved CP2794 gNB binary contains neither the SIB1-compat marker nor the
SI-`n0` scheduler marker. Thus the intended compatibility branch was doubly
inert in every prior OCUDU/M2 phone run.

The stage generator now validates the flag, exports it into the detached
runner, and prints its runtime value. Enabled and disabled config-only controls
generate exact exports of 1 and 0; the enabled runner includes the runtime echo.
The outer RF gate remains closed by default and returns RC2 with zero artifacts.

The controller-built current gNB contains the required code but cannot run on
[host-redacted] because of newer glibc and mbedcrypto ABIs. Both OCUDU checkouts are at the
same commit. A hash manifest over 30 Pavonis-bearing source files found 23 exact
matches and seven differences; those seven files plus one required PRACH worker
header were backed up and synchronized to [host-redacted]. The native Release build then
passes with hash `9c28a111...`, both compatibility strings, zero missing
libraries, and `--help` RC0. The controller-ABI copy was removed; the preserved
CP2794 binary was not modified.
