# CP3026: Stage-1 energy windows are not valid Msg1

Date: [date-redacted]

The exact CP3024 local-M2-primer-to-OCUDU handoff was repeated with the CP3025
energy-triggered bounded capture active. The primer again reached private
service. The native OCUDU target started with the SIB1 compatibility and n0
markers active, and its transport health remained clean: zero Soapy TX
timeouts, downlink-late events, underflows, and time errors. The target still
produced zero accepted PRACH, RAR, PUSCH, CRC-OK UL, or RRC setup events. The
wrapper returned 1 only because target activation timed out; cleanup restored
the phone and stopped qcore and the radio process.

The CP3025 instrument worked as designed. The final stage-1 segment contains
1393 opportunity rows, 23 energy-gated rows, 161 candidate evaluations, zero
selections, maximum raw RMS `-57.836 dB`, maximum peak `-48.688 dB`, and
maximum search time `3438 us`. It flushed exactly 23 manifest rows and 23 raw
CF32 files, each containing the complete 23520-sample detector input for that
opportunity. The phone monitor had 13 strong target rows at `-81 dBm` RSRP,
`-11 dB` RSRQ, and `+19 dB` SINR, but no target activation.

The first replay with the historical CP1965 tool was geometry-confounded: that
tool hard-codes PRACH RB offset 8, while every CP3026 manifest row reports RB
offset 1. A corrected analysis-only harness reads the manifest geometry and was
preserved with the checkpoint. Corrected replay results are:

- geometry-correct baseline: 23 windows, zero accepts, maximum best ratio
  `0.162`;
- energy-aligned wide CFO: 3417 evaluations over 17 non-noise windows, zero
  accepts, maximum best ratio `0.229`;
- full-window coarse timing/CFO search: 220524 evaluations over all 23 windows,
  zero accepts, maximum best ratio `0.305`;
- refined timing/CFO search around the five coarse leaders: 44935 evaluations,
  zero accepts, maximum best ratio `0.340`.

The broad harness searched all 64 preamble identities. Its strongest result was
preamble 36, not one of the cell's advertised preambles 0 through 7, and still
failed the detector threshold. Preamble 0 never exceeded ratio `0.207`. Thus
the retained energy bursts do not hide a valid phone Msg1 under a timing/CFO
transform; scheduled-slot self leakage or unrelated phone UL is a better fit.

The live stage-1 configuration also has a separate deterministic defect. Every
trace row reports `input_samples=23520` and `candidate_span_samples=23520`, but
the six explicit shifts are `48384`, `73728`, `118016`, `118160`, `169200`,
and `169344`. Each transformed candidate therefore reads entirely beyond the
input and becomes zero. Baseline plus those six entries exhaust
`MAX_CANDIDATES=7`, so the valid built-in signed grid is never reached. The
161 evaluations are 23 opportunities times seven candidates, but only the
baseline candidate contains samples.
