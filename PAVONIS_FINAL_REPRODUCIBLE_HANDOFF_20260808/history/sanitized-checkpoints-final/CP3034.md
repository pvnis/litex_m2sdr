## Verdict

CP3034 does **not** prove that the current OCUDU target omits or corrupts
PBCH/SIB1. It proves that the independent capture helper, on its present
physical/configured receive leg, did not recover PBCH after clipping was
removed. That helper has not been cross-validated against the phone-visible
current target in this geometry, while CP3033 measured a strong PCI-500 cell on
the phone. This is a capture-path/air-delivery discriminator, not a target-SIB1
negative.

The gain-40 point is permanently void for decoding; the gain-20 point is the
unclipped reference and must not be repeated unchanged.

## Next rung

Run the preserved srsUE/bladeRF acquisition path, with heavy diagnostics off,
against the exact same native-compatibility target and judge only normal PBCH
and SIB1 acquisition:

- srsUE PBCH/SIB1 success: current air broadcast is decodable and CP3034 is an
  independent-helper/path artifact; return to phone cell-selection semantics.
- srsUE PBCH/SIB1 failure: current target downlink delivery is suspect; compare
  against the preserved CP2392/CP3019 controls before changing the target.

No phone manipulation and no protocol/RF knob change is justified before this
split.
