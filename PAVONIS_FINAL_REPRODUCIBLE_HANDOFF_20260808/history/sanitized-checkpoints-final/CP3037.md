# Checkpoint 3037: independent RX1 PBCH control path is invalid

Date: [date-redacted]

## Question

Can the low-level bladeRF RX1 helper decode the preserved CP2392 golden target,
thereby providing a direct control for CP3034B's current-target no-PBCH result?

## Frozen shape

- Preserved golden gNB binary `1add70ea...` and config `950694cb...`.
- Current CP3013/CP2074B Soapy module and the CP3036 transport controller.
- Same one-second RX1 helper, center, sample rate, bandwidth, filter, and chunk
  geometry as CP3034B.
- No phone, srsUE, source, binary, target-profile, or protocol change.

## Runs

### CP3037: gain 20

Capture mechanics passed: 352 chunks, zero timestamp gaps, `CAPTURE_OK=1`, and
zero clipping. RMS was `-33.99 dBFS`, component maximum `676`, and PBCH/CSI
were absent. This is 10.08 dB below CP3034B and therefore sensitivity-limited.

Raw SHA-256:
`2e03048cfd9b1cb89b6776dd64be36e8a224c8f29a2c5d0f6b6e7de605d75411`.

### CP3037B: gain 28

Only capture gain changed. Mechanics again passed with 352 chunks, zero gaps,
`CAPTURE_OK=1`, and zero clipping. RMS rose to `-25.88 dBFS` and component
maximum to `1747`, placing it within 1.97 dB of CP3034B's `-23.91 dBFS`
current-target capture. PCI-1 PBCH/CSI remained absent.

Raw SHA-256:
`52b28d422435fb558e9e66cbb042e96e09e3fdbc6ac9ae2c7ac63fef80ae0948`.

Both golden gNB runs had zero Soapy deadline-write timeout, downlink-late,
underflow, and time-error events. All final host gates passed.

## Verdict

The independent bladeRF RX1 helper is not a valid PBCH calibration path in the
current cable/port geometry. At comparable unclipped amplitude it decodes
neither the current target nor the preserved golden target. CP3037 therefore
does not reverse CP3035's current-target acquisition failure, but it removes
CP3034B as independent proof of that failure.

CP3036's golden `set_cell` contrast remains the only positive bladeRF-side
control, and it is limited above PBCH/MIB by the separate srsUE overrun storm.
Do not spend more RF on RX1 helper gain or repeat CP3034/CP3037 unchanged.

## Next rung

Use M2SDR's established immediate `readStream` self-RX path with no external UE
and decode the exact current target at PCI 500. This removes bladeRF, USB, and
the external cable from the receive side. The full append is explicitly valid
for this downlink-only instrument run and remains void for PRACH/RAR conclusions.
