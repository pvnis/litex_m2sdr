# CP3055 - Isolated channel-1 ATT16 reboot/data no-RF gate

CP3055 prepares the single-variable discriminator identified by CP3054. It
does not edit or replace the proven CP2892/CP2893 path. Instead, exact copies of
the remote OCUDU helper and full handoff are placed under new CP3055 names, and
only the target TX attenuation and the corresponding paths/telemetry are
changed. A new outer wrapper retains CP3053's full reboot-under-target and
bidirectional-data sequence.

The helper uses its own append-only run root and sets `TX_ATT=16`. Its start
marker reports `tx_attenuation_db=16`; the isolated handoff requires that
marker and packages the new run root. All other target values remain frozen:
physical channel 1, CP3025 gNB, CP3013 Soapy module, phase mode off, early
capture off, RX gain 40 dB, the established protocol/SIB1/PRACH configuration,
full phone reboot after target start, and prearmed activation plus private HTTP.

## Verdict

CP3056 is RF-gated. It changes only channel-1 target attenuation from CP3054's
0 dB to 16 dB. The first boundary is phone Msg1; if access resumes, the same
run continues through RAR, Msg3, registration, private interface, and both HTTP
directions. No detector threshold, PRACH timing, stage-1 envelope, scheduler,
protocol, gain, binary, or Soapy change is permitted in this comparison.
