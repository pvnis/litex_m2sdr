# CP3061 - Filtered phone RACH diagnostic no-RF gate

CP3061 gates the missing phone-side MAC/PHY discriminator without transmitting
RF. Prior checkpoints already closed OCUDU broadcast compatibility, target
lifecycle, M2SDR channel selection, downlink level, and gNB PRACH receive [interface-redacted].
The remaining question is whether Qualcomm commands a physical random-access
transmission after the observed internal UL-CCCH records.

## Instrument

An isolated QCSuper shim enables exactly three Qualcomm Diag log codes:

- `0xb821`: NR RRC OTA, retained as the established phase marker;
- `0xb889`: NR5G MAC RACH Trigger;
- `0xb88a`: NR5G MAC RACH Attempt.

The shim sets QCSuper's existing `limit_registered_logs` mask before DLF capture.
It does not modify the installed QCSuper package. The lifecycle wrapper pins the
shim hash, records only a raw local DLF, and restores the phone from temporary
`diag,adb` to its original authorized `adb` USB mode on normal exit or failure.
The compact parser emits counts by code only and never emits RRC payloads,
subscriber identifiers, NAS bytes, or credentials.

Final hashes are:

- filtered entry: `efe1c8031e297b5bdfd143a1b2241115837ff3c3658aebe4d355718575bc3b38`;
- remote lifecycle wrapper: `ebaef596d9a6dc06bd26280f86a05edce43440c07fdf2b69250245df1d342f95`;
- aggregate DLF parser: `f275a3d0dee1e1138df9280bb86a27e0fa3fc22d7ce7f0a930c29630f3ddd55c`.

## No-RF proof

The first smoke was packaging-void: QCSuper re-entered the shim through its
generic system-Python shebang after USB transition and lost the isolated venv.
No RF process ran, and cleanup restored `adb`. The final shim uses the pinned
QCSuper venv interpreter directly.

Fresh smoke `[date-redacted]CP3061B_QCSUPER_FILTERED_NO_RF` passes start,
eight-second status, stop, and final authorized-ADB gates. The log has the
filtered-code marker and one logging-enable event with zero errors. Its no-RF
DLF is correctly empty: zero records, zero malformed/trailing bytes, and zero
unexpected codes. The repeated entry marker documents QCSuper's USB re-entry;
the explicit interpreter keeps both entries inside the isolated environment.
An in-memory synthetic DLF check then proves the parser's 12-byte `<HHQ>`
framing, all three code counts, timestamp conversion, variable payload lengths,
and zero malformed/trailing bytes.

## Verdict

The observer is ready for one bounded frozen-target run. Wrap the proven
channel-1 ATT16 CP3059/CP3060 target without changing radio, protocol, timing,
detector, subscriber, or phone policy. Interpret in this order:

1. no `0xb889`: access is suppressed before Qualcomm MAC triggers RACH;
2. trigger but no `0xb88a`: trigger-to-attempt handoff is the failing boundary;
3. attempt present but no detector-valid air Msg1: inspect the aggregate attempt
   result/geometry with a privacy-preserving parser, then localize phone RF TX;
4. gNB Msg1/RAR appears: continue the already-armed attach and data ladder.
