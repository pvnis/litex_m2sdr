# CP3062 - Filtered phone RACH diagnostic wrapper no-RF gate

CP3062 integrates the CP3061 filtered Qualcomm observer around the proven
continuous local-M2-primer to OCUDU/M2 target handoff. No RF is transmitted in
this checkpoint.

## Frozen run shape

The observer starts before the phone-working srsENB/M2 primer. That primer is
the in-run positive control for NR5G MAC RACH Trigger (`0xb889`) and RACH
Attempt (`0xb88a`). Without restarting qcore or changing phone policy, the run
then swaps to the current OCUDU target with:

- M2SDR physical channel 1;
- real 16 dB TX attenuation through the CP3059 stage-side force path;
- CP3025 gNB and CP3013 Soapy source/module hashes;
- PRACH phase sequence off and early raw capture disabled;
- no post-target phone reboot;
- target activation, private interface, and bidirectional HTTP path armed.

No radio, broadcast, scheduler, PRACH detector, timing, threshold, subscriber,
or phone-policy value changes from the established target. Omitting the already
negative reboot keeps QCSuper alive and preserves the primer as a positive
control in the same diagnostic epoch.
