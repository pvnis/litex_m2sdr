# CP3063 - Phone MAC attempts RACH but OCUDU accepts none

CP3063 executes the CP3062 frozen channel-1 ATT16 target with the bounded
Qualcomm RACH observer. RF is transmitted. The local srsENB/M2 primer is the
same-run positive control; the target is the CP3025 OCUDU gNB on the CP3013 /
CP3059 LiteX path. No PRACH timing, candidate, threshold, scheduler, phone
policy, subscriber, or radio parameter changes are made.

## Observer verdict

The filtered observer is valid. It writes 108 well-formed records in 9,646
bytes with no unexpected codes, malformed records, or trailing bytes. The
primer phase records 23 NR-RRC packets, one RACH trigger, and one RACH attempt.
That attempt reports result code 0 and message bitmask 15, establishing the
complete successful RACH path as an in-run positive control.

After target readiness at `[date-redacted]`, the phone records 45
NR-RRC packets, five RACH triggers, and 33 RACH-attempt records. They form five
groups beginning at approximately +26.20, +37.24, +48.28, +59.31, and +70.35
seconds. Twenty-eight records carry result code 1 and 29 carry the Msg1-only
bitmask. Public Qualcomm diagnostic examples identify result code 1 as a Msg2
RA-response timer expiry. Five terminal records carry result code 7; its exact
name is deliberately left unassigned because the available evidence does not
prove that enumeration.

This closes the hypothesis that the target-side phone simply suppresses random
access. Its MAC triggers RACH and performs repeated Msg1 attempts, but it sees
no Msg2/RAR.

## Run result

The target activation timeout is the expected ladder failure, not a wrapper or
observer failure. The observer exits cleanly, USB adb is restored, [host-redacted] is
idle in DMA program mode `N`, and both final host gates pass.

The smallest next discriminator is a simultaneous, independent bladeRF RX2 UL
capture covering the full target-attempt epoch. Align bounded capture windows
to the five observer timestamps and replay only those windows through the
validated detector. This directly separates no valid phone RF Msg1 from an
M2SDR collection/presentation failure. Do not [interface-redacted] stage-1 candidates from the
current capped trace.
