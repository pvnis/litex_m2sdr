# CP3067 - Same-file primer/target UL observer no-RF gate

CP3067 stays no-RF. It qualifies the next experiment after CP3066 and corrects
the strength of that checkpoint's timing inference without reopening detector
[interface-redacted].

## Why another observation is required

CP3066 proves that the exact Diag timestamps, nearby peaks within 100 ms, the
advertised RB, all alternative baseline RB placements, and the validated
stage-1 envelope contain no detector-valid preamble. It does not yet prove that
the Diag timestamp is sample-synchronous with the phone's physical burst.
CP2707's established air positive control found the strongest phone PRACH 642
ms before the srsENB RACH-log trigger. That trigger is not the current embedded
Diag timestamp, so the offset cannot simply be copied; it must be measured.

The configuration branch does not provide a fresh discriminator. CP3046
already proves that the successful srsENB/M2 primer and current OCUDU cell match
on PRACH index 0, frequency start 1, root 1, zero-correlation zone 0, eight
preambles, target -110 dBm, ramp 4 dB, transmission maximum n7, response window
10, UL Point A/BWP, and the absolute occasion lattice. CP2714 and CP2718 also
closed the remaining decoded MIB/SIB1 structural compatibility profile. Those
audits will not be repeated.

## Gated run shape

The CP3067 wrapper preserves the hash-pinned CP3062 sequence and changes only
the passive observer timing:

1. Arm bladeRF RX2 at 1747.5 MHz, 11.52 Msps, 10 MHz, gain 32, normal filter.
2. Capture exactly 2,073,600,000 SC16 samples, or 180 seconds.
3. Start the existing filtered Diag plus local srsENB/M2 primer.
4. Continue without interruption through the frozen OCUDU/M2 channel-1 ATT16
   target and all target attempt groups.
5. Retain the full raw remotely only until bounded primer and target windows
   have been extracted, replayed, and hashed.

This makes the primer a same-device, same-file physical positive control and
allows direct measurement of embedded Diag timestamp versus observed air time.

## No-RF proofs

- Shell syntax and sequence probe pass; the capture-start call precedes the
  CP3062 base invocation mechanically.
- RF approval defaults closed with exit 2 and zero artifacts.
- A non-exact capture length fails before artifact creation.
- The remote capture timeout is derived from sample count plus 30 seconds; the
  detached-control wait bound is 240 seconds.
- Capture, control, and compact analyzer deploy by pinned hash and pass remote
  syntax checks.
- The detached start/wait ownership smoke passes and its temporary tree is
  removed.
- [host-redacted] is idle, has exactly one authorized ADB device, a readable bladeRF,
  and more than the required 9.2944 GB.
- [host-redacted] is idle, has `/dev/m2sdr0`, all CPU policies report performance
  governor/EPP, and the pinned CP3025 gNB hash matches.

## Verdict and next rung

The gate passes. Run CP3068 once with a fresh stamp. The run is valid only if
the primer Diag reports success and the same raw file contains a strong
advertised-band primer burst. Use that positive to derive the Diag-to-air
offset, then inspect/replay target windows at both exact timestamps and the
measured offset. A target negative after this calibrated join is valid evidence
of no physical Msg1; a recovered target burst instead returns the frontier to
OCUDU receive timing/presentation. No threshold, stage-1, broadcast, power, or
phone-policy changes are allowed in CP3068.
