## Verdict and correction

The independent bladeRF RX2 observer is not a valid phone-uplink instrument in
the current antenna/port geometry. Consequently, CP3065 and CP3066 establish
only that this observer path contains no valid target PRACH. Their stronger
inference that the phone emitted no physical Msg1 is superseded and must not be
used to choose the next branch. CP3066's replay-RB correction remains valid.

The target frontier returns to the actual M2 physical-channel-1 RX stream used
by OCUDU. The next observation must tap that stream. The safest existing route
is an explicitly detection-void, observation-only gNB-owned RX append spanning
the target attempt epoch, with the CP1894 rule stated in the report. A valid
same-path waveform finding would decide wrong timing/frequency versus absent
transmission; it must not be judged on live PRACH/RAR while append is enabled.
No detector, stage-1, broadcast, power, or phone-policy [interface-redacted] is justified by
CP3068.
