# CP3069 - M2 channel-1 RX observer no-RF gate

CP3069 stays no-RF. It gates the same-path waveform observation required by
CP3068 without rebuilding OCUDU, changing the deployed gNB binary, or modifying
any protocol/radio parameter.

## Observer shape

The frozen CP3062 primer-to-target sequence remains intact. The target's
CP3059 remote helper is extended with a default-off observation branch:

- selected logical RX port 0, which maps through the frozen physical-channel
  offset 1 to the phone antenna's M2 RX channel;
- existing gNB-owned `readStream` append path;
- exactly 921,600,000 post-conversion CF32 samples, or 80 seconds at
  11.52 Msps;
- append metadata and RX readback enabled, individual raw-window dumps off;
- summary cap 2,200,000 so the append cannot silently stop at the old cap;
- raw, metadata, and readback written under a separate
  `/home/[host-redacted]/pavonis_m2_rx_observer/cp3069_<stamp>` tree.

The separate root is not included in the normal [host-redacted] package command, avoiding
an accidental multi-gigabyte tar transfer. The usual run tree and artifact
packaging remain unchanged.

## Classification

This is deliberately a CP1894 detection-void run. Full-rate gNB-owned append
is a known observer effect and no live PRACH, RAR, Msg3, CRC, or registration
result from this execution may be used as a ladder datapoint. The only judged
questions are whether the target Diag still supplies attempts, whether the full
append and metadata complete, and what waveform appears in the actual M2 RX
samples at the Diag-aligned epochs.

## No-RF proofs

- The append defaults to off; in that state `PAVONIS_SOAPY_RX_DUMP` and all
  file paths are absent and the inherited append-enable value remains zero.
- Enabled length is hard-gated to 921,600,000 samples; an invalid value exits
  before creating a run tree.
- Capture and metadata paths are outside every directory named by the existing
  package command.
- The remote helper and both local wrappers pass shell syntax and sequence
  checks. RF approval defaults closed with exit 2 and zero artifacts.
- The [host-redacted] helper deploys by hash. Program mode is N, gNB/qcore/srsENB are
  idle, CPU governors are performance, `/dev/m2sdr0` is present, storage
  exceeds 12 GB, and the pinned CP3025 gNB hash matches.
- Binary-safe direct matching proves the deployed gNB contains the append path,
  sample-cap, and dump controls. The first `strings | grep -q` form returned
  exit 141 from SIGPIPE under `pipefail`; this is the campaign's known false-
  negative signature, not a failed binary proof. The corrected check passes.
- [host-redacted] is idle and has exactly one authorized phone.

## Verdict and next rung

The gate passes. Run CP3070 once with a fresh stamp. Require the complete
7,372,800,000-byte CF32 file, complete append metadata/readback, and target Diag
attempts. Use metadata wall timestamps to map the embedded Diag events into M2
sample offsets, extract only bounded windows, then replay actual RB 1 baseline
and stage 1. If the phone makes no target attempts, or append truncates, the
waveform result is void. Regardless of outcome, live detector/RAR results are
void by design.
