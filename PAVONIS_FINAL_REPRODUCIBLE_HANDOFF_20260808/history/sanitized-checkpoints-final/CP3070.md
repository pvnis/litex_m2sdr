# CP3070 - M2 RX observer arm-file void

CP3070 executes the CP3069 waveform-only shape. RF is transmitted, but the
waveform axis is void because the append never arms. No ladder conclusion is
drawn.

Stamp: `[date-redacted]CP3070_M2_RX_OBSERVER`.

## Valid execution context

The unchanged primer-to-target lifecycle runs and cleans up. The target uses
physical channel 1, TX attenuation readback 16 dB, the pinned CP3025 gNB, and
the expected Soapy source/module hashes. Final [host-redacted] state is idle with M2
program mode N.

Filtered Diag is healthy: 125 records, zero malformed/unexpected/trailing data,
seven RACH triggers, and 37 attempt records. Using completion of the target gNB
start as the conservative phase boundary gives two primer triggers/two attempts
and five target triggers/35 attempts. Thus the phone supplied target access
intent while this observer shape was active.

## Instrument failure

The helper state proves `M2_RX_APPEND=1`, the exact 921,600,000-sample cap, and
the intended external CF32/metadata/readback paths. The generated gNB harness
also contains append enable, path, port, cap, summary cap, and dump exports.
However, the external observer directory is empty.

The generated harness explains the failure mechanically:

- `PAVONIS_SOAPY_RX_APPEND_IMMEDIATE=0`;
- the starter assigns `PAVONIS_SOAPY_RX_DUMP_ARM_FILE` to its inherited arm
  file;
- that arm file is not touched in this run;
- consequently no CF32, metadata, or readback file is opened.

The CP3069 helper supplied the append controls but omitted the one existing
starter control that touches the arm before launch. This is instrumentation
plumbing, not an RF or M2 receive result.

## Verdict and next rung

CP3070 is valid evidence that target Diag supply survives the intended observer
shape, but it is waveform-void and detector-void. Add only
`PAVONIS_SOAPY_RX_APPEND_IMMEDIATE=1` to the enabled append environment. Keep
the default-off branch unchanged, prove from starter source that immediate mode
touches the exact arm file before harness launch, redeploy by hash, and rerun
once with a fresh stamp. No detector, stage-1, broadcast, power, phone-policy,
or packaging change is allowed.
