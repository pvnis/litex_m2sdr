## Purpose

timing correction or weakening OCUDU's default licensed-band guard.

## Isolated implementation

A new helper path was created from CP3073 rather than overwriting it:

`cp3080_ocudu_m2sdr_timing230613_ra40_remote.sh`

The helper derives one value from the already validated RA response window:

- window `1..10`: `PAVONIS_ALLOW_EXTENDED_RA_RESP_WINDOW=0`;
- window `11..80`: `PAVONIS_ALLOW_EXTENDED_RA_RESP_WINDOW=1`.

It forwards that value to OCUDU and records it in probe, state, and start
markers. The continuous wrapper selects the new helper and verifies the marker;
the outer wrapper pins the resulting base hash. No gNB, Soapy, stage, qcore,
phone, timing, detector, threshold, or RF setting changed.
