# Checkpoint 3082: bounded shifted-path Msg3 capture no-RF gate

Date: [date-redacted]

## Purpose

CP3081 restored phone Msg1, gNB RAR transmission, phone RAR receipt and phone
Msg3, but the gNB did not decode PUSCH. This checkpoint gates the already-built
CP2204 shifted-path exact scheduled-Msg3 capture before changing any UL offset.

## Isolated implementation

Three fresh wrappers preserve the CP3080/CP3081 chain:

- `cp3082_ocudu_m2sdr_timing230613_ra40_msg3_target_remote.sh`;
- `cp3082_run_continuous_srsenb_to_ocudu_msg3_target_rf.sh`;
- `cp3082_run_filtered_phone_msg3_target.sh`.

The helper defaults to capture off and raw cap zero. The approved shape enables
scheduled-Msg3 targeting, metadata-only processing, at most eight scheduled
targets and at most 128 raw symbols. Full-rate Soapy RX append remains off.
Each raw file is written after the dynamic non-PRACH shift and CFO correction,
immediately before the normal PUxCH processor. The helper removes only stale
target-capture files at start and packages the bounded manifest/raw set after
gNB shutdown, so the outer wrapper can recover it even when endpoint activation
times out.

No gNB, Soapy, stage, qcore, phone, RF configuration, threshold, RA timing,
dynamic-offset or PUSCH behavior changed.
