# Checkpoint 3094: context transport passes; edge estimator fails the Msg3 CP gate

Date: [date-redacted]

## Run

CP3094 ran the frozen phone shape with only the CP3093 context-carried edge
binary selected. The physical path remained channel 1 at 16 dB attenuation;
PRACH timing was `230613/0`, the RA response window was 40, full RX append was
off, and the bounded Msg3 capture was eight targets with 128 raw symbols.

The run is a valid endpoint-class datapoint despite the outer wrapper's expected
nonzero endpoint return. Host health is clean: zero Soapy TX timeout,
downlink-late, underflow, and time-error markers. Both host postchecks pass,
the M2SDR is back in program mode `N`, the gNB is stopped, and the phone remains
available over ADB. The deployed gNB and wrapper hashes remain
`e7021783...` and `c5ba425c...`; no preserved baseline was overwritten.

## Accepted-edge transport

The run produced 15 dynamic publications and 15 consumes. Thirteen
publications came from `upper_accept_edge`; two came from the immediate
stage-1 path. This confirms that normal upper-detector accepts now reach the
dynamic non-PRACH offset path.

The context-stage trace was capped at 64 rows and therefore covered only the
first three publications. All three logged stage/publication pairs match
exactly in slot and edge value. Later publications are trace-blind rather than
observed mismatches. Unlike CP3092, the live CP3093 source has no global ring,
wrapped-slot lookup, or mutex: the upper task reads the edge from the copied
`prach_buffer_context` associated with that exact detector input. The aliasing
transport defect is closed, with the trace-cap caveat recorded.

plus Msg3 transmission. All eight bounded target slots contain scheduled-grid

fixed short-waveform result.

## Verdict

PASS for exact context transport; FAIL for the current energy-edge estimator.
The phone waveform is present and the upper decoder runs after all grid writes,
but per-occasion timing remains outside the CP.

Stay no-RF next. Package the already-bounded CP3094 strong PRACH windows and
pair each accepted occasion with its captured Msg3 residual. Develop and replay
a more precise accepted-event edge estimate from those saved samples before
another RF roll. Do not retune static timing, grant semantics, thresholds, or
power, and do not rerun CP3094 unchanged.
