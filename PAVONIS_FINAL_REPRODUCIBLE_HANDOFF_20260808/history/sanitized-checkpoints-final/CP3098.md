# CP3098: canonical Msg3 symbol branch passes the no-RF gate

Date: [date-redacted]  
RF transmitted: no

## Question

CP3097 showed that the CP3095 nearest-lattice edge snap fixes fractional
timing but preserves an arbitrary whole-OFDM-symbol alias. That alias predicts
the exact number of active symbols observed in every reliable CP3096 Msg3
target. Can the shared edge publisher select one congruent canonical branch,
without changing the established behavior when the new control is absent?

## Patch

The common edge publisher in
`ocudu/include/ocudu/support/pavonis_dynamic_non_prach_ul_offset.h` now accepts
the default-off, env-cached control:

```text
PAVONIS_NON_PRACH_UL_RX_OFFSET_EDGE_LATTICE_CANONICAL_SAMPLES
```

The control only activates when the lattice period is nonzero and the proposed
canonical edge is congruent to the configured anchor modulo that period.
Absent, invalid, non-congruent, and period-zero configurations retain the
CP3095 nearest-snap behavior. The publish row now distinguishes:

```text
edge_samples
edge_samples_snapped
edge_samples_applied
```

The CP3098 wrapper sets period `823`, anchor `-138`, and canonical edge `4800`.
This is the CP3097 branch `-138 + 6*823`; with the frozen calibration it
publishes offset `-242132`.

## Focused proof

`cp3098_test_canonical_edge.cpp` uses the exact eight CP3096 raw/snapped edge
pairs. It passes under `-Wall -Wextra -Werror` in five independent processes:

1. fully default;
2. nearest-snap only;
3. valid canonical `4800`;
4. invalid non-congruent `4801`;
5. canonical requested with period zero.

The nearest mode reproduces all eight CP3096 snapped edges. The canonical mode
maps every pair to edge `4800` and offset `-242132`. Invalid and period-zero
requests remain disabled.

## Verdict

PASS. CP3098 is a minimal, default-off implementation of the CP3097 model. It
does not claim that edge `4800` is a permanent architectural fix; it makes the
whole-symbol branch hypothesis directly testable while preserving every prior
baseline and frozen RF/protocol setting.
