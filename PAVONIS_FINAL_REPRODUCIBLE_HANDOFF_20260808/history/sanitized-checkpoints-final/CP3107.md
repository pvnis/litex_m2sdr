# CP3107: Msg3 contention-origin rebase passes no-RF gate

Date: [date-redacted]  
RF transmitted: no

## Scope

CP3106 proved that every CRC-OK Msg3 traversed PHY, FAPI, MAC, DU, RRC and
F1/SRB0, then expired in the fallback scheduler at age 65 slots against the
64-slot contention-resolution timer. The active non-PRACH receive shift was
`-230610` samples. At `11520` samples/slot, its nearest whole-slot correction
is `+20`.

This checkpoint adds a default-off rebase at the narrow MAC CCCH handoff. It
changes only `ul_ccch_indication_message.slot_rx`, which becomes the scheduler
contention origin. PHY/FAPI PUSCH result slots, CRC/HARQ attribution and all
other channel timing remain nominal.

## Implementation

The new header caches these controls once:

```text
PAVONIS_MSG3_CONRES_SLOT_REBASE_FROM_NON_PRACH
PAVONIS_MSG3_CONRES_SAMPLES_PER_SLOT
PAVONIS_MSG3_CONRES_MAX_SLOT_OFFSET
PAVONIS_MSG3_CONRES_SLOT_REBASE_TRACE_LIMIT
```

It reads the existing dynamic non-PRACH offset snapshot, rounds a negative
sample offset to the nearest positive slot correction, and rejects absent,
invalid, nonnegative, zero-divisor or oversized values. Enabled telemetry is
metadata-only and bounded; it records nominal/adjusted slots, sample/slot
offset and generation.
