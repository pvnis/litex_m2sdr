# CP3108: MAC-level rebase moves expiry with the origin

Date: [date-redacted]  
RF transmitted: yes, one bounded frozen phone run

## Run validity

The exact CP3106A RF shape ran with only the CP3107 wrapper added. Preflight,
local M2 primer, qcore, OCUDU start/stop, phone diagnostics and cleanup all
passed. Channel 1, ATT16, RA window 40, edge `-6722`, dynamic offset
`-230610`, CFO zero and full append off were preserved. No Soapy timeout,
downlink-late, underflow or time-error markers occurred.

The run is valid for Msg3/Msg4 judgment. Its nonzero wrapper result is the
expected target-activation timeout because the phone did not progress.

## Result

The gNB produced 25 CRC-OK PUSCH results out of 75. All 25 again traversed
PHY/FAPI, MAC unpack and CCCH dispatch, DU creation, Initial UL RRC, RRC Setup
packing and F1/SRB0. The new rebase fired exactly 25 times, always:

```text
offset_samples=-230610 offset_slots=20
```

It did not unlock Msg4. Every attempt still ended at
`fallback_pdsch:conres_expired`; there were zero new-TX allocations.

The first event sequence is representative:

```text
PHY Msg3 slot       369
rebased CCCH slot   389
first PDSCH check   454
```

Thus the first candidate moved to nominal+85 and remained exactly
rebased-origin+65 against the 64-slot timer. Wall time from PHY CRC callback to
expiry also moved from CP3106's 38.7 ms class to 58.3-59.4 ms. The direct MAC
placement therefore moved the downstream availability/check point with the
origin and left the failing age invariant.

## Source conclusion

`ul_ccch_indication_message.slot_rx` crosses DU creation and scheduler
configuration before the UE enters the scheduler repository. The scheduler
then uses that value for both `ue_drx_controller` and
`ue_pcell_state.msg3_rx_slot`. The correction must be applied at scheduler
repository insertion, after the creation event is dequeued, so the external
event timeline remains nominal while the stored contention/DRX timer origin is
adjusted.

Verdict: valid negative. Move the rebase from `pdu_rx_handler` to
`ue_repository::add_ue`, pass only the adjusted local value to the DRX
controller and UE cells, and add bounded metadata proving nominal, adjusted
and first candidate slots. Gate no-RF before another frozen run. Do not change
the timer, RF, timing, power, grant or threshold fixtures.
