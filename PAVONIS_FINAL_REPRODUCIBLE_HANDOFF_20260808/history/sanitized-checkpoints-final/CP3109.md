Date: [date-redacted]

## Change

CP3108 showed that rebasing `ul_ccch_indication_message.slot_rx` at the MAC
handoff moved the first fallback PDSCH check by the same 20 slots and left the
65-slot failure invariant.

This checkpoint restores `pdu_rx_handler.cpp` byte-for-byte to the CP3105
state. The outer MAC/DU/scheduler creation event therefore carries the nominal
Msg3 slot again. The existing default-off arithmetic helper is now called only
inside `ue_repository::add_ue`, after the scheduler creation event has been
dequeued. Its adjusted local value is passed to the new UE's DRX controller
and UE-cell contention state; the caller's slot and all PHY/FAPI/CRC/HARQ
attribution stay nominal.

The enabled path emits the existing bounded
`PAVONIS_MSG3_CONRES_SLOT_REBASE` row plus a
`scheduler_conres_slot_rebase` path stage. No payload or persistent identity
is recorded.
