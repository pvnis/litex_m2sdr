## Entry point

`pavonis_poc_cold_lab.sh` is a fail-closed staged entry point:

1. CP2317 ZMQ attach and private user-data;
2. preserved CP2392 M2SDR plus bladeRF bounded-hardware attach/data;
3. CP3114 real-phone M2SDR OTA attach and bidirectional private HTTP data.

Each later stage is unreachable if the previous stage fails. `run` requires
both `PAVONIS_POC_RUN_APPROVED=1` and `PAVONIS_POC_RF_APPROVED=1`; `probe`
is read-only/no-RF. The script uses fresh identifiers, mode-600 transient
private UE material, helper-only SSH/SCP, deterministic cleanup, exact source,
binary, wrapper, config, kernel, module, Soapy and gateware pins, and direct
milestone gates. The ZMQ stage explicitly handles CP2317's known summary-parser
false negative by requiring the direct ping, Random Access and RRC markers.

The CP2392 runner remains an immutable regression fixture and can still emit
historical diagnostics. Those rows are not POC success conditions and remain
class C. The phone stage uses only the CP3114 final data gates.
