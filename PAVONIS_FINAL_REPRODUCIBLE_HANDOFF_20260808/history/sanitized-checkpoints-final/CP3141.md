# CP3141 - qcore stale-session and IMS negotiation fix

## Verdict

PASS, no RF and no live deployment.

qcore now gives standards-layer responses for both Phase 1 session-negotiation
failures:

- an unsupported IMS DNN receives a PDU Session Establishment Reject with
  5GSM cause 27, preserving the request's PDU session ID and PTI;
- an `existing PDU session` or `existing emergency PDU session` request for a
  session absent from qcore receives a PDU Session Establishment Reject with
  5GSM cause 54 before any user-plane allocation.

Registration-time stale-session synchronization remains state-honest. A fresh
qcore reports the requested session in the reactivation-failure bitmap and
reports it inactive in PDU Session Status; it does not pre-plant or invent
session state.

## Root cause

The old IMS branch validated the DNN before decoding the inner 5GSM message.
It answered the outer UL NAS Transport with a 5GMM Status cause 91 and then
discarded the PDU Session Establishment transaction. The handset therefore
did not receive a reject tied to the pending session ID/PTI.

The UL NAS Transport `request_type` was also discarded. Consequently qcore
could not distinguish a fresh initial request from an explicit request to
recover a session that the fresh core did not have.

The corrected split follows TS 24.501:

- clauses 6.4.1.4.3 and table 9.11.4.2.1 for cause 27;
- clause [ip-redacted] for cause 54;
- clauses 5.5.1.3.2 and 5.5.1.3.4 for registration-time session-status
  synchronization.

No reactivation error-cause IE was invented. The available 5GMM causes describe
resource or service-area failures, not an AMF with no matching session context;
the inactive PDU Session Status is the specified local-release signal.

## Changes

- Propagate UL NAS Transport request type into session establishment.
- Reject missing existing sessions before parsing type or allocating user
  plane.
- Move IMS handling into the 5GSM session procedure and reject with cause 27.
- Preserve the generic 5GMM Status builder as an unused public helper; the IMS
  path no longer calls it.
- Extend the mock UE to assert reject cause, PDU session ID, and PTI.
- Add regressions for IMS rejection, explicit missing-session rejection followed
  by a fresh request, and CP3140-style registration stale-state synchronization
  followed by a fresh request.
