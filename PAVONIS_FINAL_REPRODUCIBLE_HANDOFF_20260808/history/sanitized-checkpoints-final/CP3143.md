valid. The CP3142 report's references to that code as OCUDU should be read as
the srsRAN primer path. The standalone cold run uses the separate modern OCUDU
binary, where this hook is absent.

This distinction also preserves the goal's baseline rule: the proven CP3121
primer files and deployed primer binary remain byte-for-byte unchanged. The
source fix exists for review and future replacement, but the success run will
not start the primer.
