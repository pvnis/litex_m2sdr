# CP3148 - Phase A report correction and real-world OTA throughput

## Verdict

**Honest partial.**

The append-only report correction is complete. It replaces the stale
primer-free and retained-context roadmap claims with the CP3144 and CP3147
truth, and it adds separate real-world OTA and conducted/high-SNR performance
envelopes.

The sustained real-phone benchmark is not proven. The first launch was a
no-RF host-state void. A later run reached target activation in 20.344 seconds
with clean RF health, but a new readiness request consumed the frozen
single-use HTTP server sequence; that attempt is instrumentation-invalid and
has no throughput result. After the benchmark was moved strictly behind the
original CP3121 HTTP PASS gate, two consecutive attempts stopped before OCUDU
at the same primer-supply condition. The single-void rule therefore stops RF.

CP3133's one-MiB medians remain the only proven real-phone throughput values:
786,864 B/s downlink and 12,012 B/s uplink. They are not relabelled as
sustained results. Phase B remains locked.
