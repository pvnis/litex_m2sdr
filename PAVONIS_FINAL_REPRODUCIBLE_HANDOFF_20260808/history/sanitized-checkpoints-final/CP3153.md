## Verdict

`PASS`. A dedicated sustained benchmark now sits beside the CP3121

## Evidence

The benchmark reuses the proven CP3121 attach, radio, scheduler, timing, and
data-plane shape. After target activation, a separate persistent core-side
HTTP source/sink serves one 45-second downlink transfer and one 45-second
uplink transfer. The phone-side client discovers the active private interface,
binds traffic to it, records interface counters, and emits independent endpoint
metrics. The analyzer requires both endpoints, both durations, and both
directions to complete.

Primer bring-up now uses the lifecycle proven by the CP3133 20-run campaign:
a fresh phone epoch, a SIM power cycle, and a policy audit with one bounded
audit retry. A primer-service timeout is classified separately and can be
retried only with a fresh artifact identifier.

The local persistent-server integration test passes. Five shell files and
three Python files pass syntax checks. Sequence proof records
`CP3153_ONE_SHOT_HTTP_PROBE=DISABLED`, and the entry point exits `2` without
creating an attempt when RF approval is absent. Both remote helper copies
hash-match their local sources; lifecycle helper pins, idle state, SDR device
state, CPU performance state, and one authorized phone all pass read-only
checks.
