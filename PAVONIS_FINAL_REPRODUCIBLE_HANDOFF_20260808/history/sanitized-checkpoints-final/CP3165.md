# CHECKPOINT 3165 - Conducted downlink deadline no-RF gate

## Verdict

Pass. The CP3164 downlink measurement defect is fixed and one exact-shape RF
rerun is unlocked.

## Defect and fix

The conducted UE client previously read until EOF. Its timeout check ran only
after a socket timeout, so continuously arriving queued bytes extended the
nominal 45-second measurement to `51.460801 s`.

The isolated CP3165 client starts one deadline thread when downlink receive
begins. At the requested interval, the thread shuts down only socket receive.
The blocking receive returns and the client records bytes and elapsed time
without waiting for sender EOF. Server, analyzer, radio configuration, and
protocol behavior are unchanged.
