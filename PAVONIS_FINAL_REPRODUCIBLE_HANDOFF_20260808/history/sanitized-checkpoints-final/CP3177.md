# Checkpoint 3177: isolated 20 MHz no-RF gate

## Verdict

PASS. A separate, hash-pinned launcher now expresses the first wider-bandwidth
step as `20 MHz / 23.04 Msps / 106 PRB / single-layer / MCS9 / FDD`.
The proven CP3176 chain remains untouched.

The gNB copy changes only the sample rate and channel-bandwidth fields in its
per-run generated YAML. The srsUE copy changes only `srate`,
`max_nof_prb`, and `nof_prb` in its per-run private config copy. The source
supports 106 PRB and 23.04 Msps, and the M2SDR reports a supported sample-rate
range of `0.55..122.88 Msps`.

The generated gNB config passes OCUDU `--dryrun`. The generated UE config
contains `23.04e6 / 106 / 106`. Their complete files remain on their owning
lab roles and are referenced only by SHA-256 because the UE config inherits
private test credentials.

## Timing audit

Every active value expressed in samples was converted from 11.52 to
23.04 Msps by doubling its integer sample count. This includes PRACH timing
compensation, PRACH collection margin, non-PRACH offsets and edge calibration,
SFN acquisition offset, TX guard, and the PRACH debug offset. The 19 stage-1
candidates double only the integer shift; fractional-sample and CFO values are
unchanged.

The machine audit proves each old/new sample pair represents the same time.
Values expressed in nanoseconds, slots, hertz, degrees, or booleans remain
unchanged.

single layer, FDD profile, attenuation, gains, sustained duration, and traffic
