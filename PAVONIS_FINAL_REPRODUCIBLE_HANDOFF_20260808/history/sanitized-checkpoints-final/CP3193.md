# Checkpoint 3193: native SR scheduler join

Date: [date-redacted]

RF executed: no

## Verdict

Pass. The retained successful-run evidence proves that native scheduling
requests already traverse the primer's MAC and scheduler correctly. The
512-opportunity follow-up branch does not repair that path; it fabricates
scheduler requests at configured SR occasions where no valid positive SR was
decoded.

This corrects the causal interpretation in CP3136. A configured SR occasion is
not proof that the UE transmitted an SR. An invalid or negative detector result
can be the expected result when the UE has no pending request. Without
independent UE-TX evidence, CP3136's 987 invalid/negative rows cannot be
classified as lost SR transmissions.

## Evidence

The analyzer hash-verifies and streams the same 20 successful phone-run
archives used by CP3136. It joins each visible PUCCH SR result to the next
same-run, same-RNTI PUSCH result within 12 slots. RNTIs are used only in memory
for the join and are not emitted.

| Trigger class | Total rows | Uncensored rows | PUSCH response | CRC OK |
|---|---:|---:|---:|---:|
| Native valid positive SR | 293 | 241 | 241/241 | 234/241 |
| Synthetic injection | 987 | 914 | 914/914 | 880/914 |

Both classes produce the same median scheduler response delay of eight slots
and the same median 512-byte grant. Native SR therefore drives the scheduler
with 100% observed grant response and 97.1% PUSCH CRC success. The synthetic
branch's corresponding CRC success is 96.3%.

All 20 runs contain native positive SR. The first native positive SR appears a
median 57.329 ms after the setup-ACK marker. The existing one-shot post-ACK
grant produces the first PUSCH about 7.8 ms after setup ACK, before the first
512-budget injection in the normal runs. Historical CP2657 independently
reached SetupComplete before the 512 branch existed.

## Decision

Do not patch PUCCH thresholds, timing, power, detector code, or the scheduler
from the CP3136 aggregate. The native path is already observed working.

The next bounded experiment changes one variable only: keep the frozen primer,
CSI removal, post-ACK one-shot grant, reactive-downlink controls, RF settings,
and phone/core lifecycle unchanged, but set the follow-up UL grant budget to
zero. Judge native SR, subsequent PUSCH/BSR supply, registration, and primer
completion. A pass retires the 512 crutch. A valid failure then names the first
missing native event without assuming every silent SR occasion is a decoder
failure.
