# Checkpoint 3198: SR-only grant-size no-RF gate

## Verdict

PASS. A default-preserving OCUDU scheduler control raises only the UL grant
size requested when SR is the sole demand signal. Focused and full scheduler
tests pass on the controller and [host-redacted]-native builds, and the established
10 MHz ZMQ chain passes through PDU-session setup and private gateway ping with
the control active.

No RF was opened.

## Source finding

The fixed `512` is not a general BSR-backed grant cap. OCUDU already sends
positive BSR demand through `compute_newtx_required_mcs_and_prbs()`, which
derives PRBs and TBS from the pending-byte count. The fixed value is used only
when effective BSR demand is zero and a pending SR remains.

The archived CP3176 10 MHz baseline confirms both paths were active:

- `5,389` UL new-transmission grants;
- TBS range `3..4,227` bytes, mean `530.9` bytes;
- `1,611` grants at exactly `512` bytes;
- `3,578` short BSR rows, including nonzero multi-kilobyte demand bins.

Reconfiguration entering fallback clears per-slice pending-demand caches but
does not clear the pending-SR bit. That can select the SR fallback after the
transition. It does not alone explain an indefinite series: normal UL-grant
handling clears pending SR, so repeated SR-only grants still require new SR
events or repeated transitions.

The separate srsENB ACK+SR candidate-selection defect supplied by review is
recorded as a primer defect, not changed here. CP3195 already retired that
primer's synthetic follow-up branch. This checkpoint changes no primer, CSI,
post-ACK, BSR, HARQ, or cadence behavior.

## Change

`PAVONIS_SCHEDULER_SR_GRANT_BYTES` is read once per process when the first UE
is constructed. Unset or invalid input preserves the configured `512`-byte
default. The aggregate UE and slice-aware UE paths share the resolved value.
The experimental value is `4096`.

The test geometry demonstrates the intended policy effect without assuming
that requested bytes equal physical TBS: a `4096`-byte request produced
`2,304`-byte FDD and `1,121`-byte TDD grants, both above the default
`528`-byte class.
