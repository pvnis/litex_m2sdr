# Checkpoint 3201: SR-grant-size OTA sensitivity

## Verdict

PASS as a formal measurement and NEGATIVE for the size hypothesis. The
hardened client records both complete 45-second receiver-authoritative windows,
but changing only the zero-demand SR fallback from 512 to 4096 bytes does not
raise sustained throughput.

## Controlled change

The CP3176 shape is unchanged: 10 MHz, 52 PRB, 11.52 Msps, one layer, MCS9,
FDD, TX attenuation 5 dB and gNB RX gain 40 dB. Cadence and every RF setting
remain unchanged. The isolated launcher adds only:

`PAVONIS_SCHEDULER_SR_GRANT_BYTES=4096`

The runtime marker appears once. The hardened traffic client records
`receiver_ack_status=received`.

## Results

Receiver-authoritative sustained throughput:

- downlink: `2.721705 Mbit/s`;
- uplink: `0.161661 Mbit/s`;
- versus CP3176: `-8.77%` downlink and `-3.24%` uplink.

Radio health is normal: cell SNR is `15.680 dB`; PUSCH is `77/128` CRC OK at
`21.000282 dB` median CRC-OK SINR; median PUSCH TBS is `544` bytes; Soapy
timeout/downlink-late counts are `0/0`.

The scheduler emitted 4,592 UL new transmissions with mean TBS `624.4` bytes
and maximum `4,097` bytes. Forty-eight grants reach `4,097` bytes, proving the
experimental selector was exercised. The 1,694 grants at `512` bytes are
BSR-derived transport-block outcomes rather than the filtered fallback.

## Interpretation

The fixed 512-byte SR fallback is not the sustained-throughput ceiling. It is a
bootstrap path for an SR with no effective cached demand, while normal
BSR-backed allocation already scales. Raising that fallback changes some grant
sizes but neither increases steady-state throughput nor shifts the median TBS
materially on this run.

The default-preserving source control remains useful for diagnostics, but the
runtime is reverted to the proven 512-byte default before cadence work. The
active gNB hash remains
`90a5db019d52b3f893572d96a8338eae67a81b1e4169e8eb12c4afab20375f8a`;
the experimental candidate and launcher remain isolated.

## Decision

Close and retire the size branch as a throughput lever. Do not combine SR4096
with cadence changes. Audit the actual OCUDU grant interval and response-delay
policy from this run and CP3176, then test one cadence variable with the
512-byte default active.
