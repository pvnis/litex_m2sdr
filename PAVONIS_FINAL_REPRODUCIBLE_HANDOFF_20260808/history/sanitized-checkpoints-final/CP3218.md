# Checkpoint 3218 - UE transmit-lead proof; gNB compensation plumbing void

## Verdict

**CONFIGURATION VOID FOR PRACH/PUSCH; POSITIVE UE-TRANSMIT-LEAD PROOF.**

Two bounded OTA attempts requested equal `+16000`-sample changes to the UE
bladeRF transmit guard and gNB PRACH collection compensation. The UE change
propagated. The gNB change did not: both runtime PRACH manifests remained at
the `237336`-sample baseline rather than the requested `253336`.

The two zero-detection outcomes therefore do not count as random-access or
connected-PUSCH results. They moved Msg1 later by 16000 samples while leaving
the gNB collection window unchanged.

## Evidence

| Metric | Attempt A | Attempt B |
|---|---:|---:|
| Cell SNR | 16.788 dB | 15.843 dB |
| UE Msg1 writes | 7 | 7 |
| bladeRF high-energy status `0` | 7 | 7 |
| bladeRF high-energy `TIME_PAST` | 0 | 0 |
| Final lead range | 38468..42073 | 39924..41649 |
| Runtime gNB PRACH compensation | 237336 | 237336 |
| gNB nonempty PRACH | 0 | 0 |
| gNB PUSCH rows | 0 | 0 |
| gNB timeout / downlink-late | 0 / 0 | 0 / 0 |

The UE-side result is decisive within its scope: raising the guard to `56000`
eliminates `TIME_PAST` on all fourteen transmitted Msg1 waveforms and keeps
their final lead above the CP3216 clean class.

The configuration failure is also mechanically resolved. The controller set
`PAVONIS_PRACH_TIMING_COMPENSATION_SAMPLES=253336`, but the intermediate
CP2188 wrapper unconditionally derives
`GNB_PRACH_TIMING_COMPENSATION_SAMPLES` from
`GNB_PRACH_TIMING_COMPENSATION_SAMPLES_OVERRIDE`, defaulting to `237336`.
The established CP1807 runner then exports that `GNB_` value to the gNB as
`PAVONIS_PRACH_TIMING_COMPENSATION_SAMPLES`. CP3217's static verifier checked
the final export but failed to check this intermediate overwrite.

## Decision

CP3217's claimed gNB-compensation propagation is superseded by this runtime
finding. Preserve its report as append-only evidence; do not silently edit it.

The next no-RF gate must:

1. set `GNB_PRACH_TIMING_COMPENSATION_SAMPLES_OVERRIDE=253336`;
2. verify the complete controller -> CP2188 override -> CP1807 -> gNB route;
3. reject mismatched guard/compensation deltas;
4. require runtime manifest value `253336` before any PRACH/PUSCH judgment.

Because both CP3218 attempts were configuration voids, they do not consume the
single-void retry allowance for the corrected shape.
