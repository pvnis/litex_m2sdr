# CP3240 - bladeRF worker lifecycle reorder, no-RF gate

## Verdict

**PASS.** A default-off, open-time-cached lifecycle branch is built and
deployed. When enabled for a true-PRACH restart it performs:

1. `bladerf_sync_config()` to shut down/join and recreate the TX sync worker;
2. TX module disable;
3. TX module enable;
4. the existing timed PRACH write.

When disabled, the existing disable-then-`rf_blade_start_tx_stream()` path is
unchanged. Samples, timestamps, RF settings, PRACH compensation, scheduler
behavior, and traffic duration are unchanged.

One bounded CP3241 OTA acceptance is unlocked through the already-isolated
CP3238 libbladeRF candidate. No system dependency is replaced.

## Mechanism

CP3239's first failing ordinary write occurs 46 calls after the second guarded
continuation. Each call contains 11,520 samples. libbladeRF rounds the plugin's
1,024-sample TX buffer request up to one 8,192-byte GPIF block, or 2,048 SC16
samples. The effective 256-buffer ring therefore holds 524,288 samples:

- 45 calls: 518,400 samples, still below capacity;
- 46 calls: 529,920 samples, first capacity crossing.

All eight active USB transfer buffers then report timeout. This is direct
evidence that the second worker accepted a full software ring but returned no
completed USB buffer.

The installed dependency commit belongs to a public feature branch rather than
current Nuand master. Its synchronous API deinitializes the old worker inside
`sync_config`. Pavonis called module-disable first, leaving the old worker to
tear down after hardware TX had already been stopped. The new branch changes
only that order. Public source provenance is recorded in
`cp3240_upstream_provenance.json`.

## CP3241 acceptance

Require, in order:

1. candidate-library and lifecycle flags in launch/result environment;
2. every restart `sync_config`, disable, enable, and write status zero;
3. every guarded continuation status zero at +56,000 samples;
4. more than 46 ordinary writes after the second continuation without ring
   exhaustion;
5. zero USB TX-buffer timeout, zero `TIME_PAST`, and zero status-1 storm;
6. only then judge PRACH, RAR, PUSCH, and sustained traffic.
