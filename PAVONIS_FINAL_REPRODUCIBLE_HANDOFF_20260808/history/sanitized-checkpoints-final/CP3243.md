# CP3243 - Reconfigure-before-disable self-invalidates bladeRF sync

## Verdict

**TRANSPORT FAIL / LADDER VOID.**

The lifecycle flag reaches the actual UE process and the new branch executes.
Its three API calls return zero, but its first PRACH write returns
`BLADERF_ERR_INVAL`; 263 of 280 bounded TX rows then carry the same error.
No throughput conclusion is possible.

The exact installed libbladeRF source gives a complete mechanical explanation:
`bladerf_sync_config()` creates a new initialized sync worker, then
`bladerf_enable_module(..., false)` calls `sync_deinit()` and format
deconfiguration. The following module enable does not recreate the sync
interface. `bladerf_sync_tx()` rejects that uninitialized object with
`BLADERF_ERR_INVAL`.

## Evidence

- Candidate timestamp-reset library propagation: PASS.
- Lifecycle flag propagation into the actual UE process: PASS.
- Runtime new-order marker: one restart row with mode `1`.
- Lifecycle API statuses: sync-config `0`, disable `0`, enable `0`.
- First post-lifecycle write: call 1283, 11,520 samples, timed START+END,
  +40,000-sample lead, status `-3`.
- TX trace: 280 rows; status histogram `0:17`, `-3:263`.
- `TIME_PAST`: zero.
- USB transfer-timeout callbacks: zero.
- Cell/SIB1: healthy at 16.617 dB.
- gNB TX health: zero Soapy timeout and zero downlink-late.
- Seven UE Msg1 attempts, 1,924 empty detector rows, zero nonempty rows.
- Exact-source verifier: all five call-chain assertions pass.

The zero return from module disable/enable is not proof that the synchronous
stream survived. Those calls operate on the module while the disable path
deliberately destroys the sync object.

## Decision

Do not rerun this shape. Keep the isolated timestamp reset. Replace only the
experimental lifecycle branch with **sync reconfiguration only**: let
`bladerf_sync_config()` deinitialize/join the old worker and initialize its
replacement, but do not disable or re-enable the module afterward. Keep the
legacy branch unchanged when the experiment is disabled. Gate source,
default-off behavior, native build/deploy, and generated inner environment
before one bounded RF retry.
