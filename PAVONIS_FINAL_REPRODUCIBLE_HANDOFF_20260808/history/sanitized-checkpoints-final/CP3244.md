# CP3244 - bladeRF reconfigure-only lifecycle, no-RF gate

## Verdict

**PASS.** A default-off PRACH restart mode now replaces the synchronous TX
worker using `bladerf_sync_config()` without disabling or re-enabling the TX
module:

`PAVONIS_RF_BLADE_PRACH_RECONFIG_ONLY=1`

This is the source-derived correction to CP3243. The rejected
reconfigure-before-disable selector is absent from current source, the built
plugin, and active wrappers.

## Evidence

- New selector is read once and cached when the radio opens.
- Enabled branch performs exactly one `bladerf_sync_config()` call.
- Enabled branch contains no module disable, module enable, or second stream
  start.
- Sync-config status is propagated directly and fail-closed.
- Disabled legacy lifecycle branch is byte-identical to its CP3243 form.
- Bounded TX trace and metadata use `restart_tx_stream_reconfig_only`.
- Actual generated UE command contains the new selector exactly once.
- Active remote and outer wrappers contain every required default/export/
  launch/result propagation layer.
- CP3245 differs from CP3243 only by fresh identity and the corrected lifecycle
  selector.
- Native 16-job build and link: PASS.
- Rollback source and plugin backup: PASS.
- Deployed source/plugin hash and binary marker proof: PASS.
- Rejected binary marker count: zero.
- Selector-off and selector-on help output are byte-identical.
- System and isolated candidate libbladeRF hashes are unchanged.
- Both radio roles were idle before work; final role process count is zero.

## Decision

Run CP3245 once through the isolated timestamp-reset library. Judge transport
before the radio ladder:

1. Runtime `restart_tx_stream_reconfig_only=1`.
2. Every sync-config and restarted write status zero.
3. Guarded continuation at +56,000 samples.
4. Survival beyond the 46-write ring boundary with no USB timeout,
   `TIME_PAST`, `BLADERF_ERR_INVAL`, or status storm.
5. Then judge Msg1/RAR/Msg3, connected PUSCH CRC, and sustained traffic.

Do not alter PRACH timing, detector policy, RF gain, scheduler policy, or
traffic shape in that run.
