# CP3245 - Reconfigure-only repeats second-worker failure

## Verdict

**TRANSPORT FAIL / LADDER VOID.**

Reconfigure-only fixes CP3243's immediate `BLADERF_ERR_INVAL`, but does not
fix repeated TX-worker operation. Both replacements and both guarded
continuations succeed. After the second replacement, no USB TX buffers
complete; the software ring fills and ordinary writes fail.

This rejects module-toggle ordering as the cause. The defect follows the
second synchronous TX worker created during one device session.

## Evidence

- New selector and isolated timestamp-reset library propagation: PASS.
- Two reconfigure-only restarts: sync-config status `0`, write status `0`.
- Two continuation starts: status `0`, exact +56,000-sample hardware lead.
- First failure: call 2385, 48 calls after the second continuation.
- TX trace: 139 rows; status histogram `0:22`, `-1:117`.
- USB TX transfer-timeout callbacks: seven.
- `TIME_PAST`: zero.
- `BLADERF_ERR_INVAL`: zero.
- Cell/SIB1: healthy at 16.196 dB.
- gNB TX health: zero Soapy timeout and zero downlink-late.
- Two UE Msg1, one nonempty gNB PRACH result, one encoded RAR, and one accepted
  UE RA response.
- Five gNB PUSCH rows are all CRC KO.

The access progress is useful but not a valid Msg3/throughput result because
the UE TX transport is already in the deterministic failure state.

## Decision

Do not rerun CP3245. Keep the no-module-toggle result as a closed negative.
The next branch must address repeated libbladeRF sync-worker operation or
avoid repeated worker replacement entirely; do not [interface-redacted] RF, PRACH timing,
detector policy, scheduler policy, or throughput parameters.

The installed libbladeRF commit predates multiple current-upstream streaming
and thread-lifecycle changes. Evaluate a current-upstream library in an
isolated prefix, with the already-proven timestamp reset retained, before
changing the radio plugin again. This is a candidate dependency A/B, not a
system migration: require source provenance, ABI/SONAME/export/dependency,
unchanged-system-library, help-identity, and no-RF build gates first.
