# CP3252 - Continuous PRACH timestamp-update no-RF gate

## Verdict

PASS. CP3253 is approved as the otherwise-identical CP3251 control.

## Change

For the default-off bounded branch only, an in-burst true PRACH now clears
`START`, `END`, and `NOW`, then sets `UPDATE_TIMESTAMP`. Continuation arming
requires the metadata to contain a real EOB bit.

This preserves the first-only restart/EOB and its one guarded continuation.
Later PRACH occasions stay inside that open burst and neither flush the working
buffer nor reopen the stream.

Official libbladeRF documentation describes this exact continuous form: one
burst start, numerous `UPDATE_TIMESTAMP` calls, and `BURST_END` only when
ending the stream.

## CP3253 gate

Require runtime 5/4/10,240, one initial restart and continuation, then six
PRACH rows with flags `0x8`, burst-open before/after, no later continuation,
and all statuses 0. USB timeout, time-past, invalid, or status-minus-one makes
ladder evidence void.
