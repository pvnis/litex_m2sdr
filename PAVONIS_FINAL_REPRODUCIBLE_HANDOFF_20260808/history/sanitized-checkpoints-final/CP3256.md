# CP3256 - Stage-1 late-arm capture no-RF gate

## Verdict

PASS. One bounded RF diagnostic is unlocked.

The existing stage-1-energy strong-window capture now honors its configured
arm file. The wrapper can schedule that arm once after a bounded delay. Both
controls are default-off and add no per-sample work to the disabled path.

## Implementation

The gNB caches the capture-enable, stage-1-energy, and arm-path environment
values once. On an energy-gated PRACH opportunity, it performs one arm-file
existence check before copying the already-computed stage-1 input samples into
the existing memory buffer. It reuses the RMS/peak calculation already
required by stage-1 and still flushes raw CF32 only at process exit.

The RF wrapper adds:

- default-off propagation of
  `PAVONIS_PRACH_STRONG_PREDEMOD_CAPTURE_STAGE1_ENERGY`;
- default-zero `PAVONIS_PRACH_STRONG_PREDEMOD_ARM_DELAY_SEC`;
- a guarded one-shot `sleep`/`touch` task on [host-redacted] when both a delay and a
  distinct arm path are supplied.

The prepared diagnostic uses a seven-second delay and a 64-window cap. Based
on CP3255 timing, this arms shortly before the first Msg1 and spans the complete
seven-attempt sequence without full-rate append or log polling.

distinct delayed arm file, and a 64-window cap added. Judge health and PRACH
