# CP3261 - Continuous RX Locates PRACH

Date: [date-redacted]

## Purpose

Locate the clean CP3253-class bladeRF PRACH transmission in M2SDR hardware
sample time after CP3259 proved it was absent from all 64 live collection
windows.

This run is explicitly instrumentation-only and detection-void under CP1894.
Its live detector/RAR result is not evidence.

## Run

Fresh stamp: `[date-redacted]`.

The RF/transport/timing shape remained CP3259-class. Strong-window capture was
disabled. The after-SIB1 M2SDR readStream append reached its exact bound:

## Evidence

Full-file block-energy analysis finds the four strongest 1 ms-class events
once per in-file UE attempt. Correlation against each attempt's saved bladeRF
SC16 PRACH waveform proves these are the transmitted preambles:

| Attempt | Waveform start vs current predemod | Best CFO | Correlation |
| --- | ---: | ---: | ---: |
| 1 | +81,051 samples | +4,000 Hz | 0.919994 |
| 2 | +100,142 samples | +4,000 Hz | 0.920814 |
| 3 | +100,142 samples | +4,000 Hz | 0.919009 |
| 4 | +100,142 samples | +4,000 Hz | 0.919781 |

Attempts 2-4 are sample-exact. Attempt 1 is a distinct first-open-burst anchor
class and is not used to set the steady-state collection value.

The current collection compensation is `253336`. The prior working class is
`352536`, a delta of `99200` samples. Applying that established delta leaves:

```text
attempt 1:  -8,149 samples
attempts 2-4: +942 samples each
```

The `+942` steady residual is within the long-PRACH cyclic-prefix class and
removes the roughly 8.7 ms miss that put the waveform outside CP3259's
23,520-sample collection buffer.

## Verdict

**Waveform present; timing class identified.**

The continuous bladeRF transport did not lose the RF signal. It changed the
PRACH emission timing relative to the gNB collection timeline by approximately
the already-established `99200`-sample class difference. CP3259's zero accepts
were therefore correct: the waveform started roughly `100142` samples after
those buffers.

Next gate and run one ladder retry with only
`PAVONIS_CP3219_GNB_PRACH_TIMING_COMPENSATION_SAMPLES=352536`. Keep the
continuous bladeRF transport, stage-1 policy, RF levels, non-PRACH co-shift,
scheduler, thresholds, kernel, FPGA, and gateware unchanged. Expect attempt 1
may remain a startup miss; attempts 2 onward should become detector-visible.
