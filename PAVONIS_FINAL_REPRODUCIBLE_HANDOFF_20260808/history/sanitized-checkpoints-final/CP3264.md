# CP3264 - Independent PRACH Controller No-RF Gate

Date: [date-redacted]

## Purpose

Remove CP3263's controller-only blocker without weakening the historical
default validation.

## Change

An isolated copy of the CP3219 controller adds:

```text
PAVONIS_CP3264_ALLOW_INDEPENDENT_PRACH_COMPENSATION
```

The flag defaults to `0`. When unset, compensation must still equal the
historical guard-derived value. Value `1` bypasses only that equality check;
integer parsing, guard range, candidate validation, pinned hashes, RF approval,
host aliases, result freshness, and every downstream control remain unchanged.
The execution summary records whether the exception was active.
