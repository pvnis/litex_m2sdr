# CP3270 - CP3269 Msg1 Replay and No-RF Gate

Date: [date-redacted]

## Offline Replay

The validated CP3259 full-span detector replay was run against only CP3269's
six strong steady-state Msg1 windows, indices `13,19,26,33,40,47`. The grid
evaluated the complete timing range at 128-sample spacing and CFO at 1 kHz
spacing, emitting accepted rows only.

Replay produced `6039` accepted rows across all six windows. One transform is
common to every window:

```text
integer shift:       +7328 samples
fractional shift:         0 samples
CFO correction:       -3000 Hz
detector delay:           82
p0 ratio range:       31.412..38.989
accepted windows:          6 / 6
```

This is not a marginal detector hit. The common transform exceeds the live
`0.61` threshold by over 50 times at its weakest window. The large positive
shift confirms the observed "CFO" envelope is absorbing run-scale timing/
phase presentation, not a physical LO offset alone.

## No-RF Gate

CP3271 adds exactly that common transform as the first explicit candidate
after implicit baseline:

```text
candidate 1: baseline 0/0/0
candidate 2: +7328 / 0 / -3 kHz
candidate 3: -192 / -0.5 / +45 kHz
candidate 4: -448 / -0.5 / +22 kHz
```

All remaining CP3269 candidates stay in order. Candidate count is 21,
limit remains 30, PRACH compensation remains `352536`, non-PRACH scheduler
error remains `115200`, and full RX append remains disabled.

Verifier checks pass for replay acceptance in all six windows, minimum ratio
greater than 30, exact first-candidate placement, no duplicate, shell syntax,
controller validate-only, and closed RF gate.

## Verdict

**PASS: one bounded CP3271 RF run is justified.**

Judge health first. A `+7328/-3 kHz` roll should now select in roughly one
post-baseline evaluation and retain RAR-window margin. If RAR reaches the UE,
the primary result is Msg3 CRC under the active dynamic non-PRACH co-shift.
