# CP3275 - Fresh RLC BSR No-RF Gate

Date: [date-redacted]

## Change

CP3274 found that every short BSR in CP3273's sustained-uplink interval
reported zero despite a 256-KiB application write loop. The UE BSR procedure
sampled RLC queue state in the MAC TTI and later encoded that cached snapshot
after the grant entered the PHY/MUX path.

This checkpoint adds one default-off experiment:

```text
PAVONIS_SRSUE_BSR_REFRESH_BEFORE_CE
PAVONIS_SRSUE_BSR_REFRESH_TRACE
PAVONIS_SRSUE_BSR_REFRESH_TRACE_LIMIT
```

When enabled, short-BSR assembly refreshes the configured LCID/LCG queue state
from RLC after the MAC SDUs have been packed. The trace is metadata-only,
env-read-once, and capped at 4096 rows by default. With all flags absent or
zero, the existing cached-snapshot path remains selected.

## Focused Proof

A new MAC test constructs the exact disputed ordering:

1. A regular BSR is triggered with queued data.
2. The next MAC-TTI snapshot is zero while the BSR remains pending.
3. Fresh RLC backlog arrives after that snapshot.
4. A 10-byte UL grant packs six data bytes and then the short BSR.

The native test encodes `fresh_bytes=1994`, LCG 6, field 17 instead of the
stale zero field. The capped trace control reports:

```text
test rc:                         0
trace rows:                      4
stale-zero/fresh-backlog rows:   1
```

The pre-existing periodic-BSR vectors execute before the opt-in test and remain
unchanged. Both focused binaries pass:

```text
proc_bsr_nr_test: PASS
mac_nr_test:      PASS
```

compiler/runtime dependency set differs from the proven UE-host ABI. The
working UE source and executable were backed up first by role and hash. Only
the three reviewed source/test files were copied, then the established native
build tree rebuilt with 16 jobs.

The native binary contains all three control strings. Launcher propagation is
present at controller export, remote launch, `sudo env`, and result/launch
sidecars. Syntax, validate-only, and the closed RF gate pass; closed execution
returns 2 without artifacts.
