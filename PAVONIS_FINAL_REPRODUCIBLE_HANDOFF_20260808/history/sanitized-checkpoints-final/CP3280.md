## First Attempt

The first attempt was a run-level PRACH/RAR oversupply state. It published 64
dynamic non-PRACH offsets and consumed 178 while PUSCH contexts were active,
instead of CP3273's single publish/consume. Its active context showed the
known two-state collapse: CRC-OK rows near `+5.5 dB` and CRC-KO rows near
`-9 dB`. It never reached user traffic and is void for BSR.

## Retry

The unchanged retry avoided the storm. It selected:

```text
candidate 5: shift=7328, frac=0, cfo=-3000 Hz, 2.519 ms
candidate 1: native baseline, 0.216 ms
```

The corresponding dynamic offsets were `-350402` and `-352102`. PUSCH quality
was 86/128 CRC OK with mean reported SINR `14.25 dB` on CRC-OK rows and
`8.67 dB` on CRC-KO rows.

The UE attached and the private user plane carried downlink data, but attach
completed late in the fixed 240-second UE run. The server recorded 8,363,880
downlink bytes over 45.09 seconds (`1.484 Mbit/s`); the UE recorded 7,114,024
bytes over 29.66 seconds (`1.919 Mbit/s`). Both endpoint results are marked
incomplete and no uplink phase began. These are partial diagnostics, not a
sustained-throughput result.

## Fresh-BSR Semantics

The capped metadata trace contains 637 short-BSR rows:

```text
cached backlog positive:       375
refreshed backlog positive:    218
cached zero / refreshed > 0:     1
encoded nonzero field:         218
refreshed median / max:        0 / 2533 bytes
LCG 0 / LCG 2 rows:            419 / 218
```

This proves the CP3275 path is active end-to-end and that OCUDU can receive a
nonzero refreshed BSR field. It also shows the common ordering: after MAC
packs the current grant, refreshed backlog is often lower than the earlier
TTI snapshot. The patch corrects stale reporting but does not itself prove a
throughput gain because the uplink benchmark did not start.

## Verdict

**PASS for fresh-BSR semantics; PARTIAL for throughput.**

Do not claim a bandwidth improvement from CP3280. The next diagnostic should
keep the radio and BSR shape identical but shorten each traffic direction to
10 seconds so both DL and UL fit inside the existing UE lifetime even on a
late attach. A positive UL result then earns extending the formal 45-second
harness; no gain means the BSR-refresh branch should be retired or redesigned.
