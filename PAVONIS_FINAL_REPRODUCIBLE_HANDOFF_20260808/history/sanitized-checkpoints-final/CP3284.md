# CP3284 - Fresh BSR Formal No-Gain Verdict

Date: [date-redacted]

## Verdict

**PASS as a formal benchmark; NO GAIN from fresh BSR.**

The CP3275 fresh-BSR path is a valid semantic correction and remains
default-off, but it is retired from the active throughput path. It does not
raise sustained uplink throughput.

## Formal Throughput

Both endpoint completeness gates and exact-duration checks pass:

```text
DL: 3.186175 Mbit/s, 17,922,304 receiver bytes, 45.000182 s
UL: 0.331044 Mbit/s,  1,862,128 receiver bytes, 45.000118 s
```

Against the current-shape CP3273 baseline:

```text
DL change: +0.364%
UL change: -11.003%
```

The short CP3282 `0.418 Mbit/s` result was run scatter and/or a duration
effect, not a sustained improvement.

## Radio Health

The run has one gNB PRACH accept, one RAR PDU, one UE RAR accept, one Msg3
path, and no RAR storm. Cell-search SNR is `15.089 dB`; CFO is `-4055 Hz`.
The first 128 PUSCH rows are 86 CRC OK and 42 CRC KO. Soapy TX timeout and
downlink-late counts are `0/0`, with the known 480-sample terminal partial
return.

## BSR Proof

The UE trace contains 3,306 rows:

```text
cached-positive:    2438
refreshed-positive: 1791
nonzero field:      1791
fresh median/max:   187 / 18177 bytes
```

The gNB binary-safe mirror independently records:

```text
LCG0: 1452 rows, all index 0
LCG2: 1732 rows, all nonzero, max index 24
```

The patch therefore propagates nonzero demand end-to-end. Its failure to raise
throughput is not an instrumentation or decode failure.

## Scheduler and PHY Join

The densest 45-second uplink interval contains:

```text
newTx grants:                  4910
scheduled bytes:              2,638,192
scheduled gross rate:         0.469012 Mbit/s
TBS median / mean / max:       512 / 537.31 / 4737 bytes
positive gap median / mean:    1 / 9.114 slots
RB width median:               52
PUSCH CRC:                     4820/5290 OK (91.12%)
CRC-OK TBS median:             512 bytes
```

CP3273 scheduled 5,341 newTx grants and 3,143,723 bytes
(`0.558884 Mbit/s`) with mean positive gap 8.419 slots. Fresh BSR makes demand
visible but does not keep enough aggregate data queued to increase grant
continuity; modal TBS remains 512 and scheduled gross rate falls.

The modulation split remains inefficient at high order: QPSK is 4534/4540
CRC OK, 16QAM 261/347, and 64QAM only 25/403. This is a secondary loss source,
not evidence that fresh BSR works.

## Decision

Disable fresh BSR for the next branch. The next no-RF discriminator should
increase application demand without changing radio policy: run multiple
parallel TCP flows over the same attached user plane. If aggregate demand
raises grant continuity and throughput, the single-flow TCP/RLC feed is the
current limiter. If not, scheduler grant continuation and high-order
modulation policy become the next source targets.
