## Verdict

**PASS.** The exact invalid format-1 HARQ-ACK can now be captured under a

## Change

`logging_pucch_processor_decorator.h` adds the cached switch:

```text
PAVONIS_PUCCH_F1_GRID_CAPTURE_INCLUDE_HARQ_ACK
```

Default is `0`. When both the existing grid capture and this switch are
enabled, an invalid format-1 resource with HARQ-ACK bits may pass the existing
EPRE floor and shared capture cap. The file format, capture loop, detector,
phase bank, thresholds, power, timing and scheduler behavior are unchanged.

The active wrapper propagates and records the switch. Existing packaging
already includes the bounded PUCCH grid filename pattern.
