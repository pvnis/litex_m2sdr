# CP3316 - PUSCH MCS-16 Isolated No-RF Gate

Date: [date-redacted]

## Verdict

PASS, ready for one bounded OTA sensitivity. No RF was executed. The candidate
changes only the PUSCH maximum MCS from OCUDU's default 28 to 16; the complete
CP3314 baseline remains unchanged.

## Implementation

The candidate uses a separate hash-pinned launcher. With the experiment
variable unset, it forwards the base gNB arguments exactly and emits no
marker. With the variable set to 16, it adds one structured YAML override:
`cell_cfg.pusch.max_ue_mcs: 16`. Values outside 0 through 28 fail closed.

The active CP3314 gNB remains at SHA-256
`bb42aea700cb8ddc272d14c1749f85b0a5aa8a02a3326c4b8fba9b2dbbd5fc44`.
The candidate launcher is a separate file and does not modify that binary or
the CP3314 runner.

## No-RF Gates

- Shell syntax passes.
- Disabled forwarding, active override, invalid-value rejection, and temporary
  override cleanup pass with a deterministic probe.
- The real local gNB accepts the baseline plus override under `--dryrun`, rc0.
- The remote candidate launcher hash matches.
- Frozen-runner validate-only passes with 23/30 PRACH candidates, four
  preconnected streams, PDSCH MCS9, 45-second directions, and all timing
  fixtures.
- The default RF gate returns rc2.

The first ZMQ invocation stopped before service startup because an old CP3214
base-binary path no longer matched its historical hash. This is a setup void.
After pinning the currently proven CP3314 gNB instead, the unchanged no-RF
control passes attach and complete sustained bidirectional traffic. Receiver
authorities report DL `7.488318 Mbit/s` and UL `15.272891 Mbit/s`. The lower
UL result versus CP3214's `33.379038 Mbit/s` is the expected ideal-channel
cost of excluding 64QAM; it remains more than 35 times CP3314's OTA UL.

## Decision

Run one bounded preconnected OTA sensitivity. Judge it against CP3314 on
receiver-authoritative uplink, scheduled new-transmission gross rate,
QPSK/16QAM CRC yield, TBS distribution, grant gaps, and BSR state. A neutral
or negative result retires the cap before any other variable is changed.
