# CP3317 - MCS16 Propagation Void, Transport Pass

Date: [date-redacted]

## Verdict

VOID for the PUSCH-MCS16 hypothesis; PASS for complete bidirectional
transport. The deep OTA wrapper did not propagate the new environment
variable to the separate launcher.

## Propagation Proof

The execution summary proves that the candidate launcher hash was selected,
but the packaged gNB log contains zero
`PAVONIS_GNB_PUSCH_MAX_UE_MCS active` markers. The packaged primary YAML has
no PUSCH block, and the full active-uplink parse still contains 2,265 64QAM
rows. The launcher therefore took its exact-forwarding disabled path.

This corrects the preliminary second-config-precedence theory: the active
override was never attempted over OTA. The no-RF ZMQ gate remains valid
because that direct runner explicitly supplied the environment variable.

## Valid Transport Result

The run has a clean `15.506 dB` cell, zero Soapy TX timeouts, zero downlink
late events, complete four-stream endpoints, and all four uplink receiver
acknowledgements. Receiver-authoritative 45-second rates are:

- Downlink: `2.982210 Mbit/s`
- Uplink: `0.792857 Mbit/s`

The uplink is 83.88% above CP3314 even though the effective PUSCH policy
remained unchanged. Its densest 45-second interval schedules
`1.111028 Mbit/s`, 63.69% above CP3314, with median TBS 544 bytes and all 321
short BSRs still zero. This is useful evidence that scheduler supply and
delivered rate co-vary substantially between otherwise equivalent runs; it is
not evidence for MCS16.

The controller rc1 comes from the radio runner's wrapper lifecycle while both
authoritative endpoint files and strict sustained analysis pass. It does not
invalidate the completed transport result.

## Decision

Do not interpret or repeat this shape. Build a new isolated launcher that
hard-pins MCS16, writes a run-local full config copy with the PUSCH block, and
execs the proven gNB directly. This avoids both the filtered environment path
and the shell-wrapper teardown status. Gate that path no-RF before retrying.
