## Implementation

The new isolated launcher hard-pins PUSCH maximum MCS16. It verifies the
proven CP3314 base gNB hash, finds the primary `-c` YAML, rejects any existing
PUSCH block, creates a sibling run-local full config, inserts exactly:

```yaml
  pusch:
    max_ue_mcs: 16
```

It then replaces the primary config argument and `exec`s the proven gNB
directly. No new environment variable must cross the deep OTA wrapper chain,
and the baseline binary and runner remain unchanged.
