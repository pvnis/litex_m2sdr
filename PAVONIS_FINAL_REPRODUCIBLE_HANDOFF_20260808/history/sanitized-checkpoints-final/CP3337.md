# CP3337: stop-only summary 5 ms gNB-only gate

## Verdict

**VALID NEGATIVE.** Removing the high-rate OCUDU TX summary does not remove
the 5 ms periodic pre-write deadline loss. The diagnostic logging hypothesis
is rejected.

The run used the exact CP3335 RF shape except for
`OCUDU_SOAPY_TX_SUMMARY_PERIOD=0`. Runtime startup output proves that value.
The gNB log contains no periodic TX summary rows and one authoritative
`reason=stop` row. There are no priority or `SCHED_FIFO` failure lines.

## Evidence

| Metric | CP3328 | CP3335 | CP3337 |
|---|---:|---:|---:|
| TX lead | 5 ms | 5 ms | 5 ms |
| Deadline guard | 2 ms | 2 ms | 2 ms |
| Summary period | 100 | 100 | 0 |
| Priority failures | not gated | 0 | 0 |
| Pre-write deadline breaks | 21 | 26 | 31 |
| Deadline-controlled write timeouts | 0 | 0 | 0 |
| Stream deficit | 168336 | 199364 | 213018 samples |
| Generic Soapy timeout / DL-late | clean | 0 / 0 | 0 / 0 |

CP3337 requested `756290090` samples and returned `756259152` from the data
writes. The stop summary reports `30938` data-write deficit and `213018`
total stream deficit/abandoned samples. This is the same failure class as
CP3328 and CP3335, not a logging-induced perturbation.

The legacy wrapper exits `1` because its pre-UE health gate expects a periodic
summary before shutdown. With period zero, the only summary is emitted by
`stop()`, after that gate. This is a gate false negative, not an RF/setup void:
the bounded 120-second gNB run completed, the final stop row was packaged, and
all counters required for the discriminator are present.

## Decision

Do not rerun period zero unchanged. Keep the summary disabled for future
reduced-lead diagnostics, but do not claim it fixes the deadline loss.

The next rung is default-off, event-triggered producer timing telemetry around
the pre-write deadline-break branch. It must capture only a bounded window per
break and answer which upstream stage stops delivering TX data before the
roughly 23-second failure clusters. No periodic large summaries and no
per-sample hot-path work.

The operator-reported normal bidirectional throughput on a USB LiteX SDR was
not produced by this campaign. It remains qualitative external context only.
