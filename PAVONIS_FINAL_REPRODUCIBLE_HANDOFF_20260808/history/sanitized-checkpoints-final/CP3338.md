# CP3338: deadline-break trace no-RF gate

## Verdict

**PASS.** A default-off, bounded, event-triggered deadline-break trace is built
and deployed on [host-redacted]. CP3339 is ready to distinguish an upstream producer
pause from time spent inside the Soapy `transmit()` call.

No RF was used.

## Instrument

The trace records only after
`select_tx_data_write_timeout()` has already returned an expired deadline:

- logical transmit and current/previous metadata timestamps;
- wall-clock gap since the previous `transmit()` entry;
- time from current `transmit()` entry to the break;
- buffer, sent-chunk and chunk-timestamp geometry;
- requested/effective deadline and M2SDR hardware time;
- raw lead, guard and guarded lead.

It is enabled by `PAVONIS_SOAPY_TX_DEADLINE_BREAK_TRACE=1`, defaults off, and
is capped by `PAVONIS_SOAPY_TX_DEADLINE_BREAK_TRACE_LIMIT` (64 for CP3339).
There is no per-sample work, no periodic output, and no file polling.

Static disabled-path proof reports:

```text
default_off_fields=1
env_cached_constructor_reads=1
transmit_getenv_calls=0
event_break_log_sites=1
event_stop_log_sites=1
```

## Runner Gate

`cp3339_run_stage6_break_trace.sh` normalizes to CP3336's exact
`d5456869...db64f7` hash when the two trace exports are removed. The outer
runner pins 5 ms lead, 2 ms guard, no UE, period-zero summaries, RT permission,
and defaults RF closed. Invalid lead/guard values fail before RF.

Next run one bounded CP3339 gate. Classify:

- large `entry_gap_us`, small `tx_to_break_us`: upstream producer/timing pause;
- normal entry gap, large `tx_to_break_us`: Soapy conversion/write-loop stall;
- both normal but negative raw lead: hardware-time/timestamp discontinuity.

Do not infer mechanism from break count alone.
