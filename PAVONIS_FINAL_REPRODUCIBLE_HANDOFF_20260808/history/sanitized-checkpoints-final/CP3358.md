# CP3358: 6.5 ms / 200 us Long gNB-Only Gate

## Verdict

**FAIL. Do not promote this policy to OTA.** The half-millisecond retime reduces
the CP3356 break count from 37 to 8 and removes all worker/release late events,
but the 420-second stop accounting still has 59456 abandoned stream samples
and 8176 unwritten data samples. The UE was never started.

## Evidence

Readback proves 6.5 ms lead and 200 us guard. The pre-UE late-health gate
passes, but periodic-summary health and authoritative stop accounting fail:

- requested / returned: 4838279450 / 4838271274 samples;
- deadline breaks / actual deadline write timeouts: 8 / 0;
- abandoned samples / stream deficit / data-write deficit:
  59456 / 59456 / 8176;
- partial returns / generic Soapy timeout / downlink-late / release-late /
  worker-late / errors: 0 / 0 / 0 / 0 / 0 / 0.

All eight bounded rows retain exact 11520-sample metadata progression. Their
raw hardware lead is positive at 34--199 us, mean 132.2 us, so this run is
guard-only; the 200 us reservation produces -166---1 us guarded lead. Two rows
break before writing any sample.

The cross-run projection matters. CP3357 projected a 201 us minimum from
CP3356, while CP3358 observed -166 us, 367 us worse. A 7 ms / 500 us point
would project only 34--199 us from these exact rows and is therefore too narrow
to justify another seven-minute run. A 7.5 ms / 500 us point projects
534--699 us, retaining 167 us even after the observed 367 us cross-run
projection error.

The stop helper and independent cleanup audit pass; no gNB remains and UDP
2152 is free.
