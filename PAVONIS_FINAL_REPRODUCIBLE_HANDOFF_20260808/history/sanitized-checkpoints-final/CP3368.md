# CP3368: Soapy Summary-Period 10000 Long Gate

## Verdict

**PASS with one recovered partial write (bounded RF, gNB only).** Runtime
proves both M2SDR worker and release summaries use `period=10000`. Across the
420-second dwell there are zero deadline breaks, deadline or generic
timeouts, abandoned samples, stream deficit, worker/release/downlink late
events, or errors.

The transmitter emits 4,838,376,810 unique stream samples and returns exactly
4,838,376,810. This removes CP3366's 44.673-second cascade and 32,794-sample
loss.

## Recovered Partial

One write call returns 480 fewer samples than that call requested. This is not
unique stream loss. The OCUDU transmit loop records the partial, advances
`sent_total` only by the returned count, and continues until
`sent_total == data_nof_samples`. Consequently cumulative call requests exceed
returns by 480, but `stream_samples == samples_ret` and `stream_deficit == 0`.
Both frozen pre-UE and authoritative stop gates correctly pass.

This distinction matters: the CP3366 deadline cascade abandoned unique
samples and produced nonzero stream deficit; CP3368's partial backpressure is
fully recovered.

## Evidence

- Runtime worker/release stop rows report `period=10000`, late count zero, and
  no acquire or underflow errors.
- The log contains 473 worker and 473 release period rows, down from CP3364's
  4,734 each, while retaining 41 Soapy period rows and one authoritative stop
  row.
- Application PHY INFO remains zero; the gNB log falls to 547,179 bytes.
- Source proof captures the `while (sent_total < data_nof_samples)` loop,
  per-call accounting, `sent_total += ret`, and completion on the full buffer.
- Host gates and cleanup pass.
