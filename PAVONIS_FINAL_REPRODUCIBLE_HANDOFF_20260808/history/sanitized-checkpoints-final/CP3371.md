# CP3371: coherent Soapy timeline v2 no-RF gate

## Verdict

**PASS, NO RF.** A default-off coherent timeline now moves the proven fixed
10 ms scheduler displacement out of the non-PRACH demod path without removing
the M2SDR's physical 8.5 ms TX submission lead.

The old paired-virtual-time experiment failed because subtracting the TX lead
from the logical clock and adding that same amount only in the driver left
approximately zero physical submission headroom. V2 keeps the quantities
separate:

```text
scheduler clock offset:       10.0 ms
TX metadata compensation:     10.0 ms
physical M2SDR TX lead:         8.5 ms
RX metadata compensation:     18.5 ms
```

For hardware time `H`, the lower PHY schedules at `H-10 ms`. OCUDU adds
10 ms to TX metadata and the driver adds the existing 8.5 ms, so RF emission
remains at `H+8.5 ms`. RX subtracts 18.5 ms, mapping an uplink sent at k2=4
back to the scheduled virtual slot. The physical queue headroom is unchanged.

## Residual Derivation

At 11.52 Msps, 18.5 ms is 213,120 samples. Removing that displacement from
the CP3370 collectors gives:

```text
PRACH:                 220056 - 213120 = 6936
static negative:      -241118 + 213120 = -27998
static positive:      -237798 + 213120 = -24678
edge calibration: -104852 - 115200 + 213120 = -6932
scheduler term:                                 0
```

The edge/TA measurement remains active; only its large fixed timeline terms
move to the Soapy boundary.
