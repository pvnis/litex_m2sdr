# CP3383 - Immediate RA procedure path no-RF gate

## Verdict

**PASS.** The CP3382 post-dispatch blind spot is instrumented without changing
RA, timing, threshold, scheduler, RF, or payload semantics. The existing
default-off, cached, capped RAR path trace now continues through task enqueue,
task execution, RA response state, unpack, sub-PDU match, TA/grant application,
and Msg3 preparation.

## Patch

`proc_ra_nr.cc` adds twelve metadata-only event types. They report state,
boolean outcomes, counts, slot, TA, and return code; they do not report RAR
payload bytes, radio identifiers, subscriber identifiers, or NAS content.

The remote pre-patch source is byte-identical to the local campaign baseline
outside this change. The source diff has thirteen addition-only hunks,
104 added lines, and zero deleted lines.

## CP3384 Gate

The CP3384 runner preserves the CP3382 radio and timing shape and changes only
the native UE binary, immediate marker visibility, fresh identifiers, and a
lower diagnostic cap. Both the buffered and immediate RAR trace limits are
pinned to `256`, closing CP3382's live `1200` cap mismatch.

- Shell syntax passes.
- Controller validation passes at PRACH `97,764`, 23 stage-1 candidates,
  native timeline, and frozen non-PRACH timing.
- RF defaults closed with exit code 2.
