# CP3385 - Msg3 sample-domain capture no-RF gate

## Verdict

**PASS.** CP3386 is prepared to measure the CP3384 PUSCH failure without
changing radio, timing, offset, CFO, gain, threshold, scheduler, or protocol
behavior. It enables only existing bounded capture hooks.

## Wrapper Override Resolution

The current benchmark controller traverses wrappers that deliberately replace
trace and capture controls. CP2188 sets both RAR trace caps to `1200`;
CP2201 forces scheduled-target metadata mode; CP2347 and CP2351 defer target
capture until post-attach security traffic. That explains CP3384's live
`1200` cap and why no Msg3 raw target files existed.

No baseline wrapper was edited. CP3386 instead uses a checkpoint-local
`BASH_ENV` file. Each fresh wrapper shell sources it, and the final CP2188 to
CP1807 `exec bash` boundary reasserts:

- immediate Msg3 target capture, maximum eight targets;
- post-RAR in-process arm;
- 128 unshifted raw symbols and 128 shifted-target raw symbols maximum;
- generic sample work bounded to 256 post-RAR symbols;
- both RAR trace caps at 256.

A nested-shell proof first writes the legacy bad values, enters a fresh Bash,
and resolves exactly to the intended CP3385 values.
