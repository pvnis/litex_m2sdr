# CP3392 - Exact MCS16 retry stops at pre-UE TX health

## Verdict

**VOID.** The UE was deliberately not started because the pre-UE authoritative
TX summary gate failed. The execution-summary fallback label suggesting UE
acquisition is superseded by the sequence log.

## Evidence

- gNB startup and native continuous TX readback pass.
- Pre-UE downlink-late gate passes.
- Pre-UE TX summary gate returns 1 after six deadline breaks.
- The wrapper records `ue_started=0` and skips UE startup.
- Final TX summary: six timeouts/breaks, 5,868 returned-sample deficit,
  42,548 stream deficit, one partial return, and zero hard errors over
  753,543,970 requested samples.

This is distinct from CP3391, where TX was perfect but the started UE did not
select a cell. It supplies no corrected-timing, PUSCH, attach, or throughput
evidence.

## Next Step

Retry the exact CP3390 shape once for this pre-UE health failure class. If the
same gate fails again, stop bare retries and join break timing against the
pre-UE stream phase before changing policy.
