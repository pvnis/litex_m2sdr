## Decision

Close constant [interface-redacted]. The next implementation is a minimal default-off source
policy in the current OCUDU Soapy TX stream:

1. preserve the current behavior when disabled;
2. when guarded lead is nonpositive but raw lead remains positive, call
   `writeStream` immediately with a bounded timeout derived from the remaining
   raw lead;
3. keep truly expired deadlines on the existing break path;
4. trace attempts, recoveries, and true expiries with metadata-only counters.

Gate it no-RF with boundary tests and a warning-clean build/deploy before
repeating the same 420-second shape.
