- edge calibration `-126560`;

- 23 stage-1 candidates;
- four streams, sequential 45-second directions.

## Decision

Run CP3429 once. Judge health first:

1. exact unique-stream TX and normal access;
2. receiver DL materially above CP3410's `6.744110 Mbit/s` and CP3424's
   `5.630004 Mbit/s`;
3. bounded UE PDSCH rows showing the actual MCS/TBS/CRC class;
4. uplink retaining the MCS19 operating class.

If the run is pre-UE void, retry unchanged once. If valid but PDSCH16 is too
aggressive over RF, revert and test a lower downlink ceiling; do not stack
bandwidth or MIMO.
