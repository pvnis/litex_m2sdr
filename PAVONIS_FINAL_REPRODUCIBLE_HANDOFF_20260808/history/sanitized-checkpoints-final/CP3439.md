# CP3439 - 15 MHz readback-gate fix, no RF

## Verdict

**PASS.** The reproducible CP3438 pre-UE proof race is addressed in an
isolated runner copy. CP3440 is unlocked for one bounded 15 MHz OTA run.

## Cause

Both CP3438 attempts stopped at the immediate TX readback gate before UE
startup. Their TX state and stream health were clean. The unchanged gate
assertions pass when replayed after publication.

The runner therefore waited on readiness but not on reliable visibility of the
complete readback proof.

## Change

After successful gNB startup, the isolated runner now:

1. emits `START settle_nativecontinuous_tx_readback seconds=2`;
2. waits a bounded two seconds;
3. emits `DONE settle_nativecontinuous_tx_readback seconds=2`;
4. runs the original assertions unchanged.

No RF, PHY, scheduler, gain, timing constant, bandwidth, or MCS setting changes
in this checkpoint.

## Isolation Proof

The CP3186 runner and chain were copied into the CP3439 artifact directory.
The mechanical validator proves:

- all `22/22` chain scripts equal their originals after path normalization;
- the stage runner equals CP3186 byte-for-byte after removing exactly one
  occurrence of the settle block;
- all copied shell scripts pass `bash -n`;
- the controller passes Python compilation and validate-only execution;
- CP3440 remains default-closed with exit code `2`.

The historical CP3186 files and CP3121 baseline were not modified.

## Decision

Run CP3440 once with a fresh stamp. The run is valid only if the settle markers
and original readback gate pass, UE startup occurs, and the normal health,
access, endpoint, and PHY artifacts are complete.
