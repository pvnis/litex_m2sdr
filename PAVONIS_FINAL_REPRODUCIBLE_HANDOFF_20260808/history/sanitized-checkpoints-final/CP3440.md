# CP3440 - Guard-expectation mismatch correction

## Verdict

**PRE-UE VOID; EXACT WRAPPER BUG FOUND.** The two-second CP3439 settle executes,
but the native-TX gate still returns `1` and skips UE startup. The cause is not
readback publication timing.

## Exact Cause

The no-RF source/readback join is:

| Layer | Guard value |
|---|---:|
| Current controller request | `100 us` |
| Inherited CP2188 chain expectation | `[date-redacted] us` |
| Hash-pinned current launcher runtime export | `100 us` |
| Live TX readback | `100 us` |

The inherited chain unconditionally assigns its historical `[date-redacted] us` value
after the controller has requested `100 us`. The current launcher correctly
applies the modern `100 us` policy. The gate then compares the healthy
readback against the stale parent-shell value and fails.

## Correction To CP3438/CP3439

CP3438's delayed diagnostic replay hard-coded the observed `100 us` value. It
proved the captured state was internally healthy, but it did not reproduce
the inherited gate's stale `[date-redacted] us` expectation.

CP3439's publication-race interpretation and two-second settle are therefore
disproven. Those checkpoint artifacts remain append-only; this checkpoint
supersedes their theory explicitly.

## Run Health

The UE was never started, so this is not a 15 MHz acquisition or throughput
result. The gNB-only stop has:

- zero Soapy timeout and downlink-late lines;
- seven deadline breaks;
- `68684` stream-deficit samples;
- zero hard TX errors.

That deficit is retained as an early `15.36 Msps` producer-headroom warning,
but cannot be joined to user traffic because the stale proof gate prevented
UE startup.

## Decision

CP3441 will:

1. remove the disproven settle block;
2. preserve the caller-supplied `100 us` guard through the isolated copied
   chain instead of overwriting it with `[date-redacted] us`;
3. leave the actual runtime policy unchanged;
4. prove the source delta and RF-default-closed behavior without RF.

Only after CP3441 passes is one new 15 MHz OTA run justified.
