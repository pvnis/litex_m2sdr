# CP3443 - 15 MHz lead13 gNB-only no-RF gate

## Verdict

**PASS.** A single-variable `13 ms` TX-lead profile is ready for a bounded
60-second gNB-only TX-health discriminator. No RF was used here.

## Rationale

CP3442's three breaks occur after producer-entry gaps of `1.887-2.229 ms`,
with raw lead only `30-228 us` past zero. Adding `2 ms` to the proven `11 ms`
baseline is the smallest conservative bracket that covers the observed burst
class without reopening timeout/backpressure policy.

## Isolated Change

The profile retains:

- `15.36 Msps`, 15 MHz, and corrected carrier/SSB geometry;
- PDSCH9 and PUSCH19;
- `100 us` inside-guard deadline policy;
- all PRACH/non-PRACH sample-domain calibrations;
- the CP3441 caller-preserving guard-proof fix;
- RF gains, attenuation, and continuous all-timed transport.

Only the TX hardware-time lead changes from `11 ms` to `13 ms`.

## Proofs

- The launcher equals the lead11 launcher after lead/checkpoint-label
  normalization.
- Controller profile and runtime exports both contain exactly `13 ms`.
- The deployed launcher hash matches locally and its validation passes.
- Shell syntax and Python compilation pass.
- Controller validate-only passes with 23 stage-1 candidates.
- The CP3444 wrapper sets stop-before-UE.
- RF is default-closed, exit code `2`.

## Decision

Run CP3444 for the normal 60-second pre-UE interval. A full UE run remains
locked unless all of these are zero:

- summary timeout;
- deadline break;
- abandoned sample;
- stream deficit;
- downlink late;
- hard TX error.
