# CP3462 - 10 MHz 2x2 lead-13 producer gate, no RF

## Verdict

**PASS.** The isolated 10 MHz 2x2 path is ready for a bounded gNB-only
producer test at 13 ms TX lead. All local syntax, deployed hash, launcher,
generated-config dry-run, controller, and default-closed proofs pass.

No RF was transmitted. No UE or phone was started. The established 1x1
baseline and every prior report remain unchanged.

## Change

The sole producer-policy change from CP3461 is TX lead:

- CP3461: 11 ms.
- CP3462/CP3463: 13 ms.

The 10 MHz bandwidth, two RX/two TX channels, PDSCH max 9, PUSCH max 19,
100 us inside deadline guard, warning-level logging, and physical channel
offset zero are unchanged. UE timing offsets are intentionally unchanged
because this gate stops before UE startup and judges only sample production.

CP3461's two break traces entered the write path only 22 us and 261 us behind
the old deadline. A 2 ms lead increase therefore supplies approximately
1.64 ms or more of guarded headroom for those observed stalls without changing
the stream rate or aggregate 2x2 payload.

## Proofs

The new base launcher is the CP3422 logic with checkpoint labels, explicit lead
telemetry, and the single 11 ms to 13 ms functional change. Its deployed
SHA-256 is
`398aed060643d2b437b4ee4455cb1ef1df8645f10f2b8d38f1d4b4718ccbeb7c`.

The 2x2 wrapper and existing additive overlay hash-match their local copies.
Both deployed validation modes pass. A fresh generated MCS19 configuration
passes OCUDU `--dryrun`; the overlay contains exactly the two expected
two-antenna rows. Controller validation returns zero. Without the explicit
approval flag, the CP3463 runner returns `2` and emits
`CP3463_RF_GATE=CLOSED`.

## Acceptance

CP3463 must prove a real 2T2R stream and strict exact delivery: zero cumulative
timeouts, deadline breaks, abandoned or stream-deficit samples, late or
release-late events, and hard errors. Any partial return must be completely
retried with zero final deficit. One clean roll is repeated unchanged before
the phone because the producer failure has previously been stochastic.
