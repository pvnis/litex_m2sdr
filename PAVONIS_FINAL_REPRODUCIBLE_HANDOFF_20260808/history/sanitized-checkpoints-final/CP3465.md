# CP3465 - Isolated real-phone 2x2 gate, no RF

## Verdict

**PASS.** The proven persistent phone benchmark is isolated behind a 2x2
OCUDU/M2SDR overlay, a hash-pinned gNB wrapper, native scheduler rank metrics,
and two default-closed approval gates. The actual CP3175 phone configuration
passes OCUDU dry-run with the overlay.

No RF was transmitted. CP3121, CP3175, all 1x1 launchers, binaries, configs,
and prior reports remain unchanged.

## Timing correction

The phone does not use the CP3422 11 ms timing family. Its proven target chain
already uses 20 ms TX lead, PRACH compensation 230,613 samples, and its
established non-PRACH/edge offsets. Therefore the previously queued
23,040-sample adjustment is not applied here; that delta belongs only to the
separate srsUE 11 ms to 13 ms branch.

CP3465 changes no phone timing, PRACH, RA-window, AL8, MCS, bandwidth, duplex,
power, attenuation, primer, data, or lifecycle setting.

## Isolated change

The additive overlay sets downlink and uplink antenna count from one to two.
The gNB wrapper maps logical channels `{0,1}` to physical channels `{0,1}` by
overriding the inherited single-channel offset from one to zero. The wrapper
then delegates to the exact CP3120 AL8 phone wrapper and its hash-pinned
underlying binary.

Low-rate native scheduler metrics are enabled only in the isolated overlay.
They expose aggregate `dl_ri` without identity material, allowing the run to
distinguish actual rank-2 scheduling from a 2T2R stream that remains rank 1.
The parser stores only counts and DL-RI statistics.

## Proofs

The deployed wrapper, CP3120 base, and overlay hashes match. Wrapper and
effective-environment probes pass. A dry run against CP3175's actual generated
phone config succeeds. The persistent server's focused receive-shutdown test
and the privacy-safe rank parser's synthetic test pass. The sustained traffic
helpers normalize to CP3157 after checkpoint identity.

Both the RF runner and outer execution controller return `2` without their
approval flags and create no attempt directory. The CP3121 immutable manifest
verifies.

## Acceptance

One bounded primer-assisted phone attempt is unlocked. It is judged in this
order:

1. host and producer health, real `2T2R`, and two-channel readback;
2. target attach and sustained bidirectional endpoint completion;
3. scheduler DL-RI rows and whether rank 2 was actually observed;
4. throughput versus CP3175's `8.331264 / 0.124854 Mbit/s` 1x1 baseline.

No throughput delta is credited to MIMO unless rank-2 scheduling is measured.
If only rank 1 is reported, the result instead bounds the current antenna/UE
channel state and closes this isolated roll honestly.
