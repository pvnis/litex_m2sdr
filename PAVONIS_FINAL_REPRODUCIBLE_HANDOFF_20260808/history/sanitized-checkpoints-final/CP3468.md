# CP3468 - Reproducible 2x2 capability handoff

## Verdict

**PASS.** A completion audit found and closed a real handoff gap. CP3467
reported the CP3466 2x2 maximum, but the portable supervisor runtime exposed
only the established 1x1 staged path. CP3468 adds a separate fail-closed 2x2
capability path without modifying that baseline or any source repository.

No RF was used.

## Fail-closed proof

The hermetic controller test proves:

- missing approvals return `2` before creating a run root;
- a failed prerequisite staged controller returns its failure and never calls
  the capability adapter;
- downlink equal to the `8.712 Mbit/s` one-layer bound is rejected;
- a complete synthetic 2T2R result above that bound passes;
- profile and overlay hashes are checked before any run;
- the private capability adapter file is created mode 0600.

Shell syntax, JSON, exact overlay hash, and the focused controller test pass.
