# CP3469 - 15 MHz 2x2 producer gate, no RF

## Verdict

**PASS.** The only remaining combination with a numerical path above CP3466
is isolated and passes local/deployed no-RF gates. No RF was transmitted and
no baseline, source, timing, MCS, power, or prior artifact was modified.

## Why this rung remains

CP3452 measured `9.015192 Mbit/s` downlink over ZMQ at 15 MHz/PDSCH7 with one
layer. Two ideal layers yield `18.030384 Mbit/s`, `10.20%` above CP3466's
measured `16.360880 Mbit/s`. The gain case is small but nonzero, so an absolute
hardware-maximum claim needs the combined producer shape closed explicitly.

This does not reopen the separate 15 MHz one-layer OTA conclusion. CP3451
proved that cell functional but PHY-limited, and CP3458 closed bare access
retries. CP3469 asks only whether the host/M2SDR producer can deliver the
combined sample load exactly.

## Isolated composition

The launcher composes two already-qualified pieces:

- CP3443/CP3444: 15 MHz, `15.36 Msps`, PDSCH9, PUSCH19, 13 ms lead,
  100 us inside-guard policy;
- CP3460: exact two-UL/two-DL antenna overlay and physical channel offset 0.

No sample-domain timing, PRACH, non-PRACH, RF, attenuation, gain, MCS, logging,
or scheduler setting changes.

## Proofs

- local shell and JSON validation: pass;
- deployed launcher/overlay hashes: pass;
- deployed base and combined launcher probes: pass;
- existing controller validation-only path: pass;
- actual deployed generated-config `--dryrun`: pass;
- default RF gate: exit `2`, zero attempt artifacts.

The first dry-run attempt intentionally produced no RF but used the wrong
input class: an already PUSCH19-generated config was fed into the PUSCH19
insertion launcher, which correctly rejected `existing_pusch`. The corrected
attempt starts from the hash-pinned raw 15 MHz source, generates the known
PUSCH19 config, appends the 2x2 overlay, and returns `0` from OCUDU dry-run.
This is a no-RF input-shape correction, not a runtime datapoint.

## Decision

Run one bounded 45-second gNB-only CP3470 producer gate. Accept only if runtime
proves genuine 2T2R, both channels at `15.36 Msps`, and zero Soapy timeout,
deadline break, abandoned sample, final stream deficit, downlink-late, or hard
error counts. A recovered partial return is acceptable only when final stream
deficit remains zero.

If CP3470 fails strict delivery, close the combined 15 MHz/2x2 ladder without
an endpoint run. If it passes, design a separate no-RF real-phone 15 MHz/2x2
endpoint gate; legacy srsUE cannot provide rank-two reception.
