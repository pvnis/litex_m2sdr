# CP3470 - 15 MHz 2x2 strict producer gate

## Verdict

**PASS for producer delivery; no endpoint verdict.** The bounded live gNB run
proves that the qualified M2SDR path can produce a genuine 15 MHz `2T2R` cell
with two simultaneous 15.36 Msps TX channels while satisfying every strict
delivery-health gate. No UE or traffic endpoint was started by design.

The outer throughput controller therefore exits with its expected endpoint
failure. That result is not a cell-acquisition, radio, or producer failure.

## Runtime proof

- gNB runtime cell marker: `15 MHz, 2T2R`;
- Soapy readback: `nof_channels=2`;
- TX channel 0: `15.36 Msps`, gain `5 dB`;
- TX channel 1: `15.36 Msps`, gain `5 dB`;
- TX lead: `13 ms`;
- host realtime-state gates: pass.

The controller's `spatial_layers=1` field is inherited parser metadata and is
stale for this composed shape. The live cell marker and two-channel hardware
readback are authoritative.

## Producer health

The stop summary records zero Soapy timeouts, zero downlink-late events, zero
hard errors, zero deadline breaks/timeouts, and zero abandoned samples. One
430-sample partial return occurred and was completely recovered; final stream
deficit is zero.

This meets the CP3469 acceptance rule exactly. It establishes producer
headroom for 15 MHz 2x2, but it does not establish acquisition, rank-two use,
or throughput at 15 MHz.

## Decision

The combined producer question is now closed. Per the operator's direction,
the current capability campaign is banked before any endpoint attempt. A new
branch must first explain the remaining downlink ceiling using existing data
and isolated controls. Bandwidth, MIMO, and further producer-stall work stay
downstream of that branch; CP3470 is retained only as a qualified producer
baseline.
