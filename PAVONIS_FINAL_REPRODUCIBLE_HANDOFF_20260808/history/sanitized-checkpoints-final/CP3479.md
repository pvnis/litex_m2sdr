# Checkpoint 3479: Downlink MCS margin model

## Verdict

**HONEST PARTIAL: the repeatable MCS9/MCS10 gap is compatible with the known
decoder threshold penalty, but existing metrics cannot prove that it is only a
margin effect.** No RF, config, source, binary, or baseline changed.

## Selector-lattice audit

The alternating selector does not lock the branches to opposite slot phases.
Each run has 256 scheduler rows per MCS, and both MCS9 and MCS10 occupy both
slot parities and all four modulo-4 classes. In CP3477 the MCS9 parity counts
are 133/123 and MCS10 143/113; in CP3478 they are 121/135 and 134/122.

Only 356/511 and 371/511 adjacent traced grants are one slot apart, so normal
scheduler gaps continually change the grant-count-to-slot relation. The
MCS9/MCS10 outcome cannot be dismissed as a fixed even/odd TX-phase artifact.

## SNR-conditioned model

The CP3472 exact decoder sweep gives 10%-BLER thresholds of 4.25 dB for MCS9
and 5.75 dB for equal-TBS MCS10: a 1.5 dB penalty.

The live trace field is not on that numeric scale. It is computed from PDSCH
DMRS residual power, while CP3472 injects known AWGN and supplies a perfect
channel estimate. The incompatibility is visible directly: among equal-
geometry rows with negative live `snr_db`, MCS9 still decodes 15/25, whereas
MCS10 decodes 0/37. A model over all rows therefore produces a meaningless
10.64 dB equivalent penalty dominated by floor behavior.

Restricting the model to non-floor (`snr_db >= 0`) equal-geometry rows and
including a run intercept gives an MCS10-equivalent penalty of **2.10 dB**,
with an approximate 95% interval of **0.90–3.30 dB**. The CP3472 1.5 dB AWGN
penalty lies inside that interval. Existing data therefore does not require an
additional M2SDR-specific 16QAM defect.

This is not proof that the path is clean: the floor rows show that the live
DMRS metric omits or aliases some run-scale impairment. The analysis closes
only the claim that the current logs can distinguish decoder threshold from a
residual hardware impairment.

## Next gate

Run the exact interleaved selector once with one bounded link-margin change:
reduce M2SDR TX attenuation from 5 dB to 0 dB. Everything else remains frozen.

- MCS10 recovery toward MCS9 at higher margin closes the hard-defect theory
  and explains the ceiling as near-threshold operation plus decoder penalty.
- A persistent large MCS10 deficit at clearly improved PDSCH margin earns
  transmitter-referenced localization.
- Evidence of RX saturation or degraded MCS9 invalidates the run and stops the
  power branch; no further power increase follows.

Bandwidth, additional MIMO, and producer-stall headroom remain locked until
that result.
