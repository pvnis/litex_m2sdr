# Checkpoint 3516: transport clean, fixed-16 ms PRACH floor

## Verdict

**BOUNDED/NONZERO TRANSPORT PASS; FIXED-16 MS ACCESS SCATTER; VOID FOR
UPDATE-TIMESTAMP, PUSCH, AND THROUGHPUT.** The small bounded queue no longer
causes CP3509's zero-write storm. All seven PRACH writes return status 0, but
the gNB's fixed receive windows are floor-class and produce no RAR.

## Health and propagation

- Runtime reads context=1, continuation-reopen=1, nonzero-only=1, bounded=1;

## Transport result

The first true PRACH returns 0 and changes pending 0 to 1. All six later true
PRACH writes also return 0 while pending remains 1. There is no `TIME_PAST`,
invalid-operation, or unexpected zero-write sequence. This accepts the combined
bounded/nonzero transport shape and rejects the small queue as the immediate
CP3509 failure mechanism once nonzero deferral is present.

No RAR is sent, so no connected PUSCH opens the continuation burst. The
`UPDATE_TIMESTAMP` branch is therefore not exercised and remains open.

## Receive-window result

- 1968 stage-1 rows: raw RMS -71.818 to -60.074 dB, zero rows at or above
  -60 dB, zero selected candidates.
- 16 bounded strong-window rows: raw RMS -68.748 to -60.074 dB, zero rows at
  or above -60 dB.
- Detector accepts, RAR, PUSCH, endpoints, and sustained traffic are all zero.

This contrasts with CP3501's same fixed-16 ms setting at approximately
-57.5 dBFS and six accepts, and CP3514's two accepts/one RAR. The fixed
collection point is run-variable and cannot supply a reliable ladder.

## Next work

Stay no-RF and derive a dynamic per-run/per-occasion PRACH collection reference
from the existing timestamp chain, or identify the minimal bounded search
window that covers the observed phase movement without per-sample hot-path
work. Preserve the accepted combined transport shape. Do not [interface-redacted] queue depth,
candidate thresholds, RF power, or another static collection constant.

Only after dynamic collection is no-RF justified should RF resume. The first
RAR/PUSCH run must still prove open-burst PRACH `UPDATE_TIMESTAMP`; transport-
clean PUSCH floor then moves to dynamic non-PRACH timing.
