# CP3518 - Fixed-16 ms RAR/Msg3 milestone; dynamic phase propagation void

## Verdict

**PARTIAL PASS; intended phase axis void.** The bounded/nonzero transport shape produced the strongest 15 MHz access result to date: the UE acquired the cell and SIB1, sent seven Msg1s, the gNB accepted six, transmitted six RARs, the UE decoded all six, and prepared six Msg3 sequences. The first nonzero PUSCH write reopened the bladeRF continuation stream successfully and all traced subsequent writes returned status zero.

The run did **not** validate the declared six-phase collection bank. Although the controller recorded the six values, the captured gNB collection manifest reports `sequence_len=1`, `sequence_index=0`, and `collection_delay_samples=245760` for every row. CP3518 is therefore a fixed-16 ms success and the phase-propagation claim is void.

The ladder frontier moves from Msg1/RAR supply to Msg3/PUSCH receive quality. The UE encoded 18 PUSCH transmissions, but the gNB decoded `0/30` CRC OK at `-27.65..-12.61 dB` reported SINR. No further PRACH timing or detector [interface-redacted] is justified by this run.

## Frozen Shape

- 15 MHz, 79 PRB, 15.36 Msps, FDD, one layer.
- Bounded bladeRF TX queue: 5 buffers, 4 transfers, 10240 samples.
- PRACH explicit context, continuation reopen, and nonzero-only arm clear enabled.
- Declared collection sequence: 10/12/14/16/18/20 ms.
- Effective captured collection delay: fixed 16 ms (`245760` samples).
- Existing non-PRACH offsets unchanged.

- Cell search: `13.106 dB`; CFO `-3658.901 Hz`; SFN and SIB1 passed.
- Soapy TX timeouts: `0`; downlink-late: `0`; TX errors: `0`.
- UE TX failures: `0`; final stream deficit: `0`.
- One partial write left a `430`-sample logical data deficit, but the bounded queue reconciled it before stream completion.

### Access ladder

- UE Msg1 transmissions: `7`.
- Stage-1 selected windows: `6`.
- gNB RAR allocations / encoded PDUs: `6 / 6`.
- UE RAR decodes and Msg3 preparations: `6 / 6`.
- The selected windows formed a stable energetic class at roughly `-57.09..-57.31 dB` raw RMS; five of six selected the baseline detector candidate.

### Continuation reopen

- The first two Msg1 writes retained the pending continuation arm.
- UE TX call `2435`, the first captured real PUSCH write after RAR, applied the continuation SOB with status `0` and `15527` samples of TX-domain lead.
- All later traced PUSCH writes stayed status `0`; there were no `TIME_PAST` or invalid-operation returns.

### Msg3/PUSCH frontier

- UE PUSCH encodes: `18`; gNB PUSCH result rows: `30`.
- CRC OK: `0/30`.
- SINR: `-27.648643..-12.605990 dB`.
- EPRE: `-68.223755..-61.784229 dB`.
- Reported time alignment: `-2.427165..+2.000427 us`.
- Every result used an 11-byte TBS.

## Decision

1. Preserve the CP3512 source correction and the accepted bounded queue/nonzero-only transport shape.
2. Treat fixed 16 ms as a usable PRACH supply fixture, not a universal timing conclusion; CP3516 and CP3518 still show run-to-run energy variability.
3. Audit the six-phase environment propagation no-RF, because the runtime manifest contradicts the controller declaration.
4. Move the active RF frontier to the existing generic non-PRACH PUSCH/PUCCH/SRS collection offset. The immediate no-RF question is whether the legacy absolute sample offsets were incorrectly carried from the 11.52 Msps baseline into the 15.36 Msps cell.
