# CP3525 - Independent non-PRACH burst policy passes no-RF gate

## Verdict

**PASS, NO RF.** The sole remaining CP3451 transport differential is now available behind a default-off, environment-read-once bladeRF diagnostic policy. One bounded CP3526 RF run is unlocked.

## Policy

`PAVONIS_RF_BLADE_NON_PRACH_BURST_ONLY` defaults off and is cached when the device opens. It is selected only when TX debug and explicit PRACH context are active and the current write is non-PRACH. It reuses the existing bounded peak calculation:

- low-peak non-PRACH writes are skipped;
- each real non-PRACH waveform is given a timed burst start and burst end;
- the existing `-21333` non-PRACH timestamp policy then applies to each timed waveform.

No new sample scan, file write, string formatting, stream restart, device reconfiguration, or PRACH-selection change was added. This is an intentionally diagnostic reconstruction of CP3451's independent PUSCH presentation, not a claimed production fix.
