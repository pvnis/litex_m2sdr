# CP3528 - Collection-relative edge calibration root cause

## Verdict

**ROOT CAUSE IDENTIFIED, NO RF.** The dynamic non-PRACH receive offset uses an edge calibration tied to CP3451's PRACH collection delay. The campaign later changed the collection window from `199472` to `245760` samples without updating that calibration. The resulting PUSCH receive offset is wrong by exactly `46288` samples.

This explains CP3527's full-scale, status-zero UE PUSCH writes appearing as floor energy at the gNB. It supersedes further bladeRF burst/timestamp work.

## Exact Derivation

The current publisher computes:

`offset = edge_calibration - edge + RAR_TA`

In the CRC-positive CP3451 reference:

- collection delay: `199472`;
- edge calibration: `-199467`;
- therefore `edge_calibration + collection_delay = 5`;
- measured edge: `5068`; RAR TA: `208`;
- `5 - 199472 - 5068 + 208 = -204327`, exactly the published passing offset.

In CP3527 the collection delay is `245760`, but calibration remains `-199467`. The invariant calibration should be `5 - 245760 = -245755`. Recomputing all generations gives:

- generation 1: `-242147` instead of `-195859`;
- generation 2 and later: `-241763` instead of `-195475`;
- error in every case: exactly `46288` samples.

The six corrected values collapse to one stable class after RAR-TA handling, while the deployed formula carries the collection-delay change directly into the PUSCH window.

## Differential Controls

- Both runs use 15.36 Msps, 79 PRBs, gNB RX gain `40`, static non-PRACH setting `-321491`, pipeline depth `40`, and CFO correction `-4000 Hz`.
- CP3451 Msg3 is CRC OK at EPRE `-35.927 dB` and SINR `5.166 dB`; CP3527's 30 Msg3 rows are CRC KO at EPRE `-69.061…-64.421 dB`.
- UE Msg3 digital RMS/power is comparable, and CP3527 transport is mechanically cleaner than CP3451.
- CP3491 already proves TX lead controls submission headroom rather than timed RF placement, so no 2 ms lead retime is inferred here.

The only arithmetic term matching the observed configuration change exactly is the omitted collection-delay contribution.
