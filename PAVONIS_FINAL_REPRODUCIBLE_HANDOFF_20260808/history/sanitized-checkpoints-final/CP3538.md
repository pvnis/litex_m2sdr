# CHECKPOINT 3538 - Zero UE non-PRACH timestamp offset rejected

## Verdict

**VALID NEGATIVE.** Removing the `-21333`-sample UE non-PRACH timestamp
adjustment collapses Msg3/PUSCH reception even with the corrected collection-
relative gNB calibration and independent timed bursts. The fixture is required
by the current timing model; it is not dead scaffolding.

## Propagation proof

- Controller and execution summary declare offset `0`, burst-only `1`.
- Live result environment reports offset `0`, burst-only `1`.
- Forty-one TX metadata rows report offset value `0`; none applied an offset.
- Twenty-five transmitted rows carry forced SOB+EOB independent-burst metadata.

This is the first valid zero-offset execution. CP3534 and CP3536 were
propagation voids and are not part of the semantic comparison.

## Radio evidence

- Cell selection: `6.540 dB`, CFO `-3886.9 Hz`.
- Access supply: seven Msg1, six stage-1 selections, six gNB RAR, six UE RAR,
  six Msg3 preparations.
- Corrected gNB timing remained active: six dynamic publishes all satisfy the
  formula with calibration `-245755`; each published `-237099` from edge
  `-8656` and TA `0`.
- PUSCH: `0/30` CRC OK, EPRE `-67.543..-64.728 dB`, SINR
  `-27.243..-13.365 dB`, timing estimates `-2.566..+2.139 us`.
- Health: zero TX timeout, downlink-late, error, or final stream deficit; one
  430-sample partial return was recovered.

The failure is the same floor-class signature as the stale receive-window runs,
not an access, power, producer-health, or propagation failure.

## Interpretation

The current working shape requires a relative displacement between PRACH and
later PUSCH of exactly `-21333` samples. Today that displacement is injected at
UE TX and only applies reliably when each PUSCH is emitted as an independent
timed burst. This is a **known workaround**, not a standards-level requirement.

The clean replacement is to absorb the same displacement into the gNB's
non-PRACH receive-time model, then run the UE with offset `0`. That should be
tested as an exact compensation transfer (`-245755 - 21333 = -267088`), not as
an open-ended calibration sweep. Independent-burst removal remains a separate
question and should be tested only after the required displacement has a single
owner.
