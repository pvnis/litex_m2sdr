# CP3546 - Same-slot PDSCH reference capture no-RF gate

## Verdict

**PASS.** A default-off, bounded diagnostic now captures the same selected
PDSCH slots at the gNB upper-PHY resource-grid output and at the UE FFT/decode
input. The exact combined binaries pass both an inert disabled control and an
enabled 30-second-per-direction ZMQ attach-and-data control. No SDR was opened
and no RF was transmitted.

The enabled control retained 16 records at each endpoint: eight MCS9 and eight
MCS10, all RV0/new data at 1,089 bytes. All 16 slot identities overlap, every
UE transport block has CRC OK, and the gNB modulation identity matches the UE
MCS in every row. After a per-slot complex scalar fit, the minimum full-grid
correlation is 0.9999999404; the maximum normalized residual is 4.7795e-5.
This proves that the two taps are directly comparable.

## Instrument

The gNB tap runs after all upper-PHY tasks for a slot complete and immediately
before resource-grid gateway handoff. It stores the completed frequency-domain
grid. The UE tap stores the matching full FFT slot grid, extracted PDSCH RE,
equalized PDSCH RE, and channel estimate after decode.

Both sides are disabled unless their capture-path environment variable is
present. Configuration is read once, selection is limited to C-RNTI RV0
MCS9/MCS10 new data with the requested TBS, and the record cap is hard-limited
to 64 (16 in this checkpoint). Once the cap is reached, a single detached
writer flushes the already-bounded records, keeping file I/O outside the PHY
caller. The older unbounded, per-call SRSUE_DUMP_PDSCH_D path was removed from
the deployed diagnostic builds.

## Controls

The final disabled control used the exact combined binaries and balanced-MCS
shape with the collectors unset. It passed attach, private session, ping, and
sustained traffic; it emitted zero collector activation markers and created
zero capture files. Receiver-authoritative throughput was 7.750 Mbit/s DL and
16.165 Mbit/s UL.

The enabled control changed only the two collector configurations. It passed
the same milestones and sustained 7.747 Mbit/s DL and 16.310 Mbit/s UL. The
near-identical traffic result, two activation markers, two flush markers,
exact sidecar/binary lengths, and ideal-channel complex fit jointly close the
no-RF observer and alignment gates.

## Honest Voids

Three iterations were correctly excluded:

1. The first attempt used a current public UE role at 23.04 Msps against the
   proven 11.52 Msps ZMQ cell and did not reach random access.
2. The first parser reused the 64-row cap for TBS and silently selected
   64 rather than 1089 bytes; the chain passed but both collectors had zero
   records.
3. The restored remote gNB tree did not include CP3473's isolated balanced-MCS
   selector, so the target MCS9/MCS10 records were absent. The final diagnostic
   binary combines that already-proven default-off selector with the new
   collector.

These are tooling/setup findings, not radio or throughput datapoints.

## Decision

CP3545 proved the saved campaign data could bound, but not localize, the
remaining roughly 0.6 dB point-estimate downlink penalty. CP3546 supplies the
missing stage discriminator. One bounded same-run M2SDR-to-bladeRF hardware
run is now unlocked using the balanced MCS9/MCS10 shape and these two taps.

The next verdict is pre-wired:

- gNB reference clean, UE raw grid degraded: impairment lies after upper-PHY
  grid generation, in OFDM/Soapy/M2SDR/RF/bladeRF receive presentation;
- both gNB reference and UE grid degraded: defect is at or above upper PHY;
- both grids clean but UE decode/yield differs by MCS: focus on UE channel
  estimation/equalization/decoder margin.

Bandwidth, MIMO, and producer-stall headroom changes remain gated until that
one run names the stage.
