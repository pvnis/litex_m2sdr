# CP3550 - Post-OFDM reference no-RF gate

## Verdict

**PASS_NO_RF_GATE.** A default-off, bounded collector now captures complete
quantized CI16 downlink slots immediately before the lower PHY calls
`transmitter.transmit()`. The collector is armed by the first selected,
completed upper-PHY PDSCH grid, retains 64 slots in memory, and performs no file
I/O in the lower-PHY producer path. Both the disabled and enabled controls pass
on the proven 10 MHz ZMQ attach-and-data shape. No SDR was opened and no RF was
transmitted.

The enabled control contains 16 exact same-slot joins between the completed
upper-PHY grid and the new post-OFDM boundary. After normal-CP removal, a
768-point FFT, occupied-carrier extraction, and the deterministic TS 38.211
center-frequency phase compensation, the minimum correlation is
`0.9999999988`, maximum EVM is `4.8643e-5`, and maximum NMSE is `2.3662e-9`.
This validates the instrument and proves that OFDM modulation and CI16
quantization preserve the selected PDSCH grids in the no-RF control.

## Implementation

The existing upper-PHY collector gained one cached, optional arm-file path. Its
first accepted record creates an empty once-per-run sentinel. The existing
lower-PHY slot collector gained an opt-in buffered mode. It copies only the
configured bounded slots, then moves the completed vector to a detached writer
at the cap. Legacy unbuffered behavior is retained, and the default-disabled
path returns after one cached environment check.

## Controls

The final disabled control passed core startup, NGAP, ZMQ random access, RRC,
private session, assigned UE interface, ping, and a 30-second bounded downlink
stimulus. The receiver recorded `28,535,600` bytes. It emitted zero activation
markers and created zero upper, UE, arm, or post-OFDM capture files.

The final enabled control passed the same milestones and recorded `29,059,832`
receiver bytes. It produced 16 upper-PHY records, 16 UE records, and 64 lower-PHY
slots of exactly 11,520 complex CI16 samples each. The lower binary is exactly
2,949,120 bytes and its manifest has one header plus 64 records. All selected
upper-PHY slots overlap the lower capture.

The first raw FFT comparison showed a misleading `0.82` whole-slot correlation
while every individual symbol correlated at 1.0. The phase advanced by the
same fixed amount per symbol and reset each slot. Source audit identified
OCUDU's TS 38.211 section 5.4 center-frequency phase compensation. Applying
that source-defined coefficient, rather than fitting arbitrary per-symbol
phases, restores the ideal result. Unexpected hardware phase errors will
therefore remain visible in the next comparison.

## Honest Voids

1. The inherited bidirectional stimulus lost its ZMQ namespace route only after
   15.4 MB of downlink. It proved attach/ping and inert collectors but did not
   reach the harness verdict, so it was not used as the final disabled gate.
2. One unchanged disabled retry failed before core startup. It is a setup void;
   the following unchanged run passed.
3. The first enabled run captured all expected files and passed protocol
   milestones, but the harness incorrectly required the intentionally empty arm
   sentinel to be nonempty. The assertion was corrected to existence-only and
   the enabled run was repeated cleanly.
4. The first offline aggregate omitted the deterministic standard phase
   coefficient. It is an analyzer artifact, not a waveform result.

## Decision

CP3548 localized the unexplained downlink ceiling after a clean completed gNB
upper-PHY grid and by the UE raw FFT input. CP3550 advances the clean boundary
through lower-PHY OFDM modulation and CI16 quantization. One bounded hardware
run is now unlocked using this exact collector and the CP3548 MCS9/MCS10 shape.

The next verdict is pre-wired:

- clean post-OFDM reference plus degraded UE FFT moves the defect downstream to
  the Soapy/M2SDR handoff, gateware/RF, or bladeRF receive path;
- degraded post-OFDM reference moves it into the live lower-PHY production path;
- clean post-OFDM and clean UE FFT would contradict CP3548 and require checking
  the bounded selector/join before any throughput change.

Bandwidth, MIMO, power, and producer-stall headroom remain locked until this
hardware discriminator closes.
