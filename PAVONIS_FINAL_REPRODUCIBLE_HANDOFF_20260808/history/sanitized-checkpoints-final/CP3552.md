# CP3552 - Post-OFDM hardware discriminator

## Verdict

**PASS_STAGE_LOCALIZATION_DOWNSTREAM_OF_TRANSMITTER.** The valid bounded RF run
proves that the live gNB lower-PHY OFDM and CI16 output is clean. All 16 selected
post-OFDM slots reconstruct their completed upper-PHY grids with minimum
correlation `0.9999999977`, maximum EVM `6.7517e-5`, and maximum NMSE
`4.5586e-9`. In the same run, every one of the 15 exact-geometry UE FFT/PDSCH
records is floor-class, with median raw-fit SNR `1.683 dB` and `0/15` CRC.

The unexplained downlink ceiling therefore starts after the bounded CI16 buffer
immediately preceding `transmitter.transmit()`. The remaining span is the
transmitter/Soapy handoff, M2SDR driver and gateware/RF presentation, or the
bladeRF receive/front-end and UE FFT boundary. Lower-PHY grid generation, OFDM,
and quantization are exonerated in both ZMQ and live hardware conditions.

## Run Health

The valid RF stamp is
`[date-redacted]_CP3552C_POSTOFDM_HARDWARE_DISCRIMINATOR`. It preserves the
CP3548 10 MHz, one-layer, ATT5, MCS9/MCS10 shape.

Cell selection passed at `7.227 dB` with CFO `-3688.934 Hz`. PUSCH was
`116/128` CRC OK with median successful SINR `12.765 dB`. Soapy TX timeout and
downlink-late counts are both zero. All nine requested bounded capture files
were fetched and the temporary UE helper restored successfully.

The aggregate controller returned 1 because the sustained-traffic duration
gate failed: the core attempted 440,192 downlink bytes but the UE benchmark
received zero, while the core received uplink at `2.545 Mbit/s`. This is not a
stage-evidence void. Attach, uplink, both endpoint collectors, the new
post-OFDM collector, and all same-slot manifests are present. The zero-DL
traffic result is consistent with the all-floor PDSCH capture and strengthens,
rather than weakens, the stage verdict.

occupied-carrier extraction, and the source-defined TS 38.211 center-frequency

The same upper-PHY reference joined 16 UE records; 15 have the exact common
52-PRB/S2/L12 geometry and one carries an extra reservation. The 15 exact rows
contain nine MCS9 and six MCS10 records, all CRC KO. Their single floor state
has median raw+channel-fit SNR `1.683 dB`, equalized-fit SNR `1.086 dB`, and
equalized EVM `0.662`.

## Honest Voids

Attempt A stopped before RF because five prior UE capture files were owned by
the privileged radio process. The helper restored correctly. An append-only
runner revision changed only those exact pre-clean operations to noninteractive
privileged removal and passed its lifecycle/closed-RF gates.

Attempt B also opened no RF. It inherited the superseded CP3548 v1 behavior of
creating the controller result directory too early, and the controller rejected
the existing directory. The append-only v3 runner applied the exact historical
CP3548 v2 fix: create only the result root before launch and create the capture
subdirectory after controller completion.

After the valid run, one stale `srsue` process remained despite controller
completion. The UE helper was already restored. The exact stale process was
terminated and the final role-process count is zero. This lifecycle defect is
recorded but does not alter saved RF evidence.

## Decision

Stay no-RF for the next checkpoint. Audit the transmitter and LiteX Soapy write
path and build the smallest default-off, bounded, same-slot reference at the
Soapy/M2SDR handoff. The acceptance control must prove that it reconstructs the
CP3552 post-OFDM slots without arbitrary per-symbol fitting and does not add
hot-path file I/O.

Do not move to bandwidth, MIMO, power, scheduler, detector, timing, or
producer-stall headroom while the downstream split remains open.
