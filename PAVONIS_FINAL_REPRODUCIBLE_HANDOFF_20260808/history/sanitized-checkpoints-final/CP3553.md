# Checkpoint 3553: Soapy Accepted-Stream No-RF Gate

## Verdict

**PASS_NO_RF_GATE.** The next downlink-ceiling discriminator is implemented,
built and integrated without transmitting. It captures the CF32 samples that
OCUDU's Soapy transmitter reports as positively accepted, immediately after
`device.write_stream()` returns. The collector is default-off, arm-triggered,
bounded to `737280` samples (64 slots at 11.52 Msps), excludes power-ramp
padding, and performs no file I/O or string formatting on the producer thread.

This checkpoint does not make a radio-path claim. It unlocks one bounded
hardware discriminator against the CP3552 post-OFDM and UE-FFT references.

## Implementation

The collector retains accepted `data` and timeout-carry samples in memory and
records their logical timestamp, logical offset, requested/returned counts,
Soapy flags and file offset. At the cap, it moves both vectors into a detached
one-shot writer. The arm source is the existing once-per-run upper-PHY capture
sentinel, so the post-OFDM and Soapy references cover the same traffic epoch.

The legacy synchronous dump remains available when buffered mode is off.
With the dump path absent, initialization returns before parsing the new envs,
and every write-side call returns at its original null-path guard.

## Honest Void

The first no-RF build used the controller workspace's TX source, which also
contains a separate coherent-timebase edit not live in CP3552. Its companion
header was therefore absent on [host-redacted] and compilation stopped before link or
deployment. A source-provenance diff isolated four unrelated hunks. CP3553 was
then reapplied to the exact backed-up CP3552 source and header and rebuilt
cleanly. The inactive controller-side edit was preserved rather than silently
deployed or reverted. The failed build log is
`remote_native_build.log` (`cf5875a3533ef084fd9d0a813eb1ad0271cf8e167e715ff15ed834f0d0ffc9c8`).
