# Checkpoint 3555: M2SDR Post-Interleave No-RF Gate

## Verdict

**PASS_NO_RF_GATE.** The next downlink-ceiling boundary is implemented and
built without RF. The existing LiteX M2SDR DMA probe now has a default-off
buffered mode that captures finalized LitePCIe TX frames after CF32-to-SC12
interleave, timed-header creation and partial-frame zero padding, immediately
before copy-mode kernel submission or zero-copy ring publication.

This is the first boundary below the bit-exact OCUDU accepted stream proven by
CP3554. It does not yet make a hardware-path claim.

## Observer Discipline

The TX worker performs only a bounded bulk byte copy and numeric metadata
append. It does no file I/O, logging or string formatting before the cap. At
the cap it moves the byte and metadata vectors into a detached one-shot writer.
Buffered mode is capped at 4096 DMA frames; the CP3556 integration requests
768. The original synchronous probe remains unchanged when buffered mode is
off, and the original null-path guard still precedes the new env lookup.

`cp3555_dma_collector_static_gate.json` passes ten checks covering those
properties, arm ordering, finalized-header capture, detached flush and legacy
path retention.
