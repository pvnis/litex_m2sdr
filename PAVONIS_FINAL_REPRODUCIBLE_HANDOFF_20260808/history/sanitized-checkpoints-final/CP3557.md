## Verdict

PASS. A default-off, bounded, selected-event capture now records the exact
time-domain `rx_buffer[0]` consumed by srsUE's NR OFDM transform. Local and
native [host-redacted] builds pass with 16-way compilation, the exact source is
deployed, the disabled path remains a single constructor-time environment
gate, and the selected-event caller performs no file IO.

This unlocks one bounded M2SDR/bladeRF discriminator. It does not yet assign
the defect to the RF/driver input or to srsUE processing.

## Source finding

The existing CP3546 collector already selects only C-RNTI, RV0, 1089-byte,
MCS9/10 PDSCH records. CP3557 extends those same records with
`ue_dl.fft[0].sf_sz` complex samples from `rx_buffer[0]` and emits
`*.fft_input.cf32` plus offsets in the existing TSV.

The copy occurs only after the selected PDSCH has been decoded, so unselected
slots incur no sample copy. This is still the actual FFT input: worker CFO is
applied to `rx_buffer` before `srsran_ue_dl_nr_estimate_fft()`, the NR OFDM
configuration is zero-initialized, no NR UE code sets `freq_shift_f`, and the
OFDM implementation mutates its input only when that field is nonzero.

At the record cap, the existing detached one-shot writer flushes all streams.
No `fopen`, `fwrite`, `fprintf`, or per-sample scan was added to the PHY caller.
