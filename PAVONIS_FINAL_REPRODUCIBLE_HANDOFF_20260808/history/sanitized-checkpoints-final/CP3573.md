# CP3573 - Format-only A/B no-RF gate

## Verdict

Pass, no RF. A new diagnostic-only transmitter can emit the exact CP3558
post-OFDM waveform through either CF32 or CS16 from one helper implementation.
The paired runner is default-closed, hash-pins the CP3561 build module, and
holds payload, native 1022-sample write size, rate, bandwidth, frequency,
attenuation, capture gain, and analysis fixed.

The next bounded pair changes only Soapy stream format and the equivalent input
representation. Bandwidth, MIMO, power, scheduler, and producer-stall
headroom remain locked.

## Equivalence proof

The CF32 file is exactly the interleaved CS16 file divided by 32768 for all
737,280 complex samples. Simulating the deployed plugin conversion gives
1,323,508 of 1,474,560 components bit-identical at SC12. Every remaining
component differs by exactly one LSB at most; RMS delta is 0.320 SC12 LSB and
peaks are 1755 versus 1756. A multi-dB RF-quality split therefore cannot be
explained by intended numeric scaling.
