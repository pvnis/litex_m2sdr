# CP3574 - Format-only A/B verdict

## Verdict

Both mechanically valid legs are floor-class. CF32 yields a 14-period median
of -5.795672 dB; CS16 yields -5.809611 dB. The CS16-minus-CF32 difference is
-0.013939 dB, far below run noise. Soapy stream format and the intended CF32
versus CS16 numeric conversion are exonerated.

The unexplained ceiling remains open. The next controlled mismatch against the
good CP3561/CP1166 shape is payload-period boundary handling. CP1166 writes
each 737,280-sample period as 721 full 1022-sample writes plus a 418-sample
tail. CP3574 continuously crosses the 64 ms boundary with full 1022-sample
writes. Gate that one-variable boundary-preservation control next. Bandwidth,
MIMO, power, and producer-stall headroom remain locked.

## Validity

Both valid legs use the same helper source, pinned build module, equivalent
waveform, 1022-sample nominal chunk, rate, bandwidth, frequency, TX attenuation,
bladeRF gain, capture length, and analysis.

- Each TX accepts 88,474,540 samples in 86,570 writes.
- Each TX has zero timeout, partial return, or error.
- Both captures are continuous and unclipped at -22.57/-22.58 dBFS.
- CF32 period range: -5.855628..-5.746170 dB, stddev 0.032107 dB.
- CS16 period range: -5.921084..-5.701626 dB, stddev 0.069919 dB.
- Both remain about 11.53 dB below CP3561.

## Voids

Two setup attempts are retained but excluded. The first stopped locally before
SSH/RF on malformed wrapper arguments. The second reached the hosts, but [host-redacted]
exited before transmitting on the same common-launcher defect; its bladeRF
capture is noise. Both defects were corrected and hash-gated before the valid
pair. No artifact identifier was reused.
