# CP3575 - Boundary-aligned chunk960 no-RF gate

## Verdict

Pass, no RF. The next single-variable control keeps the CP3574 CS16 helper,
payload, plugin, and RF shape but changes writes from 1022 to 960 samples.
Exactly 768 writes cover each 737,280-sample / 64 ms payload period, so no
write crosses a period boundary.

CP3568 and CP3570 already showed that two substantially different non-aligned
write sizes, 510 and 1022, are both floor-class. Recovery with 960 therefore
implicates period-boundary crossing rather than generic chunk size. Persistence
at the floor closes boundary alignment and forces an exact CP1166 helper-state
audit. Bandwidth, MIMO, power, and producer-stall headroom remain locked.
