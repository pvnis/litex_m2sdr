# CP3577 - Post-setup TX gain reassert no-RF gate

## Verdict

Pass, no RF. The CP3561 event stream identifies the concrete state splitter:
the initial attenuation request changes 20 dB to 5 dB, then setupStream resets
the readback to 20 dB. CP1166 explicitly sets 5 dB again after setup and again
after activation. The generic CP3573 helper records its readback before setup
and never reasserts, so every CP3568-CP3576 summary that reports 5 dB describes
pre-stream state rather than the active TX state.

This is the first specific mechanism that explains the CP3561 versus generic
helper split. Run one bounded generic CS16/1022 control with only post-setup and
post-activate reassertion added. Recovery toward CP3561 proves the ceiling was
an active-stream attenuation reset; persistence closes it.

## Source and artifact evidence

- CP1166 source lines 253-262 set gain initially, observe setup state, then
  reassert after setup and activation.
- CP3561 events: initial 20 -> 5 dB; stream setup reads 20 dB; post-setup
  reassert 20 -> 5 dB; activation reads 5 dB.
- Generic helper lines 117-125 set gain and record readback before setup, then
  setup and activate without another gain call.
- Capture RMS is -18.203 dBFS for reasserted CP3561 versus
  -22.57/-22.58 dBFS for the non-reasserted CP3574 pair. This amplitude
  comparison is supportive, while the direct state transition is decisive.

## No-RF implementation gate

A small wrapper preserves the hash-pinned CP3573 helper and proxies only the
device gain lifecycle. It remembers the requested TX gain, calls the original
setup/activate methods, reasserts the gain, records before/after readback, and
augments the existing summary.
