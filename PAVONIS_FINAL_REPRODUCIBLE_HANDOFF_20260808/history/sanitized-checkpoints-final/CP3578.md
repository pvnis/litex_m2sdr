# CP3578: Post-setup attenuation reassert recovers the replay signal class

Date: [date-redacted]

## Verdict

PASS. The one-variable post-`setupStream()`/post-`activateStream()` attenuation
reassert restores the exact-payload CS16 replay from the CP3574 floor class to
the CP3561 good class. This closes the CP3568-CP3577 replay discrepancy as an
M2SDR stream-lifecycle state bug: `setupStream()` reset active TX attenuation
from the requested `5 dB` to `20 dB`, while the generic helper reported only
its pre-setup state.

The production OCUDU downlink ceiling remains a separate open question. This
checkpoint does not claim that the live gNB uses the same defective lifecycle.

## Change under test

The CP3574 CS16 shape was frozen: exact payload, build-module provenance,
`1022`-sample writes, RF center, rate, bandwidth, capture gain, and analysis.
The sole semantic change was reasserting the configured TX attenuation after
stream setup and again after activation.

The device-state events are mechanical:

| Stage | Before | Requested | After |
|---|---:|---:|---:|
| post-setup | `20 dB` | `5 dB` | `5 dB` |
| post-activate | `5 dB` | `5 dB` | `5 dB` |

## Evidence

Transport remained clean: `88,474,540` accepted samples in `86,570` successful
writes, with zero timeout, partial-return, or error events. The bladeRF capture
was continuous and unclipped at approximately `-18.31 dBFS` with peak component
`1531`. Raw waveform correlation against the exact reference was
`0.707990919` at `-4 kHz`.

The exact 16-record known-grid median was `+5.710442 dB`. Across 15 complete
64 ms periods, the median was `+5.743512 dB`, range
`+5.648855..+5.826953 dB`, and standard deviation `0.044248 dB`.

That is only `+0.018593 dB` from CP3561's `+5.724919 dB` good-class period
median and `+11.553123 dB` above CP3574's matched CS16 result. The measured
recovery equals the state change and leaves no useful residual for format,
chunking, payload-boundary, plugin, or simultaneous-RX explanations.

## Closed branch

The CP3565 same-window self-RX/external split was real, but the generic helper
used to isolate it had an unobserved active attenuation reset. CP3568-CP3576
therefore measured a 20 dB-attenuation runtime while their pre-stream summaries
said 5 dB. CP3578 recovers the reference class without changing waveform or
transport. The following theories are closed for this replay discrepancy:

- CF32 versus CS16 and SC12 numeric conversion;
- sub-MTU, native-MTU, and boundary-aligned write geometry;
- 64 ms cyclic-payload boundary crossing;
- Soapy plugin provenance;
- simultaneous M2SDR self-RX observer effect.

## Next frontier

Open a new production-path campaign at the unexplained live downlink ceiling.
First establish the exact OCUDU TX gain/attenuation state after setup and
activation. If normal configuration is not reasserted, test the existing
default-off force-att path as a sole-variable control. If live active state is
already correct, continue below the clean finalized-DMA observation point.
Bandwidth, MIMO, and producer-stall headroom remain gated until that ceiling is
resolved or bounded honestly.
