# CP3584 - Real-phone 15 MHz 1x1 no-RF gate

## Verdict

**PASS (no RF).** The first bandwidth rung is prepared as a true one-variable
comparison against CP3175. The real-phone path remains single-layer, on the
same physical channel, at the same attenuation and 20 ms lead. The independent
change is channel width from 10 to 15 MHz; the sample rate and all
sample-denominated timing values are coherently scaled by 4/3.

No RF was transmitted. Both nested approval gates fail closed with return code
2 and the outer closed-gate probe creates no attempt directory. The immutable
CP3121/CP3153 baseline manifest still verifies.

## Why this rung

CP3582 bounded the remaining live M2SDR cadence penalty at roughly 1 dB and
CP3583 banked that result into the report. The next throughput question is
therefore width, before changing rank or producer lead. CP3175 is the valid
real-phone 10 MHz 1x1 reference at `8.331264 / 0.124854 Mbit/s` DL/UL. This
checkpoint deliberately does not inherit CP3466's 2x2 change.

The existing 15 MHz software control is positive: CP3452 sustained
`9.015192 / 22.793159 Mbit/s` over ZMQ at 79 PRB. CP3540 also proved that the
15.36 Msps M2SDR transport can carry a valid 15 MHz hardware run, although
that run was a timing-validation shape rather than the real-phone capability
benchmark. A bounded phone run is therefore justified.

307484 samples. The edge lattice is scaled to period 1097, anchor -184, and
canonical offset -8963 samples, using nearest-integer rounding where required.
These are dependent geometry conversions, not additional [interface-redacted] levers.

- The filtered runner differs from the proven CP3154 phone runner only in the
  PRACH sample conversion and explicit 15 MHz geometry markers.
- The deployed overlay and wrapper hash-match their local sources.
- Wrapper source and effective-environment probes report 15.36 Msps, 15 MHz,
  one antenna per direction, physical channel 1, and the scaled edge lattice.
- The actual CP3175 generated phone configuration plus the new overlay passes
  OCUDU `--dryrun` with return code 0.
- The inner and outer RF gates return 2 while closed; no attempt artifact is
  created.

## RF acceptance gate

One bounded real-phone OTA run is unlocked. It is valid for throughput only if
runtime evidence proves 15.36 Msps, 15 MHz, 1x1, physical channel 1,
attenuation 16 dB, a complete attach, bidirectional echo, complete 45-second
DL and UL transfers, and same-class producer health. A setup or retained-state
failure is void, not a bandwidth result. Any valid endpoint is compared only
against CP3175 before opening the MIMO rung.
