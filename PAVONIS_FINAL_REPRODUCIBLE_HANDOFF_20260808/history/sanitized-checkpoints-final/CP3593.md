# CP3593 - Phone 15 MHz MIMO reaches Msg3; Msg4 frontier

## Verdict

**Valid 15 MHz 2x2 access partial; no rank or throughput verdict.** Runtime
proves a 15 MHz `2T2R` cell, two 15.36 Msps channels, physical channel offset
`0`, and the corrected non-PRACH timing. The phone reaches one valid Msg3, but
does not complete RRC setup or target activation.

This is not a producer or uplink-timing failure. Four accepted PRACH selections
all publish `-306747` samples. One RAR leads to Msg3 CRC-OK at 8.028 dB SINR
with total EVM 0.296. OCUDU unpacks the CCCH, creates the UE, receives the RRC
Setup Request, packs the RRC Setup downlink, forwards it to the lower stack, and
schedules the fallback contention-resolution PDSCH. No RRC Setup Complete
follows.

## Runtime and health

- Cell: 15 MHz, `2T2R`.
- Hardware TX readback: two channels at 15.36 Msps.
- Non-PRACH offset: four identical `-306747` publications.
- PUSCH: one Msg3 CRC-OK, no recorded CRC-KO result.
- Rank telemetry: zero rows because connected data is never reached.
- Producer: 2,226,093,880 stream samples in 2,318,847 writes.
- One 520-sample partial return is fully recovered; stream deficit is zero.
- Timeout, error, deadline-break, deadline-timeout, downlink-late, underflow,
  and time-error counts are zero.

## Required discriminator

The nominal MIMO change contains one unavoidable physical-map confound: the
working CP3589 1x1 profile uses physical channel offset `1`, while 2x2 uses
offset `0` so that both hardware channels are addressable. The failed post-Msg3
downlink may therefore be a channel-0 primary-path problem rather than a rank
problem.

Do not run a third bare 2x2 retry. First no-RF gate and run a 15 MHz 1x1 phone
control on physical channel offset `0`, with all CP3589 timing, width, lead,
attenuation, antenna count, and scheduler settings otherwise frozen. If that
control also loses RRC Setup/Msg4, the primary physical path is the splitter.
If it passes, return to the 2x2 branch and inspect pre-CSI Msg4 transmission
geometry rather than RF power or producer cadence.
