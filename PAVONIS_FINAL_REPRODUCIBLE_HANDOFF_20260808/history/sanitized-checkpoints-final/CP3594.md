# CP3594 - Phone 15 MHz 1x1 map-0 no-RF gate

## Verdict

**PASS, no RF transmitted.** This is the isolated discriminator required by
CP3593. It preserves the proven CP3589 15 MHz 1x1 phone profile and changes only
the physical channel offset from `1` to `0`.

The cell remains one uplink antenna and one downlink antenna. Width, sample
rate, TX lead, attenuation, PRACH timing, corrected non-PRACH timing, scheduler,
MCS, kernel, FPGA, and gateware remain unchanged. This is not a MIMO run.

Local and deployed probes prove 15 MHz, 15.36 Msps, one antenna, map `0`,
calibration `-316443`, active stop `13872`, and lattice
`1097/-184/-8960`. The actual phone base plus 15 MHz overlay passes OCUDU
`--dryrun`. All scripts pass syntax checks; inner and outer approval gates
return `2` and create zero attempt directories; the immutable baseline verifies.

## Decision rule

Run one bounded phone control. If it reproduces CP3593's Msg3-then-missed-Msg4
failure, channel 0's current primary RF path is the splitter and the 2x2 branch
is not at fault. If it attaches and passes data like CP3589, map 0 is exonerated
and the next no-RF audit targets the 2x2 pre-CSI RRC Setup/Msg4 allocation.
