# CP3595 - Phone 15 MHz 1x1 map-0 discriminator

## Verdict

**PASS.** The real phone attaches to the private 15 MHz / 15.36 Msps / 1x1
cell with `physical_channel_offset=0`, exchanges bidirectional user data, and
completes both 45-second sustained transfers. Physical channel map 0 is not the
cause of CP3593's Msg3-then-Msg4 failure.

Sustained throughput is:

- downlink: **12.651808 Mbit/s**;
- uplink: **0.331426 Mbit/s**.

Against CP3589's otherwise matching map-1 baseline, downlink differs by only
+0.451%. The larger uplink increase is a useful observation but is not treated
as a map-dependent result from one roll.

## Sole-variable proof

The runtime wrapper marker proves 15 MHz, corrected timing
`-316443 / 13872 / 1097,-184,-8960`, and
`physical_channel_offset=0`. The gNB reports `1T1R`; all CP3589 width, timing,
lead, attenuation, scheduler, and phone-data settings remain frozen.

Five accepted access occasions publish non-PRACH offsets in the established
`-306739/-306747` class, all using canonical edge `-8960`. The phone reaches
target activation in 34.103 seconds, returns four bidirectional echo requests,
and the bounded PUSCH trace records 256 CRC-OK and zero CRC-KO rows.

## Producer health

The run delivers 2,763,862,840 stream samples in 2,879,023 writes. One
460-sample partial return is fully recovered: logical write deficit is 460,
while stream deficit is zero. Timeout, error, deadline-break,
deadline-timeout, and downlink-late counts are zero. This is a valid path
discriminator and throughput result, not a producer-stall artifact.

## Interpretation and next rung

CP3595 exonerates the channel-0 physical path. CP3593's failure therefore
returns to the 2x2 pre-CSI Msg4 branch: OCUDU decoded Msg3 and scheduled the RRC
Setup/ contention-resolution PDSCH, but the phone did not complete setup.

Do not run another bare 2x2 retry. Stay no-RF and compare CP3593's 2x2 Msg4
allocation and transmitted PDSCH geometry against CP3589/CP3595 1x1 successes.
The next RF run must be earned by a specific sole-variable difference or a
bounded trace that directly distinguishes allocation from transmission.
