# CP3596 - MIMO Msg4 geometry audit, no RF

## Verdict

**Honest partial.** Existing artifacts close the physical-map and rank-2
theories, but do not contain enough metadata to distinguish a malformed
two-port RRC Setup from a one-off Msg4 transmission/phone-decode miss. No RF,
config change, rebuild, or deploy was performed.

## Cross-run join

CP3593 and CP3589 use byte-identical generated base YAML; their antenna
overlays are the intended external difference. Their access timelines also
match exactly:

- CP3593 2x2: Msg3 slot 6767, first fallback PDSCH slot 6794;
- CP3589 1x1: Msg3 slot 8207, first fallback PDSCH slot 8234;
- both schedule Msg4 27 slots after Msg3.

The packed RRC Setup is 296 bytes in 2x2 and 294 bytes in 1x1, consistent with
the two-port cell configuration changing the RRC payload. The existing trace
records only `new_tx_allocated`; it omits MCS, TBS, PRBs, symbols, layers, and
precoding state, so the two-byte payload delta cannot yet be tied to an air-side
failure.

## Source audit

Fallback RRC Setup uses DCI 1_0 with TC-RNTI. OCUDU explicitly fixes the
fallback PDSCH to one layer; rank two is not used before setup. The fallback
builder leaves optional PDSCH precoding empty, and the MAC-to-FAPI adaptor maps
that empty state to the omnidirectional matrix. For a two-port cell that matrix
is implemented as one layer on port 0, not as a two-layer transmission.

CP3595 proves that the same physical port-0 path completes attach and sustained
data in 1x1 mode. Therefore these explanations are closed:

- bad physical channel 0;
- rank-2 Msg4 allocation;
- changed Msg3-to-Msg4 scheduler cadence;
- an unrecorded difference in the generated base YAML.

## Required next discriminator

Do not run another bare 2x2 attempt. Add one default-off, environment-cached,
row-capped metadata trace at successful fallback-PDSCH allocation. It must emit
slot, newTx/retx, DCI class, MCS, TBS, CRB start/count, symbol range, layer
count, optional-precoding presence, and cell TX-port count. Disabled behavior
must remain unchanged and the focused fallback scheduler tests must pass.

One bounded 2x2 run is then justified with this trace. A pass establishes the
rank/throughput endpoint. A repeated Msg4 failure supplies the exact TBS needed
to arm the already-existing bounded completed-grid collector for a final
port-energy discriminator, without speculative power or scheduler changes.
