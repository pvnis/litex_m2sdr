# CP3597 - MIMO Msg4 geometry trace no-RF gate

## Verdict

**PASS; one bounded trace-enabled 15 MHz 2x2 phone run is unlocked.** The
fallback-PDSCH geometry trace is minimal, default-off, environment-cached,
row-capped, metadata-only, built and tested locally and natively on [host-redacted], and
deployed through a new append-only binary path. The frozen CP3109 runtime binary
and CP3121 baseline remain untouched.

## Patch scope

The existing Msg3-path trace gains one geometry row after a fallback PDSCH has
already been allocated. It records only slot, newTx/retx, DCI class, cell TX
ports, MCS, TBS, CRB start/count, symbol range, layers, optional-precoding
presence, k1, and power offsets. It records no payload, identity, NAS/RRC
bytes, sample data, or per-sample work.

The scheduler's direct return is refactored into a local grant reference so the
completed PDSCH metadata can be read, then the unchanged grant handle is
returned. Exact pre-patch diffs are `header.patch` and `scheduler.patch`.

## Build and test evidence

- Local `gnb` build: pass with 16 jobs.
- Native [host-redacted] `gnb` build: pass with 16 jobs.
- Local fallback scheduler suite: 48/48 pass.

- Enabled positive control: five bounded rows; newTx and retx rows contain all

The first local compile correctly rejected an implicit bounded-MCS conversion;
the call now uses the explicit stored value. No failed build was deployed.

## Deployment and closed gates

The native binary is deployed separately at role `CP3597 diagnostic gNB`,
SHA-256
`1154351c334e8916d268b6e7531d1183efb8b872d4c22fbdd9da89c4585d409a`.
The new wrapper verifies that binary and delegates all frozen 15 MHz 2x2 radio,
timing, attenuation, and trace settings to the CP3591 wrapper. Wrapper and env
probes pass, the real 15 MHz 2x2 config passes `--dryrun`, the runner and
controller both fail closed with rc 2, and the closed controller creates no
attempt directory. The immutable baseline manifest passes.

## RF judgment

Run one fresh bounded CP3597 attempt. If setup succeeds, record rank telemetry
and sustained throughput against CP3589/CP3595. If Msg4 fails again, the new
row provides the exact TBS/resource geometry; use that value to arm the
existing bounded completed-grid collector rather than changing power,
scheduler timing, or rank policy.
