## RF judgment

Run 1, selector off, is a binary compatibility control. It must pass attach,
bidirectional data, sustained transfer, and producer health and remain in the
CP3589/CP3595 approximately 12.6 Mbit/s downlink class. Failure is a binary-
baseline incompatibility and does not judge MCS10.

Run 2, selector on, is unlocked only by a valid control. It must prove the
selector startup marker and balanced bounded MCS9/MCS10 newTx rows. Before
interpreting modulation, require matching PRB/layer geometry and same-class TBS
between the two branches; earlier table geometry predicts this because MCS9
QPSK 679/1024 and MCS10 16QAM 340/1024 have near-identical spectral efficiency.
Judge producer health and attach first, then per-MCS HARQ outcome. Aggregate
throughput is secondary and is not expected to rise from MCS10.

If MCS10 is same-class with MCS9, the next sole-variable payoff is PDSCH max11.
If MCS10 is materially worse, the current phone path reproduces the finite
modulation-margin ceiling and no power sweep follows.
