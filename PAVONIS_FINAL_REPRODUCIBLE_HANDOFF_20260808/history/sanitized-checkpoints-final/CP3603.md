## Verdict

PASS, NO RF. CP3602's deterministic selector-propagation failure is closed by
a distinct hash-pinned wrapper at the final remote executable boundary. The
wrapper hard-codes selector enable 1, MCS9/MCS10, one-grant alternation, and a
512-row trace cap. It delegates to the unchanged CP3600 wrapper, which delegates
to the CP3594 15 MHz/1x1/map-0 shape and the CP3601-proven gNB binary.

Local syntax, sequence, runner rc2, executor rc2/zero-artifact, deployed hash,
and immutable-baseline checks all pass. No source or radio configuration was
changed.

## RF judgment

Run one fresh-stamp armed attempt. Before interpreting the endpoint, require:

1. `PAVONIS_CP3603_PHONE_15MHZ_MCS_AB_ARMED_GNB_WRAPPER_ACTIVE`;
2. CP3600 runtime wrapper `selector_enable=1`;
3. gNB `PAVONIS_DL_MCS_AB active` startup marker;
4. exactly 512 bounded selector rows, balanced 256/256 MCS9/MCS10;
5. matching PRB/layer/TBS geometry between MCS9 and MCS10;
6. normal attach/data and clean producer health.

If propagation fails, the run is void. If propagation passes and throughput is
same-class with CP3601, the current phone path has crossed MCS10 and PDSCH
max11 becomes the next throughput rung. A material decline keeps the finite
modulation-margin ceiling open; do not sweep power.
