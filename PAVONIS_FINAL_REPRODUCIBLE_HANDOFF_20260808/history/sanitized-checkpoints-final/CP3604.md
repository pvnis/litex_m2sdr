# Checkpoint 3604: phone 15 MHz MCS9/MCS10 OTA A/B

Date: [date-redacted]

## Verdict

PASS for aggregate MCS10 capability. The current 15 MHz phone path attaches,
passes bidirectional user data, and sustains **12.784640 Mbit/s downlink** and
**0.309619 Mbit/s uplink** while the bounded new-transmission selector is
exactly balanced between MCS9 and MCS10. This contradicts a hard MCS9 ceiling
on the post-localization path.

The result does not provide per-MCS BLER. The strict equal-TBS condition from
CP3603 is false: the dominant grants keep 79 PRBs and one layer, but MCS9 uses
3265-byte TBS and MCS10 uses 3521-byte TBS. The run therefore proves usable
aggregate MCS10 operation, not an isolated modulation-only error rate.

## Propagation and selector proof

The final executable boundary emits exactly one CP3603 arm marker and one
CP3600 runtime marker with `selector_enable=1`. The scheduler emits one active
marker and exactly 512 bounded newTx rows:

- branch 0 / MCS9: 256 rows;
- branch 1 / MCS10: 256 rows;
- dominant MCS9 geometry: 203 rows at 79 PRBs, 3265 bytes, one layer;
- dominant MCS10 geometry: 204 rows at 79 PRBs, 3521 bytes, one layer.

The first local launch attempt stopped before hardware because the new result
root did not exist. The root was created, a fresh stamp was used, and no prior
artifact name was reused.

## Access, throughput, and health

Target activation completes in 22.810 seconds. One RAR allocation is followed
by 256/256 PUSCH CRC-OK rows. Against the CP3601 all-MCS9 binary control,
downlink rises by 1.0425%; uplink changes by -8.56%, within the already-observed
uplink variability and not the axis under test.

The final transmitter summary reports 2,533,401,400 delivered samples across
2,638,959 writes. One 700-sample partial return is fully recovered. Stream
deficit, timeouts, errors, deadline breaks/timeouts, and downlink-late rows are
all zero.

## Decision

Retire “the current phone endpoint cannot cross MCS9” as the ceiling model.
Do not claim per-MCS BLER from this run. The next sole-variable endpoint is
all-MCS11 on the same 15 MHz/1x1/map-0/ATT16/timing/traffic shape. That run can
directly determine whether the first materially higher 16QAM rate raises the
sustained ceiling. Bandwidth, MIMO, and producer-stall headroom remain parked
until this endpoint is judged.
